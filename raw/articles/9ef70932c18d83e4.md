有些用户不想用 Magpie 去代理 Claude Code，只想把Magpie 当成 Claude Code 的多账户切换工具。其实在Magpie 发布的第一天就已经支持这个功能了，只是没有把它显化出来，日后会把这个功能显化出来。

现在你只需要：
1. 别在 Agent 页面中启用 Claude Code。
2. 在供应商页面给 Claude Code 供应商登录多个账号。
3. 把你想用的那个账号设为首选即可。
