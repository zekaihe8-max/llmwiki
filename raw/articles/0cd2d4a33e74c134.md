OpenAI 进军实体工程：GPT‑6 Astra 一周内设计出一台硬件，马自达、Ganassi 赛车队也参与试用

OpenAI 正在把模型能力从写代码扩展到机械、电子和系统设计。内部已经跑通从外观、结构、电路板到固件的完整设计流程，但还过不了「能不能量产」这一关，所以现在向行业公开招募合作方，一起改进。

用 Astra 从零设计一台设备

这次测试的目标是：全程不做任何人工直接修改，做出一台能和 Codex 对话的小设备。功能需求由 GPT‑6 定义。外观由 Astra 设计，参考了 OpenAI 之前和 Work Louder 的合作，也借鉴了游戏和玩具的风格。机械部分，Astra 设计了外壳和固定元器件的内部结构。电子部分，它负责选元器件，并设计 PCB 的布局和走线，保证能装进外壳。最后它还做了交互界面，写出了连接 Codex 的固件和软件。

两名员工把这件事当副业做，不到一周就完成了设计，合同制造商不到一个月就做出了一小批样机。不过 OpenAI 也坦白说，离量产还差几轮评审和修改：模型没能稳定考虑到工厂的生产限制、公差和装配细节。这正是下一代模型要补的短板。

OpenAI 内部硬件团队怎么用

机器人和算力基础设施团队用 Codex 和 ChatGPT 建模和修改 CAD 模型、把 3D 模型转成可用于生产的 2D 图纸、搭建仿真和有限元分析，还用它们做设计评审。从今年 2 月以来，硬件团队的 token 用量增长了 23 倍。

三位员工分别讲了自己的用法：
· Grace Lam 说，从想法到成品零件的速度明显变快，出图和仿真设置省了大量手工活。
· Qiong Wang 用它梳理跨部门的设计约束，在 ECAD（电子设计软件）里执行操作，并做设计评审。她认为将来它有可能变成一支硬件专家团队，把一块电路板从概念一路做到可以交付工厂生产的 Gerber 文件。
· Jackie Lee 在建筑工程和 BIM（建筑信息模型）领域用它自动处理重复建模，检查图纸和规范之间的不一致，并把协调中发现的问题整理成可以直接处理的待办事项，最后仍由专业人员审核。

评测成绩

OpenAI 用 BenchCAD 2.0 衡量进展。这个评测考察模型能否重建 3D 零件和装配体，以及能否识别电路板上的连接关系。一个尚未发布的内部新模型平均得分 0.875；GPT‑6 Astra 在最高推理档位下得分 0.594。差距不小，说明下一代模型在这类任务上进步明显。

行业合作

OpenAI 扩大了和 Chip Ganassi Racing 赛车队的合作，主要测试把现有零件的 3D 扫描数据转成可编辑的 CAD 模型和 2D 生产图纸。原始设计文件丢失时，这一步特别有用。车队工程师负责审核精度和能否制造，并表示可以直接在 CAD 里和 Codex 协作，反馈改动会被直接执行。

另外，OpenAI 新宣布与马自达开展研究合作，对象是空气动力学和碰撞安全团队。Astra 会对新车头造型建模，模拟气流，再细化最有希望的方案，在兼顾造型和成本的前提下降低风阻。马自达的工程师提到，设计师常问「非得长这样吗？」。通过模拟几十种变体，可以看清哪些特征真正影响空气动力学，哪些地方设计师可以自由发挥。更多结果会在接下来几个月公布。
