学习 Pi 你必须知道的 5 个分支项目🔥

1、Oh My Pi（OMP）｜功能增强派

[github.com/can1357/oh-my-…](https://github.com/can1357/oh-my-pi)

给 Pi 加上 LSP、Debugger、Subagent、浏览器等能力，适合想要完整 Coding 工作流的用户

2、senpi｜重新设计 Agent 工作流

[github.com/code-yeongyu/s…](https://github.com/code-yeongyu/senpi)

重点改造 System Prompt、权限管理、Context 压缩和并行工具执行，让 Pi 有一套更完整的默认行为

3、mu｜让小模型帮大模型干活

[github.com/qybaihe/MU](https://github.com/qybaihe/MU)

引入轻量 Judge 模型处理任务分类、上下文保留等决策，减少主模型在简单判断上的消耗

4、Orbi｜让 Pi 自动处理 GitHub Issue

[github.com/orbi-build/orbi](https://github.com/orbi-build/orbi)

从 Issue 到代码实现、Review、PR，甚至发布流程，适合维护 GitHub 开源项目的朋友

5、Pi Pocket｜把 Pi 装进口袋

[github.com/TannerMidd/pi-…](https://github.com/TannerMidd/pi-pocket)

基于 Pi Durable，支持移动端访问、共享 Session 和后台任务恢复，出门也能远程使用 Agent

这几个不全是传统意义上的 Fork，有些是基于 Pi 构建的独立项目

不过放在一起看挺有意思，Pi 的核心保持精简，社区却能把它玩出完全不同的方向
