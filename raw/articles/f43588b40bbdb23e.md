有人把 Blender 的建模流程做成了 28 个 Skill，GitHub 已经 2000 多颗星了！！

装到 Codex 或 Claude Code 里，你用人话描述想要的模型，AI 就能照着流程去调用 Blender。

这 28 个 Skill，基本把做一个游戏模型要走的路都串起来了👇

→ 建模、雕刻，把形状做出来
→ 重拓扑、拆 UV，让模型能正常贴图
→ 做 PBR 材质，烘焙贴图
→ 用几何节点批量做重复的东西
→ 给角色绑骨骼、做动画，再打光渲染
→ 导出到 Unity、Unreal、Godot 这些引擎

我觉得最有意思的是，它还管验收。

模型做完还能检查一遍，看看有没有零件悬空、表面重叠闪烁，或者贴图没带上。

我用千问给小侄子做的那本古诗立体书，里面有些模型就是用这套 Skill 做的。
