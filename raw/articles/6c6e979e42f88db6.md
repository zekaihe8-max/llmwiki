月之暗面正式发布 Kimi Hosted Agents，将 AI Agent 的整套运行框架做成云端服务。以前企业调用模型 API，还得自己搭建运行环境，安排工具调用、保存任务进度，处理断线和失败重试。现在这些工作由 Kimi 接手，企业只需配置任务、接入数据，就能把 Agent 放进自己的业务系统持续运行。

比如基金对账，Kimi 提供了一套由三个 Agent 分工的现成方案：一个读取外部对账单，一个核对内部账目，另一个独立复核差异，最终生成异常报告。真正修改账目仍由人工审批。类似的模板还有投研建模、港股 IPO 跟踪、监管处罚日报等。平台目前提供 12 套 Agent 模板、140 多项 Skills 和 30 多个插件，也支持企业接入自己的数据库和工具。

Anthropic 今年 4 月就推出了 Claude Managed Agents，同样为开发者托管 Agent 运行环境、任务状态和工具调用。Google 5 月发布了基于 Antigravity Harness 的 Managed Agents API，OpenAI 也推出了基于 Codex 的 Agents API，微软则在 10 月底推出了 Copilot Harness 托管服务。这些产品都在帮开发者省去自建 Agent 底层框架的工作，让 AI 更容易接入实际业务。
