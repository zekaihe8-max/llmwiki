逆向任意顶级 iOS App 设计 ？

Reverse Engineer Anything 有 iOS 版本了？哦，原来是三个 Agent Skills：先对照头部 App 学设计、再按 Expo 官方最佳实践搭工程、最后用动效/UI 品味规则做动画，来实现对顶级 iOS App 的复刻。

1. Appllama Skills  设计研究 + 原生感建造标准
Appllama 是高收入移动 App 的设计库（真实界面、流程、营收/下载语境）。技能两件套：appllama-usage 教智能体怎么当设计总监用 Appllama MCP；appllama-app-design-skill 定 Expo/RN 的建造门槛：HIG、语义色、原生控件、反 slop、导航（push/replace/sheet）、动效是否该有、弹簧跟手速、动画不进 JS 线程、模拟器整段流程逐帧过关。MCP（[mcp.appllama.io](http://mcp.appllama.io)）属 Pro 计费；设计技能可单独装。
[github.com/Appllama/appll…](https://github.com/Appllama/appllama-skills)

2. Expo Skills  官方「怎么把 Expo 做对」
Expo 团队出品：框架侧含项目结构、Router、动画、原生 UI、设计系统、数据拉取、Web→Native、升级等；服务侧含 EAS 上架、托管、工作流、Update、云模拟器等（标清付费边界）。文档/CLI 仍是权威，技能是帮智能体少走歪路。Claude Code / Codex 可用官方插件；其他 Agent 用 skills CLI。另有 Expo MCP 做装依赖、触发构建、模拟器截图等活活。
[github.com/expo/skills](https://github.com/expo/skills)

3. Emil Kowalski Skills  动效与界面品味
开源作者有 Vercel、Linear 背景；核心论点是 Agent 缺品味（进场用错 ease-in、实色边框代替半透明阴影等），技能把易错点写成可执行规则。含：总技能 emil-design-eng、animate / animate-expo、严格评审与改进计划、找该不该动的机会、性能、动画词汇、Apple 设计原则、Swift、选 UI 库、原型多版本、移动端「像原生」修补、用极端数据压 UI、Sonner toast 指南等。星标远高于另两个，偏跨 Web/移动的通用动效方法论。
[github.com/emilkowalski/s…](https://github.com/emilkowalski/skills)

三个 Skills 怎么配合
Appllama 回答「学谁、长什么样」；Expo 回答「工程与分发怎么按官方做」；Emil 回答「动效与细节怎样不廉价」。共同载体是 skills. sh / Agent Skills，不是传统「逆向 IPA」工具链。
