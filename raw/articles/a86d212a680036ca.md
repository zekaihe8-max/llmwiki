One tip to improve your grilling

Instead of talking about the 'what', try explaining more of the 'why'.

BAD: "I want to build an analytics panel for admins with graphs and filters"

GOOD: "Admins can't currently see an overview of the important data in the app"

If you start by explaining your proposed solution, the agent will stick to it. It'll assume all the important stuff is settled, and just grill you on implementation.

But if you describe the problem, you'll give the agent license to be more creative.

You'll end up with a much deeper, better conversation.
