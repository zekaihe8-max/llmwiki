其实学 AI 和 AI Agent，Google 家的网站不用收藏那么多，记住这几个就够了🔥

现在外面一堆卖几千块的 AI Agent 课，但是 Google 官方其实早就把从零基础到写代码的整套资料免费放出来了，很多还自带沙盒环境和代码，不要一上来先搜二手教程

我自己整理下来，比较值得看的是这 8 个入口：

1、Google Skills
[skills.google](https://t.co/jsx6xxtIwR)
谷歌整合后的官方学习平台，里面有近 3000 门课和云端沙盒

想学 Agent 重点看 GEAR 路线里的 Agentic AI 和 ADK 路径，能直接在浏览器里动手跑实验，还能拿官方徽章

2、Kaggle 5-Day AI Agents 训练营
[kaggle.com/learn-guide/5-…](https://t.co/mA4CZQLkIj)

目前口碑最好的一套免费 Agent 实操课
五天把架构、工具与 MCP、上下文与记忆、评测、多 Agent 和 A2A 串了一遍，配齐了谷歌官方白皮书和可运行的 Notebook，想系统学透刷这一套就够了

3、Grow with Google AI
[grow.google/ai](https://t.co/U8f9UQVK31)

完全不写代码的零基础入口

适合纯小白和非技术职场人，从 5 小时的基础课到 10 小时的实操课，把提示词、调研分析到轻代码搭应用走一遍，先建立基本认知

4、Google Codelabs
[codelabs.developers.google.com/onramp/instruc…](https://t.co/nT4UmTLKZk)

不想听概念、想直接上手敲代码看这个

分步骤带着用 ADK 从零搭 Agent、接工具和做编排，很多实验在 Cloud Shell 里就能直接跑通，省得折腾本地环境

5、ADK 官方文档
[adk.dev](https://t.co/DRcYD8QgrU)
谷歌开源的多 Agent 框架文档

真要写单 Agent、LoopAgent、并行编排或者接 MCP、A2A，直接翻一手文档，比在外面找拼凑教程靠谱得多

6、Gemini API Cookbook
[github.com/google-gemini/…](https://t.co/sjvdQvWzjw)

官方维护的代码范例库
Function Calling、长上下文、结构化输出、多模态和 Agent 示例都在里面，平时写东西当模板库翻就行

7、Machine Learning Crash Course
[developers.google.com/machine-learni…](https://t.co/5C5H73u9gR)

想补 AI 和大模型底层常识就看这个

谷歌老牌免费课，现在已经更新了 LLM 和生产系统模块，互动图解很清楚，顺手还能把官方术语表当词典查

8、Google Research Blog
[research.google/blog](https://t.co/kOo5gvb4hW)

适合用来追踪前沿思路和一手数据

比如之前用 180 组实验拆解多 Agent 到底什么时候提效、什么时候拖后腿的研究就是发在这，当信息源盯着看就行

如果只收藏三个：Kaggle 5-Day AI Agents + Google Skills + ADK 官方文档
如果是纯零基础不写代码，那就把第三个换成 Grow with Google

说到底，这些免费资源质量已经够高了，建议挑一个先动手跟着跑一遍

不然网站收藏再多，吃灰了也没什么实际的提升
