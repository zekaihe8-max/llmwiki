Claude 更换名称缩减额度，我实测了一下额度，Claude Pro 也基本上废了 额度被砍半🔥

前面 Anthropic 刚宣布 Claude 套餐更名，原来的 Max 5x 改成 Max，Max 20x 改成 Ultra

这次还有一个比较大的变化，就是官方重新明确了不同套餐的额度，Ultra 每周额度是 Pro 的 10 倍，而不是之前很多人理解的 20 倍

不过我发现，问题可能还不只是套餐更名

最近用 Claude Pro 的时候，我明显感觉额度不对劲了

以前简单聊几句，5 小时额度基本上都不会涨 1%，现在随便干一点活，5 小时额度就掉了 5%，每周额度也跟着掉 1%

我怀疑 Pro 的实际可用额度也缩水了，而且幅度可能还不小

所以今天我直接拿自己的使用记录做了一次换算，结合 Claude 的 Usage 页面和 ccusage 的 Token 统计，算了一下现在 Pro 到底能用多少

1、5 小时额度

今天我消耗了大约 61.4 万 Token，按照 ccusage 统计的 API 价格是 0.5 美元

对应 Claude 5 小时额度消耗了大约 5%～6%

倒推下来，5 小时额度跑满大概是：

1000 万～1200 万 Token

API 等价成本约 8～10 美元

2、每周额度

我把本周的使用记录也统计了一下，目前累计消耗约 2257 万 Token，API 等价成本约 8.8 美元

对应每周额度消耗了 7%～8%

倒推下来，Pro 每周额度大概是：

2.8 亿～3.2 亿 Token

API 等价成本约 105～125 美元

3、实际能用多久？

按照这个结果换算，一周的额度大概相当于 12～13 个完整的 5 小时窗口

如果每天只消耗 8 美元左右的 API 等价用量，一周额度还比较充裕

但是如果像我之前那样，每天消耗 18～22 美元，基本上 5～6 天就能把每周额度吃完

而且如果这些任务集中在几个小时内，5 小时额度可能会更早触顶

4、Max 和 Ultra 呢？

这次更名之后，Max 和 Ultra 的额度也需要重新理解

以前大家熟悉的 5x、20x，主要指 5 小时窗口的额度倍数，并不代表每周额度也有这么多倍

现在 Ultra 官方明确是 Pro 每周额度的 10 倍

所以不能直接把原来的 Max 20x 当成每周 20 倍来计算

我现在最想知道的是，Pro 本身的额度是不是也调整了

因为按照我的实际使用感受，现在 Pro 的 5 小时额度消耗速度，至少比以前快了一倍，甚至更多

如果 Pro 的基础额度真的下降，再叠加 Max、Ultra 的限制变化，那对重度用户的影响就非常明显了

当然，这些数字是我根据个人使用记录倒推的，Claude 并没有公开 Token 和额度百分比之间的准确换算公式，缓存、模型和任务类型都会影响结果

但是有一点我可以确定，但是现在我感觉使用 PRO 真的是大不如前了 随便用一下 额度掉得非常快 肉眼可见的

有没有最近也在用 Claude Pro 或 Max 的兄弟，你们感觉额度有没有变化？
