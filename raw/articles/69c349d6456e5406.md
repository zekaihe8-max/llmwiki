周末开始完整学习「2026 AI Agent 企业解决方案及落地实践手册」

这份腾讯、腾讯云和 WorkBuddy 联合发布的 78 页手册，今天先从第一章「AI 整体解决方案」开始！

第一章把腾讯云 Agent 叙事收成一条链：WorkBuddy 当办公入口与数字员工 → ClawPro 做开通与统一管控 → Agent Runtime 做沙箱与治理底座 → TokenHub 做统一模型入口；价值主张是组织产能从「人协同」转向「人定目标 + 数字员工交付」。

全景图
个人侧 LightClaw / QClaw，办公侧 WorkBuddy，研发 CodeBuddy，企业应用 ADP×ClawPro，知识乐享、营销企点、数据 Data Agent；底下是 TokenHub（混元+第三方）、Agent Runtime（执行引擎 / 云沙箱 / 记忆 / 网关 / 可观测），再配安全中心、网关、iOA 等。SkillHub 自称 25000+ 生态开源 Skills。主线是「超级个人 → 超级团队」。

WorkBuddy：三阶段与「三代办公」
· 能对话（问答工具，如 ChatGPT / DeepSeek）→ 能干活（办公助手，嵌工作流、调工具）→ 能上岗（数字员工：进业务系统、改数据、对结果与 KPI 负责）。
· 办公范式：人操作软件 → 人在协同平台催办填报 → 人给目标、设边界、做判断；数字员工理解上下文、调工具、持续执行并交付完成的工作。
· 文中强调：系统越复杂、流程越密，越是数字员工主战场；WorkBuddy 被定位成连接工具、岗位与企业资产的「企业 AI 工作台」。

ClawPro：管控台
面向企业 IT：员工一键开通、任意 Agent（开源 / 自研 / 自定义）接入、多层安全（看·审·管·扫）、多 IM（微信 / QQ / 企微 / 飞书 / 钉钉等）、分组与 Token/Agent 配额、Claw Team 多 Agent 编排、私有 Skill 库。能力拼装含 IM、Skill、IAM、Mem、Cost、Net、轻量同构等。

Agent Runtime
以 Agent 为第一视角的基础设施：治理平台层 + 七大原子能力（Sandbox、Wall、Gateway、Identity、Observability、Skills、Memory 等）。沙箱隔离、出站/入站、零信任与凭证托管轮转、模型与工具网关审计、全链路可观测。服务对象含大模型厂商、Agent 服务商与行业企业。

TokenHub
统一大模型入口：混元 + 第三方，覆盖对话、推理、代码、视觉、图/视频等；按量、保障型资源、专属部署。对 WorkBuddy、Claude Code、Cursor、Cline、OpenClaw 等强调 同一 Base URL + API Key，兼容 OpenAI / Anthropic 双协议；个人套餐 / 在线推理 / 企业配额池分账。
