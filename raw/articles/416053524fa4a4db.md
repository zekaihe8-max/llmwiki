开源项目 Swipt 让 iPhone 可以自己运行自动化脚本，读取其他 App 的界面、点击按钮、输入文字，还能通过 MCP 接受 Claude Code 等 AI Agent 的指令。

之前介绍的多数 iPhone Use 项目，都需要电脑持续运行，通过蓝牙、WDA 或苹果开发者接口控制手机。Swipt 则直接在 iPhone 上运行自动化服务，安装配置完成后，无需 Mac 常驻。

它利用苹果 CoreDevice 开发者协议，通过设备配对和本机环回 VPN，让 iPhone 连接自己的开发者服务。这样就能读取系统无障碍控件树，获取按钮的文字和位置，再发送点击、滑动、输入、双指缩放等指令。

Swipt 还内置 JavaScript 运行环境。外部 Agent 可以通过 MCP 直接提交脚本，在手机上连续执行多个操作，不必每点一下都重新发起远程控制请求。

Swipt 还支持安装自动化插件（Swiplet）。可以用 TypeScript 编写插件，添加独立界面、快捷指令和持续运行的后台任务。普通自动化流程可以完全由脚本执行，不需要每次调用大模型。

官方已经做出了一个类似「李跳跳」的开屏广告跳过插件。它会监听 App 切换，利用无障碍控件和 OCR 寻找跳过按钮，自动点击。插件内置了大量 App 和广告 SDK 的识别规则，还能记住成功点击过的位置，下次优先复用。

目前 Swipt 优先支持 iOS 27，iOS 17.4 至 26 也在兼容范围内。安装需要开发者模式、侧载签名、设备配对和环回 VPN。免费 Apple 账号签名通常需要每 7 天续期，后台服务也无法保证始终运行。
