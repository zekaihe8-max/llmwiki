## What you get

[#what-you-get](#what-you-get)

- Any model: Claude, Codex, Grok, Gemini, and more. Gemini runs through
Antigravity, and OpenCode or any Agent Client Protocol agent plugs in as a
harness. Give every task the model that fits, and delegate to subagents on
any of them.

- Reuse your subscriptions. Sign in with the Claude, Codex, and Grok
subscriptions you already pay for; Antigravity, OpenCode, and ACP agents
keep their own logins. Happy adds a harness, not another bill.

- Open source MIT. It runs on your own hardware and your projects stay
ordinary folders. Read the code, fork it, ship your own build.

- End-to-end encrypted mobile app. Left your desk? The same sessions are
already on your phone, and what moves between your devices is encrypted.

- Natively multiplayer. Invite a colleague or a friend into the session.
You both watch the same agent work, and either of you can steer it.

## Original Happy CLI

[#original-happy-cli](#original-happy-cli)

The original CLI wraps the Claude Code and Codex harnesses directly in your
terminal and lets you continue from your phone.

For multi-model sessions and teams, move to the desktop app and Happy Harness.

```
npm install -g happy

<span class="pl-c"><span class="pl-c">#</span> Start Claude Code</span>
happy claude

<span class="pl-c"><span class="pl-c">#</span> Or start Codex</span>
happy codex
```

- [happy-ios](/slopus/happy/blob/main/packages/happy-ios): native Swift/UIKit iOS app

- [happy-android](/slopus/happy/blob/main/packages/happy-android): native Kotlin/Jetpack Compose Android app

- [happy-i18n](/slopus/happy/blob/main/packages/happy-i18n): shared JSON translations

- [happy-cli](/slopus/happy/blob/main/packages/happy-cli): the original Happy CLI (happy on npm)

- [happy-server](/slopus/happy/blob/main/packages/happy-server): the relay server for encrypted sync

- [happy-push-server](/slopus/happy/blob/main/packages/happy-push-server): Cloudflare Worker that delivers push notifications via APNs/FCM (replaces the Expo push service)
