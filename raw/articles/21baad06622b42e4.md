Claude 这篇文章，对小白帮助很大

最近看了 Claude Code 官方团队分享的代码验收经验，感觉还是很受启发的，毕竟AI写代码越来越多，准确性就是一个大问题

我结合平时使用 Pi、DSH、Codex 的情况和文章的内容启发，总结了三个建议

1、不要只看 Agent 有没有完成任务，尽量让它自己运行项目、执行测试，前端项目最好能提供截图，自己再打开页面检查一遍

2、简单的重构、文档修改可以多交给 Agent，但是涉及数据库、权限、登录这些核心功能，我还是建议自己检查关键逻辑，尤其要注意有没有影响原来的功能

3、Agent 修 Bug 也要有个限度，如果连续尝试几次还是解决不了，就应该停下来分析原因，换个思路，而不是让它一直重复修改，白白浪费 Token

其实 Pi、DSH、Codex 都可以按照这个思路来用，区别只在于怎么配置工具和工作流

我现在更倾向于让 Agent 不仅负责写代码，还要负责提供测试结果，最后再根据任务的重要程度决定自己检查多少

这样比单纯追求 AI 写代码的速度更实用，不然你不追求质量，写出来的内容会越来越差，差到AI都难以维护的状态

研究Harness和AI搭配，其实本质都是一个软件工程的问题，解决好还是需要人的介入
