推荐 Top10：面向 前端 / 产品 / UI 的 Agent Skills（2026.11 更新版）

5 月份分享的这份 Top10 Agent Skills，有 1.3k 收藏，最近还有朋友在收藏关注，因为已经是半年前分享的，我再更新一版，避免有失效或不是最优的版本。

1. frontend-design
来自 Anthropic，更偏「高完成度、强风格」的前端设计实现。OpenAI 的 frontend-skill 在 4 月下架后，它是各家工具里最稳的视觉方向 skill，适合想把页面做得更有辨识度时用。
[github.com/anthropics/ski…](https://t.co/mWGc9UNNXa)

2. design-taste-frontend
来自 Taste Skill（leonxlnx），补上 frontend-skill 留下的品牌站、落地页位置。强项是不做模板味的页面，多用真实照片和产品界面，并用浏览器检查来卡住完成度。
[github.com/leonxlnx/taste…](https://t.co/f2HRkKz6Jf)

3. figma-design-to-code
来自 Figma 官方，接替原来的 figma-implement-design。设计稿转代码优先用这个：它会先拿到设计上下文和截图，并复用 Code Connect 里的组件。
[github.com/figma/mcp-serv…](https://t.co/MrhmqfU7V0)

4. web-design-guidelines
来自 Vercel，做 UI 审查依然很强。可访问性、表单、动效、排版、交互细节，都能对照最新的 Web Interface Guidelines 系统地补漏。
[github.com/vercel-labs/ag…](https://t.co/WzJU5PmwH7)

5. react-best-practices
来自 Vercel，做 React / Next.js 基本必装。规则已经扩充到 70 条，官方名称改成了 vercel-react-best-practices，提升的是实现质量和性能。
[github.com/vercel-labs/ag…](https://t.co/rx339BypwV)

6. shadcn
来自 shadcn/ui 官方。它会读取项目里的 components.json，按你现有的组件、主题和 CLI 来拼界面，适合产品 UI 和设计系统落地。
[github.com/shadcn-ui/ui/t…](https://t.co/FlbPe7bZPs)

7. emil-design-eng
来自 Emil Kowalski，专攻交互和动效的手感：按压、悬停、时机和过渡。同一仓库里的 review-animations 适合做完以后再审一轮。
[github.com/emilkowalski/s…](https://t.co/yHz7ondguN)

8. composition-patterns
来自 Vercel，官方名称是 vercel-composition-patterns。适合做组件库和复杂的产品 UI：用复合组件和状态上提来减少布尔 props，让结构更容易接着改。
[github.com/vercel-labs/ag…](https://t.co/m1o5L4rev7)

9. webapp-testing
来自 Anthropic，依然适合日常的本地应用验证：检查页面行为、截图、日志和交互回归。OpenAI 的 playwright skill 已经进了废弃仓库，这个更贴近现在的用法。
[github.com/anthropics/ski…](https://t.co/XMlMJlr6bM)

10. deploy-to-vercel
来自 Vercel，由原来的 vercel-deploy-claimable 改名而来。做完页面马上能拿到预览链接；现在优先走 git 关联部署，不行再退回 CLI 或可认领的临时部署。
[github.com/vercel-labs/ag…](https://t.co/YWoxALunjt)

怎么选 ？
· 偏品牌官网/营销页：frontend-design、design-taste-frontend
· 偏产品 UI/设计稿还原：figma-design-to-code、shadcn、react-best-practices、composition-patterns
· 偏体验审查/可用性：web-design-guidelines、webapp-testing
· 偏交互细节/动效：emil-design-eng
· 偏预览闭环：deploy-to-vercel
