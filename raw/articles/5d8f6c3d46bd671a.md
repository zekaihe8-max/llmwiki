Claude Code 和 Codex 的上下文压缩，可能从一开始就走错了方向。

这里一个新思路：不压缩，保留完整会话，需要什么再检索什么。

作者实测 40 万 Token 会话（Opus 5.5）：

• 缓存失效压缩：38 秒 / $1.99
• 缓存命中压缩：29 秒 / $0.17
• 按需检索恢复：15 秒 / $0.10

更快、更便宜，还避免摘要丢失关键细节。

AI 的记忆，也许不该靠总结，而该靠检索。

Compaction is a mistake.

When an agent's context fills up, tools like Codex and Claude Code compact it:
1. The model prefills the entire session again
2. It writes a summary of everything so far
3. A new session starts from that summary

I measured this on a real ~400k-token
