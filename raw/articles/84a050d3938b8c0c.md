DeepSeek 调整 API 计费规则。11 月 1 日才开始收费的联网工具，仅过约 17 天就重新免费。

从 11 月 18 日起，模型自主调用的网页搜索、图片搜索和网页抓取不再按次收费，只收模型 Token 费用。

这项调整覆盖 DeepSeek 自带的联网工具、Claude Code 接入 DeepSeek 后的网页搜索，以及 DeepSeek Harness 默认的服务端搜索。

不过，开发者直接调用独立的 Search 和 Fetch API 仍需付费，两项接口均为每 1000 次成功请求 5 元。
