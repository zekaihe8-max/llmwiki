DeepSeek V1 作者开源了 Personal Agent 项目 Linger🔥

天下苦 Personal Agent 烧 Token 和云端隐私焦虑已久，前 DeepSeek V1 作者张博这次终于出手，开源了一套跑在自己电脑上的本地 Agent

第一时间我就去扒了一下它的 GitHub 仓库和文档，整体思路还是挺不错的，就是对本地硬件和动手能力还是有一定要求

1、直接驻留在你自己的电脑上，能操作已经登录好的浏览器、邮箱和日历，省去反复配置凭据的麻烦，还能自动整理成本地记忆库并主动提醒

2、主打本地推理省 Token 费，靠自研的 PolyStrata 引擎做显存和内存分层调度，官方称 12GB 显存配 64GB 内存就能跑起 125B 的大模型

3、本身是开源的中间层架构，轻任务可以走本地模型，复杂重活也支持直接挂你已有的 Claude Code、Codex 或者 Pi 订阅来干

我自己看了一圈它的架构和文档，方向确实很对胃口，尤其是本地记忆配合已有订阅这个组合，落地思路比纯画大饼务实很多

但是因为刚开源没几天，我看 GitHub Issues 里 Windows 安装报错、CUDA 检测卡住和界面纯英文这些坑还不少，而且 12GB 显卡跑 125B 的速度目前也是官方数据，真要挂云端订阅的话数据其实也不是绝对不出本机

不过这也是刚出来的早期版本，后续肯定会慢慢修复更新，我也准备等安装包稳一点后拉起来实测一波，看看跟 OpenClaw、Hermes 比到底谁更顺手

GitHub 仓库：[github.com/simplexai-labs…](https://t.co/GHHaQcBrFV)
