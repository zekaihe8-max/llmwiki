用 gflow-cli 做小猫讲乘法口诀动画的核心流程（焚诀版）：

心法：不要直接文生视频，按「先图锁字和角色 → 图生视频做动画 → 换标准配音拼接」走最稳。

1. 准备：uv tool install gflow-cli，浏览器登录 Google Flow，直接复用账号积分。

2. 锁首帧：先用 nano-pro（image t2i）抽第 1 幕锚点图，后续所有分镜全用 image i2i --ref 引用第 1 幕，只换黑板算式和小鱼干。核对无错字再进下一步。

3. 转视频：用 veo-fast 跑 video i2v（--initial-frame 传本地图片路径）。提示词里必须写死「黑板文字与简笔画保持完全静止清晰」，且不要写 childlike voice（易触发音频审核拦截）。

4. 修音拼接：Veo 画面很稳但原生中文偶发偏音，用免费 Edge TTS 合成标准童声，按每段时长用 ffmpeg 对齐混音拼接成片。
