虽然我很讨厌 Anthropic，但是它这 8 个 AI 学习网站，真的值得所有新手收藏

前面我推荐了 Anthropic 官方的 5 篇 AI Agent 入门文章，没想到大家的反馈都很好

所以我就直接把我收集到的 Anthropic 的网站和课程分析出来了，你研究下去你会发现它提供的学习资源远不止技术文章，甚至还有免费的系统课程、中文教程、Agent 开发文档和开源项目

达里奥虽然不厚道，但是 Anthropic 给的资料和学习内容还是十分厚道的，最主要很多资料都有中文版本，尤其是课程和内容质量都有保障

这里我整理了 8 个 比较不错的课程和内容

1、Claude Academy｜免费 AI 学习课程

我最推荐新手从这里开始，有系统的 AI、Claude Code、Agent Skills 和 MCP 课程，部分还提供中文内容

[academy.claude.com](https://t.co/wBJsP6JD2L)

2、Anthropic Engineering｜AI 技术文章

这里是我平时比较喜欢看的地方，主要分享 Agent 架构、Harness、上下文工程和各种 AI 技术实践，内容质量很不错

[anthropic.com/engineering](https://t.co/J0gJ10F2jT)

3、Claude Code Docs｜AI Coding 教程

从 Claude Code 安装、CLAUDE.md、Skills、Hooks 到 Subagent 都有详细的教程，适合想学习 AI 编程的朋友

[code.claude.com/docs/en/overvi…](https://t.co/VKpZk78Q2O)

4、Claude Platform Docs｜Agent 开发文档

如果你想自己开发 AI Agent，可以从这里学习 API、工具调用、SDK 和相关的开发技术

[platform.claude.com/docs/en/home](https://t.co/VDP3wp3ODT)

5、Anthropic Research｜AI 前沿研究

这里主要是 Anthropic 发布的研究成果和论文，包括模型能力、AI 安全、Agent 行为等，适合有一定基础的朋友

[anthropic.com/research](https://t.co/GZyrVLyvhB)

6、Claude Resources｜AI 实际应用案例

主要分享各种 AI 使用案例、指南和视频，比较适合不想一开始就研究复杂技术的小白

[claude.com/resources](https://t.co/nzpqer93h3)

7、Claude Cookbooks｜AI 开源实战案例

Anthropic 官方维护的 GitHub 项目，包含大量代码示例，比如 RAG、工具调用、Agent 工作流等，可以直接拿来学习和参考

[github.com/anthropics/cla…](https://t.co/zfafOyk5vH)

8、Anthropic Skills｜官方 Skills 开源库

如果你对 Skills 感兴趣，我推荐看看这个仓库，可以学习别人怎么设计 Skill、编写 SKILL.md，以及组织相关工具和脚本

[github.com/anthropics/ski…](https://t.co/nuQYd2wyWB)

如果你不知道从哪里开始，我也简单整理了 3 条学习路线：

1、小白入门：Claude Academy → Claude Resources → Claude Code Docs

2、AI Agent 开发：Engineering → Platform Docs → Claude Cookbooks

3、Harness 深入研究：Engineering → Research → Anthropic Skills

其实这些资源并不需要全部学完，根据自己的兴趣和需求选择就可以了

我觉得 Anthropic 最大的优点之一，就是愿意把很多技术思路和实际案例公开分享出来，而且很多文章写得比较通俗易懂

还是那句话，公司虽然很垃圾，但是内容确实值得看，取其精华，去其糟粕

尤其是刚开始学习 AI 和 Agent 的朋友，我觉得这些免费资源已经足够作为一个不错的学习起点了
