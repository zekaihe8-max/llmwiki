今日，DeepSeek 更新官方 API 文档，正式公开工具延迟加载（Deferred Tool Loading）机制。

过去，Agent 接入几百个 MCP 工具，如果一开始就把所有工具的使用说明塞进上下文，会白白占用大量 Token。但如果由客户端按需加载，又可能因为修改工具列表，导致此前的上下文缓存失效，增加推理成本。

DeepSeek API 允许客户端按需检索工具，再将新增工具的定义追加到对话末尾。这样既能减少无关工具对上下文的占用，也不会破坏已有的缓存前缀。

Anthropic 和 OpenAI 均已支持类似机制。DeepSeek 目前仅在 deepseek-flash 模型的 Anthropic Messages 和 OpenAI Responses 接口中提供该能力。

实际上，早在今年 9 月，DeepSeek Harness 的代码中就已出现相关实现，10 月也已有开发者实测验证。
