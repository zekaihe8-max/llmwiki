Grok Bot 居然有人给它搭了一座 3D 办公园区，而且整个项目都开源了 🔥

之前我还吐槽 Grok Bot 的任务进度不够透明，没想到最近社区有人直接把多个 Bot 做成了一座 3D 虚拟办公园区

这个项目叫 Grok Bot 3D Campus，感觉有点像给自己的 AI Agent 开了一家公司，每个 Bot 团队都有独立的办公室

而且不只是做个好看的界面，里面还有几个挺实用的功能

1、可以查看不同 Bot 正在处理什么任务，哪些已经完成，哪些还在执行

2、每个团队都有自己的任务看板，还能查看额度消耗、定时任务和异常情况

3、遇到需要人工审批的操作，可以集中查看，还能通过面板给 Bot 安排新的任务

最有意思的是，作者把整个项目开源了，连对应的 Skill 和部署教程都准备好了

你可以直接把 GitHub 地址发给 Grok Bot，让它按照项目说明，帮你在自己的 Vercel 上搭建一套管理界面

GitHub：[github.com/sarbarshem/gro…](https://t.co/P4Wp0zBAuK)

在线演示：[grok-bot-3d-campus-demo.vercel.app](https://t.co/dku0i6y5uw)

不过公开演示用的是模拟数据，真正管理自己的 Bot，还需要部署私有版本，配置对应的连接和权限

而且刷新任务状态需要读取 Bot 的工作信息，也会消耗一定的额度，没必要设置得太频繁

我觉得这个项目最适合已经创建了多个 Grok Bot 的朋友

以前要挨个打开聊天窗口查看进度，现在可以直接看到整个 Agent 团队在干什么

尤其是手里有十几个 Bot 的情况下，这种可视化管理方式确实挺有意思的
