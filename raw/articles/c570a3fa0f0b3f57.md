腾讯混元正式发布 Hy4：首次能看图、能操作电脑，开源权重还在路上，团队对 Hy4 与顶级闭源模型的差异非常坦诚！

# 模型信息

Hy4 总参数约 770B，MoE 架构，上下文 1M token。相对 8 月的 Hy4 preview，正式版大幅加了预训练和后训练。新能力有两块：第一次能看图，能做细粒度识别、复杂图表分析和视觉数学推理；第一次支持 Computer Use，命令行和图形界面都能操作，还专门练过 Blender、CAD 这类专业软件，以及跨应用的长周期任务。

# 几个主打场景

金融方面，腾讯和 FiT 做了几千个工作区、上万个任务，覆盖基金研究、个股分析、量化、资产配置、公司财务和税务。213 位金融从业者参与评测，其中 153 人来自外部机构，超过七成有五年以上经验，共 579 个真实任务。按四分制，Hy4 得 3.04，DeepSeek-V4.1-Flash-1017 是 2.97，Kimi K3.1 Pro 和 GLM-5.3 都是 2.68。搜索相关的幻觉率从预览版的 15.76% 降到 5.45%，靠猜测出错的比例从 23.1% 降到 5.6%。对 Word、Excel、PowerPoint 的协同编辑也做了加强；合作方 Manus 称办公文档任务完成率接近 97%，这是对方自报数字。

办公和协同方面，在 WorkBuddy 评测里平均分 83.18，任务通过率约 96%。接上企业微信后，它可以把聊天、邮件、文档、日程和会议串起来，整理多项目进度、待办和优先级。

前端和游戏方面，加强了复杂交互、业务逻辑和状态管理，并加深了对 UE、Unity、Godot 的适配。相对预览版，GameDev 和 GameLogic 分别提升约 19.1% 和 9.8%，这是和自己比，不是和别家比。

科研方面，内部基准 TenureTrail 有七个学科、123 个可执行研究任务，Hy4 在开源权重模型里排第一，在全部对比模型里大约是第三（约 53.6，Claude 约 59）。它在数学构造、物理建模、地球科学、系统工程和社会经济决策上表现较好。一个官方案例是：给 84 张无序、部分镜像的二维切片，含约 699 万个细胞，Hy4 在离线、没有专用配准工具的情况下，约 1.5 小时完成小鼠胚胎三维重建。

# AI 研发与开源副产品

混元在为「递归自我改进」做准备。Hy4 配上 Hyra 2.0 开发框架，能优化同架构小模型的预训练基础设施，并自动训出在多项评测上超过官方 Jev 基线的变体。还开源了两个基础模型：做单细胞表征的 HyCell，以及做物理场建模的 HyPDE。

# 公开榜单表现如何

腾讯自己跑了一组对比。在非内部的公开类评测里，Hy4 多数排在第二到第四；十二项主表里没有总榜第一，最好成绩之一是 E-Bench 2.0 的第二。开源阵营里和 Kimi K3.1 Pro 大致打平，各有胜负：代码、三维建模、检索和科研偏 Hy4，终端自动化和科学终端任务偏 Kimi。

Agent 评测 APEX-Agents v1.1 上，腾讯表里 Hy4 是 75.2，略高于它测到的 Claude Opus 5.5（约 74.8）和 DeepSeek（约 72.9）。但在其他多数行上，Opus 仍领先。腾讯自己也写了：和顶尖闭源模型仍有明显差距，尤其在前沿数学、超长开发任务、模型迭代和视觉问答上。例如 Hy-FrontierMath T5 大约只有 13，和 GPT 系接近满分差得很远。
