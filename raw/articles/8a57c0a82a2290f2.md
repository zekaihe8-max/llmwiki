Google 白送的 Colab 计算单元别吃灰 3 套 MiniMax H3 生视频落地组合🔥

开了 Google AI Pro 或者 Ultra 每月白送 200 到 2000 个 Colab 计算单元 加上 MiniMax H3 开源了带原生音画同步的基础权重 拿来搭一条完整的生视频流水线刚好合适

按折腾程度整理了 3 套一层套一层的项目组合 每套都能跑出完整成片

1、agy CLI + Colab 算力 + ComfyUI + MiniMax H3 + SeedVR2

适合想让 Agent 接管环境配置和批量出片的人

用 agy CLI 配合官方 google-colab-cli 或者 colab-mcp 连上 Colab 的 A100（80GB）或 G4（96GB）算力 让 Agent 自动拉起 ComfyUI 跑通 MiniMax H3 官方量化工作流（显存压到 42.5GB）再串一个 SeedVR2 节点补齐 2K 超分

从装依赖、跑工作流到把带原生音效的 2K 成片存进 Google Drive 全给串起来了

2、Colab 算力 + WanGP + MiniMax H3 + Showrunner

适合懒得连节点、想一个界面搞定的新手

开 Colab 的 L4 或者 A100 跑一遍 WanGP 的 Colab 脚本 它把 Qwen-Image 生首帧、MiniMax H3 生视频、Showrunner 多镜头连贯、配乐和超分全打包进了一个界面

套完流程能出多镜头连贯的完整短片 还能用内置分块模式压低显存门槛

3、Colab 轻实例 + MoneyPrinterTurbo + MiniMax H3 API

适合只有 200 算力点、不想几小时烧光额度的人

只开 Colab 免费或者 T4 轻实例 跑 MoneyPrinterTurbo 官方 Notebook 负责文案、faster-whisper 字幕、配音和剪辑 视频生成外包给 MiniMax H3 API 按秒计费

算力点几乎不怎么掉 适合稳定批量出 9:16 短视频成片

顺手补两个省钱避坑点

用本地权重跑的时候 成片目录挂 Google Drive 但是大模型权重先拷到 Colab 本地盘再加载 不然光读盘白烧算力点 算力点归零也会马上断掉 WebUI

另外美、欧、英、韩地区跑 MiniMax H3 开源权重 记得先去官网填一份免费授权豁免表

涉及到的 agy CLI、google-colab-cli、ComfyUI 工作流、WanGP 和 MoneyPrinterTurbo 链接都整理好放评论区了 按需拿走
