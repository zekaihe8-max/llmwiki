Pi 最近好像沉寂了？翻了一下 GitHub，发现 Mario 他们其实在忙一件更大的事

这段时间总感觉 X 上的 PI 相关的内容都变少了，没有之前 Codemode、MCP 和 Pi Durable 那么多值得关注的新功能

本来以为 Mario 最近是不是放慢了开发节奏，结果我去 GitHub 看 PR 分支，发现其实只是发版本的速度降低了，但是更新内容的速度没有减缓

而且我还从里面挖到了一些比较有意思的内容

1、p2：新的 Web 和 TUI 项目

官方正在尝试基于 Pi Durable 和 Chord 开发新的交互界面，已经有了 Web、远程设备管理、会话管理和沙箱等功能

不过目前还是实验性原型，后面会被替换，并不是正式产品

2、Chord v2：重新完善底层架构

重点放在插件运行时、跨设备通信和存储复制上面

还增加了代码热重载相关机制，让旧任务可以在原来的代码版本上完成，再切换到新的实现

看得出来，官方现在也越来越重视 Agent 长时间运行的问题

3、Anthropic Message Threads

这个功能已经进入开发分支

通过服务端延续之前的会话，减少每轮请求重复传输大量历史消息

对于长对话或者长期运行的 Agent 来说还是挺实用的，不过 Token 计费不会因此直接减少

4、Pi 主线的稳定性优化

这几天修复了不少之前遇到的问题，包括大文件读取占用内存、MCP OAuth 登录卡住、Tool Search 搜索异常，以及插件界面残留

另外也增加了 pi auth login 和 pi auth logout 命令，可以直接在终端管理模型认证

其实看了一圈下来，Pi 最近并没有停止更新，只是方向发生了一些变化

我甚至都在期待 PI 是不是可以推出他们的桌面端或者是手机端，这样的话，我们使用起来就会更方便了，而且交给官方维护也更放心

如果你也感兴趣的话 可以看一下对应官方的开发分支
