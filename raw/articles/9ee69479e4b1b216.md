企业 AI 支出一年涨了5.4倍，到1768亿美元。钱流向了谁？

Anthropic 在企业 API 支出里的份额从40%升到55%，OpenAI 从27%升到31%，Google 从21%跌到9%。

Menlo Ventures 刚发布第四份企业 AI 报告，最值得看的几组数字都整理在下面👇

【一、Agent 已经是 AI 的最大用户】

在 OpenRouter 上，Agent 现在产生了80%的 token，每周130.9万亿，大约是人类使用量的7倍。

报告把拐点放在2025年11月 Opus 4.5 发布：Agent 流量在发布后一周翻了三倍。2026年2月 Opus 4.6 和 GPT-5.3-Codex 发布后，Agent 流量超过了人类。此后 Agent 流量涨了37倍，人类使用只涨了5倍。

这也解释了为什么支出涨得这么快：Agent 可以并行工作，人走开了它还在干，花多少钱跟着干了多少活走，不再跟着有多少员工走。

【二、钱在往头部实验室集中】

Anthropic、OpenAI、Google 三家拿走了69%的企业 AI 部署支出，共1227亿美元，去年这个比例是50%。三家的支出一年涨了7.5倍，其他所有公司加起来只涨了3.3倍。

Anthropic 和 OpenAI 合计占企业 API 支出的86%，报告的说法是“越来越像两强之争”。Google 在2025年11月靠 Gemini 3 Pro 回到第一梯队，但之后旗舰模型没有跟上，API 支出更多流向了便宜的 Flash 模型。

【三、企业实际花的钱，是预算的2.5倍】

企业原计划把今年的 AI 支出提高到去年的1.9倍，实际平均花了4.7倍。中位数是2.2倍，计划是1.8倍，差距主要来自少数重度用户。

这些钱大多不是从别处挪来的：新增支出里，55%来自全新预算，只有22%来自原有软件预算。报告的判断是，AI 在做大软件市场，而不是吃掉它。

另一个数字：每花1美元训练模型，企业就花约1.7美元来使用它。

【四、编程是第一个爆发的场景】

AI 应用市场一共773亿美元，其中编程340亿美元（增长7.7倍）、聊天助手250亿美元，两项占了76%。排第三的医疗只有37亿美元。

Claude Code 和 Codex 合计240亿美元，占编程市场的70%，去年才大约10亿美元。其余编程公司也增长了2.9倍，到101亿美元。

报告的解释是，编程天然适合 Agent：有能直接动手的环境（代码库），有完整的上下文（代码和文档），还有能自动验证的结果（编译和测试）。

编程市场96%被 AI 原生公司拿下，但在 IT（ServiceNow 占91%）、数据科学和 HR 这些领域，传统巨头还守得住。

【五、开源：用量涨了，收入没涨】

开源模型处理了19%的 token，却只拿到4%的支出，因为平均价格降了3.3倍，现在每百万 token 只要0.13美元。

在开源模型的支出里，中国模型占89%：Kimi 61%、DeepSeek 15%、GLM 11%、Qwen 3%。

【六、Agent 正在带动新的基础设施】

使用代码沙箱的 AI 开发者从11%升到40%，用搜索的从5%升到30%，用浏览器基础设施的从4%升到14%。
