没想到 Google Antigravity 也支持远程电脑运行

在使用 AGY 的时候发现，其实AGY也带了 Remote Agents 功能，可以直接把 Coding Agent 放到 Google 云端运行

在用的时候，就不需要一直一直开着电脑，像修 Bug、升级依赖、运行测试这些耗时任务，都可以交给云端 Agent

使用方法也很简单：

1、打开 [antigravity.google.com](https://t.co/vqTYNX2PP7)

2、创建 Remote Project，连接 GitHub 仓库

3、给 Agent 分配任务，后续在网页或手机上查看进度

目前 Google AI Pro 和 Ultra 用户可以使用，不过功能还在逐步开放，不是所有账号都有入口

看来谷歌也有意识到自己的短板，在慢慢的优化自己家的Harness😂
