# MopMonk-DS-1.0-Preview

[#mopmonk-ds-10-preview](#mopmonk-ds-10-preview)

MopMonk-DS-1.0-Preview is a cybersecurity-specialized large language model built on DeepSeek V4.1 Flash, a 40-layer mixture-of-experts model. Through large-scale domain data construction and specialized post-training, it focuses on Offensive Cyber Capabilities, advancing the model's proficiency in deep vulnerability discovery, vulnerability analysis, and exploit development. MopMonk pushes general-purpose LLMs beyond security knowledge comprehension and vulnerability detection toward complex exploitation and autonomous security task execution.

## Training Pipeline

[#training-pipeline](#training-pipeline)

MopMonk is built through a two-stage training pipeline:

- Continuous Pre-Training (CPT) on domain corpora spanning binary and web vulnerability analysis, using standard next-token prediction with general-capability replay to prevent catastrophic forgetting.

- Supervised Fine-Tuning (SFT) on validated agent trajectories produced by an offline structured knowledge transfer pipeline, where the base model distills expert demonstrations into structured guidance and independently generates diverse, non-imitative solving trajectories in live environments.

### Training System

[#training-system](#training-system)

Long-context full-parameter SFT on a 40-layer MoE requires distributing both sequence computation and expert state. Our NeMo-based system combines FSDP2, context parallelism, expert parallelism (HybridEP/DeepEP), TileLang attention, and Transformer Engine grouped expert kernels on multi-node NVIDIA Hopper GPUs. FP32 gradient-shard accumulation and 16K length bucketing reduce numerical error and shape-induced recompilation respectively. The grouped expert integration reduces mean training update time by 32% over the original configuration.

### Inference Optimization

[#inference-optimization](#inference-optimization)

The model is served in BF16/FP32 mixed precision, preserving the finer parameter representation learned during SFT rather than requantizing to MXFP4/FP8. Efficiency is recovered through three custom operator optimizations built on DeepInfer's Hopper integration:

- SM90 Rotary-Attention Fusion removes intermediate global-memory transfers by fusing query-RoPE, sparse attention, and inverse-RoPE into a single SM90 kernel, reducing component latency by 6.77–13.40%.

- Expert Projection-SwiGLU Fusion computes gate/up projections and SwiGLU activation locally, eliminating an intermediate tensor round-trip. Adaptive split-K handles sparse expert workloads.

- Shape Specialization and Phase-Dependent Communication provides decode-specialized grouped GEMM kernels and per-phase communication SM allocation, yielding 22–28% decode gains in controlled comparison.

The selected combination improves continuous decoding rate by 4.65–5.71% over an already optimized baseline, with TTFT essentially unchanged.
