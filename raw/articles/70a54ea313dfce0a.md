## 为什么做牛马经纪人

[#为什么做牛马经纪人](#为什么做牛马经纪人)

>

简历是最不重要的一环，你的目标，你对市场水温的感知，并围绕市场需求反向调整当下的工作投入与更长期的职业规划，这三点都远比简历重要的多

换句话说，为了搞清楚这三点，你持续研究、做新的尝试，并根据反馈修正判断，你的简历很难不出众

因此，虽然这个产品的入口是简历，但这只是作为一个出发点，最初始的信源，而最最核心的功能实际上都是围绕着前面说的三件事进行构建的：

## 安装

[#安装](#安装)

>

告诉你的 Agent 这个项目链接，ta 知道怎么装的。

手动安装方式与环境要求（点击展开）

需要 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) >=0.2.2-rc.5 <0.3.0 与 Node.js >=22。

-

方式一：在 DeepSeek Harness 桌面端 / Web 界面直接安装（推荐）
打开 DeepSeek Harness → 左侧栏进入 插件 → 点击 添加插件 → 填入：

- dsh-niuma-broker，或

- 从 GitHub Releases 下载的 dsh-niuma-broker-0.1.2.tgz 本地绝对路径
点击 安装，完成后点击 立即启用 即可。

-

方式二：使用 DSH CLI 安装（DSH 0.2.2-rc.5 必须带 --profile）

- 桌面端（desktop profile）：先打开一次 DeepSeek Harness Desktop 完成初始化，再完全退出桌面端，运行以下命令后重新打开桌面端：

```
<span class="pl-c"><span class="pl-c">#</span> 从 Releases 离线包安装</span>
dsh plugin --profile desktop add /path/to/dsh-niuma-broker-0.1.2.tgz

<span class="pl-c"><span class="pl-c">#</span> 或从 npm 安装</span>
dsh plugin --profile desktop add dsh-niuma-broker
```

- Web 端（web profile）：

```
<span class="pl-c"><span class="pl-c">#</span> 从 Releases 离线包安装</span>
dsh plugin --profile web add /path/to/dsh-niuma-broker-0.1.2.tgz

<span class="pl-c"><span class="pl-c">#</span> 或从 npm 安装</span>
dsh plugin --profile web add dsh-niuma-broker
```

>

若终端尚未将 dsh 加入 PATH，macOS 下桌面端内置 CLI 位于 /Applications/DeepSeek Harness.app/Contents/Resources/runtime/cli/bin/dsh。

使用 AI 能力前请先在 DSH 设置中配置至少一个模型（手动编辑与本地管理无需模型）；当前最佳体验平台为 macOS（原生支持系统日历、提醒事项与 Things 同步），Linux / Windows 支持核心简历、岗位与洞察功能。

## 说明与许可

[#说明与许可](#说明与许可)

- 数据与模型调用：插件没有独立的云端后台，简历、履历库与岗位记录默认保存在本机 ~/.dsh/profiles/<profile>/career-broker/；使用 AI 匹配、深度解读或工作提炼时，相关上下文会发往你在 DSH 中自行配置的模型服务商。

- 可控与克制：后台工作提炼、官网定时巡检与展开自动解读默认关闭，由你按需开启；工作提炼支持按目录勾选工作区，请勿勾选包含受 NDA 约束保密信息的目录。不模拟登录，也不代投递。

- 免责与开源协议：内置公司列表仅作公开招聘页快捷入口，与所列公司无任何关联；AI 建议仅供参考，投递前请由本人核实。本项目采用 [MIT License](/Nimbus318/dsh-niuma-broker/blob/main/LICENSE)，第三方开源声明见 [THIRD_PARTY_NOTICES.md](/Nimbus318/dsh-niuma-broker/blob/main/THIRD_PARTY_NOTICES.md)。
