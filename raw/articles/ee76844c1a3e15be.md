DeepSeek Harness 现在连电脑都能直接操作了🔥

今天翻了一下 DSH 最近的更新日志，发现官方已经把 Computer Use 做成了实验性插件，而且是随 DSH 一起提供的

这个功能其实在 10 月底就已经加入，只不过当时没有太注意

现在 macOS 用户可以直接在：插件 → 更多 → 实验性插件 中开启，授予系统权限之后，就能让 Agent 观察桌面、操作应用程序，不再局限于终端和代码工具

目前还是实验性功能，Windows 版本也还在开发中

顺便看了一下最近的 0.2.2 系列更新，除了 Computer Use，还有几个变化挺值得关注

SubAgent 现在支持具名和多层级协作，AgentTeam 也能直接在会话中开启，统一管理成员和任务

Git Worktree 的代码审查功能进一步完善，可以在 DSH 内处理 GitHub Review、查看差异和同步审阅进度

而最新的 v0.2.2-rc.3，又增加了一个挺实用的功能：可以把 DeepSeek App 或网页版的历史会话导入 DSH，接着之前的内容继续聊

另外，之前比较头疼的插件稳定性问题也有改善，可选插件加载失败不再直接导致整个 Web 启动失败，Windows 桌面版更新异常的问题也进行了修复
