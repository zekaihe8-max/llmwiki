AI 写的网页动效总觉得差点意思的？试试这套开源 Skill

GitHub 上有个开源项目 animation-principles
把迪士尼 12 条动画法则，做成了 144 个 Agent Skill
相当于给 AI 配了一套动效手册

里面不光讲原则，还直接给了代码和动画参数
比如按钮按下缩多少、过渡用多少毫秒，都写明白了

全套分了 12 大类，别一口气全塞进去占上下文
按项目挑三五个装进 Claude Code 或 Cursor 就够：
- 写纯网页：挑 css-native
- 用 React：挑 framer-motion（React 动效库）
- 做复杂动画：挑 gsap-greensock（JS 动画库）
- 调按钮手感：拿 buttons-ctas
- 要欢快弹跳：搭 joy-delight

每个都是独立的 SKILL.md，MIT 协议开源
嫌 AI 写的动效太死板，直接挑几个装上试试
