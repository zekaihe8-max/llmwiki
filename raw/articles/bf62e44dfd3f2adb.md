把 Pi Agent 当作内核，做出一套属于自己的 AI 助手🔥

最近大家都在关注 Grok Bot 这类 Personal Agent，现在 Agent 也能通过插件去实现类似的功能，装入插件就可以实现自己的个人助手

开源项目的名字叫： PiClaw，作者没有重新开发一套 Agent 内核，而是基于 Pi Agent，搭建了一套完整的 Web 工作台

它比较有意思的几个地方：

1、支持网页聊天、文件管理、代码编辑和终端操作，手机和电脑都可以访问

2、支持定时任务和长期记忆，还能通过 Dream 自动整理以前的对话和笔记

3、保留 Pi 的 Extension 和 Skill 扩展能力，可以接入 SSH、Proxmox 等工具管理自己的服务器

而且支持 Docker 自托管部署，模型也可以自由切换

PiClaw 最有价值的地方，不仅仅是增加了一个 GUI 界面，而是把 Coding Agent 变成了一个可以长期使用的 Personal Agent

尤其是 Pi 本身足够精简、扩展自由度又高，未来完全可以基于它搭建更多不同形态的个人 AI 助手

相比直接使用现成的 Personal Agent，我更想尝试一下这种方式，通过插件把 Agent 改成自己想要的形状，虽然已经有 PI Durable

但是社区永远不缺乏人才，直接去 Pi Agent 现在去处理了，如果感兴趣 可以去研究一下，我自己也在看具体是怎么实现的
