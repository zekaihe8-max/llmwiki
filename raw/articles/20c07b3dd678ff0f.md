这周 GitHub 上最值得看的 5 个 AI Agent 开源项目🔥

平时逛 GitHub 和 Hacker News 看到不少有意思的新东西，挑了 5 个这几天热度很高、方向也各不相同的项目整理出来

有管多 Agent 远程审批的，有抓全网真实讨论的 Skill，也有纯汇编跑模型的硬核项目，大家按需挑着看就行

1、Coucou｜在 Mac 刘海屏和手机锁屏盯住所有编程 Agent

已有 7500 多 Star，支持 Claude Code、Codex、Cursor、Antigravity 和 Hermes，能在刘海屏直接看实时改了哪行代码以及 5 小时和每周剩余额度，权限弹窗点一下就能批

离开电脑锁屏后，它还会通过你自己的私有 iCloud 同步到 iPhone 灵动岛和锁屏上用面容 ID 远程审批，顺带还内置了免费的本地离线语音输入，但是完整的多 Agent 支持记得下 GitHub 里的安装包，商店沙盒版会有功能限制

项目地址：[github.com/Louis-CFM/couc…](https://t.co/DmQYjBZGe9)

2、last30days-skill｜一次抓全十几个平台真实讨论的调研 Skill

目前 7.5 万多 Star，前两天刚更新了监控提醒，它能同时去搜 Reddit、Hacker News、X、YouTube 字幕、GitHub、arXiv 甚至预测市场，按真实互动量打分把 SEO 水文筛掉

一行 npx skills add mvanhorn/last30days-skill -g 就能装进 Claude Code、Codex 或 Gemini CLI，注意本地需要 Python 3.12 以上，Reddit 和 HN 免配置就能跑，但是抓 X 这类平台需要自己配好接口或登录态

项目地址：[github.com/mvanhorn/last3…](https://t.co/CH8hsKlDRW)

3、llm.asm｜用 1.7 万行纯汇编跑本地大模型的 24KB 裸机系统

刚开源两天就冲上 HN 首页前十，零 C、零 Rust 也零系统依赖，作者纯用 x86-64 汇编手搓了推理引擎和一个只有 24KB 的可引导操作系统内核，挂在无硬盘的 Proxmox 或 KVM 虚拟机上不到 100 毫秒就能启动跟 Qwen3-0.6B 对话

目前没有网卡驱动只能靠串口或键盘交互，长提示词预填充也还是 llama.cpp 更快，实用性不算强，但是思路确实够硬核

项目地址：[github.com/alesha-pro/llm…](https://t.co/fuSfpVpreE)

4、AgenticAlgorithmEngineering｜逼着 AI 先做假设再改代码的性能优化插件

海德堡大学算法工程组刚开源的项目，专门治 Claude Code 和 Codex 凭感觉瞎改代码的问题，强制让 Agent 走先做性能剖析、提出可证伪的提速假设、跑过基准测试和断言才保留 Git 补丁的流程

拿来压榨核心模块性能很合适，但是如果要自动生成完整的实验报告，本地得提前配好 Python 3 和 LaTeX 环境

项目地址：[github.com/CHSZLab/Agenti…](https://t.co/bcqdYhhJRw)

5、minipg｜不用装 Docker，单个可执行文件 800 毫秒拉起 PostgreSQL 18

同样刚冲上 HN 首页，底层直接调系统自带的虚拟化能力，不用开笨重的 Docker 桌面端也不用管镜像，一行命令就能把完整的 Postgres 18 跑起来，整个数据库就是一个便携的 .pgdb 文件夹

平时写代码让 Agent 本地搭个临时测试库随用随删非常省事，但是目前还是早期原型阶段，拿来跑本地开发环境就行，别直接上生产环境

项目地址：[github.com/progrium/minipg](https://t.co/PVnWEd3fr0)

这 5 个项目不用全装，日常同时开好几个编程 Agent 的优先试一下 Coucou，经常查资料找选题的装个 last30days-skill 就够用了

后面那几个偏底层折腾的先收藏起来，周末有空拿来研究一下也很有意思
