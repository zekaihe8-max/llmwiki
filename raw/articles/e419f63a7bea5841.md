最近 Claude Code 推出了 Code Mode，我第一时间想到的就是 Pi Agent 之前内置的 Codemode

两者的设计思路其实非常接近，都是让 Agent 通过 JavaScript 一次完成多个工具调用，而不是像以前一样，每执行一个工具，都要把结果返回给模型，再决定下一步

比如搜索几十个文件、筛选错误日志、批量修改代码，这些操作可以直接通过代码串起来，最后只把有用的结果返回给模型，减少不必要的 Token 消耗

不过两者还是有一些区别

Claude Code 的 Code Mode 目前还是实验性功能，主要围绕自身的编程工具和权限系统设计，而且只能搭配指定的 Claude 模型使用

Pi 则使用 QuickJS 沙箱来运行 JavaScript，还能组合 Extension、MCP 等工具，模型也可以自由选择，甚至能调用专门的分类模型处理一些简单判断

如果你已经在用 Pi，我分享几个比较实用的技巧：

1、可以先通过 pi --tools +codemode 临时体验，不需要修改原来的配置，觉得好用再设置成默认启用

2、Pi 支持 on 和 only 两种模式，前者可以同时使用普通工具和 Codemode，后者主要通过 Codemode 调用其他工具，我更建议新手先用 on

3、尽量把重复性任务交给 Codemode，比如并行检查文件、过滤测试日志，只返回错误和关键结果，不需要把几千行原始输出全部塞进上下文

不过需要注意，QuickJS 只是隔离脚本执行环境，不代表工具操作都有系统级沙箱保护，涉及删除文件、修改数据库等操作还是要做好权限控制

我觉得 Code Mode 真正有价值的地方，不只是节约 Token，而是让代码处理确定性的步骤，让模型专注于需要推理和判断的任务

这也是我比较喜欢 Pi 的原因，除了写代码，还可以自由组合模型和工具，搭建自己需要的 Agent 工作流
