Anthropic 修复了 Claude Code 一项浪费额度的问题。此前，开发者发现，后台子 Agent 即使没有执行新任务，也会因为不断汇报进度而消耗大量 Token。

Claude Code 可以让多个子 Agent 在后台同时工作，比如查代码、修 Bug、运行测试。为了显示任务进展，每个子 Agent 约每 30 秒更新一次状态。

问题在于，此前每次更新状态，模型都要重新读取整个对话记录，哪怕最终只生成几个字。任务运行越久，重复消耗的 Token 就越多。

10 月底，有开发者发现，团队一周内约 16.4% 的模型费用花在了这些状态更新上。Anthropic 工程师随后确认了这一机制，但表示这属于较极端的案例。

现在，Claude Code 改用更便宜的 Haiku 5.5，根据简短笔记生成状态提示，不再反复读取完整对话。官方称，单次状态更新成本降低约 99%，使用后台子 Agent 的会话整体节省约 5% 的额度，相当于同样额度能多发约 6% 的请求。

这项优化仅针对 Claude Code 命令行版本，不涉及桌面应用。目前已向大部分 Pro、Max、Ultra 用户及全部 Team、Enterprise 用户开放，需更新至 v2.1.316 或更高版本。
