Claude Code 想省 Token，你必须知道的 5 个项目🔥

1、context-mode｜减少 Context 污染

[github.com/mksglu/context…](https://github.com/mksglu/context-mode)

通过 MCP + Hooks 过滤冗长的工具输出，只把需要的结果交给 Claude，避免大量无关内容占用上下文

2、RTK｜压缩终端输出

[github.com/rtk-ai/rtk](https://github.com/rtk-ai/rtk)

专门优化 git、测试、构建等命令输出，减少无效日志占用的 Token，还能统计压缩效果

3、claude-mem｜跨 Session 记忆

[github.com/thedotmack/cla…](https://github.com/thedotmack/claude-mem)

自动记录 Agent 的操作、决策和项目上下文，下次开启 Session 可以检索历史记忆，减少重复解释项目背景

4、Serena｜精准检索代码

[github.com/oraios/serena](https://github.com/oraios/serena)

通过 LSP 提供符号级代码检索，直接定位函数、类和引用关系，减少反复读取整个文件的 Token 消耗

5、caveman｜精简 Agent 输出

[github.com/JuliusBrussee/…](https://github.com/JuliusBrussee/caveman)

重点优化 Agent 的回复冗余和 Token 消耗，减少不必要的解释，适合想进一步压缩 Claude Code 使用成本的朋友

如果刚开始折腾，我更推荐先研究 context-mode、RTK 和 Serena

不过别一次性全部装上，工具本身也有额外开销，最终省不省钱，还得看完整任务的 Token 消耗和实际费用
