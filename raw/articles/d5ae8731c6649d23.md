折腾 Pi Agent 和 DeepSeek Harness 这段时间，我发现自己对 Agent 的关注点慢慢变了

以前更在意哪个模型强、哪个产品功能多，现在反而更关心 Harness 能不能适应我的工作流

DeepSeek Harness 的优势很明显，桌面端方便，很多功能不需要自己配置，对新手更加友好

但是我还是更倾向于 Pi，主要有三个考虑：

1、可控性，工具怎么加载、上下文怎么压缩、Agent 怎么执行任务，我希望这些都能自己调整

2、扩展性，Pi 的 Extension 生态很丰富，可以根据需求组合插件，不只是用来写代码

3、长期使用，模型可以随时切换，但自己积累的 Skills、配置和工作流最好能一直沿用

当然，Pi 也不是没有问题，插件装多了同样会增加维护成本，甚至出现兼容性问题

所以我现在选 Harness，不再单纯比较谁的功能更多，而是看它能不能让我持续改进自己的工作流

毕竟模型更新得太快了，没必要每次换模型，都把整个 Agent 重新折腾一遍
