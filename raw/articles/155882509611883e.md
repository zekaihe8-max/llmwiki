Pi Agent 必须知道的 6 个隐藏设置和技巧🔥

Pi 用久了会发现，它有很多功能其实已经内置了，只是平时很少有人去关注，有些甚至不需要额外安装插件就能实现

尤其是缓存、上下文压缩和会话管理这几个地方，我觉得非常值得研究一下，合理配置之后可以进一步优化 Token 成本和使用体验

我整理了 6 个比较实用的技巧：

1、缓存自动保温 cacheWarming

默认是 streaming，改成 idle 之后，两次任务之间也可以保持提示缓存，再搭配 PI_CACHE_RETENTION=long 延长支持模型的缓存时间

2、查看缓存损耗 showCacheMissNotices

设置成 true，缓存大面积失效、预热成功以及压缩消耗都会显示提示，方便观察 Token 成本

3、自定义上下文压缩 compaction

reserveTokens 控制自动压缩的触发时机，keepRecentTokens 控制保留多少近期上下文，还可以通过 modelOverrides 给不同模型单独配置

4、会话分支 /tree、/fork、/clone

/tree 可以在同一个会话内切换分支，/fork 从历史消息创建新会话，/clone 复制当前分支，空输入时连续按两次 Esc 也能打开会话树

5、让 Shell 别名生效 shellCommandPrefix

Pi 默认使用非交互式 Shell，别名不会自动生效，可以通过这个配置加载 ~/.bash_aliases，然后 /reload，就能直接用 !ll 这样的命令

6、自定义模型思考档位 modelThinkingLevels

可以给不同模型设置默认思考等级，不需要每次手动切换，搭配 /scoped-models 还能限制快捷切换的模型范围

其他还有 /export 导出会话、/share 分享会话、/hotkeys 查看快捷键，以及 PI_OFFLINE 关闭自动联网等功能

这些都是 Pi 自带的能力，不需要额外安装插件

我个人更推荐优先研究缓存和压缩，特别是长期使用 API 的话，能够更好地控制上下文和缓存成本

不过缓存保温本身也会产生调用费用，并不是开得越久越省钱，最好结合自己的模型和使用频率调整

Pi 的优势不只是核心足够精简，而是很多东西都可以按自己的需求去配置，没必要什么功能都依赖插件
