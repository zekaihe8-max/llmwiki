Antigravity 支持 MCP 了，插件有这 5 个就够了🔥

现在 AGY 已经自带 Plugin Marketplace 和 MCP 支持，默认也做了懒加载

我整理了官方市场和社区里最实用的 5 个 MCP，基本覆盖了日常开发最常用的方向：

1、Context7｜查带版本号的最新文档

写代码最怕框架刚升级模型还在背旧文档

装上它能拉取对应版本的最新 API，省很多排错时间

项目地址：[github.com/upstash/contex…](https://t.co/sUDxLe7gwi)

2、DeepWiki MCP｜快速看懂陌生开源项目

免费免鉴权的远程 MCP，AGY 原生只能看本地项目

想摸清某个 GitHub 仓库的架构，靠它最省事

文档地址：[docs.devin.ai/work-with-devi…](https://t.co/RigDkZLOgK)

3、GitHub MCP｜补齐远程 PR 和 Issue 协作

桌面端虽然自带本地 Git 面板

但是查 Issue、审 PR 和翻 Actions 报错日志还得靠它

项目地址：[github.com/github/github-…](https://t.co/57hXuOVmKm)

4、Supabase MCP｜连真实数据库和线上日志

看真实库表、RLS 和线上日志不用来回切控制台，用 Firebase 的换官方 Firebase MCP

接 Supabase 记得加上 read_only=true，防模型手滑改线上库

文档地址：[supabase.com/docs/guides/ge…](https://t.co/JjnhyAOjGR)

5、Figma MCP｜前端还原设计稿

能读到真实的设计变量和布局，比甩截图给模型准得多

平时不碰前端设计稿的话，这个可以跳过

文档地址：[developers.figma.com/docs/figma-mcp…](https://t.co/JoG1BNshei)

日常写代码只留前 3 个基本就够了

另外像 Playwright、Sequential Thinking、Filesystem 这几个不用盲装

AGY 桌面端自带浏览器，CLI 底层也接了 Chrome DevTools MCP

思考档位、/plan 和本地文件读写也都是原生的，装了基本是重复
