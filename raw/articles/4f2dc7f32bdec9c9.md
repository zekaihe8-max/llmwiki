很多人买了 Google AI 会员，其实不知道 Gemini 和 Antigravity 的额度是分开算的

我最近在研究 Gemini 的时候就发现，这边额度掉得非常快，稍微多跑几次深度思考和研究就见底了

结果切到 Antigravity 一看，额度基本没什么问题，还剩一大截

两边额度不互通，就很容易出现一边不够用、一边放着浪费的情况

尤其是平时习惯用手机创作、查资料的人，Antigravity 又没有独立 App，不知不觉全把 Gemini 这边烧光了

想把两边的额度都用充分，我整理了 3 种解决方案，看看哪一种更适合你

1、按任务拆开用，轻活给 Gemini，重活给 Antigravity

Gemini App 和网页版只拿来做随手搜索、语音聊想法、日常问答，平时默认切快速模型，尽量少在里面死磕深度研究

写长文、整理资料、读本地知识库这类真正吃额度的活，统一挪到 Antigravity 里干，还能开 Orchestrator 模式让强模型规划、轻量模型执行，额度耐用很多

2、电脑开 Remote Control，手机浏览器当 Antigravity App 用

适合像我一样重度手机创作的人

电脑端把 Antigravity 的 Remote Control 打开，手机浏览器登录 [antigravity.google](https://t.co/T5tjjXimXw)，添加到主屏幕就跟普通 App 差不多

出门在外照样用手机调动家里电脑的 Antigravity 干活，走的是 Antigravity 的额度，还能读写本地文件

唯一前提是电脑得开着机、保持联网

3、用 Remote Agents 放云端跑，关电脑也能用手机派活

Pro 和 Ultra 个人账号可以在 Antigravity 里建 Remote Project，把自己的 GitHub 仓库接上去

这样电脑关机也没关系，手机打开 [antigravity.google/remote](https://t.co/bIKluL6OtH) 就能发任务、看进度，把 Antigravity 的额度放到云端用满

接私有知识库的话，提前检查下仓库里别留明文密钥和 token

这 3 种都是官方原生路径，不用折腾第三方插件，也不用担心账号合规问题

我自己目前更偏向 1 加 2 的组合，手机查资料用 Gemini App，真要动笔和折腾文件就切去 Remote Control，把两边额度都利用起来

你平时 Google 会员的额度都是怎么分配的，这 3 种里哪一种更适合你
