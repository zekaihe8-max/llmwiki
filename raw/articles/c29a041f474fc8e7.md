Grok Bot 终于可以继承其他 AI 的记忆了，以前折腾的 Hermes Agent 总算没白费🔥

这个功能我觉得非常实用，尤其是之前长期使用 Hermes Agent、OpenClaw，或者其他开源 Personal Agent 的朋友

我以前折腾 Hermes Agent 的时候，积累了不少记忆、个人偏好和工作习惯，换一个 Agent 最麻烦的就是需要重新让它了解自己

现在 Grok Bot 终于支持记忆导入了，而且操作非常简单

1、找到导入入口

电脑端：Settings → General → Import → Start Import

手机端：Settings → Import Memory

如果没有找到，可以先更新 APP，部分账号可能还在逐步开放

2、让原来的 AI 整理记忆

点击 Start Import，复制 Grok Bot 提供的提示词

然后把它交给 ChatGPT、Claude 等 AI，让它整理之前积累的个人信息、长期偏好和工作习惯

如果你之前用的是 Hermes Agent 或 OpenClaw，也可以让它们根据自己的记忆文件整理一份内容

3、导入 Grok Bot

把整理好的内容复制回 Grok Bot，点击 Add to Memory，就会交给你的主 Bot 处理

整个过程不需要重新聊天几百轮，相当于把之前积累的个人信息直接迁移过来

不过要注意，它不是直接同步其他 Agent 的数据库和聊天记录，而是通过整理后的文本导入记忆，最好先检查一遍内容，避免把过期信息和敏感数据一起带过去

我这边看到最近刚更新到的新功能，就是最近这几个版本才加入的 然后配合到我自己沉淀的个人知识库，再加上机器人的记忆，我整个 Hermes agent 的迁移就已经完整了
