Claude Code 跑分垫底，被 Pi 反超了🔥

昨天 OpenClaw 联合 Hugging Face、UC Berkeley 发了份 ShellBench 评测，从上千万次真实交互里筛出 100 个脏活仓库，拉着 12 个模型在 5 套 Harness 上跑了 5.3 万多次

我一开始以为闭源的 Claude Code 肯定稳拿第一，结果平均通过率排下来，OpenClaw 45.23%、Pi 45.22%、Hermes 45.11%，全都压过了 Codex CLI 的 45.04%，Claude Code 只有 42.87% 排在最后

更有意思的是耗时，OpenClaw 跑完一轮中位数要 2.86 分钟，Pi 只要 1.31 分钟，通过率几乎一样，时间省了一半多

本质还是上下文和工具足够干净，真实项目里本来就有一堆过期文件和干扰项，外层再塞太多提示词和花哨机制，模型跑久了反而容易乱

刚好今天 Pi 发了 1.7.0 正式版，把对比衬得更明显了

别人都在忙着往客户端里塞埋点、算配额，Pi 这次干脆把安装和升级的遥测代码全删了，连环境变量和配置开关都没留

顺手还把昨天聊过的终端断点恢复协议 OSC 7577 正式发了出来，连切思考档位掉 Copilot 缓存这种省钱细节也给修好了

越来越喜欢这种克制的路子，软件不大，默认功能也不多，但是干起活来一点都不含糊，还不惦记你电脑里那点数据

你们平时写代码跑长任务，现在主力留的是哪套 Harness？
