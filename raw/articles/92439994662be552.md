Grok Bot 也能打通国内生态了，推荐 5 个值得收藏的官方 MCP 和 Skill🔥

我之前一直觉得 Grok Bot 最大的短板之一，就是对国内生态的支持不够完善

没想到最近国内不少大厂已经开始主动开放 MCP 和 Skill 了，点咖啡、领外卖券、叫车，甚至跑腿都可以让 AI Agent 帮忙

我整理了 5 个比较有代表性的，大家可以尝试接入 Grok Bot

1、瑞幸咖啡｜MCP + Skill + CLI

这个我觉得非常实用，直接告诉 AI 想喝什么咖啡，它就能帮你查附近门店、选择商品、匹配优惠券，最后确认付款

官方同时提供了三种接入方式，对经常喝瑞幸的朋友很方便

[open01.luckincoffeecdn.com](https://t.co/bOy2GGjTtn)

2、美团｜官方 Skill

美团已经开放了红包助手和跑腿 Skill

可以让 AI 帮你领取外卖优惠券、查询红包，还能叫骑手取快递、送东西或者帮买商品

以后很多跑腿的小事，可以直接交给 Agent

[clawhub.ai/meituan-tech/s…](https://t.co/OpjaBynvjw)

3、麦当劳｜官方 MCP

麦当劳中国也推出了自己的 MCP 服务

支持查询菜单、领取优惠、麦乐送、到店自取、订单查询，连积分兑换券也支持

需要自己申请 MCP Token，配置完成后就能通过 AI 操作

[open.mcd.cn/mcp](https://t.co/mQ9gh29swt)

4、滴滴出行｜MCP + Skill

这个也很有意思，可以让 AI 帮你规划路线、预估打车费用、查询司机位置和订单

普通版可以跳转滴滴叫车，Pro 版还支持直接创建和取消订单

[mcp.didichuxing.com/claw](https://t.co/rMIXoWi1al)

5、高德地图｜官方 MCP

如果你经常让 Grok Bot 帮你安排出行，我建议看看这个

支持地点搜索、路线规划、周边查询，还能把 AI 整理的旅行攻略直接生成高德专属地图

[developer.amap.com/api/mcp-server…](https://t.co/cC3RH3grgo)

我觉得这几个项目挺有代表性的

以前想让 Grok Bot 对接国内生活服务，很多时候还得自己写接口，现在国内厂商已经开始把这些能力主动开放出来了

而且 Grok Bot 本身就支持 MCP 和 Skill，理论上可以通过安装和配置把这些服务接进来

不过官方提供接口不代表 Grok Bot 已经全部原生集成，实际使用还需要完成授权、配置，涉及支付的操作最好保留人工确认

以后出门前直接让 Grok Bot 帮我点杯瑞幸、领张美团券、再叫辆滴滴，这才是我想要的 Personal Agent

国内生态这块，总算开始有点意思了
