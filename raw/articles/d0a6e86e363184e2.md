苹果今年彻底砍掉英特尔芯片支持，大家都以为黑苹果凉透了

但最近在非苹果设备上硬装苹果系统，反而迎来一波大爆发
连平时写代码的 AI 工具，都被玩家拉去手搓底层驱动了

这阵子扎堆冒出来的实测战果，个个都很离谱：
华硕骁龙本跑通原生 macOS 27，显卡加速和触控板都能用（见图 1）
RK3588 开发板直接硬启 macOS 27.2，网口和核显初步通了
Switch 掌机装进 iOS 17，开机直接拿 Safari 刷网页
开源驱动 NullMoth 让英伟达 RTX 50 系显卡跑上图形加速

苹果底层又没开源，以前几年啃不动的驱动，怎么突然扎堆跑通了？

以前折腾黑苹果，装系统倒不难，真正卡死人的是写驱动
苹果不公开源码，想让非苹果硬件听懂指令，只能硬拆底层程序
拆出来的代码像天书一样，写一套驱动动辄死磕几百小时

但现在圈里都说，这是给 Claude Code 配上 Ghidra 开了挂
Ghidra 是反编译工具，负责把苹果藏起来的底层程序拆成代码
接着 Claude Code 和 Codex 通读代码、看报错，一轮轮打补丁

过去顶尖逆向高手才啃得动的活，现在普通极客带 AI 就能试！

很多人拿 Claude Code 或 Codex，还只当写网页的助手
其实它最狠的地方，是把普通人碰都不敢碰的底层黑盒撬开了

硬件厂以后想靠闭源驱动把用户锁死在自家机器上，没那么容易了
