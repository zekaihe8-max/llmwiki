为什么要它：从剧情出发每次重写打戏，H3 常常打得像流水账、机位死板、刀插进身体、两人换边。这个库里的写法都出过片、人工看过；踩过的坑写成了检测规则，写错了提交前就会被拦下。

## 三种用法

[#三种用法](#三种用法)

- 当 AI 助手的 skill（推荐）：装进 Claude Code 或 Codex，说“帮我写一段打戏：……”，它会自动挑镜头块、整句搬、跑检查。

- 不用 AI 助手，只写提示词：翻 库对照.md 挑镜头块，照 SKILL.md 的写法拼，跑 python3 工具/检查.py 提示词.txt，再拿到你自己的 H3 环境去跑。

- 有 ComfyUI + H3：再用 工具/出片.py 一条命令出片，或 --只导出 拿填好提示词的工作流 JSON 自己在 ComfyUI 里跑。

## 显卡

[#显卡](#显卡)

写提示词不用显卡。 下面只说出片。

配置
状态

RTX 4090 48GB 改装版 + 123GB 内存

实测。1664×928、243 帧（约 10 秒）一段，提交到下载完约 6–8 分钟

48GB 以上的专业卡（RTX 6000 Ada、L40S、A100、H100 等）

显存够，理论上可以，未测

24GB（普通 4090、3090）

未验证。光模型就超过 24GB（主模型 int8 21GB + 文本编码器 int8 27GB + 视频 VAE 5GB），只能靠把模型轮流放进显存、换 nvfp4 文本编码器（15.7GB）等办法，会慢很多，能不能跑通没试过

更小的显卡 / 没有显卡

不建议本地跑。只用写提示词那部分，或者租云显卡

实测机器内存 123GB；模型轮流放进显存时会占内存，内存小的机器可能装不下。硬盘留 60GB 给模型。

### 搭工作流

[#搭工作流](#搭工作流)

仓库不带工作流文件，只写了搭法：照 [docs/工作流怎么搭.md](/huangserva/h3-fight/blob/main/docs/%E5%B7%A5%E4%BD%9C%E6%B5%81%E6%80%8E%E4%B9%88%E6%90%AD.md) 在 ComfyUI 里搭好（约 20 个节点），用“导出（API）”存成 库/模板/三参考图.json（有参考图）和 库/模板/无参考图.json（只靠提示词）。节点编号随意，出片.py 按作用找节点；参考图张数、首帧引导、种子、输出名都由它填。

搭完跑 python3 工具/自检.py，它会去 ComfyUI 的 /object_info 核对每个节点和模型文件。

## 快速上手

[#快速上手](#快速上手)

```
<span class="pl-c"><span class="pl-c">#</span> 0. 先搭好工作流（见上）</span>
<span class="pl-c"><span class="pl-c">#</span> 1. 写：从库里挑块拼好 my_fight.txt（或者让 AI 助手写）</span>
<span class="pl-c"><span class="pl-c">#</span> 2. 查：有“错误”就改</span>
python3 工具/检查.py my_fight.txt
<span class="pl-c"><span class="pl-c">#</span> 3. 出片：三张参考图 = 人物、场景、对手</span>
python3 工具/出片.py my_fight.txt --名字 fight01 --输出 out/ --参考图 hero.png arena.png rival.png
<span class="pl-c"><span class="pl-c">#</span> 4. 下一段接着打：首帧钉上一段最后一帧</span>
ffmpeg -sseof -0.05 -i out/fight01.mp4 -frames:v 1 out/fight01_last.png
python3 工具/出片.py my_fight2.txt --名字 fight02 --输出 out/ --参考图 hero.png arena.png rival.png --首帧 out/fight01_last.png
```

库里的 k4d 就是用这个流程从库里整句搬出来的一段：照着 库/来源/k4d.txt 换人物和武器，是最快的入门。

## 局限

[#局限](#局限)

- 一段最多约 10 秒（243 帧），长片要多段拼接。

- 一段最多一句短台词。

- 闪电、法术、能量类特效为主的镜头不适合这套写法（会失控）。

- 写的镜头和出来的画面常有出入，一定要人工看片；看片发现的新问题请写回踩坑表。

- 24GB 显卡未验证。
