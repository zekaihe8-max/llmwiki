Pi Durable 社区又发现 5 个有意思的开源项目🔥

前面分享过不少 Pi Durable 的玩法，最近又去 GitHub 找了一圈，发现社区已经开始往多 Agent 协作、浏览器和跨设备这些方向发展了

整理了 5 个之前没介绍过的项目：

1、Durable Pi｜多设备 Agent 网络

把不同设备上的 Agent 连接起来，通过网页或终端统一管理，还能自动监控任务、排查故障，支持断点恢复

[github.com/disler/durable…](https://t.co/wY1710Zicx)

2、pi-agents｜持久化多 Agent

支持多个 Agent 并行执行、互相通信和任务编排，最有意思的是中途退出或者重启后，还能恢复任务

[github.com/mavam/pi-agents](https://t.co/drOVPmq6aS)

3、Pi Tab｜浏览器里的 Pi Agent

通过书签或 Chrome 扩展直接使用，可以读取网页、操作 DOM、填写表单，还支持跨标签页 Agent 协作

[github.com/aitimos/pi-tab](https://t.co/bdChrlktsB)

4、Foreman｜AI 监工

专门监督 Coding Agent 有没有跑偏、任务有没有完成，支持 Codex、OpenCode、Pi 和 Pi Durable 等

[github.com/thruwire/forem…](https://t.co/IAhHsEwq8D)

5、Entwurf｜跨 Agent 通信

让 Pi、Claude Code、Codex 等 Agent 互相发送消息、恢复会话，不需要改变原来的运行方式

[github.com/junghan0611/en…](https://t.co/ztJfcgSFdh)
