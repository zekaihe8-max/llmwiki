Today, we launched MemT-1.0-Pro [#MemT](/hashtag/MemT?src=hashtag_click), a memory-native model developed in collaboration with
[@NVIDIAAIDev](/NVIDIAAIDev).

Built on NVIDIA Nemotron 3 Ultra, with distributed training powered by NVIDIA Megatron-Core and Megatron Bridge.
Here's how it compares to MemT-1.0-Flash:
🧠 554B parameters with native memory
📈 +4.76 pts on BEAM-1M
📈 +6.51 pts on MemoryAgentBench

Store history in native memory. Use it in later interactions — without keeping the original history in the query context.

Advancing memory for long-horizon AI agents.
