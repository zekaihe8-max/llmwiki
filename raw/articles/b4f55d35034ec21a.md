Pi 1.7.0 发布，删掉遥测还补了会话恢复🔥

我看了一下完整的更新日志

这版没有硬塞花哨概念，主要是把终端断线恢复、缓存省钱和隐私细节磨得更顺了

整理了 5 个比较值得关注的变化：

1、终端会话恢复正式落地，补上多目录与权限保护

昨天聊过的 OSC 7577 协议这版正式发出来了，支持协议的终端重启后能自动拉起刚才的会话

这次还加了 --agent-dir 参数（对应 PI_CODING_AGENT_DIR），分项目配独立目录跑的时候，恢复回来不会串回默认目录，而且会自动带上启动时的 --tools、--no-extensions、--skill 等限制参数，防止重启后权限被放大

2、彻底移除了安装和升级遥测

这版把新装和更新时的 /api/report-install 遥测上报删掉了

连 enableInstallTelemetry 配置项和 PI_TELEMETRY 环境变量也一起移除，本地跑着更干净

3、GitHub Copilot 切思考档位和改工具不再掉缓存

用 Copilot 接模型的可以重点看这条，现在在支持的 Claude 5.x 和 GPT-6 模型上中途改思考强度，或者在 Claude 5.x 上增减工具

都能保住 Prompt Cache，而且 Copilot 下的 Claude 模型也支持缓存保温了

4、Codemode 支持生图和画幅控制

现在可以在 Codemode 里用 Radius 生图，调 OpenRouter 生图模型时也能给 models.generateImages() 传 aspectRatio 和 size 指定比例尺寸

Radius 的生图和分类模型也进了内置列表

5、多家平台默认模型同步换新

Cloudflare Workers AI 和 AI Gateway 默认模型换成了 GLM-5.3

千问个人 Token Plan 里的 qwen4-max-preview 切到了正式版 qwen4-max，百灵默认模型也换成了 Ling-3.1-flash

另外还修了一批实用细节，比如双感叹号命令输出不再算进上下文预估（避免大输出误触发提前压缩）

models.json 写错字段在 JSON 和 RPC 模式下会有明确警告，Windows 按 Ctrl+Break 退出不再把终端搞乱，Bedrock 上 Kimi K3.1 和 GLM 5.3 思考档位失效的问题也修好了

整体还是熟悉的 Pi 风格，更新全在解决断线、掉缓存、误压缩这些日常真会碰到的痛点

顺手把遥测删干净也挺拉好感，在用 Pi 的敲一行 pi update 就能升上去了
