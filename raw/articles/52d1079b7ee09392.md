Coze 企业版下线：AI Agent 平台，正在被 AI 自己淘汰？

2024 年，Coze 凭借零代码 Bot、插件和可视化工作流迅速走红，让普通人也能开发 AI Agent。

2025 年，Agent 开发逐渐走向工程化，MCP、工具调用、多 Agent 协作成为主流。

2026 年，Claude Code、Codex 等 Coding Agent 崛起，开发者开始直接用自然语言生成代码、编排工作流、构建 Agent。

Coze 企业版此时宣布分阶段下线，或许并非巧合。

过去，AI Agent 平台解决的是「普通人不会编程」的问题。

现在，Coding Agent 正在降低编程本身的门槛。

当 AI 可以直接帮你造工具，为什么还要被一个低代码平台的能力边界束缚？

真正被颠覆的，可能不是 Agent，而是上一代 Agent 开发方式。
