DeepSeek Harness 最容易踩的 3 个坑，解决方法都给你整理好了🔥

最近一直在研究 DeepSeek Harness，然后遇到了几个比较典型的问题，就把解决方案和对应的配置分享了出来

因为我自己主要使用桌面 APP，所以这次整理了 3 个适合 APP 端的解决方法，基本不需要敲命令

1、OpenCode Go 接入后出现 400 错误

如果是开启自动审查权限后报 MissingSessionID，直接在对话框左下角把权限切换成工作区内修改就行

旧版本普通对话也报错，可以在左侧插件 → 添加插件，搜索 dsh-opencode-session 安装，完全重启后生效

2、更新插件后，整个 DSH 无法启动

一般先检查第三方插件有没有依赖冲突，能进入 APP 的话，直接在插件列表里逐个禁用排查

如果启动时已经报错，新版桌面端会弹出恢复窗口，可以选择禁用第三方插件、备份配置并重启

注意这个操作可能重置原来的插件配置

3、长会话 Token 越来越多，压缩失败

最简单的方法就是在对话框输入 /compact，手动触发上下文压缩

如果使用的是 96K、128K 这类小窗口模型，社区还发现默认压缩预留空间可能过大，需要进一步调整 Agent 预设里的 Compaction 参数

DeepSeek Harness 的插件化设计确实很有意思，但是是目前稳定性还有提升空间

我怀疑梁子的心思不放在这上面，所以针对 DeepSeek harness 很多地方都没有去做细节上的完善，不过社区已经有相关的插件去做补充了

希望官方能下场 自己去解决这些细节内容，毕竟把维护权交给社区 对大家来说也不是很安全
