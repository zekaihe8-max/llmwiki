6 个 AI Agent 开源开发者福利，最高还有上万美元的额度补贴🔥

其实很多 Agent 或 AI 厂商，针对开发者都有一定的补贴和奖励

我找了一圈，发现已经有不少厂商开放了对应的申请入口，只需要填写自己的开源项目和相关信息，通过审核之后，就有机会拿到会员或者 API 额度补贴

我把几个看到的项目收集了起来：

1、DeepSeek Harness

官方正在筹备插件开发者激励，包括 Token 支持、技术交流和作品推荐，目前已经开放意向登记，具体额度还没公布

申请：[trtgsjkv6r.feishu.cn/share/base/for…](https://t.co/U2ahPtYcCB)

2、Cline

针对开源项目提供 $1,000～$10,000 的 Credits 资助，个人开发者和小团队也可以申请

申请：[cline.bot/oss-grant](https://t.co/YqFJHcbnEB)

3、OpenAI Codex

主要面向开源项目维护者，通过审核可以获得 6 个月 ChatGPT Pro，还有机会获得额外的 API Credits

申请：[openai.com/form/codex-for…](https://t.co/c0T1leXVc1)

4、Claude

针对开源维护者和活跃贡献者，官方目前提供 6 个月 Claude Ultra 会员福利，对项目影响力和贡献记录有一定要求

申请：[claude.com/contact-sales/…](https://t.co/pm4tWJa2vA)

5、Kilo Code

开源项目赞助计划，入选后可以获得企业版权益，部分项目最高每月 $200 Credits，还有代码审查工具

申请：[form.typeform.com/to/KeAxDfj5](https://t.co/Tm2QufDwmj)

6、Dify

提交原创 AI Workflow 模板，入选官方 Marketplace 热门推荐后，可以获得 1 个月 Dify Professional 会员

活动：[dify.ai/blog/build-for…](https://t.co/9gxYoi4tXn)

其实这些福利还是挺值得关注的，特别是自己本身就在维护开源项目，或者准备开发 Agent 插件的兄弟

不过需要注意，不是说申请了就一定能拿到对应的奖励，还会有一定的审核，有些对项目 Star、下载量和贡献记录也有要求

另外，像 Claude 这些平台，即使有开发者福利，违规使用账号依然可能面临封号风险

所以说，利益和风险并存，大家还是根据自己的实际情况去申请就好
