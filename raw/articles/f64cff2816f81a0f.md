国内 AI Coding 套餐现在真的卷起来了，40 元左右就能用上不少旗舰模型 🔥

我最近看很多 AI 厂商都开始发福利了，我就去逛了一圈 看一下国内大厂的 AI Coding Plan，发现现在很多厂商都开始转向 Credits、Token 等额度计费，套餐也越来越适合 Claude Code、OpenCode、OpenClaw 这些 Agent 工具

1、火山方舟 Agent Plan Small｜40 元/月

这个最大的优势就是模型选择多，不需要单独购买各家的套餐

支持豆包 Doubao Seed、DeepSeek V4 系列、GLM-5.3、MiniMax M3、Kimi K2.8 Preview 等模型，部分更高阶模型需要升级套餐

额度方面：

每月 20,000 AFP，每周 7,000 AFP，每 5 小时 2,000 AFP

AFP 是火山自己的积分单位，不同模型按照输入、输出 Token 和对应系数扣除额度

比较适合平时喜欢切换模型，或者想用不同模型测试 Coding Agent 的开发者

购买：[volcengine.com/activity/agent…](https://t.co/gYiBP36YDh)

2、小米 MiMo Token Plan Lite｜39 元/月

小米最近的 Token Plan 我觉得也挺有意思，主要使用自家的 MiMo 模型

支持 MiMo-V2.6-Pro、MiMo-V2.6-Flash，还有语音识别和语音合成模型

每月提供 41 亿 Credits，所有模型共享额度

比如 MiMo-V2.6-Flash，未命中缓存的输入每 Token 消耗 100 Credits，输出每 Token 消耗 200 Credits，Pro 版本消耗更高

比较大的优势是没有独立的 5 小时额度限制，可以在一个月内集中使用

另外目前首购有 88 折，北京时间凌晨 0 点到 8 点还有 0.8 倍额度消耗优惠

购买：[mimo.mi.com](https://t.co/oKCFJ5dqGz)

3、MiniMax M Plan Plus｜49 元/月

MiniMax 这款更偏向长期运行 Coding Agent 的用户

支持 MiniMax M3、M2.7，以及图像、语音等模型能力

官方给出的 M3 月度参考用量约为 6 亿以上 Token，同时支持 3～4 个 Agent 并发，最高支持 1M 上下文

不过这里的 6 亿 Token 是根据 M3 使用方式估算的，并不是所有模型都能直接使用这么多

文本、图像、语音会共享套餐额度，M2.7 也有对应的滚动窗口使用限制

购买：[minimax.cn/m-plan?tab=ind…](https://t.co/li4QCqRtIA)

这三款其实各有各的优势

如果喜欢折腾不同模型，我会优先考虑火山方舟，毕竟一个套餐就能切换好几家厂商的模型

如果比较在意连续跑 Agent、不想频繁遇到 5 小时额度限制，小米 MiMo 值得尝试

这里面大部分都是使用国内厂商，但是国内厂商的模型能力参差不齐，但是总体的 token 使用数量的话还是值得考虑的

如果你的业务需求不高 然后需要大量的 token，那我就建议你可以考虑一下国内这几个厂商的套餐，而且现在很多套餐都有对应的优惠 可以多加一起参考
