即使是让 Agent 操作软件，但人还是要看结果的，所以现在软件设计重心变成了怎么让人更好的验收。

举几个 Claude Artifacts 设计的好的地方：

1. 多人协作 -> 人和 Agent 协作

以前的软件比如 Google Docs、Figma 会强调人和人之间的协作，你也可以很方便的看到谁在操作、操作的历史。

而在 Artifacts 里面，你能看到 Agent 正在做的操作，也能看到 Agent 所有的操作历史。你可以在设计稿里面添加评论告诉 Agent 怎么改，Agent 改完还会回复你的评论让你再看看。

2. 人直接操作 -> 标记和评论

以前软件是人操作为主，所以要考虑人怎么用，但是很多操作是真的很复杂，UI 操作也只能设计的很复杂。

举个例子来说，传统视频剪辑软件，我要把某一个时间段静音的视频剪掉，我就只能通过有一个 Timeline，有专门的带 Waveform（波形）的音频 track，然后用户通过放大 Timeline 的波形去甄别出来哪里是没声音的，然后手动打上标记，最后再点击删除把标记的一段删除掉。

这个场景换到 Claude Motion，它只有一个很简单的代表时间和场景的 Timeline，需要剪辑其中一段，只要大致框线一个时间段出来，然后写一条评论发给 Claude：帮我把这一段视频中静音的部分剪掉，然后 Claude 就会自己去找出来静音部分去删除，完全不需要你去放大 Timeline 去标记这些繁琐的操作。

3. 人主导 -> Agent 采访人之后实施

传统软件都是你自己想清楚了再去软件上实施，就像写 PPT/Slides，得你自己有想法才能写的出来，遥想当年要写一个 PPT 打开 PowerPoint 半天不知道写点啥好。

现在你使用 Claude Design 或者 Claude Slides，只要大致的描述一个想法，甚至很模糊，然后 Claude 会想你提一些问题，你只要做几个选择题，然后就能把你的想法猜的一个差不多，接下来就是按照你的想法生成，甚至于还会出几个版本让你选择。

当你看到已经设计出来的结果，会把自己原本模糊的想法具像化，可以更容易的知道是不是自己想要的结果，再做出调整，不得不说比起以前要容易了很多。
