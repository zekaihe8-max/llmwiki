# 重磅开源：你的微信聊天记录终于可以直接转发给 Grok Bot了！

7 min read

大家的痛点被我攻克了！沉淀知识库，挖掘商机，提炼要点等等……一键让 Grok Bot 打通你的微信，今天直接免费开源！

以前手动搬运：

- 看到有价值的信息，只能一段段复制聊天文字。
- 遇到图片或者文档，得一个个手动存到电脑本地。
- 打开 Bot 窗口贴完文字，再把文件拖进去拼在一起。

现在直接转发：

- 微信里顺手一点，记录和文件打包送达。
- 省掉所有中转保存和来回切换。
[/cgnot996/article/2119298485803794467/media/2119253772019130368](/cgnot996/article/2119298485803794467/media/2119253772019130368)

折腾两次人就彻底烦了。为了把微信和 Bot 彻底打通，我做了 Grok Bot Anywhere，让 Grok Bot 走进更多场景，全面开源。

## 微信转发，走一遍

在微信里把聊天记录给到 Bot，以前想都不敢想，现在顺手得不行。

你在微信里操作起来只有这几步：

1. 选好要整理的聊天记录，点击转发，选择其他应用，再点选择电脑中的应用，菜单里直接列着各个 Bot 的名字。想发给谁就点谁。

[/cgnot996/article/2119298485803794467/media/2119253780789354496](/cgnot996/article/2119298485803794467/media/2119253780789354496)

2. 屏幕上马上弹出一个悬浮输入框。微信导出的压缩包已经作为附件带上了，你可以补一句你想让 Bot 做什么。

[/cgnot996/article/2119298485803794467/media/2119253787303202817](/cgnot996/article/2119298485803794467/media/2119253787303202817)

3. 敲下回车直接发出去，上传附件时界面上有清晰的进度条，发大文件心里也能知道发送的进度。

[/cgnot996/article/2119298485803794467/media/2119253792277618688](/cgnot996/article/2119298485803794467/media/2119253792277618688)

4. 发送完成后，知识管理员那边立刻收到了压缩包和你刚才补充的那句话。

[/cgnot996/article/2119298485803794467/media/2119253799529586688](/cgnot996/article/2119298485803794467/media/2119253799529586688)

5. Bot 解开聊天记录，麻利地回了一份概览，群聊主题和讨论要点一清二楚。

[/cgnot996/article/2119298485803794467/media/2119253807700078593](/cgnot996/article/2119298485803794467/media/2119253807700078593)

沉淀知识库、提炼要点、挖掘商机都从这一步开始。

需要说明的是，解压、分类、入库这些动作都是 Bot 侧自己配的规则，工具只负责送到。挖掘商机怎么处理，同样看你给 Bot 设定的逻辑。

用起来也完全可以放宽心。

软件不破解微信，也不读微信数据库，走的是微信官方开放的出口。

合并转发导出的压缩包是微信自己的出口，里面包含完整的文字和附件。聊天记录里没下载到本地的文件不会进压缩包，转发前记得先点开加载，敏感内容也要先想好哪些能发。

这里的对接方案参考了微信流，要特别感谢苍何老师开源的探索。

这是我个人做的非官方项目，和 xAI 没有任何合作、授权或背书关系。名字是答疑群同学一起取的，寓意 Grok Bot 无处不在。

## 每个 Bot 单独配

每个 Bot 承担的事情不一样，规矩自然不能搞一刀切。

你可以给手头的每一个 Bot 单独定规矩：

- 接收转发：随时开关，决定它要不要出现在微信转发列表里。
- 收到之后：自由选择先放进输入框看一眼，还是直接发走。
- 来源设置：可以区分通用来源和微信来源。
- 发送后动作：设置发送完是跟随全局、自动隐藏还是直接打开 Bot。
- 独立快捷键：分别设置唤醒输入框和在官方应用中打开该 Bot 的快捷键。
[/cgnot996/article/2119298485803794467/media/2119253814922649600](/cgnot996/article/2119298485803794467/media/2119253814922649600)

把每个 Bot 的边界和习惯设定好，用起来就像专门定制的一样顺手。

## 发过的都有账

在发送记录里，已发送和待发送的状态全都能看得明明白白，连 Bot 的回复也留在记录里。遇到待发送的内容，点一下就能放回输入框再发。

[/cgnot996/article/2119298485803794467/media/2119253823097286656](/cgnot996/article/2119298485803794467/media/2119253823097286656)

背后的机制其实很简单踏实：

- 先存本地再发：内容先完整保存在本地电脑上，排队发送，断网或者没登录都不会丢。
- 结果不明就停下：发送结果不明确时暂停该 Bot 等你核对，不擅自自动重发。
- 失败文件留本地：只要没发送成功，文件一直保存在本地磁盘，随时可以重试。
[/cgnot996/article/2119298485803794467/media/2119253832039530496](/cgnot996/article/2119298485803794467/media/2119253832039530496)

微信分享组件完全没有网络权限，只老老实实把内容写到本地。

## Touch Bar 彩蛋

老款 Mac 上的 Touch Bar，总算找到正经用武之地了。

带 Touch Bar 的 Mac 可以在设置里勾选常驻，把主力 Bot 直接排在键盘上方。

[/cgnot996/article/2119298485803794467/media/2119253840675713024](/cgnot996/article/2119298485803794467/media/2119253840675713024)

手指在键盘上方顺手一碰，输入框马上弹出来。

点一下就直接打字，这种随手唤醒的手感相当舒服。

[/cgnot996/article/2119298485803794467/media/2119253849626329088](/cgnot996/article/2119298485803794467/media/2119253849626329088)

要是电脑没有 Touch Bar 也不用慌。普通快捷键随叫随到。

macOS 按 Control+Option+Space，Windows 按 Ctrl+Alt+Space，同样能在任何界面唤起输入框，这个快捷键也支持自己录制。

## 代码全部开源

把好东西全盘开源交给大家，心情确实痛快，但在 Windows 这边我也只能无奈摊手。

项目采用 MIT 协议开源，桌面端、系统原生部分，连同 SDK、命令行和技能文档全部公开，版本号是 0.1.4。

各系统的支持情况我老老实实交代：

- macOS：支持 macOS 14 以上系统，提供带签名和公证的安装包，装上登录就能用。
- Windows：代码全在仓库里，但签名问题我实在搞不定，公开分发会被安全机制拦截。
- Linux：暂时不支持。

0.1.4 的 GitHub Release 提供了 Windows x64 未签名压缩包，想用有两条路。

[/cgnot996/article/2119298485803794467/media/2119253917779513344](/cgnot996/article/2119298485803794467/media/2119253917779513344)

第一条路是下载 Release 的未签名压缩包。

解压后如果被 SmartScreen 或 Smart App Control 拦截，需要自行解除锁定，或者用自己的证书签名后再运行。

需要说明的是，这个压缩包尚未在 Windows 实机完整验证过。

第二条路是从源码本地构建运行，再用自己的证书签名。开发环境需要 Node 22.13 以上版本。

在终端里依次执行：

bash

```
<span style="--shiki-dark:#08c0ef;--shiki-light:#009fff">git </span>clone --recurse-submodules https://github.com/RongleCat/grok-bot-anywhere.git
<span style="--shiki-dark:#08c0ef;--shiki-light:#009fff">cd </span>grok-bot-anywhere
<span style="--shiki-dark:#08c0ef;--shiki-light:#009fff">npm </span>run setup
<span style="--shiki-dark:#08c0ef;--shiki-light:#009fff">npm </span>run dev
```

打包命令是 npm run package:win，产物未签名，同样要用自己的证书签名。

微信里只有一个 Grok Bot 入口，点开之后再选择具体的 Bot。这个入口依赖打包和签名，如果系统开着 Smart App Control，自签名大概率会被直接拦下。

实机跑过的是开发模式，包括启动、主窗口、命令行、微信入口和选 Bot 面板。打包后的压缩包、右键实际点击、输入框焦点还没跑过，欢迎 Windows 用户跑一遍后反馈。
