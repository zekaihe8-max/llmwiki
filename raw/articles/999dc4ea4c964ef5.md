课程第四周，请到了 Claude Code 作者，Boris 分享的核心并不是“多用 AI 写代码”，是把研发瓶颈系统化地自动化掉，并为六个月后更强的模型提前设计。他自己身边同时跑着“几千个” Claude agent；团队从去年 11 月起代码已接近全部由 Claude 写出，人均产出约提升 10 倍。

# 五条要点

1. 自动化你的瓶颈
代码写得太多以后，人开始只扫一眼、不再细读，于是他们把 code review 自动化了；下一步是审批。做法是先找出拖慢交付的环节，再为这些环节建系统，而不是泛泛“全面 AI 化”。

2. 为六个月后的模型而建
Claude Code 早期收入曾连续数月几乎持平，因为当时模型不够强；Opus 4 出来后增长才陡升。他的方法：读 agent 对话记录，看模型现在会在哪里失败；那里往往就是下一版模型会补上的能力。

3. 小团队更快
Claude Code 有好几个月基本就是他一个人。他认为有了 AI，一两个人可以超过百倍规模的团队；约束反而催生创造力。

4. 用“循环”思考
他祖父在苏联用穿孔卡片编程；他自己写能跑几天甚至几周、并不断拉起大量 agent 的循环。他预期手敲代码会逐渐变成穿孔卡片那样的过时技能。

5. 懂领域的人会赢
他预计 2027 年最好的会计软件会由会计来做。当写代码变便宜，真正的壁垒是对问题本身的深度理解。
