大家好，Magpie 今天有一个很重要的更新，就是 Magpie 中的 Claude Code Provider 的实现方式，从之前的使用 claude -p 改为了直接使用 Claude Code TUI。当然这是可配置的，你可以设置回以前的方案。

关于为何做这个改动，其实一开始我是不太情愿的，因为使用 Claude Code TUI 去做这个实现的话，会特别多额外的工作。收益不是很高，甚至 streaming 没法完美实现。但是最近发生了一件事情，让我觉得我不得不得不做这个改动了，就是有人发现直接使用 claude -p 在 5 小时窗口情况下，会比用 Claude Code TUI 多花两倍的 Token（虽然 Claude 今天已经取消了5小时窗口，但是我不确定 Anthropic 以后会不会有其他的区别对待）

换成直接用 TUI 方式实现，除了能够让我们的额度消耗跟直接使用 TUI 一模一样之外，另外一个更大的优势就是在 Magpie 使用 Claude Code Provider 跟用户直接使用 Claude Code TUI 是一模一样的，几乎没有了被检测出来在第三方使用导致封号的风险。
