New market map: AI-native collaboration workspaces in 2026 — 65 companies, 11 layers

The agent is becoming the teammate. At Linear, agents now create 50% of new work, up from 3% a year earlier, and 95% of paid workspaces have installed one. Meanwhile the open-source camp owns the GitHub stars: AppFlowy (78K), AFFiNE (74K), NocoDB (65K).

Layer by layer:

1. Docs & wiki (8) — Notion ($11B val.), Superhuman Docs (ex-Coda, $1.4B), Confluence + Rovo (80%+ of the Fortune 500 use Rovo). Pages and databases are now open to agents over MCP.

2. Spreadsheet-databases & no-code apps (9) — Smartsheet ($1B rev.), Airtable ($480M), [monday.com](https://t.co/0cCcKRMyg1) (~250K organizations), DingTalk and Feishu tables.

3. Work management (6) — Linear ($2.5B val.), ClickUp ($300M rev.), Asana, Wrike ($2.2B). Agents get assigned tasks like teammates.

4. Open-source wiki (5) — AFFiNE, AppFlowy, Outline (41K stars), Docmost. Self-hosted, with MCP built in.

5. Open-source low-code (5) — Appsmith, ToolJet (41K stars each), Budibase, NocoBase.

6. Open-source spreadsheet DBs (5) — NocoDB (65K stars), Teable (22K), Grist (12K), Baserow. Tables sit on real Postgres/MySQL.

7. Data platforms with a UI (4) — Directus (39K stars), Mathesar, Saltcorn.

8. Data versioning & review (5) — Dolt (25K stars), Bytebase (15K), lakeFS ($250M val.), Xata ($175M val.). Agents write on a branch first, a human merges.

9. Agent-native workspaces (4) — Agent-Native by [Builder.io](https://t.co/OKhg8uZQ9D), Busabase, Ambiguous, Dock. Every agent write carries a diff and an author.

10. Agent team workbenches (7) — Ando ($20M raise), SageOx ($15M), Adapt ($10M), Lua ($5.8M), Scuba.

11. Shared memory (7) — Engram ($600M val.), Letta ($70M), Mem0 (150K+ developers), Supermemory, Zep.

Data as of Nov 2026, public sources; company-reported numbers are labeled as such on the map.
