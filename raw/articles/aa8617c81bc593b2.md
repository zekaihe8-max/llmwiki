很多人想知道我的 Grok BOT 到底是怎么安排的

我在这里就分享一下

1、小墨助手：总入口，拆分跨领域任务，转给对应的 Bot

2、Agent 安装助手：安装、配置和管理各类 Agent，并负责备份

3、邮件管理助手：扫描 Gmail，管理待办和提醒

4、调研助手：一次性深度调研，查资料、比方案、出结论

5、X小助手：分析和收集 X 上的信息，起草发帖，发帖必须你确认

6、SubStack 运营小助手：负责 SubStack 的运营（职责按名字推测，需要你补充）

7、知识库小助手：维护 Obsidian 知识库，整理资料、对照选题台账

8、Github代码小助手：管 GitHub 代码和 PR，代码交给云端 agent，合并前等你确认

9、图片视频小助手：生成 X 长文封面、配图和动画短片

每一个机器人都有自己的职责，一开始我也尝试过使用群聊的方式让他们组合 但是我发现又浪费 token 做的事情又很差

所以后面的话我就没有再用群聊的方式去使用，如果感兴趣的话 我后面可以再发一期讨论一下

这里的机器人衍生是根据自己的需求去做处理，不要只知道添加别人的机器人到自己的内容里面，这样的话又浪费 token 做事情又差
