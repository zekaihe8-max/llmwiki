谷歌会员白送的 Colab 算力点，除了生图生视频还能这么玩🔥

黑五很多人刚上车 Google AI Pro，其实 Pro 每个月送 200 个 Colab 算力点，Ultra 送 1000 到 2000 个，90 天不用就过期作废了

前面分享过用它跑图生视频和 3D，最近又翻了一圈 Reddit 和 GitHub，挑出 5 个现在最火、实用度拉满的新玩法

1、Unsloth（80.2k Star）

大模型微调和强化学习首选，支持 Qwen、Gemma、DeepSeek 跑 QLoRA 和 GRPO，比常规方案快 2 倍、省 70% 显存

新版自带 Unsloth Studio 网页端，在 Colab 上启动后会自动给出访问链接，拿来练手微调自己的专属模型特别合适

2、ACE-Step 1.5（15.2k Star）

目前最火的开源 Suno 平替，支持 50 多种语言，最长能生成 10 分钟完整歌曲，还能做翻唱和局部重绘

在 Colab 的 A100 上不到 2 秒就能出一首歌，平时做视频配乐或者玩 AI 音乐，拿算力点白嫖非常香

3、ComfyUI + LTX-2.5 / FramePack（148.5k Star）

本地显卡显存不够的，可以把 ComfyUI 丢到 Colab 跑 Flux.2、Qwen-Image 2.1，或者配 LTX-2.5 做音画同步视频、配 FramePack 跑 60 秒长视频

社区现成的一键 Notebook 很多，开一张 24G 显存的 L4 就能跑得很稳

4、MinerU 4.2 / DeepSeek-OCR-2（84.3k / 24.2k Star）

专门拿来给个人知识库和 Agent 洗数据，批量把复杂的 PDF、论文、财报和扫描件转成带公式和表格的 Markdown

本地 CPU 跑得慢，丢上 Colab 的 L4 或 A100 几分钟就能清完几百页文档

5、官方 Google Colab CLI + VS Code 扩展

今年官方补齐的开发者玩法，本地保留自己的 Git 仓库和编辑器，一条 colab ssh 或者装官方 VS Code 扩展就能挂载云端 GPU 跑代码，不用再折腾第三方 SSH 隧道

顺便提醒两个容易踩的坑

选卡优先用 L4，每小时只要 1.5 到 1.9 个算力点，200 点能跑 100 多小时，H100 只有 Ultra 能开而且一小时烧 18 点

另外算力点一旦归零会立刻切回免费版规则，正在跑的 WebUI 会被掐断，千万别拿去挖矿或者挂公共代理，容易触发风控
