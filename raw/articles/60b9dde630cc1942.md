让 AI 自己写代码调工具，连 Claude Code 都跟进了！！

昨天浏览器工具 browser-use 刚砍掉 24 个动作，改让 AI 写代码干活
紧接着 Claude Code 也上了个实验功能叫 Code Mode，路子一样

平时用 AI 写代码，是不是总觉得查几个文件就慢半拍，聊没几轮就变笨还烧额度？

以前调工具得一步步来，搜一次文件就把几千行原始结果全塞回对话里
来回折腾好多趟，上下文窗口很快就被废话撑爆了

但开了 Code Mode 后，你照样提需求
Claude 会直接写段 JavaScript 把多步活串起来
能同时跑几条命令，先在代码里筛掉废话，只把关键结果传回对话

跑测试、打包这类长任务，开自动模式还能直接扔后台跑，最长 2 小时
期间你照样在原窗口跟它聊别的，不用干等着！！

但先别急着冲，这功能还在实验，有两件事得提前说清楚：

第一，门槛挑人
只支持终端版（v2.1.323 起）配官方订阅或直连账号
中转站、云代理和桌面端都还用不了
想尝鲜的终端跑这句：
CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1 claude

第二，安全别大意
权限拦截还在，但官方明说沙箱只管脚本里的终端命令
代码本身和文件、网络、MCP 接口都在沙箱外，跑陌生项目记得套容器或虚拟机

两天内，开源项目和 Claude Code 走向了同一条路
以后写 Skill 或 MCP，别再堆几十个零碎按钮了
把接口做得方便 AI 写脚本串起来调，省上下文也省钱
