Hermes Agent 最新稳定版 v0.23.0，我把值得看的更新捋了一遍 👀

这次最实用的，是不同入口终于能接着干同一件事。

1. 浏览器也能用完整工作区
聊天、群聊、插件和设置都能在网页里操作。需要运行 Hermes gateway，并手动开启 Web Access，默认不开。

2. 终端、桌面、机器人共用会话
同一个聊天共用历史和任务队列，不用每换一个入口就重新交代背景。桌面里还能修改正在排队的指令。

3. 一个桌面连多台机器
本机、SSH 和远程 gateway 可以同时在线，管理不同机器上的任务不用反复断开重连。

4. 终端能看图，对话能回退
截图直接在支持的终端里显示。聊偏了可以用 /rewind 回到前面的消息，修改重发，或者另开分支。

5. 插件更新和付费工具更好管
插件支持批量更新，也能选择自动更新。付费 MCP 工具可显示价格和累计花费，超过设定上限会再次询问。

另外，最近上架的官方安全审查插件 hermes-security，需要单独安装，不是升级就默认自带。手机端目前仍是 Beta 候补，别当成正式全量上线。

截至11月9日，最新稳定版是 v0.23.0；后面的 Canary 是预发布构建。
