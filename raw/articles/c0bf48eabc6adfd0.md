It feels possible to me to check deterministically if a PR can be automerged or not.

Given very, very strict constraints:

- Only reorganises code
- Does not change the module graph
- Does not make test coverage worse
- X other rules

Feels like there is a tool here waiting to be created.

Obviously doesn't work for new features. Might not even work for bugfixes. But it might enable a class of refactorings that help us all make changes more confidently.
