10 月 29 日，Cursor 扩展商店遭到攻击。黑客将 Claude Code 插件的 2.1.313 版本替换成恶意安装包，试图远程控制用户电脑。该版本上架约 11 小时，Cursor 称最多有 5000 名用户受到影响。

安全研究人员发现，黑客只修改了插件的一个文件，在正常代码前插入 66 行恶意程序。插件看起来仍能正常使用，但只要 Cursor 加载它，恶意代码就会执行，不需要用户主动使用 Claude Code。

恶意程序会收集电脑名称、Git 邮箱、公网 IP 等信息，再偷偷添加黑客的 SSH 登录密钥，尝试开启远程登录，并让电脑主动连接黑客服务器。它还会安装开机自启的后台脚本，每隔约 60 秒尝试重新连接，让黑客有机会长期访问电脑。

不过，黑客的代码存在错误。大多数 Mac 和 Windows 电脑需要管理员权限才能开启 SSH 远程登录，因此这一步通常会失败。但如果用户原本就开启了 SSH 服务，黑客仍可能借助植入的密钥和远程连接进入电脑。而且即使远程登录失败，恶意密钥、后台脚本和设备信息收集也可能已经完成。

Cursor 随后下架恶意版本，一度关闭整个扩展商店，轮换密钥并重新构建服务。目前商店已经恢复，黑客服务器也已被关停。Cursor 称，没有发现其他插件遭到篡改，也没有证据表明 Anthropic 官方分发的版本受到影响。

受影响用户不能只卸载插件。 恶意脚本可能继续留在电脑里运行。Cursor 已提供清理工具，并建议检查 SSH 授权文件中是否出现 svc-telemetry。
