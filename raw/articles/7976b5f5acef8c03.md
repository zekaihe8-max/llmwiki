虽然很讨厌 Anthropic 动不动封号，但是不得不承认，它的 Agent 资料确实是目前讲得最透的🔥

前面分享过它的 5 篇入门文和 8 个网站，收藏破了一千，但是很多人还是不知道从哪看起，最后全在收藏夹吃灰

这次我不列零散清单了，干脆把这套免费资料排好顺序，整理成一篇能跟着练的学习路线长文

先用一张表把 8 个官方入口捋清楚，新手别一上来就去啃 Research 论文，主线盯住 Engineering 博客，再按这三层一步步往上走：

1、第一层先学会用，让 Agent 稳定干活

看懂团队用法和最佳实践那三节，给工具写一份不超过一屏的项目说明，配上能跑的检查命令，让它交活时附上证据而不是只给结论

2、第二层再学会搭，搞懂 Agent 是怎么拼出来的

读完工作流、工具设计和 Skill 这三篇，分清 MCP 和 Skill 各自管什么，照着官方模板写出第一个自己的 Skill

3、第三层读懂 Harness，明白换个外壳为什么差这么多

读透上下文工程、长任务和 11 月的记忆新文，再对照 Claude Code、Pi 和 DeepSeek Harness，看清压缩、断点交接和结果验证怎么落地

整套资料一分钱不用花，讲的全是通用方法，就算哪天被封号不用 Claude 了，换到 Codex、Pi 或 DeepSeek Harness 一样成立

文末按纯小白、写 Skill、折腾 Harness 分了三条路线，不用硬着头皮全啃完，先收藏起来，挑适合自己的那一层边看边练就够了
