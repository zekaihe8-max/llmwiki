Hermes Agent 也推出官方移动端了，Personal Agent 都开始往手机上靠拢了🔥

Nous Research 最近开放了 Hermes Mobile Beta，iOS 和 Android 都可以申请测试

之前我使用 Hermes 基本上都是通过 Telegram 或者远程连接，现在终于有自己的手机客户端了

我看了一下，比较值得关注的有 3 个地方：

1、远程接管 Agent

可以直接连接自己部署在 VPS 上的 Hermes Gateway，查看任务执行情况、管理对话，不需要在手机上重新部署 Agent

2、手机直接审批工具调用

Agent 遇到需要人工确认的操作，可以直接通过手机处理，不用一直守在电脑旁边

3、管理自动化任务

可以在手机上查看和管理 Routines，让 Agent 在服务器上长期运行，自己随时查看任务状态

官网：[hermes-agent.nousresearch.com/mobile](https://t.co/Z7crjL2MK8)

其实我发现最近不管是 Grok Bot、Muse、Dots，还是现在的 Hermes，都在往移动端靠拢

我觉得这也是必然的，因为手机才是离我们最近的设备，基本上每天都会带在身边，随时随地都可以使用

而且 Personal Agent 本来就不应该局限在电脑上，Agent 在云端干活，手机负责沟通、审批和接收结果

以后真正的个人助手，应该是我们需要它的时候随时能找到它，而不是每次有事都得专门打开电脑
