# Workbuddy 实测腾讯 Hy4 flash：给马斯克做一个最牛逼的网站！竟然没花钱？

5 min read

今天，腾讯 Hy4 flash 正式发布，我试着用这个模型给马斯克做了一个网站。

> [https://elon.qiaomu.ai/](https://elon.qiaomu.ai/)

马斯克虽然有很多缺点，但最近看到的两件事，让我对他非常敬佩，忍不住想做这个网站。

第一个是黄仁勋出事，X 刷到很多墙倒众人推的小丑，连给老黄写传记的光头作家都跳出来背刺。

而马斯克，一直在 X 上力挺黄仁勋，完全不怕引火烧身，仗义！

[/vista8/article/2122258229803827578/media/2122257615510183936](/vista8/article/2122258229803827578/media/2122257615510183936)

第二个，马斯克在 2020 年吹过的牛逼真的实现了！

昨天，SpaceX 的星舰第二级飞船 42 号被“大筷子”稳稳接住！

[/vista8/article/2122258229803827578/media/2122257640483155968](/vista8/article/2122258229803827578/media/2122257640483155968)

个人最喜欢的传记作家 Walter Isaacson 发出如下感慨

[/vista8/article/2122258229803827578/media/2122257674406600704](/vista8/article/2122258229803827578/media/2122257674406600704)

基于网站统计发现，马斯克吹的牛逼不会准时兑现，通常会晚 2.2 年，但兑现率极高。

乔帮主分享下用 Workbuddy 中免费 Hy4 flash 做这个网站的过程和技巧。

### 第一版开发

网站信源来自一个18岁法国少年。

他把 1998 年以来马斯克所有的访谈集合在了网站上，部分还提供了英文转写文本。

> [https://silicon-valley.tech/](https://silicon-valley.tech/)

可惜内容都是英文，视频内嵌 Youtube，估计很多人看不了。

所以，我增加 B 站上的对应视频，把英文转写都变成中文写的文章，还增加了很多有趣的功能模块。

比如马斯克提到的书，提到的电影，提到的人等。

网站开发初始提示词很粗糙：

[/vista8/article/2122258229803827578/media/2122257704995721216](/vista8/article/2122258229803827578/media/2122257704995721216)

运行了大概 1 小时左右，第一版上线。

[/vista8/article/2122258229803827578/media/2122257719176712192](/vista8/article/2122258229803827578/media/2122257719176712192)

项目用了两个自用 Skill，今天开源分享下。

服务器开发部署 Skill：实现网站开发，域名解析，服务器管理等。

npx skills add joeseesun/qiaomu-website-develop

Github 发布 Skill：把代码开源发布到 Github，写个清晰的 Readme 文档

npx skills add joeseesun/qiaomu-github-publisher

### 打磨迭代

开完好第一版，修了几个样式Bug，比如首页的栏目和顶部菜单有点重复。

[/vista8/article/2122258229803827578/media/2122257739296686080](/vista8/article/2122258229803827578/media/2122257739296686080)

比较令我意外的是，Hy4 flash 模型没讨好、盲从我的要求，它不建议这样调整。

有些朋友可能不知道，模型训练对齐的方式，很容易得到谄媚人类的模型，这也是 ChatGPT、Claude 等模型想规避的地方，没想到 Hy4 flash 现在也能做到。

在我解释原因后，它才开始听话执行。

[/vista8/article/2122258229803827578/media/2122257770170982400](/vista8/article/2122258229803827578/media/2122257770170982400)

类似小 Bug 修复差不多后，我大胆提了一个很模糊的需求：

> 这个开发好以后，你再想想基于这些数据可以增加什么有趣实用的模块，记住浏览者多数是中国人，热爱学习和马斯克，喜欢图形化，图表呈现，我希望我们网站成为最牛逼的马斯克资料网站，你拓展功能然后发布更新，不需要我的许可。

出来结果让我有点震惊！

Hy4 flash 给我加了个趋势页，第一个模式是话题热力图，深色代表这一年提及这个话题更多。

比如 2026 年提的最多的是人工智能、xAI和Grok、星链、无人出租车。

比如 2023 年提的最多的是 OpenAI 和推特（那年好像刚收购）

有很多有趣的东西，大家可以自己查看探索。

我们都知道，马斯克拥有很多家企业，这个页面有个模块，显示他的“注意力分配”。

23 年一多半精力都在推特（X），近两年主要精力恢复回 SpaceX 和特斯拉，但 xAI 显著增多（黄色）。

### 追求极致

教给大家一个通用的模型 “PUA” 话术：

> “还有什么你觉得可以优化的地方？” 或 “你觉得可以增加什么功能，让 xx 达到世界一流水平”。

[/vista8/article/2122258229803827578/media/2122257847782453248](/vista8/article/2122258229803827578/media/2122257847782453248)

它画了一张优先级图，不过我不想加对话式问答，因为需要消耗 Token。

个人觉得 RSS 更新、多语种和 MCP 有必要，另外还想加一个 Skill，安装分发更简单。

[/vista8/article/2122258229803827578/media/2122257861153804288](/vista8/article/2122258229803827578/media/2122257861153804288)

仅用了 17 分钟，它就开发了网站的 MCP 和 Skill 。

它按我要求把 MCP 部署到了服务器上，这样有地址的朋友都可以用。

只需跟你的 workbuddy 或 codex 说：

> “安装这个 MCP： [https://elon.qiaomu.ai/mcp](https://elon.qiaomu.ai/mcp) ”

注意，Workbuddy 安装好 MCP 后，需要按下图信任并启用 elon mush MCP。

[/vista8/article/2122258229803827578/media/2122257877062893568](/vista8/article/2122258229803827578/media/2122257877062893568)

安装好以后，可以这么问：“ elon mcp：马斯克的第一性原理是啥”。

[/vista8/article/2122258229803827578/media/2122257888160960512](/vista8/article/2122258229803827578/media/2122257888160960512)

它不仅画了一张图，还搜到一些访谈文本片段，我追问让它给我具体视频地址。

用了 23s，全搞定，不仅给了所有提及“第一性原理”的视频地址、语料页，甚至还给了时间戳。

[/vista8/article/2122258229803827578/media/2122257902375448576](/vista8/article/2122258229803827578/media/2122257902375448576)

还让它开发了一个 Skill，提示词有点绕口：

> 用乔木 skill 发布 skill 把这个 skill 开源到 github

[/vista8/article/2122258229803827578/media/2122257928015196160](/vista8/article/2122258229803827578/media/2122257928015196160)

这个任务开始有点跑偏，它用了 Workbuddy 技能市场的发布 Skill，纠正后才搞定。

马斯克 Skill 安装指令

> npx skills add joeseesun/elon-musk-archive

另外，再开源一个我的自用发布 Skill，它会自动测试 npx 安装指令，添加个人品牌信息，推送 Github。

你可以安装改造成自己的

> npx skills add joeseesun/qiaomu-skill-publisher

想要做好产品，其实没尽头，需根据自己和用户需求持续迭代。

比如我又让 Hy4 flash 增加了 “随机一篇”、“相关推荐”、“字体设置”等新功能。
