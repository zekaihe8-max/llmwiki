OpenAI 推出 Images 2.6：能导出 SVG 矢量图，还能做 GIF 动图，出图快一半

OpenAI 11 月 4 日发布图像模型 Images 2.6，ChatGPT 和 Codex 所有档位的用户今天起都能用，电脑、手机和网页版都有。

这次一个重要变化是能把生成的图导出成 SVG 矢量图，可以直接拿去做网站、App 和印刷品。另外还能生成 GIF 动图，出图速度比上一版快 50%，改图时能更准确地只改指定的地方。

开发者可以通过 API 调用这个模型。API 是开发者把模型接进自己产品的接口，按用量付费。OpenAI 说，现在全球用户每周在 ChatGPT、Codex 和 API 上生成 40 亿张图，平均每天超过 5 亿张。

【导出 SVG：图能直接拿去用了】

AI 生成的图通常是“位图”，比如常见的 PNG、JPG。位图由一个个小色点拼成，放大后会变糊，边缘出现锯齿。想把 AI 画的图标、Logo 用到正式场合，通常要设计师照着重新画成矢量图。

SVG 是“矢量图”，记录的不是色点，而是线条和形状本身，比如“从这里到那里画一条曲线，填上蓝色”。所以它放大多少倍都清晰，小到 App 图标、大到户外海报都能用同一个文件；在设计软件里还能单独改某根线条的颜色和粗细，不用整张重画。网站上的图标、Logo，大多就是 SVG。

OpenAI 在公告里说，导出 SVG 让设计“可以直接用在网站、App 和印刷品上”。这一项写在给开发者的新功能里，公告没说 ChatGPT 里能不能直接导出 SVG。

【GIF 动图】

GIF 是一种会循环播放的短动图，社交媒体上的表情包大多是这种格式。用户可以用一句话描述，或上传一张照片、一张手绘草图，让模型做成动图。

OpenAI 举的例子有：让品牌吉祥物动起来，把商品图做成循环小动画，拍视频前先用动图试一试角色动作。

合作方 OpenArt 公开的示例提示词是这样做的：先让模型在一张图里按 3 列 2 行画出 6 帧连续画面，再按顺序播放成动图。

这种把多帧画面拼在一张图里的做法叫“精灵图”，游戏动画常用。据 Decrypt 转述 The Verge 的报道，ChatGPT 的 GIF 功能是分批开放的，做好后可以调播放速度、逐帧查看和修改。

【两个 API 版本】

API 里有两个版本可选：

1. Flare 偏速度。画质设为低时，最快约 6 秒出一张图。海报、商品图这类需要排版的图，效果也有改进。

2. Sunburst 偏画质。画质设为中或高时细节更多，连续改好几轮，人物和商品的样子也更不容易走样。

这些速度和画质的说法都来自 OpenAI，目前还没有第三方测试结果。

【给开发者的其他新功能】

除了导出 SVG，还有两项：

1. 图片标注：ChatGPT 里已有的功能加进了 API。在图上圈出要改的位置，模型只改那一块。
2. 复杂度参数：控制模型动笔前花多少功夫安排画面。画质参数管细节清不清楚，复杂度管画面里能安排多少东西。OpenAI 建议简单修改用低复杂度，元素多、要求多的画面用中或高。

设计工具 Figma Weave、图片编辑应用 Picsart 等已经提前接入。

【价格】

ChatGPT 和 Codex 的所有订阅档位都能用 Images 2.6，公告没提要额外付费。

OpenAI 定价页显示，2.6 的 Flare 和 Sunburst 两款同价：生成图片每 100 万 token 30 美元，输入参考图每 100 万 token 8 美元，输入文字每 100 万 token 5 美元。这和上一代 2.5 的价格一样。

Flare 速度更快，但按 token 算的单价和 Sunburst 相同。定价页的批量处理价目表（不急着要结果的任务，价格减半）里暂时没有 2.6。

谷歌 10 月推出的同类模型 Nano Banana 2.1，生成图片也是每 100 万 token 30 美元，按谷歌定价页的换算，一张 1K 分辨率的图约 0.034 美元。
