# 没有应用后端的参考客户端

浏览器直接请求配置的 API，默认是 [api.deepseek.com](https://t.co/3FwgW6PKlb)。可以在线试用，也可以从 Releases 下载压缩包后双击 index.html；本地开发需要 Node.js 22.12+ 和 pnpm。直接用本地文件打开时，浏览器和 API 都要允许 file:// 的存储和跨域。

默认模型在代码里写死为 deepseek-flash。聊天走 Anthropic 兼容的 Messages / Files 接口，语音走独立的 ASR 和 TTS。多会话、消息分支、流式回答、深度思考、搜索引用、附件和朗读等，都是为了对齐官方 App 的体验。

# 搜索和读链接在服务端完成

客户端负责展示返回的内容块，并在下一轮把该回传的部分原样送回。阅读链接工具始终声明；是否加上 deepseek_web_search，由本地的智能搜索开关决定；深度思考对应 thinking。所有生成请求都固定带 safety_check: high，因此会走带服务端工具的那套协议。系统提示是一句固定身份说明：「该助手为 DeepSeek，由深度求索公司创造。」

回传时，历史思考和搜索结果不再发送；只有成功读过的链接会带上 signature，供服务端恢复网页正文。若服务端给出安全拒绝，已经流下来的思考和正文要由客户端丢弃，只保留工具块。新对话若还没有标题，结束时会向服务端要一句自动标题。每轮还会插入 latest_reminder，内容是日期、星期、位置、Web 和界面语言，日期按浏览器本地时区计算。

API Key 和设置存在 localStorage，会话和附件原件存在 IndexedDB。发送、上传和语音都会把相应内容交给 API；清空本地对话不会删除已经传到服务端的文件。历史导入导出用 ZIP，格式版本是 export_format_version: 3，可导入官方 DeepSeek 导出的记录；导入会替换全部本地会话。导出不含 API Key 和非图片附件原件，导入的回复也不能继续生成。
