斯坦福 CS329Z: Engineering AI Agents 公开课程资料

感谢 [@michaelryan207](/michaelryan207) 分享，讲座录像陆续上传到 Stanford Online 的 YouTube 频道，两份作业仓库也已开放。

CS329Z 课程详细介绍可以参考：
[x.com/shao__meng/sta…](https://x.com/shao__meng/status/2095330467000328632)

课程把重点放在从单一大模型转向复合系统：把检索器、工具、优化器等部件组合起来，并学会拆解问题、选择组件、整理数据、做评测和权衡设计。课表覆盖 Agent 结构、RAG、工具、记忆、多智能体、优化、数据、评测、安全、编程 Agent 和主动式 Agent，并有 Terminal-Bench、SWE-bench 的嘉宾课，以及 Andrew Ng 的对谈。

课程 Youtube 视频列表（最新发布两讲）：
[youtube.com/playlist?list=…](https://t.co/FNeTnCCrKH)

作业 HW1 由 Michael Ryan 设计，要求不用现成的 Agent 框架，只靠对话补全接口和自己写的代码，搭出一套 Agent Harness。学生先在真实公司邮件语料上做优先级分类、每日摘要、从零实现 BM25 检索和多跳问答；再把它做成一家虚构能源公司的内部助手，补上工具调用循环、文档检索、终端、上下文压缩、跨会话记忆、人工审批和防护。

用不到 5 美元的 API 额度，就能在家搭出自己的「Claude Code」。作业讲义给出的参考实现成本更低：跑完除模拟评估外的实时测试约 0.05 美元，评估再加约 0.18 美元。

[github.com/cs329z/assignm…](https://t.co/SsMRpYE9Ez)

作业 HW2 由 John Yang [@jyangballin](/jyangballin) 设计，使用 Harbor 框架制作接近 Terminal-Bench 风格的真实 Agent 评测任务。学生先跑 HumanEval、SWE-bench Verified、Terminal-Bench 2.1 等已有任务，再自己写一道包含问题、运行环境和验证器的任务，让 mini-SWE-agent 尝试五次，并评审三名同学的任务；其中自拟任务占 70 分（满分 100）。两份作业都采用 MIT 许可。

[github.com/cs329z/assignm…](https://t.co/pIKGHujGsA)
