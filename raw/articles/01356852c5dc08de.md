Vercel Labs 推出了开源工具 agent-desktop，让 Claude Code、Codex 等 AI Agent 能直接操作 macOS、Windows 和 Linux 上的桌面应用。

演示中，多个 Agent 分头在备忘录写清单、添加提醒事项、操作计算器。部分操作可以在后台完成，不影响用户正常使用鼠标。

它通过操作系统的无障碍接口读取应用界面结构，识别按钮、输入框等控件，并直接执行点击、输入等操作。相比依赖截图和坐标定位的传统方案，这种方式可以更准确地定位目标，减少视觉分析的 Token 开销。

Agent 每次操作后还会重新检查界面。如果目标发生变化或无法确认，就拒绝盲目点击。遇到复杂窗口，也可以先读取整体结构，再深入局部区域，避免一次性处理大量无关信息。

不过，视频中同时移动的彩色光标只是可视化效果。多个光标可以同时移动，但实际桌面操作仍需依次执行。双击、拖拽等动作还需要调用真实鼠标输入，可能打断用户。

项目最早由独立开发者 Lahfir 创建，最初仅支持 macOS，后来陆续扩展至 Windows 和 Linux。作者现已加入 Vercel Labs，项目也随之归入 Vercel Labs。
