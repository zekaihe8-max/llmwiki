有人专门为 Pi Agent 训练了一个模型，而且效果还挺明显！

而且用的还是国产模型 Qwen3.8-27B，名字叫 Qwen3.8-27B-pi-adapted ，是专门为了 PI agent 做训练的，直接一步到位 让模型去适配 Pi

以前我们能想到的让 PI 更好用的方式，通常是安装插件、调整提示词或者修改工作流

但是这次换了一种思路，直接从底座基座模型开始训练，为了针对每一个Harness 做适配

简单理解，就是让模型在 Pi 里面反复完成真实的编程任务，根据任务有没有成功、测试能不能通过来调整它的行为

相当于让一个原本会写代码的程序员，专门熟悉 Pi 的工具和操作习惯，学会用更少的步骤完成任务

而且这次不是从零训练模型，而是在原版 Qwen 上通过强化学习和 LoRA 做针对性优化

根据项目方测试，SWE-bench Pro 的通过率从 29.4% 提升到了 62.7%，工具调用次数减少了 55%～62%

我觉得最有意思的是思考和实现的方式，这次是直接从模型本身出发针对 Agent 进行训练

以后我们选择模型，可能不只是考虑它写代码有多强，还要看它能不能真正用好 Agent 提供的工具

目前模型权重已经公开，也可以尝试本地部署，不过这些成绩还是特定测试环境下的结果，并不代表所有任务都有同样的提升
