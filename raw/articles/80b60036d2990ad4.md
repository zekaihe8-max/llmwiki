Grok Bot 的开源替代品越来越多了，推荐 5 个最值得关注的项目🔥

最近 Grok Bot 越来越火，没想到 GitHub 社区已经有人开始复刻它的功能了，而且有几个项目的 Star 都超过了 6000

我花了点时间整理了 5 个比较有意思的开源项目，有的可以直接调用 Claude Code、Codex，有的支持多 Bot 协作，还有的连独立云电脑和手机端都做出来了

1、Munder Difflin｜9182 Stars

这个项目有点意思，直接把 AI Agent 做成了一间虚拟办公室

支持 Claude Code、Codex、Pi、OpenCode、Cursor 等十多个 Coding Agent，每个 Agent 都有自己的记忆、邮箱和办公位置，还能互相分配任务

最主要的是可以直接使用自己现有的 CLI 和订阅，不需要重新开发 Agent

项目：[github.com/HarnessMD/mund…](https://t.co/7qXWxacsWM)

2、OpenMausBot｜7637 Stars

这个应该是我看到最接近 Grok Bot 产品形态的一个项目

直接做成了类似聊天软件的界面，每个 Bot 都有自己的身份、模型和工作环境，可以使用 Claude Code、Codex 等 CLI，还能连接独立的虚拟电脑执行任务

目前支持 Mac、Windows 和 Linux，已经提供桌面客户端

项目：[github.com/milind-soni/Op…](https://t.co/S8ShQ1GUR7)

3、Open Duet｜6308 Stars

同样是一个开源的 Personal Agent 项目，不过它更偏向 AI 员工管理

可以给不同的 Agent 分配工作、设置长期记忆和定时任务，还支持多 Agent 协作、任务看板和操作审批

你可以直接使用 Claude Code 或 Codex 作为底层执行引擎，也能部署到自己的服务器上

项目：[github.com/Anil-matcha/op…](https://t.co/id8wOR9bsf)

4、Rakazo｜6257 Stars

这个我个人比较感兴趣，因为它的底层使用了 Pi Agent

不仅支持长期记忆、定时任务、多 Bot 协作，还能给 Bot 分配浏览器、终端和独立电脑

目前已经有 Web、桌面端、iPhone 和 Android 客户端，支持 Docker 部署，甚至可以直接放到自己的 VPS 上长期运行

整体已经很接近我之前想用 Pi 打造的个人助手了

项目：[github.com/elie222/rakazo](https://t.co/owGCdhif8X)

5、OpenBot｜3993 Stars

这是一个本地优先的多 Agent 工作台

支持 Claude Code、Codex、Grok、OpenCode、Gemini 等工具，每个 Agent 都有独立的工作目录和会话，还可以互相发消息、传文件、控制浏览器

它也支持桌面端和服务器部署，不过目前还是开发预览版，默认执行权限比较高，而且采用非商业许可证

项目：[github.com/nightly-labs/o…](https://t.co/WNfvWHNrDB)

这几个项目里面，我比较推荐先看看 OpenMausBot 和 Rakazo

一个是直接复刻 Grok Bot 的使用体验，另一个则是基于 Pi 搭建完整的 Personal Agent，甚至连多端客户端都已经做出来了

不过要注意，项目开源不代表模型调用和云电脑资源也全部免费，Claude Code、Codex 等依然需要对应的订阅或 API 权限

我觉得现在最有意思的是，Grok Bot 这种多 Agent + 云电脑 + 长期记忆的产品形态，已经开始被越来越多的开源项目复刻了

如果你跟我一样喜欢自己折腾 Agent，又希望数据和运行环境掌握在自己手里，这几个项目确实值得研究一下
