HackerTube：Andrej Karpathy 用 Hacker News 推荐视频自建「净化版 YouTube」，Claude Opus 5.5 两小时做完

周五晚被 YouTube 夸张缩略图和算法垃圾刷到崩溃后，Andrej Karpathy 周六用 Claude Opus 5.5（Claude Code）从 Hacker News 评论里筛出近二十年被推荐过的 YouTube 片，做成仿 YouTube 的 HackerTube：约 4 万条推荐评论 → 6,454 条视频、150 个主题；他自己几乎不再写代码，全程跟 Claude 对话，手工只做了 Google API 密钥、开 VPS、买域名三件事，整个过程两小时！

[karpathy.bearblog.dev/hacker-tube/](https://t.co/MeAdrJpISQ)

# 动机：主流推荐对他失效

他打开 YouTube 看到的是「被劣化的一墙垃圾」：夸张缩略图、重复话题、低智内容。承认这类算法可能适合互联网上的「中位数用户」，但不适合自己。解决办法不是再调推荐，而是换信源：把 HN 评论里「有人认真推荐过」的视频当成策展层。

# 怎么做出来的

Opus 拉全量 HN 评论，先过滤，再用 Sonnet 走 Claude Code 的 Workflow 去掉垃圾与低质，收成约 4 万条「在推荐 YouTube 视频」的评论，汇总成 2007–2026 间、跨 150 主题的 6,454 条片。再套上 YouTube 式界面、买域名、推到 VPS，并做安全加固与优化。文末补充工作方式：日常默认 Opus 5.5 Medium；不再自己读改代码、敲终端，只跟 Claude 说话；VPS 起来后把 IP 交给它，让它自己更新、部署、加固、优化。他说这仍有一点「和队友轮流干活」的感觉，因为中间要等 Claude 跑完。

# 产品上刻意做的几件事

内容侧押在「HN 上有人推过」；缩略图不用上传原图，改用 50% 进度帧（避开夸张封面）；For You 不登录，状态放在浏览器本地会话；有键盘快捷键；站点数据可导出，方便丢给自己的 agent 再做一个变体。一句话：策展靠社区推荐，交互尽量轻、可复制。
