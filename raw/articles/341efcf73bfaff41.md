# Hark Pro 上手保姆级指南：从入门到做出第一条视频

7 min read

Hark Pro 是 Hark 推出的个人 AI Agent。由 Figure AI 创始人 Brett Adcock 创立，10 月 6 日正式上线。

它自带一台叫 Handoff 的云端独立虚拟机，不仅能帮你操控网页办杂事、整理资料，还能直接通过对话完成从写脚本、调动云端工具到输出成片的完整视频制作。

这篇我们直接从下载安装开始，带你做完一条 30 秒的动画视频。走完一遍，再看看如何让 Hark Pro 帮你处理日常任务、连接账号，以及搭建可以重复使用的工作流。

### 1. 从哪里开始？先注册 Hark Pro

Hark Pro 目前支持 iOS、Android 和网页版，也提供 macOS 客户端。

### 2. 登录后，先告诉 Hark Pro 怎么配合你

打开 Hark Pro，你会看到三个主要区域：Home、Chat 和 Projects。

- Home：你的个人主页，放提醒、操作卡片和定制小工具。
- Chat：平时直接给 Hark Pro 下任务的地方。
- Projects：专门管理某一个长期项目的独立对话。

第一次先用 Chat 就够了。建议先发一段初始化指令，直接复制给 Hark Pro：

text

```
你好，从现在开始请使用简体中文和我交流。
我的时区是 Asia/Shanghai（UTC+8）。
回复尽量简短，
先告诉我结论，再补充必要细节。
我希望你能主动完成任务，
而不仅仅是告诉我该怎么操作。
如果任务需要使用电脑、浏览器或其他工具，
请优先判断你是否能够直接执行。
遇到无法完成的操作，请明确说明卡在哪里。
完成任务后，
给我实际成果以及可以打开的位置。
```

Hark Pro 会自动记住这些，不用说“请记住”。

[/cashinmyhouse/article/2123699145193947369/media/2122783965954424832](/cashinmyhouse/article/2123699145193947369/media/2122783965954424832)

几条默认规则，即使你不说也成立：

- 花钱一定先问你。下单或订座前，它会弹出一张订单卡片，写清商家、商品、总价和付款卡，你点按钮才付款。
- 代你发消息前先给你看草稿。
- 密码和验证码不在聊天里发。需要登录时，它会弹出安全表单。密码、信用卡等敏感信息存在加密保险库 Secured by Hark 里，Hark 自己也看不到，只在需要填写的页面上解密。

想放宽或收紧，直接说：“以后 X 不用问我”或“以后 Y 一定先问我”。

### 3. 让 Hark Pro 做出你的第一条视频

这部分是我觉得最值得试的地方，Hark Pro做视频的能力真的媲美 Opus 5.5！这是我用它做出来的视频：

[/i/web/status/2122701990006530496](/i/web/status/2122701990006530496)

Hark Pro 不用文生视频模型，而是自己写代码，把视频一帧一帧做出来。 分镜、动画、剪辑、配乐都由它自己完成，最后渲染成 MP4 发到聊天里。你不需要会编程，不需要任何剪辑软件，甚至不需要安装任何插件，它会自己尝试组合不同的工具完成制作。

第一步：先知道它擅长什么

它做得好的：

- 文字动画、产品宣传片、品牌片头、数据可视化动画
- 镜头推拉、匹配剪辑、转场、胶片颗粒和光晕质感
- 用图像模型生成原创画面，再让它们动起来
- 用代码合成配乐和音效，卡着节拍剪
- 输出 1080p MP4

它做不到的： 真人表演、口播配音、实拍感的动态场景。

第二步：发出任务

以下是我给它的第一个任务，直接在 Chat 里对它说：

text

```
给你自己做一个产品宣传片，30s，
主要就是宣传你的视频制作能力。
我要像 claude 那种的，
很高级的审美风格。
用上你最牛逼最前沿的能力，
我要看看你能把分镜、剪辑、配乐
等方面的审美 push 到什么边界。
我可以给你看几张
 claude 审美风格的参考图。
但你不要直接用这些参考图哦，
你要去做自己的视频内容。
```

[/cashinmyhouse/article/2123699145193947369/media/2122783602337562624](/cashinmyhouse/article/2123699145193947369/media/2122783602337562624)

这段把三件事交代清楚了：

- 做什么、做多长：一条 30 秒的产品宣传片，主题是它自己的视频制作能力。
- 审美标准定在哪：对标 Claude 那种高级感，并明确要它把分镜、剪辑、配乐推到极限。
- 参考怎么用：可以看参考图找感觉，但不能直接拿来用，内容必须是它自己做的。

以后换成自己的任务，沿用这个写法：做什么 + 多长 + 什么风格 + 参考什么、不能怎样。 涉及账号或外部操作时，再补充行动边界。

第三步：等它做完

做视频通常要几分钟到十几分钟，取决于长度和复杂度。不用盯着，做好后视频会以文件卡片的形式出现在聊天里。

### 4. 视频做好后，播放检查

点开文件卡片完整看一遍，重点看：

- 是否符合你的审美要求？
- 时长是否是你要的？
- 文字是否完整、有没有错字？手机上看得清吗？
- 转场自然吗？
- 配乐和画面的节奏对得上吗？

出现任何问题，继续让它修。

### 5. 在同一条对话里，让它做第二版

不用新开对话，直接接着说就行。它知道你在说哪条视频，工程文件也还在，改起来很快。比如我这里要求：

text

```
将 20s 左右的中英文文字
放到画面正中央，
上下左右都要居中。
```

打开第二版和第一版对比，确认改好了。

到这里，我们已经走完了最常用的一轮：交代任务，打开成品，检查内容，再提修改。 以后做网页、整理资料表、写报告，都是这个顺序。

### 6. 探索 Hark Pro 的四个核心功能

① Handoff：让 Hark Pro 真正操作电脑

这是 Hark Pro 最核心的功能。Handoff 可以自己打开订票网站、寻找航班、填写信息，并在需要时请求你的确认。

[/cashinmyhouse/article/2123699145193947369/media/2122788767740440576](/cashinmyhouse/article/2123699145193947369/media/2122788767740440576)

官方介绍，Handoff 可以操作网页、填写表单、进行研究、购物和预订。而且不是每次都需要手动打开一个特殊模式，当你提出需要浏览器操作的任务时，Hark Pro 可以自动启动 Handoff。

例如：

text

```
请帮我搜索三款适合视频剪辑的笔记本电脑。
预算 1500 美元。
优先考虑性能、屏幕、散热和续航。
请实际浏览品牌官网，
整理型号、配置、价格和购买链接。
先做研究，不要购买。
```

[/cashinmyhouse/article/2123699145193947369/media/2122790123167510528](/cashinmyhouse/article/2123699145193947369/media/2122790123167510528)

如果 Handoff 开始执行，你可以查看它的操作过程。任务涉及购买、提交或修改信息时，检查对应的确认步骤。

② Projects：给长期工作单独开一个项目

Chat 适合日常零散任务。但如果一件事需要反复修改，建议使用 Projects。比如刚刚的视频，我们可以把后续工作集中到一个项目中。

[/cashinmyhouse/article/2123699145193947369/media/2122781665085083648](/cashinmyhouse/article/2123699145193947369/media/2122781665085083648)

新建项目后可以告诉 Hark Pro：

text

```
这个 Project 专门用于制作科技类短视频。
统一采用极简、高级、强对比的视觉风格。
默认画幅 16:9，背景以黑色为主。
每次制作都先明确视频目标，
再生成成品。
保留历史版本，不要覆盖原文件。
请把后续相关制作集中在这个项目中。
```

Projects 可以集中管理同一个主题的对话和文件。以后要做第三版、第四版，直接回到对应项目。

③ Panels：让 Hark Pro 给你做一个专属小工具

这是 Hark Pro 很有意思的另一个功能。Panels 是可以放在 Home 页面的小型定制应用，你可以用自然语言让 Hark Pro 创建。它展示的是 Hark Pro 从网页、账号或服务里读到的数据，并按时自动更新。

[/cashinmyhouse/article/2123699145193947369/media/2122782640390688768](/cashinmyhouse/article/2123699145193947369/media/2122782640390688768)

比如给自己做一个内容数据面板：

text

```
请为我的 Home 创建一个
内容数据追踪 Panel。
追踪我的 YouTube 频道
（这里填你的频道链接）
最近发布的五条视频，显示：
- 标题
- 发布时间
- 播放量
- 点赞量
- 评论量
每天更新一次数据。
不要自动发布任何内容。
创建完成后，
回到 Home 检查 Panel 是否出现，
并核对数据是否和频道一致。
```

Hark 官方介绍，Panels 还可以连接外部服务获取数据（比如 Strava、Venmo），但连接前要单独核对授权方式。

④ Scheduled Tasks 和 Specialties：让任务重复执行

这是两个不同的功能。

Scheduled Tasks 是定时任务，比如每天早上整理一份信息。可以直接发：

text

```
请创建一个定时任务。
每天北京时间早上 9 点，
检查 Hark 官方网站有没有新公告。
只整理过去 24 小时内新增的信息。
每条包含标题、发布日期、
来源链接和一句话摘要。
没有新公告就不用重复发送旧内容。
创建后告诉我下次运行时间。
```

[/cashinmyhouse/article/2123699145193947369/media/2122790390185250816](/cashinmyhouse/article/2123699145193947369/media/2122790390185250816)

建立之后，检查任务是否保存、时区和下次运行时间是否正确。

Specialties 是可重复使用的工作流。比如你以后每次做研究，都要求同样的步骤，可以这样说：

text

```
请帮我建立一个
可重复使用的资料研究工作流。
每次我提供一个研究主题，
你都按照以下步骤执行：
1. 找到相关官方资料。
2. 交叉核对重要事实。
3. 区分已确认信息与推测。
4. 整理成中文资料表。
5. 附上原始来源。
6. 列出还需要进一步确认的问题。
请将这套流程保存为
可重复使用的 Specialty。
保存后告诉我今后如何调用。
```

[/cashinmyhouse/article/2123699145193947369/media/2122790659900010496](/cashinmyhouse/article/2123699145193947369/media/2122790659900010496)

Hark 官方说明，Hark Pro 可以逐步学习重复执行的工作流程，也可以根据要求创建 Specialty。

> 第一次不要一下建立十几个。先把一个流程做对，再考虑重复使用。

### 7. 需要更多能力时，再连接外部服务

Hark Pro 不只会使用浏览器。官方还支持通过 Services 直接连接部分平台，例如 Google Workspace 和 Microsoft 365。如果你平时有大量邮件、日历和文档需要处理，可以按需授权。

[/cashinmyhouse/article/2123699145193947369/media/2122783070344675328](/cashinmyhouse/article/2123699145193947369/media/2122783070344675328)

但不建议新用户第一天就把所有账号都连接进去。先明确任务，再决定要开放什么数据。

连接邮箱：先做一次只读整理

在 Hark Pro 的服务连接或相关设置入口查看当前支持的账号。确认服务、账号和权限后，完成授权。第一次可以跟它说：

text

```
请帮我整理最近七天与指定项目有关的邮件。
包含发件人、主题、日期、
主要内容和待办事项。
有明确截止日期的单独标出来。
没有写截止日期就标注「未说明」。
本次只读取和整理。
不要发送、删除、归档或移动邮件。
```

收到结果后，抽查原始邮件。确认内容正确，再考虑让 Hark Pro 执行回复或其他操作。

如果某个网站没有直接的 Services 连接，也可以询问 Hark Pro 能否通过浏览器操作。例如：

text

```
我需要使用一个第三方网站完成工作。
请先告诉我能否通过 Handoff 操作。
如果需要登录，
请使用产品提供的安全授权流程。
不要要求我把密码或验证码
直接发送在普通聊天里。
登录成功后先完成只读检查，
不要修改账号信息。
```

Hark Pro 提供名为 Secured by Hark 的加密凭证库，用于保存网站登录和支付信息。

### 8. 如果卡住了，从这里排查

- 找不到之前的文件或对话：用右上角搜索，它能搜到整个账号里的内容。
- 等了很久，不知道做到哪：看聊天里的实时进度卡片，或直接问“做到哪了？卡在哪一步？”
- 说过偏好还是没照做：先当场指出；反复出现就问它“你关于这件事记得什么”，把错的改掉。
- 准备执行的操作不对：直接说“停下”。
- 确实是产品问题：设置 → 反馈，附一张问题截图，会直接到 Hark 团队；也可以发邮件到 [[email protected]](/cdn-cgi/l/email-protection)。

### 最后，检查自己有没有真的上手

- 已经成功注册并登录 Hark Pro
- 知道 Home、Chat、Projects 分别用来做什么
- 给 Hark Pro 发出一个具体任务，并明确交付格式
- 实际打开任务成果，检查是否符合要求
- 在原对话里提出修改，并核对新版成果
- 知道 Handoff、Panels、Specialties 和 Scheduled Tasks 的区别
- 知道在哪里检查账号授权和使用额度

如果这七件事都做过，你基本就掌握了 Hark Pro 的使用逻辑。接下来可以把视频任务换成你自己的工作，比如做研究、生成资料表、制作网页，或者把一个重复处理的流程交给它。

真正值得研究的地方，是你能不能把一个平时需要自己打开五六个软件才能完成的任务，完整交给 Agent。
