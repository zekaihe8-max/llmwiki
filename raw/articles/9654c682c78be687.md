10 个 Pi Agent 同时运行，互相交流、分工协作，全新的协作方式🔥

最近看到一个挺有意思的实验，有开发者在隔离虚拟机里同时运行了 10 个 Pi，全部搭配 DeepSeek V4.1，让它们互相交流、分享发现，一起寻找项目中可复现的漏洞

作者表示效果出奇地好，而实现这种协作方式的关键，就是 pi-intercom 插件

这个插件主要解决 Pi 不同会话之间的通信问题，提供了几个比较实用的能力：

1、会话互通：不同的 Pi 可以互相发现、发送消息，不需要人工复制上下文

2、任务协作：Agent 可以主动询问其他 Pi，分享自己的发现，再根据收到的信息继续工作

3、任务交接：通过 /handover，可以把当前任务的进度和上下文交给另一个 Pi 继续处理

不过它主要负责通信，多个 Pi 仍然需要分别启动和安排任务

我觉得这种方式很有意思，以前更多是一个主 Agent 调度多个 Subagent，而现在可以让多个独立的 Pi 组成一个团队，自行交流和协作

尤其是 Pi 本身足够精简、扩展自由度高，再搭配 DeepSeek 这类国产模型，未来完全可以探索用较低成本搭建自己的多 Agent 协作系统
