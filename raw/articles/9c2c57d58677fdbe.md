谷歌 Antigravity 终于把插件市场做明白了，装 MCP 和 Skill 不用再手改配置了🔥

之前折腾 AGY 最烦的就是配各种工具，得自己找路径改 JSON，还容易跟老版本写法冲突

现在 AGY 的 Plugin Marketplace 已经把这块收拢到一起了

谷歌的生态能完善真的是太好了，这样我就可以直接对接我想要的厂商了，不然用 Codex 转到谷歌，最大的问题就是生态没有那么完善。现在已经补完了，就是等谷歌慢慢填充就好了

看了下目前这套插件市场，有几个很实用的点：

1、不只是 MCP，而是整套打包一键装

一个插件可以把 MCP、Skills、Rules、Hooks 和自定义 Agent 打包在一起

点一下就全配齐，不用自己东拼西凑

2、桌面端和命令行打通同步

桌面 App 在 Customizations 里的 Marketplace 一键安装

命令行敲 /plugin 或 agy plugin install 也能装，两端装完会自动同步

还能用 agy plugin import 导入 Claude Code 和 Gemini CLI 的配置

3、生态覆盖已经挺全了

Google 自家补齐了 Firebase、Chrome DevTools、Developer Knowledge，以及 Docs、Sheets、Drive 和刚上的 Gmail

合作市场里 GitHub、Cloudflare、Supabase、Figma、Notion、Linear、Context7 这些也都在

4、底层补了懒加载和 MCP Apps

MCP 工具默认懒加载，Schema 缓存在本地按需读取，不会一装就把上下文撑爆

新版还上了 MCP Apps，工具能在侧边栏和对话里渲染交互式卡片，不再只是纯文本

不过装的时候还是有两点要注意

需要 API Key 的插件在 CLI 装完默认是禁用状态，得补完配置才生效

另外权限保持默认 Ask 就行，别贪多一次装一堆，工具来回调照样烧 5 小时额度
