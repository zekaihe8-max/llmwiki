OpenCode 正式推出 Browse，让 AI Agent 直接操作用户日常使用的 Chrome 等浏览器。它通过 MCP 和浏览器扩展连接 Codex、Claude Code、OpenCode 等工具，无需为 AI 单独启动浏览器，就能复用现有标签页、登录状态和扩展程序。

Agent 可以在后台打开自己的标签页，通过 Playwright 点击、填写表单、截图、录屏和记录网络请求，不影响用户正常浏览。遇到登录、双重验证或付款等需要用户亲自操作的环节，可以把控制权交还给用户。

Browse 还支持跨设备控制。例如 Agent 运行在远程服务器上，却能操作用户 MacBook 上已经登录账号的 Chrome，无需把密码或整个浏览器会话迁移到云端。跨设备连接需要额外使用 Tailscale 等工具加密。

OpenCode 开发者还专门加入了反检测机制。项目采用 Patchright，减少浏览器暴露的部分自动化特征，并默认模拟人类鼠标移动、打字和滚动的节奏，试图降低被网站识别为机器人的概率。

不过，这些措施无法保证绕过网站风控。遇到验证码或反机器人拦截时，Browse 会识别异常，并将需要人工验证的步骤交给用户。项目已按 MIT 协议开源。
