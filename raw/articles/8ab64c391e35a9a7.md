DeepSeek Harness 官方推荐插件集合，这 4 个插件值得收藏！🔥

DeepSeek Harness 的第三方插件已经达到 3.5 万个了，但这么多插件，到底哪些值得安装？

最近官方专门介绍了 4 个社区开发者的作品，我整理了一下，涵盖自媒体创作、设计排版、上下文管理和论文阅读，都是比较实用的方向

1、dsh-media-desk｜自媒体工作台

把灵感记录、脚本创作、封面制作和视频分镜整合在一个工作台里，适合经常做自媒体内容的用户

GitHub：[github.com/woniuniuniu/ds…](https://t.co/pvpPVIuzCu)

2、dsh-guizang-design｜归藏设计

可以把文章转换成网页、图文卡片、封面，还支持网页 PPT 和去 AI 味，生成的作品能够保存下来，方便后续继续修改

GitHub：[github.com/op7418/dsh-gui…](https://t.co/4BuQNDa4G4)

3、dsh-context｜上下文可视化

可以查看 DSH 的上下文组成、Token 使用情况、压缩过程以及多 Agent 协作时的上下文变化

我觉得这个对经常使用 DSH 的开发者来说还是挺有必要的，至少能知道 Agent 到底在处理哪些信息

GitHub：[github.com/bowenliang123/…](https://t.co/SOcko7RRg0)

4、agentero-dsh｜AI 论文阅读器

把论文阅读、划词翻译、高亮批注、笔记和 Agent 问答整合到 DSH 里面，还能帮忙搜索文献和整理研究内容

比较适合学生、科研人员，以及经常阅读技术论文的开发者

GitHub：[github.com/poco-ai/agente…](https://t.co/DMlogfsk6d)

这几个项目其实也能看出 DeepSeek Harness 插件生态的发展方向

现在已经不只是给 Agent 增加几个工具了，而是可以根据自己的需求，把 DSH 改造成一套完整的工作台

不过插件更新速度也比较快，安装之前还是建议看一下对应的兼容版本，避免升级之后无法正常使用
