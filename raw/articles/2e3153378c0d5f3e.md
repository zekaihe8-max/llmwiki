无论是用 Zoom、飞书、腾讯会议开会，还是听 X Spaces 和 YouTube 直播，知了都能实时给出双语字幕、边听边写结构化纪要。遇到需要发言的时候，按住键盘右边的 ⌥ 键开口，对方就能在会里直接听到翻译好的语音。这一切都靠直接读取 Mac 系统声音并在本机识别来完成，声音不出电脑，不用往会里塞机器人，对方更是完全无感。

## 主要功能

[#主要功能](#主要功能)

### 实时纪要与双语文字记录

[#实时纪要与双语文字记录](#实时纪要与双语文字记录)

开会时纪要窗口边听边整理总结、议题要点、结论、待办、鱼骨图和人名术语表，点一下结论或待办就能跳回双语文字记录里的原话。纪要会统一文中人名和术语的写法并记下听错的变体，按 ⌘F 搜索时能连同识别错的写法一起搜出来。

### 实时字幕与语言识别

[#实时字幕与语言识别](#实时字幕与语言识别)

对方开口几秒钟就能在本地自动认出语言并翻成你的系统语言，按 ⌃⌥S 可以在纪要窗口、字幕条和不显示之间切换。字幕条只在有人说话时出现，鼠标划过时自动变透明，不会挡住底下的按钮。

### 同声传译

[#同声传译](#同声传译)

按住键盘右边的 ⌥ 键说话，对方在会议软件里就能直接听到翻译后的语音，打开同声传译时知了会自动把系统麦克风切到一键安装的虚拟驱动 BlackHole 2ch。填了 Ling API key 后可以用自然人声或用 8 到 30 秒录音克隆你自己的声音，不填也能用 Mac 自带语音。

  [/wquguru/cicada/blob/main/docs/interpreting.png](/wquguru/cicada/blob/main/docs/interpreting.png)

### 会议记录

[#会议记录](#会议记录)

每场会议的双语文字记录、纪要和原始录音都保存在本机，打开实验性的说话人识别后还能区分对方不同的说话人并在有 Ling key 时填上名字。会议软件挂断或 10 分钟没人说话时会自动结束并截掉空白，会后随时可以补生成纪要，或导出成 Markdown、Word 和 SRT 字幕。目前记录里的你只包含按住说话键说的话，会上直接开口的部分见[路线图](#%E8%B7%AF%E7%BA%BF%E5%9B%BE)。

  [/wquguru/cicada/blob/main/docs/records.png](/wquguru/cicada/blob/main/docs/records.png)

## 隐私与权限

[#隐私与权限](#隐私与权限)

声音采集、语言识别、语音识别（Apple SpeechAnalyzer）和会议录音全部在本机完成。会离开电脑的只有识别出来的文字（发去做翻译和生成纪要），以及填了 Ling API key 并按住说话键用同声传译时你说的那几句语音。不填 API key 时，实时字幕、翻译（走 Google 或退回 Apple 本机翻译）、会议记录和同声传译都能正常用。实时纪要、一步语音翻译和声音克隆需要你自己的 Ling（蚂蚁集团的大模型服务）API key（配置方法见[下文](#%E9%85%8D%E7%BD%AE-ling-api-key)），开一小时会大约花 0.15 到 1 元人民币，Ling 每月赠送 10 元额度，约够 10 到 50 小时会议。

知了只在用到某项功能时才请求对应的权限，拒绝后其他功能照常可用。

## 配置 Ling API key

[#配置-ling-api-key](#配置-ling-api-key)

- 打开 [Ling 开放平台](https://chat.ant-ling.com/platform/api)，注册或登录。

- 点创建令牌，复制以 sk- 开头的那串 key。

- 在知了里打开设置里的 AI 服务，粘贴后点保存并检查，也可以直接粘贴到纪要窗口顶部的提示框里。知了会发一个只用一个 token 的请求确认 key 可用。

- 同一页面可以选模型（默认 Ling-3.1-flash），每种语言用哪个 Ming 声音在同声传译设置里选。想移除 key，在同一页面点移除即可。

## 系统要求与安装

[#系统要求与安装](#系统要求与安装)

需要 macOS 26 或更新版本、Apple 芯片的 Mac。界面有中文、英文、日文和韩文，默认跟随系统语言，也可以在系统设置的语言与地区里单独给知了指定。

从 [Releases 页面](https://github.com/wquguru/cicada/releases/latest) 或 [官网](https://cicada.indaloop.app) 下载 Cicada-<版本>-macOS-AppleSilicon.dmg，打开后把知了拖进应用程序文件夹。应用目前是本地签名，还没有苹果公证（见[路线图](#%E8%B7%AF%E7%BA%BF%E5%9B%BE)），第一次打开被拦下时，去系统设置的隐私与安全性里点仍要打开。下载页同时提供 checksums.txt，可以用 shasum -a 256 Cicada-*.dmg 核对。有疑问可以去 X 找作者 [@wquguru](https://x.com/wquguru)。

打开后跟着首次引导开一个权限、听一段双人示例会议直接看字幕效果、接上 Ling key（也可以先跳过），要用同声传译时再装虚拟麦克风。之后有新版本时菜单栏图标会出现橙点，点一下就能更新，权限不会丢。

## 路线图

[#路线图](#路线图)

按先后排，想要哪一项欢迎在 Issues 里说。

- 记录我的发言，开会时持续听麦克风并做回声消除，把你直接开口说的话也记进文字记录和纪要。

- 支持更早的 macOS（14.4 起），在旧系统上改用较早的系统语音识别与翻译接口。

- 正式签名与公证，首次打开不再需要点仍要打开，AI key 也能放回系统钥匙串。

- 声纹识别，在现有的说话人识别基础上，在本机记住常一起开会的人的声音，下次开会也能自动认出。

- 不用 key 也有纪要，在支持的 Mac 上用 Apple 本机模型整理纪要，以及自选 AI 服务接入其他兼容 OpenAI 接口的服务。

- Windows 和 Android，共用纪要与会议记录格式，iPhone 和 iPad 因系统限制暂不计划。

每项的细节和取舍见 [docs/ROADMAP.zh-CN.md](/wquguru/cicada/blob/main/docs/ROADMAP.zh-CN.md)。

## 卸载

[#卸载](#卸载)

退出知了，去应用程序文件夹里把它拖进废纸篓即可。会议记录和录音都在 ~/Library/Application Support/LiveSubs 文件夹里，不需要的话可以手动删掉。想清除软件设置可以运行：

```
defaults delete com.wquguru.cicada
```
