Cloudflare 又有一批 AI 羊毛可以薅了🔥

之前我分享过不少 Cloudflare 的免费玩法，最近官方在 AI 方面又更新了不少功能

我花了一些时间把免费的功能和额度整理了一下，这次有几个确实挺实用的，而且普通免费账户就能体验

1、免费 AI 云端浏览器 Browser Run

每天免费 10 分钟浏览器运行时间，最多支持 3 个并发浏览器

可以拿来给 Agent 做网页自动化、截图、网页转 PDF、抓取内容，不需要自己维护 Chromium

使用：登录 Cloudflare，创建带 Browser Run 权限的 API Token，就可以通过 API 调用了

2、免费 AI 知识库 AI Search

每个月免费提供：

500 万 Token 文档索引
10GB 存储
1000 次语义搜索
1000 次全文搜索

使用也比较简单，进入 AI Search 创建实例，在 Items 上传文档，等索引完成后直接去 Playground 测试

我觉得这个最适合拿来整理自己的技术资料，还能通过 MCP 接入 AI Agent

3、Workers AI 免费模型额度

每天免费 10,000 Neurons，可以调用部分开源模型

直接进入 Workers AI 选择支持免费计划的模型就能测试，也可以通过 API 接到自己的项目里

不过注意不是所有模型都免费，部分 DeepSeek、GLM、Kimi 新模型需要付费权限

4、AI Gateway 免费模型管理

这个我之前也介绍过，免费提供 API 调用分析、缓存和限流功能

可以把自己的模型 API 接进去，统一查看调用记录和用量

需要注意的是 Gateway 本身免费，不代表背后的 GPT、Claude 等模型调用免费

5、Pi Agent 也可以部署到 Cloudflare

这个是我比较感兴趣的，Cloudflare 已经原生支持 PiHarness，可以把 Pi Durable 运行在 Durable Objects 上

Workers 每天免费 10 万次请求，Durable Objects 和 Workers AI 也有自己的免费额度

使用官方 Agents SDK 示例部署，搭配免费模型，就可以尝试做一个不需要常驻 VPS 的轻量云端 Agent

不过这不是把本地 Pi CLI 原样搬上去，完整的 Linux 执行环境还需要额外资源

最后提醒一下，AI Search 从 11 月 1 日开始对超出免费额度的用量计费，AI 生成回答和外部模型也可能单独收费

我还是非常推荐大家把 Cloudflare 免费账户利用起来，尤其是 AI Search 和 Browser Run，个人开发者用来折腾一些小项目已经很不错了

Cloudflare 这个赛博大善人的名号，确实不是白叫的
