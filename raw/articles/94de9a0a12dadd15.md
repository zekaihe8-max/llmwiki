DeepSeek Harness 现在可以直接调用 Claude Code 和 Codex 作为自己的子 Agent 了🔥

最近一直在研究 DeepSeek Harness，发现官方已经支持直接调用 Claude Code 和 Codex 作为自己的子 Agent 去执行任务了，而且还是官方自带的插件，不需要自己去开发

我也花了一些时间实测了一下，整个使用流程其实非常简单

1、打开 DeepSeek Harness 的插件页面，找到实验性插件，往下滑就可以看到 Codex 智能体和 Claude Code 智能体，把对应的插件安装并启用就可以了

2、使用之前，我这边先把对应的 CLI 安装并登录好，之后就可以直接让 DeepSeek Harness 调用 Claude Code 或 Codex，把任务指派给它们去处理

不过我实测下来，目前还是存在一些兼容性问题

我使用的是最新版 Codex CLI，模型是 GPT-6.1-SOL，结果一直出现调用失败的问题

后来我也去社区找了一下，在 GitHub 上找到了跟我类似的反馈，问题可能出在 DeepSeek Harness 插件与新版 Codex 模型之间的兼容性上

目前可以尝试通过修改配置文件，或者回退到兼容版本的方式解决

整体体验下来，我感觉这个功能还是挺不错的，毕竟现在可以直接让 DSH 去调用其他 Coding Agent，不需要自己重新开发一套对接方案

不过目前还是实验性功能，兼容性方面还需要等官方后续慢慢更新和优化

我现在反而更希望官方后面能出一个调用 Pi Agent 的插件，这样我就可以把自己的任务直接指派给 Pi 去执行了

毕竟 Pi 我已经研究了很长一段时间，如果后面能把这几个 Agent 全部组合起来使用，对我来说还是挺有吸引力的
