🎉 所有用 Mac 的朋友，用上这个开源会议纪要和同声传译软件，还能白嫖支付宝家每月50小时的额度！

知了 / Cicada，已经按 Apache-2.0 协议免费开源，改了自用、拿去商用或闭源再发布都行。

几大功能：
- 实时字幕翻译，不管跨国会议、直播还是视频，都能自动翻译

- 飞书级别的会议纪要，每 45 秒更新，有总结、议题和鱼骨图，每条结论和待办都标着原话出处和时间

- 同声传译，克隆音色，语音直接转成另一种语言，直播室聊天无障碍

- 说话人识别，目前在实验阶段，需要在设置中打开

其中实时纪要用 Ling 模型，同声传译用 Ming-3.0 模型。配置只需三步：

1. 去 Ling 开放平台注册登录（免费额度可支撑50小时/月，链接在评论区）
2. 在 API 控制台创建一个API Key
3. 打开知了，粘贴到“设置 › AI 服务”

有问题欢迎在评论区或 GitHub 提，我会持续更新，Windows、Linux、Android也将推出！
