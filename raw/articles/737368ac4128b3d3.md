下午集中 review 了一波 Claude Code 和 Codex 自带的这个云环境，我发现这些云环境比我想象的要强大很多。虽然这些机器都是临时的，但是按照现在的订阅账户来算，如果不使用这些机器完全就浪费掉了。所以我把公司的东京开发服务器的一系列工作流程平滑地迁徙到了一份云电脑兼容配置的版本上去。那通过这种方式，我觉得未来适应一段时间就可以把东京服务器完全做成构建和部署服务器，而去掉开发相关的工作。从长期来看，这个趋势个人计算设备其实并不是在增强，而是在减弱。它的地位越来越更像是作为一个显示屏和成果交付的一个终端设备而存在。做完这件事情之后，我会把我所有的 Mac mini 和 Mac Studio 全部作为 CI 电脑配置，将所有开发工作都迁移到这些订阅套餐提供的云电脑当中。
