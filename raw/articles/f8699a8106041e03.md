原来服务器相关的福利不只有 Cloudflare，谷歌相关服务器资源的福利也不遑多让，尤其是你手里如果还有谷歌 AI 会员的话，那就一定不能错过

我整理了其中比较值得关注的 10 个，有些是 Google AI Pro、Ultra 会员专属，还有一些不需要订阅也能免费体验

1、Google AI Pro 每月 10 美元云赠金

订阅 Google AI Pro 后，可以通过 Google Developer Program 每月领取 10 美元 Google Cloud 赠金

可以用来抵扣云服务器、Cloud Run、Gemini API 等符合条件的服务，赠金自发放日起有效期为一年

2、Google AI Ultra 每月最高 100 美元赠金

Ultra 5x 每月提供 40 美元，Ultra 20x 每月提供 100 美元

如果本来就订阅了 Ultra，可以拿这些额度部署项目、运行服务器，不需要额外购买同等金额的云资源

3、Google Cloud 新用户免费 300 美元

符合条件的新用户可以领取 300 美元云服务试用金，有效期 90 天

可以体验 Compute Engine 等云服务，不过现在这笔试用金不能抵扣 AI Studio 的 Gemini API 费用

4、Google Cloud 免费 VPS

每月提供一台 e2-micro 的免费计算额度，包含 30GB 标准持久磁盘和 1GB 出站流量额度

支持美国俄勒冈、爱荷华、南卡罗来纳三个区域，适合部署轻量网站和测试项目

不过公网 IPv4 需要额外收费，这个需要注意

5、Cloud Run 每月 200 万次免费请求

可以直接部署 Docker 容器、API 和小型 Web 项目，不需要自己维护服务器

每月提供 200 万次免费请求，还有一定的 CPU 和内存计算额度，比较适合运行一些轻量 Agent

6、Google Cloud Shell 免费 Linux 环境

谷歌提供免费的浏览器 Linux 终端，包含 5GB 持久存储空间，默认每周最多使用 50 小时

可以拿来执行命令、测试代码和管理服务器，不过不适合当成长期运行的 VPS

7、Cloud Storage 每月免费 5GB

每月提供 5GB-month 的区域对象存储额度，还包含一定的免费读写操作

适合存放网站图片、项目文件和备份，免费区域限制在美国指定机房

8、Firestore 免费数据库

提供 1GB 免费存储空间，每天 5 万次读取、2 万次写入和 2 万次删除

比较适合个人项目、轻量应用和 Agent 数据存储，不需要自己部署数据库服务器

9、Cloud SQL 免费体验 30 天

Google Cloud 还提供 Cloud SQL 30 天免费试用实例，支持 MySQL 和 PostgreSQL

可以拿来测试数据库、开发后端项目，而且这个试用和新用户的 300 美元赠金是不同的福利

10、Google Colab 会员 GPU 计算福利

Google AI Pro 每月提供 200 个计算单元，Ultra 5x 提供 1000 个，Ultra 20x 提供 2000 个

可以体验 GPU 计算、Python 数据处理和模型推理，对 AI 开发者来说比较实用，不过不能直接当作 VPS 使用

另外，Google Developer Program 还有每月 35 个 Google Skills 学习点数，通过 GEAR 加入后可以体验云计算实操实验，不订阅 AI 会员也能申请
