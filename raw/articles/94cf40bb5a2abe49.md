Pi Agent 现在也能在手机和网页上用了，整理了 3 种使用方案

最近一直在研究 Pi Agent 的移动端，发现社区其实已经有不少解决方案了，不一定非要守着终端才能使用

我整理了 3 个方向，大家可以根据自己的需求选择

1、直接安装手机 APP

iOS 可以试试 Pi: Local Agent Harness，已经上架 App Store，支持在 iPhone、iPad 本地运行 Pi，还能管理文件、运行 Shell 和使用 Skills

Android 则可以看看 Pocket Pi，把 Pi 和 Termux 运行环境打包进 APK，不需要 Root，甚至可以通过无障碍权限操作手机里的其他 App

这两个都是第三方项目，安卓版本目前还比较早期

iOS：[apps.apple.com/us/app/pi-loca…](https://t.co/sF1CdkiIXv)

Android：[github.com/CelestialCreat…](https://t.co/rrAhDAwGBn)

2、安装插件，通过 Web 控制 Pi

如果不想换掉原来的 Pi，我觉得直接安装 Web 插件也挺方便

比如 pi-web-ui，只需要执行：

pi install npm:@kkkiio/pi-web-ui

重新启动 Pi 后输入 /webui，就可以通过浏览器访问当前会话，查看工具调用、Thinking 和历史记录

不需要重新部署一套 Agent，手机也能通过浏览器操作，不过远程访问记得配置内网连接，别直接暴露公网

GitHub：[github.com/kkkiio/pi-web-…](https://t.co/RbNtbbi549)

3、使用第三方 Agent 管理工具

这个方向我自己用得比较多，尤其是 Herdr，不管是命令行还是桌面 UI，管理多个 Coding Agent 都很舒服

现在可以考虑这几个项目：

Herdr：统一管理多个 Agent，配合 HerdrChat 可以在 iPhone 上远程接管任务

Paseo：支持 iOS、Android 和 Web，可以同时管理 Pi、Claude Code、Codex 等多个 Agent

Whip：针对 Herdr 开发的移动端客户端，支持 iOS 和 Android，通过 SSH 连接电脑上的 Agent

Herdr：[herdr.dev](https://t.co/xkUt8qSr9Y)

Paseo：[github.com/getpaseo/paseo](https://t.co/b4GqMrVy5O)

Whip：[github.com/kosumic/whip](https://t.co/1aVnTEce2O)

我自己还是更喜欢第三种方案，毕竟平时不只用 Pi，还要同时管理 Claude Code、Codex 等工具

如果只是想在手机上直接运行 Pi，可以考虑第一种；如果想保留原来的使用习惯，第二种会更简单

现在 Pi 的移动端生态虽然还没有完全成熟，但社区已经把这几个方向都做出来了，就看后面官方会不会推出自己的移动端了
