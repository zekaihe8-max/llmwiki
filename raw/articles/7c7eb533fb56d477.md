千问也开源了自己的 Agent Harness 了🔥

千问今天不仅发布了自己的千问四大模型，还一起发布了自己的 Agent Harness

如果算起来的话，除了 DeepSeek harness，千问也加入了开源大军 发布了自己的： Qwen Code 1.0 Preview

不过 Qwen Code 并不是一个全新的项目，它最早基于 Google Gemini CLI 开发，后面逐渐独立维护

1、Agent Harness

这次不只是更新了 CLI，而是把 Qoder 和 Qwen Code 的 Agent 能力整合到一起，围绕任务执行、工具调用和模型交互构建更完整的运行框架

2、多模型支持

不局限于千问自家的模型，同时支持 OpenAI、Anthropic、Gemini 等模型协议，也可以接入其他兼容 API 和本地模型

3、跨平台和自动化

支持 Windows、macOS、Linux 三端，提供会话恢复、非交互式执行等能力，方便接入自己的开发和自动化工作流

千问这次主要更偏向把 Qoder 已有的 Agent 能力整合成一套完整的开源 Coding Agent，他不是借现有的 PI agent 开发的，更像是一套 Agent 的整合

应该是大厂也慢慢的发现，不仅要开始卷模型能力，也要开始做好配套的 agent harness，开源就是一条很好的道路，毕竟千问的模型基本上都是开源的

不过 Qwen Code 1.0 目前还是 Preview 阶段，具体体验怎么样，我后面也准备拿它跟 Pi、DeepSeek Harness 对比一下
