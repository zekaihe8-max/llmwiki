DeepSeek Harness 插件最大的两个问题，官方终于开始着手解决了🔥

使用 DeepSeek Harness 插件，其实我觉得最大的两个问题，就是插件的稳定性和安全性

第一个是稳定性，很容易出现更新之后插件就没有办法使用了，现在官方已经直接下场解决

另一个是插件安全的问题，最近也慢慢在 GitHub 社区有了讨论热度

1、插件稳定性，官方开始针对性修复

之前我就提到过，DSH 虽然已经有 3.5 万个第三方插件，但数量多不代表每一个都能长期稳定使用

尤其是 DSH 更新比较频繁，底层接口一旦发生变化，一些老插件可能就会失效，甚至影响整个程序的启动

好消息是，在最新的 v0.2.2-rc.2 版本中，官方已经做了两项重要修复：

可选插件加载失败，不再导致整个 Web 端无法启动
插件虽然启用了，但没有成功加载，会明确显示未运行及具体原因

虽然还没有彻底解决版本兼容的问题，但至少不会因为一个插件出错，就把整个程序搞崩了

2、插件安全问题，社区开始讨论解决方案

另一个我比较关注的就是安全性

因为插件不只是一个简单的工具，很多时候还涉及文件读写、终端执行，甚至访问账号和密钥

最近 GitHub 社区就有人提出了 Install Gate 的想法

简单来说，就是希望在插件安装之前增加一道安全检查，提前识别依赖、权限和潜在的恶意代码风险，而不是等安装之后再发现问题

不过目前还只是社区提案，并没有成为正式功能

其实我觉得，DeepSeek Harness 的 Everything is a Plugin 理念确实很不错

但是插件生态发展到现在这个规模，已经不能只关注有多少插件了

稳定性决定用户愿不愿意长期使用，安全性则决定用户敢不敢放心安装

这两个问题如果能持续解决，我觉得 DSH 的插件生态才有机会真正成熟起来
