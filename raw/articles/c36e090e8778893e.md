Pi 作者 Mario 自己给 AI 造了一门编程语言🔥

前几天 Mario 突然发了条推文，说考虑了一下，决定给 Codemode 搞一门专用语言，名字就叫 Pico

本来以为他只是随口说说，没想到第二天就有测试结果了

更有意思的是，他直接让 Agent 去开发 Pico，再通过 Pi Durable 的 Codemode 调度多个子 Agent，拿 Pico 跟 QuickJS、Armin 的 djs/TS 做对比测试

相当于让 AI 开发一门给 AI 用的语言，最后再让 AI 自己测试，真是有点套娃了

不过 Mario 真正想做的还不止这些

他最终想搞出一个能保存执行状态的虚拟机，把运行中的状态压缩成很小的快照

这样以后 Agent 执行任务中断了，就可以直接恢复，不用像现在 Pi Durable 那样依赖 Replay 机制

目前 Pico 还是实验阶段，但我感觉 Mario 已经不满足于折腾 Coding Agent 了，现在连 Agent 底层怎么运行、怎么恢复都想自己重新搞一套

不得不说，这个研究方向还是挺让人期待的
