Claude Code 删掉了超过 80% 的系统提示词，Pi Agent 这种极简设计反而越来越有优势了🔥

Anthropic 最近公布了一个挺有意思的数据，针对新一代 Claude 模型，他们精简了 Claude Code 超过 80% 的系统提示词，但是内部编程评测的表现并没有明显下降

我又看了一下 TokenSave 的历史统计，发现 Claude Code 的初始输入 Token 也经历了很大的变化

2025 年 7 月：19,498 Token
2026 年 5 月：36,309 Token
2026 年 10 月：18,841 Token

从最高点到现在，已经减少了大约 48%，虽然这里还包含工具定义等上下文，但整体变化还是非常明显的

为什么我觉得这个变化值得关注？

以前模型能力不够强，需要写大量 System Prompt，反复告诉 Agent 应该怎么操作、什么时候调用工具、遇到问题怎么处理

现在模型越来越聪明，很多事情不需要再写死规则，模型自己就能判断

这也是为什么我一直比较喜欢 Pi Agent

Pi 默认就只有 read、bash、edit、write 四个基础工具，内置提示词非常精简，剩下的功能交给 Extension、Skill 和开发者自己决定

而且我觉得 Pi 最有意思的地方，不是它比 Claude Code 少了多少功能，而是它从一开始就没有打算把所有功能都塞进核心

当然，复杂 Agent 依然需要权限控制和工具管理，精简并不代表这些能力可以全部删除

但是如果模型本身已经足够聪明，我们为什么还需要一个越来越复杂的 Harness 来告诉它应该怎么做？

以后可能是 Pi 这种极简 Agent 未来越来越值得关注，甚至可能不需要Harness 直接使用AI完整的能力即可
