GPT、Claude 接连出现封号风波，我越来越觉得 DeepSeek Harness 值得研究了🔥

最近 GPT 又爆出来可能会有一波大规模封号，Claude 之前也是一样，尤其是反代、共享账号和第三方接入的用户，确实应该提前做好迁移准备

我甚至觉得，未来很多人的最终归宿可能还是国产模型

而在国产模型这一块，我个人非常看好 DeepSeek 的统治力，既然 DeepSeek 连自己的 Harness 都开源了，那就更应该提前了解一下

尤其是 DSH 的模型适配能力，实际上远比很多人想象的丰富

它底层接入了 pi-ai，支持 30 多类模型 Provider，还可以自行添加 OpenAI、Anthropic 兼容接口

目前比较值得关注的模型和套餐：

1、DeepSeek：官方账号、官方 API

2、GLM：智谱 API、Coding Plan

3、Kimi：官方 API、Kimi Coding

4、MiniMax：官方 API、Token Plan

5、Qwen：百炼 API、Coding Plan、Token Plan

6、OpenCode Go：支持 DeepSeek、GLM、Kimi 等模型

7、Command GOAT：支持第三方 Agent API 接入

8、Ollama、OpenRouter：支持本地模型或多模型 API 接入

另外 GPT、Claude、Gemini 这些海外模型也能通过对应的 API 接入，但不代表可以直接使用 ChatGPT Plus、Claude Pro 的订阅额度

我觉得 DSH 最大的优势，就是不需要绑定某一家模型服务商

今天用 DeepSeek，明天切到 GLM、Kimi、Qwen，甚至直接换一家的 Coding Plan，也不用重新折腾整套 Agent

随着国产模型越来越强，我觉得 DSH 很有可能成为一个值得长期使用的 Agent 框架
