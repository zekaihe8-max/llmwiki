Cursor 推出 Live Apps，现在用户只需描述需求，云端 Agent 就能直接搭建可运行的网页应用。它会按需创建 Postgres 数据库，配置基于 Cursor SSO 的身份验证，并准备托管环境。应用完成后，用户可以预览、选择域名，通过安全检查并确认发布，最终获得一个可以分享的在线链接。

Cursor 官方列出的应用场景包括活动报名、工位安排、销售数据看板、新员工培训和工程服务门户。团队可以把应用分享给指定成员或整个组织，访问者通过 Cursor 账号登录。

发布前，系统还会检查代码中是否存在 API 密钥、暴露凭证等安全问题。团队管理员可以查看所有应用、设置安全规则，也能随时撤下已发布的应用。

Lovable 本身也支持通过自然语言生成带数据库、用户注册和托管的完整应用。Cursor 则把这套能力接进了原有的编程 Agent，除了从零搭建，还能直接部署 Cursor Origin 和 GitHub 上已有的代码仓库。对于已经在 Cursor 中开发项目的团队，现在可以直接在同一套工具里完成开发和上线。

目前 Live Apps 仅支持 Cloud Agents，本地 Agent 暂不支持。
