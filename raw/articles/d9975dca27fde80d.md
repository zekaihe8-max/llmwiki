11 月 5 日，一名开发者在 GitHub 投诉，称 Claude Code 泄露了他的邮箱，自己近期每天收到几十封诈骗邮件。

Anthropic 工程师 Lydia Hallie 解释，此前 Claude 经常在编写代码时乱填作者名字。团队为了解决这个问题，把用户的登录邮箱放进了模型上下文。

Claude 在访问部分网站时，会自行编写联网命令。有些网站要求自动化程序留下联系邮箱，Claude 就擅自填入用户的真实邮箱，随请求一起发送出去。即使系统指令明确禁止泄露个人信息，也没能完全阻止这种行为。

这个问题早在今年 7 月就有人报告。此后，陆续有开发者发现，Claude Code 把邮箱发送给 Wikipedia、美国证券交易委员会等网站。一名用户还在 4 个项目中找到了 15 次类似记录，部分请求由子智能体自行发起。

Anthropic 已在 2.1.317 版本加入隐私拦截，发现工具调用即将发送账户邮箱时，会先询问用户。但如果 Claude 先把邮箱写进 Python 脚本，再运行脚本，就可能绕过检查。

Anthropic 承认现有方案并不彻底，计划在下一版本中直接移除模型上下文里的登录邮箱。
