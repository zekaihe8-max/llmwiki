# T3 Code

[#t3-code](#t3-code)

T3 Code is an "agent harness control surface". It enables control of the agents on your machine with a best-in-class mobile app ([iOS](https://apps.apple.com/us/app/t3-code-remote-claude-more/id6787819824), [Android](https://play.google.com/store/apps/details?id=com.t3tools.t3code)), [web app](https://app.t3.codes) and [Electron-based desktop app](https://t3.codes).

Works with your subscriptions on Claude Code, Codex, Cursor, Grok Build, OpenCode, Google Antigravity, and fx. If they're set up on your computer, T3 Code can control them.

## "Wait, what are you selling me?"

[#wait-what-are-you-selling-me](#wait-what-are-you-selling-me)

Nothing. We built T3 Code because we wanted the best possible development experience with agents. We were inspired by existing solutions like the Codex desktop app, Conductor, Claude Desktop and Cursor Glass, but none met our bar.

We wanted something performant, remote-ready, and truly open. If we ever go the wrong direction, we want you to have everything you need to fork and build the editor that you want.

## Installation

[#installation](#installation)

Warning

T3 Code currently supports Codex, Claude, Cursor, Grok Build, OpenCode, Antigravity, and fx. Install and authenticate at least one provider before use:

- Codex: install [Codex CLI](https://developers.openai.com/codex/cli) and run codex login

- Claude: install [Claude Code](https://claude.com/product/claude-code) and run claude auth login

- Cursor: install [Cursor CLI](https://cursor.com/cli) and run agent login

- Grok Build: install [Grok Build CLI](https://x.ai/cli) and run grok login

- OpenCode: install [OpenCode](https://opencode.ai) and run opencode auth login

- Antigravity: enable it in Settings, then use Install Antigravity and Sign in with Google. No CLI is required.

- fx: install [fx](https://fx.sh) and run fx login on the machine running the T3 Code server ([setup guide](/pingdotgg/t3code/blob/main/docs/user/providers-fx.md))

### Command line

[#command-line](#command-line)

```
curl -fsSL https://t3.codes/install.sh <span class="pl-k">|</span> sh
```

On Windows, in PowerShell:

```
irm https:<span class="pl-k">//</span>t3.codes<span class="pl-k">/</span>install.ps1 <span class="pl-k">|</span> iex
```

Then run t3 to start the server and open the local web app. t3 service install keeps it running in the background, t3 update moves to a newer release, and t3 --help has the full reference.

To try it once without installing, run npx t3@latest. It offers to install the t3 command for you.

### Desktop app

[#desktop-app](#desktop-app)

Install the latest version of the desktop app from [GitHub Releases](https://github.com/pingdotgg/t3code/releases), or from your favorite package registry:

#### Windows (winget)

[#windows-winget](#windows-winget)

```
winget install T3Tools.T3Code
```

#### Windows (scoop)

[#windows-scoop](#windows-scoop)

```
scoop install extras/t3code
```

#### macOS (Homebrew)

[#macos-homebrew](#macos-homebrew)

```
brew install --cask t3-code
```

#### Debian, Ubuntu (.deb)

[#debian-ubuntu-deb](#debian-ubuntu-deb)

Download the .deb from [GitHub Releases](https://github.com/pingdotgg/t3code/releases), then:

```
sudo apt install ./T3-Code-<span class="pl-k">*</span>.deb
```

#### Arch Linux (AUR)

[#arch-linux-aur](#arch-linux-aur)

Stable:

```
yay -S t3code-bin
```

Nightly:

```
yay -S t3code-nightly-bin
```

The AUR packaging is maintained in this repository under [packaging/aur](/pingdotgg/t3code/blob/main/packaging/aur).

#### Nix (nixpkgs)

[#nix-nixpkgs](#nix-nixpkgs)

```
nix profile add github:NixOS/nixpkgs/nixos-unstable#t3code
```

The package is maintained in [nixpkgs](https://github.com/NixOS/nixpkgs/tree/nixos-unstable/pkgs/by-name/t3/t3code)
and includes the desktop app (t3code-desktop) and the t3 command.
See [Nix installation](/pingdotgg/t3code/blob/main/docs/user/install.md#nix-nixpkgs) for NixOS configuration and updates.

### Install vp

[#install-vp](#install-vp)

T3 Code uses Vite+ so you'll need to install the global vp command-line tool.

#### macOS / Linux

[#macos--linux](#macos--linux)

```
curl -fsSL https://vite.plus <span class="pl-k">|</span> bash
```

#### Windows

[#windows](#windows)

```
irm https://vite.plus/ps1 <span class="pl-k">|</span> iex
```

Checkout their getting started guide for more information: [https://viteplus.dev/guide/](https://viteplus.dev/guide/)

### Install dependencies

[#install-dependencies](#install-dependencies)

```
vp i
```
