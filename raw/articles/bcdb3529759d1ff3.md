用 AGY 写前端，装这 5 个高星 Skill 就够了🔥

前面刚整理完 AGY 的增强插件，顺手又翻了一圈 GitHub 上高星的前端 Skill

很多人用 Antigravity 写前端 出来的页面还是满满 AI 味 排版挤、配色花、写完还不自查

其实不用去装几千个 Skill 的大合集 按前期定风格、写代码规范、后期精修、浏览器验收这一条链路 挑这 5 个高星的就行

1、ui-ux-pro-max-skill（153.8k Star）

管前期定调子 内置 80 种 UI 风格、194 套配色、74 组字体和 141 条 UX 准则 React、Next、Vue、Tailwind 都覆盖到了

原生支持 Antigravity 装完就能按行业和风格先出设计方案

安装：npm i -g ui-ux-pro-max-cli && uipro init --ai antigravity

2、impeccable（116.5k Star）

专门治 AI 廉价感和后期精修 自带 24 个设计指令 可以让 AGY 按需改排版、动效和层级 还附带一个 Rust 写的 62 项 AI-slop 检测器

仓库原生适配了 Antigravity 的新旧技能目录

安装：npx impeccable install

3、vercel-labs/agent-browser（53.8k Star）

Vercel 做的 Rust 浏览器自动化 CLI 加 Skill 能看无障碍树、跑视觉 diff、测 Core Web Vitals 和截图

AGY 桌面端自带浏览器 但是用 agy CLI 或者跑自动化验收时 配上这个会顺手很多

安装：npx skills add vercel-labs/agent-browser -a antigravity

4、vercel-labs/agent-skills（34.9k Star）

Vercel 官方前端规范包 里面有 40 多条 React 性能规则 和 100 多条 Web 设计与无障碍准则

前面两个管好不好看 这个专门管写出来的代码脏不脏、性能拖不拖后腿

安装：npx skills add vercel-labs/agent-skills -a antigravity

5、google-labs-code/stitch-skills（12.7k Star）

Google Labs 官方专门给 Antigravity 配的 Stitch 技能集 既能对接 Stitch 做设计转 React 和 shadcn 组件 也能从现有代码反推一份 DESIGN.md

Gemini 4 写前端没有设计文档约束很容易偏挤 配一份 DESIGN.md 效果稳很多

安装：npx skills add google-labs-code/stitch-skills -a antigravity

不想一次装这么多的话 先装 ui-ux-pro-max-skill 加 impeccable 就能解决八成审美问题 写 React 再补上 vercel-labs/agent-skills

另外提醒一个坑 Antigravity 的规则、Skill 元数据和 MCP 描述共享 2 万 Token 预算 千万别贪全去装几百上千个 Skill 的合集 装多了上下文变脏 模型反而更容易跑偏
