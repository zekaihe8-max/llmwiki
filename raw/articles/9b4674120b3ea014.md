谷歌Antigravity 不好用？大概率是没装上这 5 个插件🔥

刚看到有人盘点了一堆 AGY 增强插件，但是里面不少功能是重叠的，全装上去不仅多余，还容易把客户端自动更新搞坏

我把仓库说明都翻了一遍，筛掉撞车的，按实际痛点留这 5 个不打架的就够了

1、agy-fast｜给 AGY 提速省额度的加速器

AGY 慢和费额度，很多时候是卡在反复搜文件、分段改代码这些无效来回轮次上

它把批量搜索、大纲提取、多文件修改和跑测试合并成了 5 个本地 MCP 工具，项目实测能少跑约 34% 的轮次、省下 31% 左右的计费额度，CLI 和 2.0 桌面端都能直接用

项目地址：[github.com/INK-Q/agy-fast](https://t.co/pBYtchi92W)

2、Ponytail｜治好 AI 爱瞎写冗余代码的毛病

以前玩 Pi 的时候我就推过它，核心思路就是逼着 Agent 像个惜字如金的老程序员，仓库里能复用的代码绝不重新造轮子

自带代码改动审查和全库体检命令，官方在 Claude Code 里测下来代码量少了 53%、Token 省了 45%，目前在 AGY CLI 里能跑完整命令，桌面端则是当规则集挂载

项目地址：[github.com/DietrichGebert…](https://t.co/UIZbAqWg2O)

3、agy-powertools｜2.0 桌面端一站式增强面板

用 2.0 独立桌面端的装这一个顶三个，输入框旁边直接能看上下文占用、缓存命中率和吐字速度，左侧还会多一个本地用量看板盯紧 5 小时和每周限额

顺带还把会话分支、原位改消息重发和简体中文界面全包圆了，而且走的是本地只读挂载，不改客户端安装文件（还在用老版 VS Code 系 IDE 的可以去装 Antigravity Panel）

项目地址：[github.com/WhiteBr1ck/agy…](https://t.co/LyLsAkdBYq)

4、Paragravity｜多账号多窗口物理隔离同开

手头有好几个谷歌 Pro 号来回切着用的，不用再反复退出重登了

它利用官方原生的数据目录沙箱机制，给每个账号生成独立窗口并排跑，会话和扩展互不串味，但是记得别把生成的配置目录同步上云盘，里面存着明文登录凭据

项目地址：[github.com/edison-land/pa…](https://t.co/dapg1E7um7)

5、antigravity2-cn｜纯粹的 2.0 全局中文汉化包

要是你已经装了上面的 agy-powertools，其实自带汉化就够用了，这个更适合不想装监控面板、只想单纯把菜单和弹窗彻底汉化的朋友

顺便提个真机小坑，Mac 上打这种底层包补丁会触发本地重新签名，导致官方自动更新校验不过，后续升新版得自己手动下安装包覆盖

项目地址：[github.com/qqxpee/antigra…](https://t.co/Fh2aC254EB)

最后还是那句老建议，插件真不是装得越多越厉害

日常写代码其实只留 agy-fast 加 agy-powertools 这两个组合就够用了，既能省轮次省额度，看用量和中文界面也全有了
