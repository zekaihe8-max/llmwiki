## Share yours

Made a layout you like? Three steps, no sign up.

- Ask your agent to write it up. Paste the prompt. It writes a RECIPE.md: the brief another agent could build your layout from. [See Pasture's](/layouts/herdrdev/pasture/).
- Push it to a public GitHub repo with the topic herdr-layout. Each layout is a folder with layouts/<name>.json, its mods/, the RECIPE.md and a preview.png. One repo can hold several.
- It shows up here within the hour, under Community.

Layouts aren't reviewed by Herdr: your agent reads every file before it adds one. Community pictures are screened before they appear.
