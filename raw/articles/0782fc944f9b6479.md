国产 Personal Agent 没注意 已经发育成这样了吗？

国外现在已经冒出了一堆 Personal Agent，比如 Meta 的 Muse、X 的 GrokBot，还有开源的 Hermes Agent

但是国内到底有哪些 Personal Agent，其实很少有人去了解。我就很好奇，顺手搜了一圈，把国内目前做得比较好的几款做个盘点：

1. 蚂蚁 灵光 2.0：目前完成度最高。独立云主机离线跑，直连支付宝账单和出行，还能通过 MCP/CLI 接钉钉、飞书、12306 和米家，盯机票降价、盯班级群连打印机打作业都能干

2. 字节 小豆：豆包旗下，刚开启邀请制公测。接入抖音、飞书和日历，支持盯降价和长期目标跟进，还能代打电话订餐厅和酒店

3. Today AI：齐俊元带队，国内上线最早。常驻云端电脑，最大亮点是个人记忆可视化，它记住了什么你可以直接看、直接改

4. 阿里千问Go! / 腾讯小微：目前声量偏低，千问Go! 偏健康理财，腾讯小微还停在极早期灰测

另外还有 Qclaw、有道龙虾、DuMate 这类接管本地电脑的工具，但是它们更偏向效率助手，离常驻管生活还有点距离

盘完一圈对比海外，国内 Personal Agent 最大的问题其实很明显：超级 App 生态太封闭了。海外日常集中在邮箱、日历和开放网页里，Agent 靠标准协议就能串起来

但是国内的高频服务全锁在微信、淘宝、美团、抖音里，互不开放接口，各家只能先在自家生态里打转，很难真正跨平台替你把事办成

我感觉下一个市场就是针对个人的 Personal Agent 市场。虽然生态割裂这道坎很现实，但是看到国内已经有不少大厂和团队开始下场做了，也希望国内发展得越来越好
