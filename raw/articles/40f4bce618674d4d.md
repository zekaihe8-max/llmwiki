现在 Personal Agent 越来越热，但是安全不能忽视

今天刷到了 Meta 员工的这篇内容，讲的是路透社曝光他们内部测试自家 Personal Agent（Muse）时遇到的各种翻车，看完其实挺有感触的

Muse 下载量刚破 1000 万，已经算是目前最头部的产品了，但是连自家员工测下来都问题不断，而且里面提到的这些情况，我们真是每一条都有可能遇到，尤其是针对自己个人信息相关的

我梳理了一下，主要集中在这几个问题上

1、首先是越权读取隐私，连加密软件都挡不住

有 Meta 员工发现自己根本没授权，Muse 却主动提醒她回复加密软件 Signal 里的消息

后来实测发现，它在安卓上是直接读取系统通知，在 Mac 上是调用了无障碍权限和截屏功能，端到端加密本来是用来保隐私的，但是 Agent 直接坐在你屏幕前面看通知和截屏，加密本身根本防不住，直接逼得 Signal 紧急出手拦截

2、其次是自主执行失控，直接涉及真金白银

以前聊天机器人答错了顶多笑一下，但是 Personal Agent 拿了操作权之后，容错率就完全不一样了

这次就有员工反馈，Muse 在未经允许的情况下，直接替他订了一笔不可退款的 Airbnb，而且最近美国多家银行也已经表态，只要你授权 Agent 操作账户，哪怕出事或者被黑，后果都要用户自己扛

3、最后是上下文错乱和离谱的幻觉

这也是很容易被忽略的地方，有员工本来在聊钓鱼天气，Muse 突然插话报出精确到分的银行余额，还有人莫名其妙被问要不要去取一张咖啡桌，完全不是自己的对话

Meta 后面解释说这大多是主动搭话触发的幻觉，但是不管它是真串号泄露了别人数据，还是凭空编造余额，放在一个管个人隐私的 Agent 身上，这两种结果其实一样吓人

其实这不只是 Meta 一家的问题，而是现在整个 Personal Agent 赛道的底层矛盾，想要它真正好用、主动替你干活，就得交出系统权限和大量个人信息，但是权限一旦放开，安全边界就很难兜住

我希望市面上的 Personal Agent 越来越好，也看好这个方向，但是在权限隔离和兜底机制真正成熟之前，大家把自己的核心隐私和账号交出去的时候，还是得留个心眼
