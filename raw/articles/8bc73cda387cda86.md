Today's experiment:

If too much choice is bad for agents, what if you could create an EXTREMELY constrained version of the tools you like?

I.e. the agent is allowed to use React, but all state must be in Zustand/useReducer?

Strip out all the nuance, create a black hole of success, all through incredibly harsh lint rules.
