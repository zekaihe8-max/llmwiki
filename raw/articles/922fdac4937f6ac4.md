# Memory-safe systems code,for you and your agents.

Ownership frees memory and rules out data races, with no lifetimes to annotate. Errors are values, every task lives in a scope, and it all compiles fast to C, then to one native binary.

[Read it in the tour](/docs/tour)

- [Ownership without lifetimes Memory is freed by ownership, as in Rust, but references can't be stored, only used, so the compiler checks them without annotations.](/docs/tour#ownership)
- [Errors are values A function that can fail returns T ! E. try passes the error up, catch handles it, errdefer cleans up; none can be ignored by accident.](/docs/tour#errors)
- [Structured concurrency go, channels and select, made structured: every task belongs to a scope that waits for it, with cancellation down the tree. Data races don't compile.](/docs/tour#concurrency)
- [Generics and interfaces Generic types and functions with bounds, and interfaces a type satisfies by having the methods, without declaring it.](/docs/tour#generics-and-interfaces)
- [Tools in one binary gojo run, build, test, fmt and doc, with the standard library and the runtime compiled in. Cross-compile static Linux binaries with zig.](/docs/tour#getting-started)
- [Made for coding agents Diagnostics say what to write instead, gojo doc prints any module's API, and these docs are one file away at /llms.txt.](/docs/std)
