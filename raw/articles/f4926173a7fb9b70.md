DeepSeek Harness 不一定非要用官方 API，这几个 DeepSeek 套餐和模型供应商，价格差距还挺大的🔥

最近一直在折腾 DSH，我也顺便收集了几个可以搭配使用的 DeepSeek 渠道，主要对比价格、速度和接入难度

分享 4 个比较值得关注的方案，各有优缺点

1、DeepSeek 官方：原生支持，最省心

[platform.deepseek.com](https://platform.deepseek.com)

优点：直接使用官方模型和 API，版本更新及时，缓存计费也比较透明，DSH 原生支持，不用折腾第三方插件

缺点：按 Token 计费，如果像我一样高强度使用 Agent，执行轮数一多，账单还是会慢慢涨上去

目前 V4.1 Flash 非高峰输入 $0.15/M、输出 $0.60/M，缓存命中另有低价

2、OpenCode Go：$10/月，最高 $80 用量

[opencode.ai/go](https://opencode.ai/go)

这个性价比确实挺高，$10 的套餐，DeepSeek V4.1 Flash 有 $80 的月度模型用量上限

优点：适合经常使用 DeepSeek 的朋友，不需要每次盯着 API 余额，还能切换其他模型

缺点：有 5 小时、每周和每月额度限制，而且最近社区有人反馈速度明显下降

另外在 DSH 上要留意 Session Header 的兼容问题，不是填了 API Key 就一定能正常使用

3、OpenRouter：模型供应商选择最多

[openrouter.ai](https://openrouter.ai)

优点：可以选择不同推理厂商，还能按照速度、价格和稳定性进行路由，部分节点的价格甚至低于官方

缺点：不同厂商的推理速度、缓存支持和工具调用表现可能有差异，需要自己筛选

它没有固定的 DeepSeek 月度套餐，更适合按量使用，或者作为备用线路

4、Command Code GOAT：$10/月的另一个选择

[commandcode.ai/pricing](https://commandcode.ai/pricing)

这个也挺有意思，GOAT 套餐目前 $10/月，官网最新价格页给 DeepSeek V4.1 Flash 标出了 $80 的模型用量

优点：价格和 OpenCode Go 有竞争力，同时支持不少其他模型，还提供独立的 Coding Agent

缺点：套餐额度与标准 Provider API 的计费通道需要区分，DSH 虽然有社区接入插件，但兼容性和长期维护还得考虑

如果是我自己选择：

① 想省心、追求官方原生能力：DeepSeek API

② 高频使用、想控制预算：OpenCode Go 或 Command Code GOAT

③ 想挑推理速度、需要备用线路：OpenRouter

不过这里提醒一下，套餐标注的 $80 不是直接送你 $80 的 DeepSeek 官方余额，而是对应模型的使用限额

而且相同模型换个供应商，速度、缓存命中和工具调用效果也可能不一样

后面我更想把这几个渠道放在同一个 DSH 里测试，看看究竟哪个更适合长期使用
