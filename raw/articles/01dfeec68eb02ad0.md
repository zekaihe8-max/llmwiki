Grok Bot + Cursor 全链路开发分享！现在出门只带手机，也能完成从写代码、测试到 PR 合并和发布的整个流程🔥

前面有朋友问我，怎么通过手机配合 Grok Bot 和 Cursor 完成整个开发流程

其实没有想象中复杂，我现在这套工作流，基本不需要一直守在电脑前，分享一下具体怎么操作

一、先做好两个准备工作

1、关联 Grok Bot 和 Cursor

准备一个同时登录 Grok Bot 和 Cursor 的账号，现在的新订阅可以把两个服务关联起来

这里要注意，尽量使用同一个账号和邮箱，避免后面出现账号无法关联的问题

2、连接 GitHub 仓库

分别让 Grok Bot 和 Cursor 连接自己的 GitHub 仓库

后续的代码修改、PR、Review 和 CI/CD，都可以围绕 GitHub 完成

二、整个开发流程其实很简单

① 手机下发任务

直接在 Grok Bot 里描述开发需求，让它调用 Cursor 去执行 Coding 任务，不需要自己一直开着电脑操作

② Cursor Cloud 云端开发和测试

这个是我比较喜欢的地方

Cursor 自带 Cloud 环境，代码修改、测试和运行都可以在云端完成

中间的执行过程还可以通过截图、录屏和结果说明来检查，不用单纯依赖 Agent 告诉你任务已经完成

③ GitHub PR + CI/CD

代码完成后，通过 GitHub 提交 PR，再检查对应的测试结果和 CI/CD 状态

确认没有问题后，合并到主分支，如果你的项目已经配置好自动部署，后续发布流程也可以直接跑起来

三、最后我需要做什么？

整个流程下来，我主要只需要关注三件事：

1、提交开发任务

2、检查结果并合并 PR

3、确认发布到生产环境

以前开发一个小功能，可能还得远程连接电脑、打开编辑器、跑测试，现在很多操作都可以交给 Grok Bot 和 Cursor 完成

而且整个过程在手机上就能跟进，对于经常出门、又需要随时处理项目的人来说，确实方便很多

当然，正式上线前还是建议自己检查代码、测试结果和权限配置，尤其是涉及数据库和生产环境的修改

如果你已经在用 Grok Bot 和 Cursor，真的可以试试把 GitHub 这条链路打通，后面会省下不少重复操作的时间
