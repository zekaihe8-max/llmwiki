我经常用 Herdr 管理多个 Coding Agent，没想到现在连手机端都有了

之前就推荐过 Herdr，算是我日常使用频率比较高的工具之一，不管是在命令行还是桌面 UI 界面，管理多个 Agent 都很舒服

最近在找移动端工具的时候，意外发现社区还有一个配套的 HerdrChat，已经上架 App Store，支持 iPhone 和 iPad，而且免费

我看了一下，感觉有几个功能挺实用的

1、多 Agent 统一管理

支持 Claude Code、Codex、Grok、Antigravity 等，可以在手机上查看不同 Agent 的运行状态、历史会话，还能同时管理多台电脑上的任务

2、手机随时接管任务

电脑上安排 Agent 写代码，出门以后也能用手机查看进度、继续对话，遇到需要人工确认的操作还能直接处理

而且支持查看子 Agent、执行记录、发送图片，甚至可以打开完整终端，不用一直盯着电脑

3、直接连接自己的电脑

通过 SSH 连接 Herdr，不需要额外注册账号，也不经过第三方中转服务器

推荐搭配 Tailscale 使用，电脑上的 Agent 可以继续运行，手机只负责管理和交互

唯一需要注意的是，HerdrChat 本身不是在手机上运行 Agent，电脑或 VPS 还是要保持在线

我也是想找一些新的移动端APP，看看能不能把 PI agent 对接上去，我自己也体验过其他家的，都没有达到最满意的程度

我看一下体验这个会怎么样，如果好的话 我会继续分享
