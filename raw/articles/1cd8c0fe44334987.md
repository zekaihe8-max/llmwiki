DeepSeek Harness 最新版本更新，最重要的是接入了自己的搜索引擎🔥

前段时间我刚研究完 Pi 和 DeepSeek Harness 的区别，没想到 DSH 又更新了一轮，这次 0.2.1 系列改动还挺大的

我第一时间翻了一下官方的升级日志，而且自己也上手体验了一下，而且针对插件做了非常多的优化，而且把对应 PI 的内核也做了更新

总结了下面几个我比较感兴趣的更新

1、Agent 现在可以自己开发插件了

以前想给 DSH 增加功能，需要自己找插件或者写代码，现在插件管理页面增加了让 Agent 创建插件的入口

直接告诉 Agent 需要什么功能，它就可以帮你开发插件，还支持第三方插件源、依赖管理和热重载

以后安装或者创建插件都非常简单，直接可以在侧边来选择创建自己的插件

2、开始兼容 Claude Code 和 Codex 生态

官方新增了 Claude Code 和 Codex 插件组合包，还做了一个实验性的 Claude Code Mods 兼容层

不过目前还不是完全兼容，更多是在验证两套插件机制能不能互通

如果后面真正打通，对 DSH 的插件生态帮助应该不小

3、Pi 底层升级，极简模式也在完善

DSH 使用的 pi-ai 已经升级到 1.0.2，更新了模型目录和适配器

另外极简模式也支持图片、长对话自动压缩，还可以通过 /compact 手动整理上下文

这一点我比较关注，因为前面我在测试极简模式的时候 容易出现问题，有提示或者是卡死 现在做了优化 后期我再做测试一下

4、接入 DeepSeek 自己的搜索能力

新增 DeepSeek Search 和 Fetch API，可以直接在网页搜索设置中开启

同时适配了 DeepSeek-V4.1-Flash-1017，还有实验性的 Git Worktrees 插件、子代理能力调整、SDK 会话恢复等更新

目前 GitHub 最新 Release 是 0.2.1-rc.3，依然属于预发布版本

我之前研究 Pi 的时候，最喜欢的就是它足够简单，想要什么功能自己加，不需要太复杂的配置

但是 DSH 的路线明显不一样，它不只想让你扩展 Agent 的能力，还想把插件、模型、工具和运行体系都组合起来

现在我反而更想看看，随着 DSH 的插件生态逐渐完善，这种万物皆插件的设计，究竟能不能在保持灵活性的同时，控制好复杂度和 Token 消耗

毕竟功能越多不代表 Agent 越好用，实际执行效率才是我更关心的东西
