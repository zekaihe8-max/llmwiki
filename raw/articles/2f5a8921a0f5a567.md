Grok Bot 的国内对手都来了，阿里、字节、腾讯、百度现在都在卷 Personal Agent

最近一直在折腾 Grok Bot，没想到国内几家大厂也开始往 Personal Agent 方向发展了，然后我就花时间把这头部几个大厂的 Agent 和 Personal Agent 都总结了一下

以前大家都在卷大模型、AI 聊天助手，现在已经开始给 Agent 配云电脑、长期记忆、Skills，甚至让它在后台长期帮你处理任务

我整理了一下国内四家大厂的产品，发现各家的路线还真有点不一样

1、阿里｜千问 Go！+ 千问办公

阿里这边其实有两条路线

千问办公我之前就分享过了，整合了 QoderWork、MuleRun 和悟空，支持桌面 Agent、云端 Agent 和企业协作

更值得关注的是千问 Go！，定位就是 Personal Agent，背后还有淘宝、高德、大麦、夸克网盘这些生态

甚至已经开始尝试云电脑、云手机，让 AI 帮你处理航班理赔、淘宝价保这些实际生活中的事情，不过部分能力还在邀测

[qianwen.com](https://t.co/e2RE7KE8zE)

2、字节｜扣子 3.0 + 小豆

字节这边我觉得也挺有意思

扣子 3.0 已经不只是以前那个工作流平台了，现在支持云电脑、长期记忆、多 Agent 协作

甚至可以把 Hermes、Claude Code、Codex、OpenClaw 这些 Agent 接进来统一管理

另外字节还在研发一个叫 Spell 的 Personal Agent 项目，据报道可能会以「小豆」的名字推出

不过小豆目前还没有正式开放，具体能做到什么程度，还得等产品上线

[coze.cn](https://t.co/ou8hbZjQXx)

3、腾讯｜WorkBuddy + LightVela

WorkBuddy 大家应该都比较熟悉了，主要是办公场景，现在也支持云端长期执行任务

但我觉得更有意思的是 LightVela

腾讯居然直接把 Hermes Agent 做成了云端服务，支持长期记忆、Skills，还能通过微信、QQ 等聊天工具远程安排任务

这个我还挺想试试的，毕竟我之前一直在自己的 VPS 上折腾 Hermes，现在腾讯直接帮你把运行环境维护好了

[lightvela.com](https://t.co/re9Hh23P7Y)

4、百度｜百度搭子 DuMate

这个我前两天刚分享过，原本还以为百度在 AI Agent 这块没什么存在感了

结果自己去体验了一下，发现做得还蛮不错的

尤其是它的工具套件，自媒体运营、数字人生成、求职、法律诉讼这些场景都有对应的功能

跟 Grok Bot 相比，百度搭子更偏向把日常工作流程直接封装好，让普通用户不用折腾一大堆配置就能使用

[dumate.cn](https://t.co/NdY7BEA0w1)

这四家看下来，我感觉国内 Personal Agent 的竞争才刚刚开始

阿里有自己的生活服务生态，字节在整合各种 Agent，腾讯背靠微信和办公生态，百度则更注重普通用户的实际使用场景

这几个里面 阿里、字节、腾讯的产品我都有去使用过，我觉得最有可能的还是字节和腾讯的产品，一个是依赖于豆包这个大生态 一个是依赖于微信这个强入口

其实阿里在整合方面是最好的 可以自动点外卖 也可以去订房间 酒店 或者是购物之类的，但是好像没有什么宣传和推广 所以知道的人比较少

百度方面是我知道最少的，整个生态 我了解的也是最少的 我就使用过它的百度搭子，不然的话 我还以为他已经从牌桌上下去了 结果他还在牌桌上 而且还混到了市占率第二的位置

这种大混战越乱越好，普通消费者得到的免费权益也就越高，希望能持续一段时间 大家可以免费体验
