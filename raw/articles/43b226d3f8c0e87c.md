[#--------------sand3d](#--------------sand3d)

3D modeling in Python, built for LLMs.

sand3d is a Python library for writing 3D objects as short programs: profiles, solids,
edits, frames, joints and assemblies, over Blender's bpy. A program says how a shape
is made, part by part and in its own words, so a model writes it in a few hundred tokens
and a person can read it.

## Why sand3d

[#why-sand3d](#why-sand3d)

[https://raw.githubusercontent.com/Sandflow-ai/sand3d/main/docs/readme/tokens.png](https://raw.githubusercontent.com/Sandflow-ai/sand3d/main/docs/readme/tokens.png)

[How it is measured, part by part](https://sand3d.sandflow.ai/tokens.html)

- Short. A part takes 2 to 6× fewer tokens than the same part in Blender Python, CadQuery or FeatureScript ([details](https://sand3d.sandflow.ai/tokens.html)).

- The whole API fits in a prompt, about 3,600 tokens ([the API](https://sand3d.sandflow.ai/api.html)).

- Named, not computed. Parts, edges and faces are reached by name, never by hand-computed coordinates.

- Deterministic. The same program builds the same mesh, bit for bit.

## A whole object, part by part

[#a-whole-object-part-by-part](#a-whole-object-part-by-part)

[https://raw.githubusercontent.com/Sandflow-ai/sand3d/main/docs/readme/washer.png](https://raw.githubusercontent.com/Sandflow-ai/sand3d/main/docs/readme/washer.png)

A front-loading washing machine in 38 lines of code ([play it and read it](https://sand3d.sandflow.ai/gallery.html)):
the cabinet, the drum, the door with its glass and handle, the detergent drawer and the dial,
each a named part, and four joints that say how they move.

```
<span class="pl-s1">door</span> <span class="pl-c1">=</span> <span class="pl-s1">s3d</span>.<span class="pl-c1">group</span>(<span class="pl-s">"door"</span>, <span class="pl-s1">ring</span>, <span class="pl-s1">glass</span>, <span class="pl-s1">handle</span>)                      <span class="pl-c"># the handle and the glass move with it</span>
<span class="pl-s1">s3d</span>.<span class="pl-c1">joint</span>(<span class="pl-s">"door_hinge"</span>, <span class="pl-s1">door</span>, <span class="pl-s1">hinge</span>, <span class="pl-s1">axis</span><span class="pl-c1">=</span><span class="pl-s">"-Z"</span>, <span class="pl-s1">range</span><span class="pl-c1">=</span>(<span class="pl-c1">0</span>, <span class="pl-c1">143</span>))
<span class="pl-s1">s3d</span>.<span class="pl-c1">joint</span>(<span class="pl-s">"drum_spin"</span>, <span class="pl-s1">drum</span>, <span class="pl-s1">front</span>.<span class="pl-c1">move</span>(<span class="pl-c1">0</span>, <span class="pl-c1">400</span>), <span class="pl-s1">kind</span><span class="pl-c1">=</span><span class="pl-s">"continuous"</span>)
<span class="pl-s1">s3d</span>.<span class="pl-c1">joint</span>(<span class="pl-s">"drawer_slide"</span>, <span class="pl-s1">drawer</span>, <span class="pl-s1">top_band</span>.<span class="pl-c1">move</span>(<span class="pl-c1">150</span>), <span class="pl-s1">kind</span><span class="pl-c1">=</span><span class="pl-s">"prismatic"</span>, <span class="pl-s1">axis</span><span class="pl-c1">=</span><span class="pl-s">"+X"</span>, <span class="pl-s1">range</span><span class="pl-c1">=</span>(<span class="pl-c1">0</span>, <span class="pl-c1">200</span>))
<span class="pl-s1">s3d</span>.<span class="pl-c1">joint</span>(<span class="pl-s">"dial_turn"</span>, <span class="pl-s1">dial</span>, <span class="pl-s1">top_band</span>.<span class="pl-c1">move</span>(<span class="pl-c1">-</span><span class="pl-c1">150</span>), <span class="pl-s1">kind</span><span class="pl-c1">=</span><span class="pl-s">"continuous"</span>)
<span class="pl-k">return</span> <span class="pl-s1">s3d</span>.<span class="pl-c1">assembly</span>(<span class="pl-s">"washing_machine"</span>, <span class="pl-s1">cab</span>, <span class="pl-s1">drum</span>, <span class="pl-s1">door</span>, <span class="pl-s1">drawer</span>, <span class="pl-s1">dial</span>, <span class="pl-s1">front</span><span class="pl-c1">=</span><span class="pl-s1">front</span>)
```

## Export: GLB, URDF, USD, OBJ, STL

[#export-glb-urdf-usd-obj-stl](#export-glb-urdf-usd-obj-stl)

One call; the file's extension names the format; lengths in metres.

```
<span class="pl-s1">s3d</span>.<span class="pl-c1">export</span>(<span class="pl-s1">machine</span>, <span class="pl-s">"washer.glb"</span>)    <span class="pl-c"># or .urdf, .usda, .obj, .stl</span>
```

format
what it carries
for

GLB

meshes, materials, the joints in each node's extras, at the current pose

the web, viewers, game engines

URDF

a link per moving part, its joints and their limits, at rest; OBJ meshes beside it

ROS, PyBullet, MuJoCo, Isaac

USDA

the same tree in OpenUSD (UsdGeom, UsdPhysics), with the materials

Omniverse, Isaac Sim, USD pipelines

OBJ, STL

the meshes alone, at the current pose: OBJ Y up, binary STL Z up

any 3D tool, slicers

.usd, .usdc and .usdz come from the .usda through USD's own tools (usdcat,
usdzip). The scene is also an ordinary Blender scene, for anything else Blender writes.

## Install

[#install](#install)

Python 3.13 (recommended) or 3.11. Blender comes with it, as the bpy module: 5.2 LTS on
Python 3.13, 4.5 LTS on Python 3.11; CI runs bpy 5.2.

```
pip install sand3d        <span class="pl-c"><span class="pl-c">#</span> or, in a uv project: uv add sand3d</span>
```

bpy has no wheel for Python 3.12, nor for Intel Macs from 5.2 on: there, use Python 3.11.

Millimetres by default. Every verb with code that runs and its render: [the quickstart](https://sand3d.sandflow.ai/quickstart.html);
objects to play joint by joint: [the gallery](https://sand3d.sandflow.ai/gallery.html); every signature: [the API](https://sand3d.sandflow.ai/api.html).
The programs themselves: [docs/examples/](https://github.com/Sandflow-ai/sand3d/tree/main/docs/examples/) and [programs/](https://github.com/Sandflow-ai/sand3d/tree/main/programs/).

## Give it to your LLM

[#give-it-to-your-llm](#give-it-to-your-llm)

Put [docs/api.md](https://github.com/Sandflow-ai/sand3d/blob/main/docs/api.md) in the system prompt: the rules of the vocabulary, every
signature, and worked examples, in about 3 600 tokens; [llms.txt](https://github.com/Sandflow-ai/sand3d/blob/main/llms.txt) points a
model at it. For objects of several parts, [the guidelines](https://sand3d.sandflow.ai/guidelines.html) give
the eight rules of an assembly program: the plan first, then the details, then the parts.

## What is in it

[#what-is-in-it](#what-is-in-it)

Everything on one flat s3d.<verb> surface:

family
verbs

profiles

rect circle slot polygon poly arc spline superellipse text offset stroke … (16)

solids and paths

extrude revolve sweep loft wire helix box cylinder tube sphere torus dome … (15)

edits

cut join intersect split hole pocket fillet chamfer shell dent … (15)

frames and placement

Frame face edge bbox local at transform grid ring along snap

articulation

joint pose seat

assembly

group assembly attach export units fingerprint … (8)

parts and materials

gear knurl thread material

No category verbs (chair(), table()): a category is a program written in sand3d.
