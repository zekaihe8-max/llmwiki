DeepSeek Harness 插件推荐,  先装这 5 个就够了

DSH 的核心是「一切皆插件」，但插件太多容易眼花。我按实用性帮你筛了 5 个优先装的：

1. dsh-market（必装）
可视化插件市场，搜索 + 一键安装 + 升级。后面找插件再也不用翻 GitHub。
仓库：[github.com/dsh-market/dsh…](https://t.co/VpudiU4BjU)
⭐ 11.9k

2. ModLens
给纯文本 DeepSeek 模型装上「眼睛」。粘贴截图就能出 OCR + 布局 + 语义，报错图、UI 稿直接丢进去。
仓库：[github.com/liustack/modle…](https://t.co/ChZw9ZlEiF)
⭐ 4.9k

3. DSH-better-sidebar
文件树 + 代码预览 + Git diff + 侧边对话，写代码时体验直接拉满。
仓库：[github.com/omdsh-dev/DSH-…](https://t.co/WSChwvWQsn)
⭐ 5k

4. dsh-context
实时看上下文构成、token 占用和压缩情况。长会话必装。
仓库：[github.com/bowenliang123/…](https://t.co/oYBG1M2MAS)
⭐ 4.9k

5. AgentTeams
多 Agent 任务图 + 团队面板，复杂任务可以拆给多个角色并行干。
仓库：[github.com/NanmiCoder/dsh…](https://t.co/nX7MYLy2Pq)
⭐ 2.9k

装法（Web 版示例）：
npx [@deepseek](/deepseek)-ai/dsh plugin --profile web add dshmarket

先装市场，后面大部分都能界面点装。

注意：DSH 还在开发者预览，装之前确认版本兼容
