xAI 更新开发文档，宣布从 11 月 7 日起，为 Grok 4.7、4.6、4.5、4.3 及三款 Grok 4.20 模型的 API 输出默认加入隐形文字水印。不只欧盟，全球及区域 API 都在覆盖范围内，连结构化输出和工具调用参数也会被标记。目前尚未明确 Grok 网页版和 X 内置聊天是否同步启用。

这种水印通过在模型生成文本时，轻微调整选词概率，让整段文字留下可识别的统计规律。直接复制粘贴不会消除水印，但缩短文本、大幅改写会降低检测可靠性。

背后是欧盟《AI 法案》的透明度要求，相关规定已于 8 月 2 日开始适用。虽然 xAI 没有签署欧盟的自愿性透明准则，但仍须遵守适用的法律义务。开发者团队可以按模型关闭水印，不过必须确认符合相关法律豁免，并自行承担标记和披露责任。

Google 早在 2024 年就将 SynthID 文字水印用于 Gemini，Anthropic 今年 8 月开始为 Claude 新模型在全球启用水印。OpenAI 则在 10 月宣布，逐步为欧盟地区的 ChatGPT 和 Codex 加水印，同时允许全球 API 用户主动开启，默认仍关闭。
