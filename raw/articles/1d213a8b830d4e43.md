DeepSeek Harness 和 Grok Bot 居然能互相派活了🔥

我自己一直在玩 DeepSeek Harness 和 Grok Bot，我又突然想到有没有什么插件可以把 DeepSeek harness 和 Grok Bot 连接起来？

我去 GitHub 翻了一下，没有找到可以直接连接 DeepSeek harness 的插件 但是找到了一些解决方案

1、Grok Bot 调用 DeepSeek Harness

项目：grokbot-dsh-orchestrator-vn

让 Grok Bot 负责理解任务、拆分和验收，简单的代码、文件处理这些工作交给 DSH 执行，还可以搭配 OpenCode Go 使用 DeepSeek Flash 降低成本

地址：[github.com/diginno-net/gr…](https://github.com/diginno-net/grokbot-dsh-orchestrator-vn)

2、DeepSeek Harness 调用 Grok Bot

项目：grok-bot-cli

可以通过命令行管理现有的 Grok Bot，支持发送消息、读取回复、管理 Bot 和群组

如果再让 DSH 调用这个 CLI，就可以把任务交给 Grok Bot 处理，不过需要本地安装并登录 Grok Bot 桌面端

地址：[github.com/ScriptedAlchem…](https://github.com/ScriptedAlchemy/grok-bot-cli)

3、把 Grok Bot 的模板搬进 DSH

项目：grok-bots-for-deepseek-harness

作者把 Grok Bot 市场里的 90 个 Bot 模板转换成了 DSH 插件，可以直接复用对应的 Agent 预设和 Skills

这个不算真正的连接，更像是把 Grok Bot 的玩法搬到了 DSH

地址：[github.com/brokep/grok-bo…](https://github.com/brokep/grok-bots-for-deepseek-harness)

这三个里面都没有我想要的那种可以直接让DeepSeek harness 去调用 Grok BOT 的，不过你也可以直接使用 webhook 的方式去调用

目前来说 社区这边还不太完善，有空的话我也去折腾一下 看能不能写个插件让 DeepSeek harness 对接 Grok BOT，这样的话 我的额度又可以充分利用起来了
