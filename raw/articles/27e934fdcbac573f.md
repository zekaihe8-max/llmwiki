A brief history of AI Coding since Nov 2025:

Nov 2025: Opus 4.5 releases, OpenClaw gets built
Dec 2025: community agrees that models get good enough to handle 95% of coding tasks
Jan 2026: Ralph loops get popular, early efforts on loops/orchestration
Feb: Everyone feels knackered, too much strategic decision-making, fears around cognitive debt begin
Mar: Skills explosion as community converges around easy-to-share processes (superpowers already ahead of the game here)
Apr: most SOTA devs haven't written a line of code in months
May: "The unreasonable effectiveness of HTML" - more interest in richer review surfaces
Jun: "Loop Engineering" wins vaguepost of the year, signals more hype around process
Jul: Every talk in every conference becomes "here is my software factory"
Aug: Opus 5 speaks incomprehensibly, interest in ASD-STE100 peaks
Sep: Grok Bot gets popular, more interest in long-running "manager" threads which retain context and delegate work
Oct: The promised speed gains haven't materialised, "dark factory" feels a long way off still
Nov: No-slop manifesto releases, reading the code still appears essential

TL;DR: no-one is writing code anymore, and we are still figuring out what that means
