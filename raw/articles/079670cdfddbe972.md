谷歌昨天刚给全员重置 Gemini 额度，付费用户却炸锅了！

昨天下午，谷歌编程工具 Antigravity 把全员额度重置回满
大伙刚夸完大善人，官方论坛就冒出一堆付费用户吐槽
有 AI Pro 账号聊了 12 次，就烧掉 45% 周额度（见图 1）

谷歌真在后台偷偷砍额度了吗？

其实没全员砍，论坛里照样有人用得很耐用
开发者扒完日志，昨天在 GitHub 揪出两个偷跑额度的 Bug

第一个 Bug 藏在自定义助手里，就是你写好规则的专属角色
开发者测了 1.5.17 版客户端，默认模式扣费完全正常
可切到自定义助手干同样的活，扣费暴涨 4 倍（见图 2）！

那没用自定义助手的人，为啥也掉得飞快？

这就撞上第二个 Bug，后台安检在偷刷你的额度
你每改文件或跑命令，后台都会派小模型先做安检
日志显示，小模型一撞上限，就全转给大号模型复审

就算没撞上限，碰到提交代码这类动作，大号模型也会反复复审
每次复审都要重读整段聊天记录，账全算在你套餐里
有用户算了重置后的账，两小时复审 49 次，白吃四分之一额度（见图 3）

加上前两天取消了独立旧池子，所有模型全从一个总额度扣
前台刚重置完，后台两个 Bug 接着猛抽，用起来就像被砍了一半

这两个 Bug 在 GitHub 上还挂着没修，官方也没回应
送重置确实大方，但后台乱扣费的洞不堵上，再重置也不够这么烧！
