# 2026 黑五海外 AI 订阅全盘点：各场景最省心选购指南

20 min read

一到黑五，到处都在传各家 AI 会员五折、买一送一或者内部优惠码。满屏消息看下来，难免纠结该趁这波订哪几家，生怕错过真折扣，又怕掉进代充和假优惠码的坑里。

我把各家 AI 官网的定价页和活动条款挨个翻了一遍，实打实给订阅费降价的就 4 家。长期用着划不划算，主要看年付优惠、师生科研福利，以及高阶档附赠的接口额度和云赠金。

日常干活用的主力账号，我还是建议直接在海外官网订正价或年付方案。跨区低价常碰到功能缩水和账号风控，实在没有外币卡，再用国内支持微信或支付宝付款的方案替补就行。

## 先避坑：黑五到底哪几家真降价，哪几家没动

照着各家官网公开的活动条款拆开看，今年黑五有真动作的海外平台就分两类，一类是订阅费直接减免，另一类是月费照旧但按用量给优惠。

- 官方订阅直降的只有这 4 家：优惠都卡着活动窗口与账号条件，前 2 个月买赠或首年折扣结束后，都会自动恢复原价续费。
- · Google AI Plans：老用户在 11 月 20 日至 26 日有早鸟价，Plus 与年付 Pro 最高 5 折。新用户 11 月 27 日开放，Ultra 两档不参加。
- · The X Subscription：仅限含 Grok Bot 的 Premium 月付档买一送一，美区一次性付 $30 用 2 个月（折合每月约 $15），之后按 $30/月 自动续订，北京时间 12 月 2 日 16:00 截止。
- · ElevenLabs：美东时间 11 月 16 日至 12 月 1 日开放，直接在官网网页购买指定的 Creator 或 Pro 年付方案，首年可省 55%。
- · Suno：只在网页端开放，订 Pro、Premier 或 Platinum 三档年付方案，首年享额外 7 折，活动到 11 月 30 日截止，月付和单独额度包不参加。
- 月费不降，趁黑五给用量优惠的 3 家海外工具：会员月费本身维持原价，但在活动期内调低了模型扣费或加送了额度。
- · GitHub Copilot：付费档在 11 月 30 日前用 Copilot Fusion 享模型费 7 折，在聊天或云端智能体里用 Auto 路由则有常驻 9 折。
- · Perplexity：订阅没降价，个人定价页对 Pro 年付和 Max 年付限时加送 $40 或 $450 的 Computer credits（云端计算机额度）。
- · Runway 开发者 API：通过 API（开发接口）调用 Kling 4.0 到 11 月 30 日享 8 折，普通用户买的个人消费级套餐不参加。

大家日常问得最多的另外几家平台反而全没动静。OpenAI 和 Anthropic 都没出黑五活动，Midjourney 与 Runway 消费档同样维持原价。

X 买一送一藏在 Grok 官网套餐页的月付视图里，老账号打开常跳去账户合并页而看不到。第三方网站挂的 ChatGPT、Claude 优惠码和非官方代充全无依据，碰到直接绕开就行。

## Google AI Plans：Plus 与年付 Pro 拉进半价区间，6 个独立额度池怎么用

几家海外大厂里，Google 这轮把 Plus 与年付 Pro 拉进了半价区间，Ultra 两档仍不参加，现行美区页面已不显示旧版 $249.99 与前 3 个月半价。它家把算力拆成 6 个互不抢占的独立额度池，选档时先把正价、优惠和额度看明白。

- 美区 4 个档位的日常正价：前两档偏日常和主力使用，Ultra 两档都只支持月付，没有年付方案。
- · Google AI Plus：月付 $4.99，带 400 GB 云存储空间，官方公开对比表里没有单列这档的年付总价。
- · Google AI Pro：月付 $19.99，年付 $199.99（折合每月约 $16.67，比月付省约 16.6%），带 5 TB 云存储空间。
- · Ultra 5x 与 Ultra 20x：Ultra 5x 月付 $99.99（含 20 TB 存储），Ultra 20x 月付 $199.99（含 30 TB 存储）。
- 黑五折扣细则与高校学生福利：老用户早鸟持续到 11 月 26 日，新用户 11 月 27 日开启，Ultra 两档明确不参加黑五补贴。
- · 折扣以登录官网实际显示为准：Google 管 Gemini AI 订阅的产品负责人说明优惠随账号现有方案变化，网传 Pro 年付 $99.99 并非人人可见。
- · 美国高校学生福利：通过 SheerID 身份验证可领 Pro 免费 1 年（12 月 31 日截止），也能选 $8.99/月的 Pro 加 YouTube Premium 组合，学校发放的账号不可用。
- · 其他国家学生福利不一样：德国和日本，以及土耳其、印度的官方学生页只送 Plus 免费 1 年，没有像美区那样给到 Pro。
- 6 个各自独立的额度池与附带会员：这 6 块额度互不挤占，美区新老 Ultra 用户符合条件还能免费升级成 YouTube Premium 家庭版，Pro 则带不可共享的 Lite 版。
- · Gemini 应用：Plus 与 Pro 额度依次是非 AI 方案的 2 倍（Hydrogen）和 4 倍（Neon），Ultra 两档再升到 Pro 的 5 倍与 20 倍（含 Carbon）。
- · Antigravity：Plus 仅给每周额度，付费 Pro（免费和促销试用不算）每 5 小时刷新至周上限，同样含 Carbon、Neon、Argon、Hydrogen 与第三方模型，Ultra 上限更高。
- · Colab 计算单元：四档每月依次给 50、200、1,000、2,000 个计算单元，Ultra 两档支持不间断后台运行、更长时长与高配 GPU（图形处理器），还能叠加单独的 Colab 订阅。
- · Cloud 与 AI Studio 月度赠金：Plus 没有，Pro 和 Ultra 两档每月送 $10、$40、$100，得去 Google Developer Program 绑定结算账号后手动领取，12 个月内有效。
- · Flow 与 Flow Music 月点数：Flow 四档每月给 200、1,000、10,000、25,000 点（不结转，每天另送 50 点），Flow Music 依次给 3,000、10,000 和两档 Ultra 均 30,000 点。
- · Gemini Notebook 与美区附带福利：单本来源上限依次是 100、300、500、600 个，美区另含 Google Home、Health Premium 与 Ultra 20x 独占的 Project Genie。

开通必须用个人 Google 账号，企业 Workspace 账号不带个人方案的 Antigravity 额度。直接在 Google One 网页或应用里订就行，试用期想提前转付费拿满额度，官方也有专门的转换入口。

千万避开在 iOS 版 Gemini 应用里走 Apple 账单扣费。走苹果内购不仅没法在网页端修改订阅方案，也没法使用上面这套 AI credits 点数。

家庭组成员必须和管理员在同一个地区。存储、Gemini 应用和 Notebook 都能共享，Antigravity 与 Flow 是全家共用同一个额度池，只有云赠金、Colab 计算单元和 YouTube Lite 不能分给家人。

跨区低价这块，Google 在部分地区确实有官方本地标价，比如印度 Plus ₹399 与 Pro ₹1,950、Ultra 5x 起 ₹6,500。

土耳其网页端为 ₺199.99、₺869.99 与 ₺4,749.99 起，日本则是 Pro ¥2,900、Ultra 5x 起 ¥14,500。

不过 YouTube、Project Genie 和 Home、Health 这些附带福利很看地区，低价区常常缩水。加上家庭组强制要求同区，主力工作号没必要为了省差价去折腾跨区。

## The X Subscription（Grok Bot 统一订阅）：打包最全，但额度按周共用

xAI 把 X 会员与 Grok，还有 Grok Bot 和 Cursor 合进了这套统一订阅。它没有学生价，这轮黑五只给 Premium 月付档开了买一送一，常规年付则相当于付 10 个月用 12 个月（省约 16.7%）。

- 美区网页 4 个付费档位（不含税）：另有 Free 免费档（$0），只给基础 X 功能、有限的 Grok 和 Cursor 起步额度，不带 Grok Bot。
- · Plus：月付 $8，官方文档年付 $80（折合每月约 $7），给基础用量与 X 认证、Grok 基础功能和 Cursor 基础访问，不含 Grok Bot 与第三方模型。
- · Premium：常规月付 $30，官方文档年付 $300（折合每月约 $25），用量为 Plus 的 4 倍，从这档起才带 Grok Bot，黑五买一送一也只限这档月付。
- · Super：月付 $100，官方文档年付 $1,000（折合每月约 $84），用量为 Plus 的 15 倍，支持 1080p 15 秒视频与高峰优先访问。
- · Ultra：月付 $200，官方文档年付 $2,000（折合每月约 $167），用量为 Plus 的 50 倍，包含 Super 档的全部功能。
- 黑五 Premium 月付买一送一细则：活动到北京时间 12 月 2 日 16:00 截止，未登录打开 Grok 官网套餐页并停在「每月」视图，就能看到支付 1 个月送 1 个月的横幅。
- · 没有单独的 Grok Bot 买一送一或额度翻倍：大家说的 Grok Bot 买一送一，指的就是含 Grok Bot 的这档 Premium 月付，Plus、Super 与 Ultra 月付均不参加。
- · 美区付 $30 用 2 个月，到期恢复原价：美区一次性付 $30 用 2 个月（折合每月约 $15），之后按 $30/月 自动续订，不想续订至少提前 24 小时取消。
- · 换页面或切年度都会看不到活动：xAI 官网定价页和 Cursor 官网定价页均不挂活动，Grok 官网套餐页切到「年度」后黑五标题与倒计时直接消失，全回常规年付价。
- · 老账号与苹果在订看不到横幅：已登录的旧订阅老账号打开套餐页会跳去账户合并页，苹果应用商店在订账号也看不到横幅，官方未公开写死新老资格，能否领以登录后实显为准。
- 哪档更值得订与老用户切换优惠：除了 Premium 月付买一送一和年付省约 16.7%，旧版 X、Grok 或 Cursor 老用户在账单设置页切换时，还可能看到定向限时优惠。
- · $30 的 Premium 才带齐主力功能：包含 Grok Bot（官方口径原价合计 $90/月），同时带多数界面无广告、视频生成与云端智能体，以及 Origin 代码托管、Bugbot 和 Cursor 第三方模型入口。
- · 重度跑自家模型看 Ultra：按官方给的倍数折算，Ultra 每花 1 美元拿到的 xAI 自家模型相对用量最高，大约是 Plus 档的 2 倍。
- 下手前必须看准的 3 条扣费规矩：统一订阅把几款工具合在了一起，哪些共用额度、哪些得另掏钱分得很死。
- · 每周共用同一个额度池：Grok、Grok Bot 和 Cursor 里的自家模型共用一份按周刷新的额度池，三处干活消耗的是同一份每周限额。
- · 第三方模型与 API 另算钱：Cursor 调 Claude、GPT 等第三方模型从首次起按 API 标价从预付额度另扣（个人无加价，团队每百万 tokens 另收 $0.25），Grok API 也不走每周额度池。
- · Cursor 独立订阅已对新客停售：新用户只能买这套统一订阅，老用户可留着旧档不强制迁移，但走 Apple 付费的旧 Cursor 想升降级必须先切换过来。

领黑五买一送一要走 Grok 官网套餐页，常规订阅也可去 xAI 官网定价页，支持银行卡、支付宝，以及 Apple Pay、Google Pay 或 Link（支付方式看登录后的结账页所在地区）。

Grok 官网套餐页会按地区换算本地货币，部分地区可见 2 个月收港币 HK$240、人民币 ¥208 或印度卢比 ₹3,399，实付金额与支付宝选项以结账页实显为准。官方严禁第三方经销商，非官方订阅可能被暂停或终止。

老用户只能在网页端切换成统一订阅，一旦确认就永久不可逆，退不回旧方案。原有的旧订阅会按未使用时间比例原路退款，不会直接抵扣新账单。

如果旧版 Cursor 走的是 Apple 计费，xAI 官方没法帮你取消，也退不了钱。切换后得自己去苹果系统设置里手动取消并向苹果申请退费，Google Play 旧订阅也要自查取消，免得被扣两份钱。

Google 和 X 这两家哪怕月费档位接近，额度怎么扣也差得挺远。Google 把 6 块业务的额度池拆得干干净净，X 则是让聊天、Grok Bot 和写代码全盯着同一个每周额度池扣，选哪家时可以先对照看看。

## OpenAI 和 Anthropic：黑五不降价，高阶档改送等额 API 额度

OpenAI 和 Anthropic 黑五都没搞个人订阅打折，网上流传的第三方优惠码也不用信。它们这轮的动作集中在百元以上高阶档，买订阅就按月附赠等额的 API 额度。

OpenAI（ChatGPT 与 Codex）

- 个人档全部只有月付，没有年付：Sora 消费端与 API 都已停服，订阅不再包含 Sora，出图改成了 ChatGPT Images 2.6。
- · 入门的 Go 档每月 $8：官方写明可能包含广告，只给本地有限的 Codex，不含云端 Codex 和主力旗舰模型。
- · 常用的 Plus 档每月 $20：含 GPT-6.2 Sol、GPT-6.1 Sol 和 GPT-6 Astra，带云端 Codex，按 5 小时加周限额计算。
- · Pro 100、200 与 500 三档月付：分别为 $100、$200 和 $500，Work 与 Codex 无 5 小时上限，每月各送等值 $100、$200 和 $500 API 额度，需激活且当期有效。
- · Pro 高阶档里的 Ultrafast 区别：Pro 500 含全量 Ultrafast，较新的帮助页写明 Pro 200 也包含 Codex 里 GPT-6.2 Sol 的 Ultrafast。
- · 多人长期用看 Business 年付：比月付省 20%，Standard 每年 $240/人（折合每月 $20），Premium 每年 $1,200/人（折合每月 $100）。
- 12 月额度规则变动与免费福利：12 月起 Plus、Pro 和 Business 的对话与 Codex 共用按 token 计的额度池，Instant chat 不扣额度。
- · 11 月 23 日新开 50,000 个学术研究者名额：先到先得，申请通过后本人加上最多 2 名合作者都能免费用 Plus。
- · 教师免费与已截止的学生优惠：美国认证 K-12 教师与校职工免费，面向大学生的 4 个月活动已在 10 月 31 日截止。
- · 官网网页和手机商店是两套独立账单：网页可绑主流信用卡，也能走手机应用商店扣费，但商店账单用不了官方网页优惠。
- · 低价区标价与跨区封号风险：印度官方页标着 Go ₹399/月和 Plus ₹1,999/月，但中国大陆与港澳不在支持名单里，主力号跨区有封号风险。

Anthropic（Claude 与 Claude Code）

Anthropic 在 10 月 30 日把原来的 Max 5x 改名叫 Max，原 Max 20x 改成了 Ultra，官方也明确不发常规个人优惠码。

- 个人与团队各档怎么收费：个人档里只有 Pro 给年付优惠，Max 和 Ultra 两档都只能按月付。
- · Pro 档月付 $20，年付 $200：折合每月约 $17，比按月付省约 16.7%。
- · Max 月付 $100，Ultra 月付 $200：Max 给 5 倍 Pro 用量且高峰优先，Ultra 每周给 10 倍 Pro 且已验证账号取消 5 小时上限。
- · Team 档至少 2 席起订：Standard 月付 $25/人、年付 $240/人（折合每月 $20），Premium 月付 $125/人、年付 $1,200/人（折合每月 $100）。
- 额度池规则、月度 API 额度与折扣包：Claude Code 从 Pro 起包含且与对话共用同一额度池，周限额自 9 月中旬起已永久提升 25%。
- · 主力模型有四款：包括 Opus 5.5、Sonnet 5.5，外加 Haiku 5.5 与 Fable 5.2。
- · 调 Fable 5.2 的扣费差别：Max 和 Ultra 用 Fable 最多占周限额 50%，Pro 用 Fable 从一开始就走额外付费。
- · 百元以上档位每月送等额 API 额度：Max 每月送 $100，Ultra 每月送 $200 API 额度，满 7 天在网页端关联 Console 领取。
- · 超额还能买 Usage Bundles 折扣包：$50 面额付 $45 是九折，$250 付 $200 是八折，$1,000 付 $700 是七折。

网页端开通只收外币信用卡或借记卡，走手机商店不仅标价可能偏高，送的 API 额度还得回网页关联领取。Anthropic 不支持中国大陆与港澳，而且受非支持区主体控股同样不在供应范围内，风控门槛在四家里最高。

要是你手头本来就有调 API 接口的开销，这两家高阶档每月附赠的等额 API 额度能抵掉不少花费。

## 其他值得留意的海外工具，和国内备选

四家综合大模型之外，做配音和做音乐的两款海外工具真拿出了黑五年付折扣，写代码、查资料和出图的几款常用订阅也有新变动值得顺带看一眼。

- ElevenLabs（配音工具黑五首年省 55%）：美东 11 月 16 日至 12 月 1 日开放，仅限官网网页直接购买，次年按原年付价续费。
- · Creator 年付首年 $99：常规年付 $220，省 55%，折合每月约 $8.25，含每月 121k 额度。
- · Pro 年付首年 $445.50，月付改年付也有半价：新上 Pro 年付常规 $990，省 55%（折合每月约 $37.13），现有 Pro 月付改年付首年 $495（省 50%，折合每月约 $41.25）。
- · 需要留意的几条购买限制：不含应用商店或经销商渠道，预付包和 API 超量也不参加，一人一户一次，取消重订不恢复资格。
- Suno（做音乐黑五年付额外 7 折）：11 月 30 日截止，只限网页端买年付，次年按常规年付续费。

## 下单前顺手核对这 4 件事

真准备掏卡付款前，花一分钟把下面这四件小事过一遍，能少踩很多乱扣费和假优惠的坑。

- 先看准结账价格，再留意到期原价续费：优惠幅度和续费条款都写在结账页里，付钱前多看一眼。
- · 去官网看自己账号的实际价格：黑五折扣与买赠资格因号而异，只在官方网页结账页确认实际价格，别碰第三方优惠码站和非官方代充。
- · 下单后顺手定个到期提醒：Google、ElevenLabs 与 Suno 黑五价管首年，The X Subscription 买一送一管前 2 个月，到期后都会自动恢复原价续费，不续费记得提前设提醒并至少提前 24 小时取消。
- 换套餐或开高阶档前，查一遍旧账单和后台开关：多点两下手机设置和开发者后台，就能避开重复扣费。
- · 升级前先查苹果和谷歌的旧账单：通过苹果计费的旧版 Cursor 官方没法代取消，Google Play 的老订阅切换后也得自己去检查有没有关掉续费，免得被扣两份钱。
- · 领完赠金顺手关掉自动充值：订了送 API 额度或云赠金的 Pro、Max 和 Ultra 档，记得去后台手动领额度，再把自动充值关掉免得超额多扣钱。

各家的定价、额度池规则和地区名单隔段时间就会微调，具体条款还是以官网结账页写明的为准。

选出每天打开干活的那一两个主力工具，登进官网看准自己账号的价格再下手就够了，用不上的年费打折也没必要囤。
