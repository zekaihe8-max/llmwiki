今天 Claude Code 的额度又没了。

这个礼拜因为大部分时间在外面旅游，刚回到东京，所以其实用得不是特别频繁，90% 以上的时间都是用手机操作云端环境的项目来自动化执行的。

我发现推理和计算放在一起的好处，就是 Claude Code 的云端环境基本上可以胜任 80% 到 90% 以上的自动化工作，而无需依赖任何权限、弹出任何卡片。而且它还有一个比较好的方式，是你可以将云端环境复制到其他的 Claude Code 账号。

很久以前，我曾经用自己东京的服务器做主要的构建和开发机器，但切换到新的云端环境之后，它将大部分自动化工作都内化了。所以当它操作我的东京服务器时，要求的权限卡片甚至比直接在东京服务器上操作还要麻烦得多，所以我现在将大量的自动开发工作迁移到 Claude Code 内置的云端项目，也就是它的云环境当中。

很多个人助理都内置一个云环境。这些云环境因为是共享机器，经常重建，但性能应该还是蛮强的，几乎可以安装任何你要求安装的东西，比如 Chrome 浏览器或者 Blender。

通过这种方式，你可以在云环境的初始脚本里面去做自动化的备份和拉取。一旦云环境重建之后，就可以让它把你 Chrome 上登录的账号再 restore 回来。至于资源，比如说 Cloudflare 或者甚至是公司的 Stripe 的可读 Key，你都可以在云环境的密钥库当中进行配置。

这样可以确保，无论你使用多少号的后端账号，都可以在不同的临时云环境当中，通过和 GitHub 项目的组合，来完成全自动化的公司产品开发、营销流转，以及根据商业化情况来实现的自动化实验。

使用云环境还有一个非常好的潜在好处，就是刚才说到的推理和计算在同一处。

推理完的结果不需要远渡重洋传到我的个人电脑上来计算、再把结果传回去。这样单次推理加计算比传统方式能节省数百毫秒，一天下来，累加起来的优势还是蛮大的。

如果你订阅 Claude Code 或者是最高级的 Grok，而没有充分使用它的云环境的话，其实还是蛮浪费的。这就相当于给这些 SOTA 模型的订阅账户赠送了额外强大的计算空间。

同时，像 OpenAI 和 Claude Code 还会为 $200 和 $500 的订阅账户赠送对应的 API 额度。这些 API 额度可以在他们的开发者平台创建 API Key，在云环境当中配置好之后，就能直接实现图像生成或者视频处理，完全不需要再经过额外的 CLI 工具就可以实现
