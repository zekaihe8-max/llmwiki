没想到 Cloudflare 给 Pi Agent 准备好了一套独立的云端电脑

Pi 默认没有沙箱环境，但是运行的时候又需要和本机隔离，不然权限没处理好，很容易造成自己电脑的数据或者软件出问题

我就花了点时间去找对应的项目，发现 Cloudflare 其实已经有一套比较完善的 Agent Computer

简单来说，相当于给 Pi 单独准备了一套 Linux 运行环境，主要有 3 个优势：

1、环境隔离：独立执行命令、操作文件，不会直接影响本机

2、多 Agent 运行：可以给不同的 Pi 分配独立沙箱，互不干扰

3、自由度高：支持安装依赖、运行代码，只要资源和权限允许，基本都能折腾

而且 Cloudflare 官方已经提供了 Pi 的接入示例

使用起来也不复杂，开通 Cloudflare Workers Paid，按照官方教程配置 Pi 和 Sandbox，通过 Wrangler 部署之后，就可以让 Pi 在独立的云端环境里执行任务

唯一的缺点就是需要付费，Workers Paid 最低每月 5 美元起，超出资源额度还会额外计费
