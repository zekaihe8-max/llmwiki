乐鑫这次有点意思，开始让 Coding Agent 直接开发 ESP32 硬件了

最近发现他们推出了一个叫 ESP-Mosaico 的开源项目，跟我们平时用的 ESP32 开发板不太一样

它不只是给 AI Agent 装一块屏幕，而是想让 Agent 从写代码、模拟调试到烧录、真机验证，直接参与整个硬件开发过程

主要有 3 个比较有意思的地方

1、Chat Coding：说句话就能开发硬件

内置 ESP-Claw，不需要自己搭建完整的开发环境

比如让它做一个俄罗斯方块游戏，Agent 就能根据硬件配置生成代码、构建程序并部署到设备上，后续还可以继续对话修改功能

2、Vibe Coding：让 Coding Agent 直接操作硬件

以前用 Claude Code、Codex 开发 ESP32，最麻烦的不是写代码，而是硬件适配、烧录、看日志、反复调试

ESP-Mosaico 把模拟器、编译部署和真机反馈接到了 Agent 的开发流程里，让它有机会根据实际运行结果继续修改代码

3、模块化设计：硬件也能自由组合

核心采用 ESP32-S31，配备 480×480 触摸屏

摄像头、传感器、摇杆、LED 等都可以通过模块扩展，甚至支持多块设备拼接，实现跨屏游戏和互动应用

而且相关的固件、开发工具、BSP 和示例项目都已经开源

我之前一直在研究怎么用 Claude Code 和 Pi 开发自己的 ESP32 小助手

现在看来，乐鑫也在往这个方向走

以后可能 AI 和硬件相关的结合会越来越深，相对的，对应的开发门槛也会越来越低。后面只需要说说话，通过一根数据线，或者连数据线都不需要，通过 WiFi 连接就可以完成烧录或者是设置

这么看下来的话 硬件这方面真的要花时间去研究了，未来真的会越来越有意思
