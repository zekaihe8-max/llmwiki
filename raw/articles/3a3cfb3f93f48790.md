ChatGPT Pro 和 Business 订阅即日起每月送最高 500 美元 API 额度，不另收费，Plus 没有

OpenAI 10 月 28 日宣布，付费的 ChatGPT Pro 和 Business 订阅用户，每月可以免费领一笔 API 额度，最多 500 美元。API 是给开发者用的接口，按用量付费，自己写的 App、网站、自动化脚本要调用 OpenAI 的模型，走的就是这条路。以前订阅 ChatGPT 和用 API 是两本账，交了订阅费，写程序照样另外充钱。现在这笔额度算在订阅里，不用额外付费。

【谁能领、领多少】

Pro 按档位给，每月 100、200 或 500 美元。据 CellCog 的说法，额度正好等于各档月费，相当于订阅费原样变成 API 额度。Business 按付费席位算：标准席位每个 20 美元，高级席位每个 100 美元，整个工作区合在一起用，上限 500 美元，也就是 25 个标准席位或 5 个高级席位就封顶，再加人也不涨。

Plus、Go、免费版和 Enterprise 都没有。据 CellCog 转述 OpenAI 帮助页，订阅还要满 7 天，免费试用和赠送的订阅不算。地区限制官方推文没提，两家媒体也没写。

【怎么领】

在 ChatGPT 的“设置 → 账单”里领取，绑定一个你自己名下的 API 组织（OpenAI 开发者平台上的账户），ChatGPT 账号和 API 账号要用同一个邮箱。Business 由工作区管理员在账单设置或管理后台领。领完后，在 ChatGPT 或 Codex 里用 OpenAI Developers 插件就能生成 API key、建项目，不用先绑信用卡。

【能干什么，有什么限制】

这笔钱可以花在 OpenAI 开发者平台的大部分服务上：调模型做对话和智能体、实时语音、生成图片，以及联网搜索、代码解释器这些内置工具。比如给自己做个小工具，或者给团队搭个内部问答机器人。

几条限制要注意，以下均据 CellCog 转述的 OpenAI 帮助页：额度当月有效，账单周期结束清零，不能攒到下个月，第一个月按剩余天数折算；用 API key 跑 Codex 不能花这笔钱；它也不会提高你在 ChatGPT 和 Codex 里的使用上限，两边额度各算各的。花钱顺序是先用赠送的，再用自己充的；两笔都花完，请求会直接报错，除非开了自动充值。
