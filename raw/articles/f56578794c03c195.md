DS Bot：把多个 AI Agent 组织成一个团队的开源协作工具。

基于 DeepSeek Harness，通过 Chief 统一协调不同 AI 助手，支持 Bot 群聊、@任务委派、Goal 目标管理、独立记忆和工作目录。

还能接入已有的 Claude Code、Codex CLI、Cursor CLI 等本地编程 Agent。

和偏向云端 AI 员工服务的 Grok Bot 不同，DS Bot 更侧重本地 Agent 的组织与协作，支持 Windows、macOS、Linux 桌面端及 Docker 自托管部署。

Apache 2.0 开源，软件免费，模型费用自理，多 Bot 协作也可能增加 Token 消耗。

适合已经在用多个 AI Agent，希望统一管理、分工执行任务的用户。
