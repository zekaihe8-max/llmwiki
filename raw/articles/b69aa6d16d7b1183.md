10 个 GitHub 上最热门的开源 Personal Agent，最高已经接近 40 万 Star

最近一直在研究 Grok Bot 的替代方案，前面也陆续分享过 OpenClaw、Hermes Agent、OpenBot 和 MausBot

这次我又去 GitHub 整理了一批社区关注度比较高的开源项目，基本都在几万 Star 以上

我按照不同的使用方向，整理了 10 个值得关注的 Personal Agent

1、OpenClaw｜约 39.5 万 Star

目前生态最完善的 Personal Agent 之一，支持大量 Skill、聊天平台和自动化工作流

适合想要一个功能全面的私人助手，而且不介意花时间配置的朋友

[github.com/openclaw/openc…](https://t.co/aRcgcBoGWZ)

2、Hermes Agent｜约 26.4 万 Star

这也是我目前使用最久的 Personal Agent，主打自主学习、长期记忆和 Skill 自我优化

我自己也在持续完善它的记忆系统，准备把它打造成长期使用的个人助手

[github.com/NousResearch/h…](https://t.co/5YCOLwa3Z2)

3、Nanobot｜约 5 万 Star

主打轻量化的 Personal Agent，代码结构比较简单，支持聊天平台、工具调用和定时任务

如果觉得 OpenClaw 太过沉重，可以研究一下这个项目

[github.com/HKUDS/nanobot](https://t.co/P6mNUbKd5d)

4、AstrBot｜约 4.7 万 Star

更偏向聊天机器人和即时通信平台的 Agent，拥有比较丰富的插件生态

适合想把 AI 接入 QQ、Telegram、Discord 等聊天平台的朋友

[github.com/AstrBotDevs/As…](https://t.co/l4sWoHCSw0)

5、QwenPaw｜约 3.8 万 Star

支持本地和云端部署，有 Web 管理界面、长期记忆、Skill 和定时任务

比较适合希望通过聊天软件管理个人 AI 助手的用户

[github.com/agentscope-ai/…](https://t.co/q3VBS3p93y)

6、AionUi｜约 3.4 万 Star

这个和 OpenBot 的思路有点像，可以把 OpenClaw、Hermes、Codex、Claude Code 等 Agent 集中到一个桌面界面里使用

适合已经有多个 AI 订阅，不想反复切换工具的朋友

[github.com/iOfficeAI/Aion…](https://t.co/h5iHggWTQJ)

7、ZeroClaw｜约 3.3 万 Star

Rust 开发的轻量级 Personal Agent，重点是低资源占用和模块化扩展

比较适合想自己部署在 VPS 上，并且关注运行效率的朋友

[github.com/zeroclaw-labs/…](https://t.co/WUjffA9DVQ)

8、NanoClaw｜约 3.1 万 Star

它比较有意思的地方是安全隔离，每个 Agent 可以在独立容器里面执行任务

如果你准备让 AI 操作文件、执行命令，又担心权限问题，可以重点研究一下

[github.com/nanocoai/nanoc…](https://t.co/hin6mJCUhK)

9、PicoClaw｜约 3 万 Star

主打极低资源占用，可以运行在小型设备和低配置服务器上

如果你平时喜欢折腾 VPS、树莓派或者其他 AI 硬件，这个项目挺值得关注

[github.com/sipeed/picoclaw](https://t.co/dTfMz6JCNm)

10、OpenMausBot｜约 2.6 万 Star

这是我最近才开始关注的项目，也是比较接近 Grok Bot 使用方式的一个

支持多机器人对话、电脑操作、定时任务，还可以通过自己的 VPS、Tailscale 或域名远程连接

[github.com/milind-soni/Op…](https://t.co/S8ShQ1Gn1z)

这 10 个里面，我觉得可以根据自己的使用需求去选择

如果想要插件生态比较完善的，可以考虑 OpenClaw；如果更关注长期记忆和自主学习，我比较推荐 Hermes Agent

如果想要类似 Grok Bot 的多机器人界面，可以研究 OpenMausBot 和 AionUi

而如果准备部署在低配置 VPS 上，Nanobot、ZeroClaw 和 PicoClaw 都值得尝试

不过 Star 高不代表就一定适合自己，尤其是网络稳定性、长任务执行和权限管理，这几个方面我觉得还是要自己实际测试一下
