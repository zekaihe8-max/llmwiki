宝玉的 baoyu-design 里有一套 DeepSeek Harness 插件，做 PPT、网页设计、数据看板、动画都能用。几个子项目分别介绍下：

1. claude-slides｜做幻灯片

把笔记、课程材料、产品需求交给 Agent，生成可编辑的幻灯片。可以在编辑器里改字、拖动元素、全屏放映，导出 PDF、HTML 或 PowerPoint。

安装包：dsh-claude-slides

2. claude-design｜做网页设计和原型

一个画布里可以放多个画板，比如把网站首页、注册页、手机版并排摆出来。支持修改文案、调整参数、播放交互原型，也能导出 HTML、PDF、PNG。

安装包：dsh-claude-design

3. claude-design-system｜整理一套设计规范

管理品牌色、字体、间距、圆角、组件和素材。做多份设计时，可以共用一套规范，保持风格一致。从组件库导入的组件，还能在预览里直接操作。

安装包：dsh-claude-design-system

4. claude-dashboard｜把数据做成看板

提供 CSV、TSV 或 JSON，让 Agent 做图表、指标和表格。页面支持筛选，Sources 面板能查看数字来自哪些原始数据行。后续换上新数据，页面会重新计算。

安装包：dsh-claude-dashboard

5. claude-motion｜做动画影片

用代码逐场制作讲解动画、产品演示、片头。在播放器里预览，修改台词、场景时长和样式，也可以在具体时间点留评论，最后导出 MP4 或 GIF。

安装包：dsh-claude-motion

6. claude-whiteboard｜画白板

适合流程图、想法地图、方案对比。Agent 往白板上放方块、箭头、表格和便签，你可以继续拖动、打字、手绘，或者留评论让 Agent 修改。

安装包：dsh-claude-whiteboard

这些插件共用 dsh-claude-artifacts，安装时会自动带上。它负责左侧的「作品」页，以及把编辑器里的评论交给 Agent。

DeepSeek Harness 桌面版打开 Plugins → Add plugin，填对应包名，安装并启用，重启后新开会话即可使用。不需要克隆仓库，也不用自己构建编辑器。
