Grok Bot 云主机 IP 不稳定，Claude Code 别接在里面跑

为什么这么说呢？

我是不建议大家在 Grok Bot 里面跑 Claude Code 的，我总结了最主要的原因有三个

第一个也是最主要的，就是它的 IP 是变动的，有的时候甚至会切回国内，X 上已经有人反映了，会直接切到郑州

这个可能和你自己的路由或者分流规则有问题，所以导致出现这种情况，但凡你的 Grok Bot IP 路由到中国，你的 Claude 账号就有很大的风险

第二个就是 Grok Bot 可能会存在重置的问题

我自己在使用过程中也遇到过一次，没有办法找到我原来的数据，导致我里面的登录持久化失效

这样的话，可能会导致你频繁地去授权 Claude Code

第三个问题就是，如果频繁地让 Claude Code 和 Grok Bot 去传话的话，也会导致你整个额度消耗过高

所以我的推荐是，不建议在 Grok Bot 上使用 Claude Code

如果一定要使用的话，建议开启本地网络代理，让 Grok Bot 的网络走你本地电脑的出口

或者使用 Cursor 里面对应的 BDK 程序，然后通过 Claude Code 去调用 Grok Bot，这个我以前也分享过
