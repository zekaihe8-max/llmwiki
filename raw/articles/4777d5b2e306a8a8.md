DeepSeek Harness 官方这次有点意思，直接把 7 套插件开发 Prompt 全部公开了🔥

以前看到一个不错的插件，我们可能第一反应是去 GitHub 找源码

但是这次不一样，DeepSeek 官方直接把演示视频里使用的提示词整理了出来，中英文都有

从 3D 可视化到视频剪辑，甚至是论文阅读器，只需要通过 Creator Mode，就可以尝试让 DSH 帮自己开发对应的插件

我挑了其中 3 个比较有意思的案例：

1、Transformer 3D 可视化

官方的提示词其实非常直接：

创建一个带左侧边栏入口的插件，做成可交互的 3D 演示游戏，帮助我理解 Transformer 内部的计算逻辑

相当于让 DSH 把抽象的模型知识，变成一个可以交互的可视化工具

2、视频编辑工作台

这个就更实用了

创建一个视频编辑工作台，支持上传多个视频、剪辑和导出，预览器在上方，时间轴在下方，同时支持通过自然语言剪辑视频

不仅是做一个 UI，还要求插件能够跟 DSH 的对话能力结合

3、论文阅读器

创建一个从右侧边栏进入的论文阅读器，保留原始排版，选中文字后可以高亮、添加笔记，或者直接在会话中提问

这类插件我觉得特别适合日常学习，完全可以根据自己的习惯继续增加功能

除此之外，官方还整理了 3D 地标展示、像素风界面、海报设计工作台和 Token 会话统计等案例

官方 7 套 Prompt 合集：
[cdn.deepseek.com/harness/dsh-cr…](https://t.co/WYQo9PYppq)

使用方法也不复杂，复制对应的提示词，在 DeepSeek Harness 里选择 Creator Mode 就可以开始尝试

不过有些官方演示经过多轮对话调整，并不是复制一次就能完全复现

我觉得最值得研究的反而是这种开发方式

以后使用 Agent，可能不一定需要到处找现成的插件，自己缺什么功能，直接让 DSH 帮忙做一个，再慢慢迭代就好了
