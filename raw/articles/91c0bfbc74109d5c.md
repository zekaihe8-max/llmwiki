Google Antigravity 体验提升小技巧

大家都知道谷歌的AGY 不怎么好用，但是可以安装一些插件或者skill去做一些优化，不能说提升很高，但是也是有一些优化

我挑了 3 个比较热门的开源插件和 Skills，可以在一定程度上弥补这些不足，让 Antigravity 用起来更顺手一些

1、Superpowers｜32.2 万 Star

主要提升 AI 编程的工作流程，让 Agent 在写代码之前先做好规划，再按照步骤执行、测试和 Debug

我觉得这是比较值得尝试的一个，可以改善任务执行流程，减少反复修改代码的问题

项目：[github.com/obra/superpowe…](https://t.co/SGHwt9O9QX)

2、Context7｜6.5 万 Star

主要解决 AI 使用过时文档的问题，可以获取较新的开发文档和 API 用法

特别是在使用更新频繁的框架和依赖时，能够减少版本不匹配、API 调用错误等问题

项目：[github.com/upstash/contex…](https://t.co/sUDxLe7gwi)

3、UI UX Pro Max｜15.2 万 Star

主要提升 AI 的前端设计能力，提供大量设计风格、配色方案、字体和布局规范

如果经常让 Antigravity 编写网站、后台管理系统或者设计页面，我觉得这个插件比较实用

项目：[github.com/nextlevelbuild…](https://t.co/7NNKFXReAE)

这三个都不是必须安装的，Antigravity 本身也有对应的能力

只不过安装之后，可以在开发流程、文档获取和前端设计方面提供一些额外的帮助，让整体效果更好一些

我个人比较推荐先尝试 Superpowers 和 Context7，至于 UI UX Pro Max，如果没有前端开发需求，就没必要专门安装了
