快去试试 ego-lite！浏览器操作交给 Agent 真的太爽了！🤣

刚才用 ego-lite 把我的费用报销流程跑了一遍，体验相当丝滑！比 Codex 的浏览器操作快太多了

以前最烦的就是报销，一堆发票要合并成 PDF，还得打开公司系统，填收款人、银行卡、项目类别、金额，再一个个上传附件……

每一步都不难，就是特别琐碎。

这次我直接给 Agent 丢了一句话：

/ego-browser 帮我申请费用报销，先合并这些发票，再填报销单……

然后它就自己开始干活了！

合并发票、打开报销系统、填写表单、上传附件，最后连按钮都从「存为草稿」变成「更新草稿」了。

我只需要检查一下结果就行。😂

上手也很简单：

1️⃣ 打开 [lite.ego.app](https://t.co/gOLDIWamQl) 下载安装（Mac 正式版，Windows Beta）
2️⃣ 导入 Chrome 数据
3️⃣ 然后在 Codex、Claude Code、Cursor 等 Agent 里输入 /ego-browser 激活 Skill 就行。

需要配置本机执行权限，敏感操作建议保留人工确认。

以前一直觉得 Agent 就该帮我们解决这些重复又琐碎的事情，现在终于越来越有那味了！
