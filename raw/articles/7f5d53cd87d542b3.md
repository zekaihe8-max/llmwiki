# box by Simular

>

box is a cloud Linux desktop for your AI. Add it to Claude, ChatGPT, Claude Code, Codex, Cursor, OpenCode, Hermes, OpenClaw, VS Code or DeepSeek Harness as a remote MCP server and your AI can use a real computer: open a browser, click, type, read the screen and run commands.

## Key facts

- Product: box, from [Simular](https://www.simular.ai/). Portal: https://box.simular.ai.

- Interface: one hosted MCP server, box (https://mcp.box.simular.ai/mcp). You sign in with your Simular account the first time your AI connects (OAuth); no key to paste. For apps that can't sign in, a personal key works as Authorization: Bearer cb_...: https://box.simular.ai/access.

- The computer: one cloud Linux desktop per account. It sleeps when no one uses it and wakes when your AI connects. A box asleep for 14 days in a row is deleted, with its files and saves; any wake resets the count.

- Cost: the box itself is free. Its model calls use your account's daily credits.

## Getting started

### One command

```
npx @simular-ai/box connect
```

It finds Claude Code, Codex, Cursor, OpenCode, Hermes, OpenClaw and VS Code on this computer, adds box to the ones you pick and leaves their other settings alone. Each app signs you in to box in the browser the first time it connects. For Claude Desktop it prints the steps. npx @simular-ai/box doctor checks the setup; npx @simular-ai/box remove undoes it. Source: https://github.com/simular-ai/box-plugin/tree/main/cli.

Or set box up in your app:

### Claude (claude.ai and the desktop app)

[Add to Claude](https://claude.ai/customize/connectors?modal=add-custom-connector&connectorName=box&connectorUrl=https%3A%2F%2Fmcp.box.simular.ai%2Fmcp)

Claude opens with box filled in, on your phone or your computer. Tap Continue, then sign in to box and approve.

Claude Free allows one custom connector. On Team and Enterprise, an Owner adds box for the organization first.

Or by hand:

- In Claude (claude.ai or the desktop app), open Settings → Connectors.

- Click Add custom connector. Name it box and paste the URL below; leave the advanced settings empty.

- Click Connect, sign in to box and approve. Then turn box on in a chat’s tools menu.

The URL: https://mcp.box.simular.ai/mcp

### ChatGPT (chatgpt.com)

- On a computer, open chatgpt.com/plugins (Plugins in ChatGPT’s sidebar). Click Add, then Add custom MCP server.

- Name it box. Under Connection, paste the URL below as the Server URL, and choose OAuth as the authentication.

- Select I understand and want to continue, then Create as a plugin. Install the plugin, then sign in to box and approve when asked.

- In a chat, type @ and pick box, then ask for a task.

The URL: https://mcp.box.simular.ai/mcp

### Claude Code

```
claude mcp add --transport http box https://mcp.box.simular.ai/mcp
```

Then run /mcp in Claude Code, pick box and choose Authenticate.

### Codex

```
# ~/.codex/config.toml
[mcp_servers.box]
url = "https://mcp.box.simular.ai/mcp"

# then sign in: codex mcp login box
```

### Cursor

```
{
  "mcpServers": {
    "box": {
      "url": "https://mcp.box.simular.ai/mcp"
    }
  }
}
```

Cursor asks you to sign in to box the first time.

### DeepSeek Harness (dsh)

```
dsh plugin add https://github.com/simular-ai/box-plugin/releases/download/dsh-v0.2.1/dsh-box.tgz
export BOX_TOKEN=cb_your_key
```

dsh can't sign in, so it uses a personal key: make one at https://box.simular.ai/access and set it as BOX_TOKEN. Restart dsh. box's tools show up as mcp__box__*.

Or tell your coding agent Set up box from https://box.simular.ai/install and it does the rest. Then ask for a task, for example: Use box to open Chrome, search Google for "Simular", and summarize the top 3 results.
