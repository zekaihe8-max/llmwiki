Factory 发布 Coding Agent 运行框架 Droid 1.0，引入程序化工具调用（Code Mode），并将其设为默认执行方式。AI 可以先编写 JavaScript 脚本，再通过脚本连续调用数百次工具，不用每执行几步就重新请求大模型，从而减少模型调用次数和 Token 消耗。

例如，迁移并核查 151 条 Linear 工单，传统方式预计需要 36 次模型请求、310 万输入 Token。改用 Code Mode 后，实际只需 2 次请求、约 6.1 万 Token，输入 Token 减少约 98%。在更广泛的测试中，使用 Claude Opus 5.5 的任务成本降低约 15%。

Factory 还优化了不同模型的工具调用策略、缓存和任务执行机制。在 Terminal-Bench 4 官方自测中，使用相同的 GPT-6.1 Sol 模型，Droid 比 Codex 高 3.5 分，成功任务成本降低 12%，但耗时增加 10%。

Code Mode 并非新技术。Cloudflare 早在 2025 年 9 月就提出了这一方案，Anthropic 随后也将类似机制用于 Agent 工具调用。今年，DeepSeek Harness、Pi 和 OpenCode 2.0 等开源 Agent 框架也陆续加入支持。
