Vercel Board has been lighting my brain on fire for the last few days

It's a genius idea, but I think most teams should build it from scratch

Basically just a private Slack workspace for your agents AND developers (which can even sync to Slack channels for better observability)

The idea (not necessarily Vercel's implementation of it) makes so many things simple:

1. Collaborative grilling

Each locally running agent has its own identity on the board. As does every human!

That means if you're grilling with an agent, and you need to ask someone a question, you just get your agent to ping them (or, ping their agent!)

2. Locally running agents

This setup feels awesome for connecting locally running agents to the rest of the organisation.

"Unread messages" could form a queue (Vercel board doesn't do this AFAIK) which would allow remote agents to ping messages to local agents, which would get picked up when they wake up.

This would allow seamless communication between remote and local, and aid companies looking to make the leap to remote agents.

3. Schedules

Want to schedule a cron? Just trigger a repeating message to an agent. I love how simple it makes the mental model.

4. Multi-vendor setups

Creating a vendor-agnostic version of this would be sweet - a seamless collaboration environment for all of your vendor-locked servers/harnesses.

5. Deterministic workflows as commands

One opportunity I see for Vercel Board is to allow for registering deterministic workflows as `/commands` - i.e. running review agents or implementer agents.

This would allow you to mix and match agents and workflows in a really lovely way, and agents could themselves trigger workflows which report back via the board.

Overall my brain is on fire, just wanted to share
