## 铁锤人 @lxfater

**昨晚还说得慢慢验，一觉醒来 Lean 官方就盖章了**：最悬的两件事是代码里的题目对不对得上、有没有偷加前提。联合声明里写了，几十人独立跑通全部代码，没报错、没多加公理，两套比对工具确认证的就是原版黎曼猜想，多套不同语言的检查程序也全过。数学界消化新思路、千禧年大奖还得等，但证明对不对，社区已经给了结论。他还补了上个月哥大和 MIT 两位学者的论文：Claude 没人插手跑了 1600 万 token，自己找到新算法，打破卡了几十年的 3SUM 和点对最短路上限，核心结论同样丢进 Lean 验真。新算法只比老纪录快一点点，导航不会突然变快，但理论铁板被凿开了。这篇有 25 个赞、16 个收藏。[原帖](https://x.com/lxfater/status/2124363506396824033)

**Claude Code 也上了 Code Mode，让 AI 写脚本调工具**：昨天 browser-use 刚砍掉 24 个动作，改让 AI 写代码干活，Claude Code 实验功能走的是同一条路。以前搜一次文件就把几千行原始结果塞回对话，上下文很快被撑爆；开了之后，Claude 会写一段 JavaScript 把多步活串起来，先在代码里筛掉废话，只把关键结果传回来。测试、打包这类长任务，自动模式下还能扔后台跑，最长 2 小时，期间可以继续聊别的。门槛是终端版 v2.1.323 起，还得配官方订阅或直连账号，中转站、云代理和桌面端暂时用不了，启动命令是 `CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1 claude`。权限拦截还在，但官方说沙箱只管脚本里的终端命令，代码本身和文件、网络、MCP 都在沙箱外，跑陌生项目还是要套容器或虚拟机。[原帖](https://x.com/lxfater/status/2124427730460565506) [官方文档](https://code.claude.com/docs/en/code-mode)

**OpenCode 把国产开源模型卖得比官方还便宜**：他写，海外平台 OpenCode 宣布智谱 GLM 5.3 和 DeepSeek V4.1 Flash 降价 60%，输入 100 万 token，GLM 5.3 官方要 1.4 美元，它只要 0.56 美元；DeepSeek V4.1 Flash 它卖 0.12 美元，连官方低谷半价时段都要 0.15 美元。原因很直白：模型文件是公开的，平台不用掏训练费，租显卡就能卖。论坛上有人替厂商叫屈，觉得开源亏了。他算了两笔账：显卡本来就紧，放出去能让外面平台帮着扛流量；海外付费用户早被 OpenAI 和 Claude 圈走，不免费放出去，编程工具和在意数据不出境的公司根本不会接。普通人先占了便宜，但只靠开源很难把训练费赚回来。[原帖](https://x.com/lxfater/status/2124439812467748949)

**官方给 GPT-6.2 发了提示词补丁**：不少人吐槽它回答敷衍，还动不动停下来反问。官方文档里放了几段能抄的系统提示，并提醒从老模型切过来，别把以前那套固定规矩直接套上。原因是 6.2 默认就更简短，再写一句「尽量简短」，两头一叠加就变成敷衍，所以第一条就是把这类旧要求删掉。防反问写得很死：活没干完、下一步也在放权范围里，就不准停下来交计划或问琐事；细节拿不准，先按能撤回的办法假设着继续干，只有真卡死、任务大改，或碰上撤不回来的危险操作，才准停下来问。写代码还附了三条：能复用就别多造辅助函数，没要求就别乱加测试，别靠乱缩写变量名充简洁。他坦言这些模板还没实测。[原帖](https://x.com/lxfater/status/2124465462406721801) [官方模板](https://developers.openai.com/api/docs/guides/latest-model?model=gpt-6.2-astra)

看法：黎曼这边机器已经验收，写代码这边则在把工具调用收成一段能跑的脚本

## meng shao @shao__meng

**MBZUAI 和 UCL 拆了 Claude Code 的源码**：技术报告「Dive into Claude Code」分析了 v2.1.88 的 1884 个文件、51.2 万行 TypeScript。核心是一条 queryLoop()：组装上下文、调用模型、接收工具请求、检查权限、执行工具，再把结果交回模型，终端、无头命令行、Agent SDK 和 IDE 都走这条路。权限上梳理了七种模式，拒绝规则优先于允许规则，CLAUDE.md 只是文字指导，要拦住的动作还得靠权限机制。上下文有五层收缩：预算削减、片段裁剪、微压缩、上下文折叠和自动压缩，先用便宜办法减内容，必要时再做语义摘要。Explore、Plan 和通用子 Agent 在各自上下文里跑，必要时用 Git worktree 隔离目录，避免把探索过程全塞进主对话。这篇有 20 个赞、34 个收藏。[原帖](https://x.com/shao__meng/status/2124369057805926670) [论文](https://arxiv.org/abs/2604.14228v3)

**常驻 Agent 系列第一篇，先讲权限**：他拆了 Anthropic 的「Building always-on agents」，后面还会写事件唤醒、通知和记忆。这一篇的关键是：凭证不要直接进 Agent 运行环境，由外面的代理在转发时注入；自动审核可以挡住一部分危险动作、减少反复确认，但不能因为过了分类器就默认所有操作都能无人执行；需要人批准时，应保存会话、结束当前运行，等人回复再启动下一次，而不是占着资源空等。三种机制各管一件事，不能互相替代。他自己的读后感是，自主性既体现在授权范围内持续推进，也体现在边界上能够可靠停下。[原帖](https://x.com/shao__meng/status/2124437881569554634)

**Parth Sharma 把一年半的 Agent 工程收成「其实就是一个 while 循环」**：理解运行框架可以先抓住这个循环，但真正影响质量的是工具设计、上下文管理和可靠的后端。每轮产生的内容都会变成后续输入，所以工具返回多少、哪些值得留，会直接影响成本和判断。他欣赏 pydantic-ai、pi 这类核心流程清楚的实现，也把子 Agent 还原成一种工具调用：启动独立会话，跑类似循环，最后交回结果。循环周围才费功夫，比如流式传输、心跳、断线重连、取消和超时要传到真实请求，重试还得考虑幂等。[原帖](https://x.com/shao__meng/status/2124331898772361395) [原文](https://parthshr370.github.io/blogs/its-all-a-while-loop/)

看法：他把 Claude Code 拆开以后会发现，强的不只是模型，是循环外面那层权限、压缩和委派

**Vibe Coding 到底创造了多少真实价值**：他转述 MIT 和沃顿研究者的一篇论文，AI 编程让代码变更量达到原来的 25.5 倍，提交量增长 240%，实际软件发布量却只增长 30%。应用商店新 App 数量大幅增长，用户参与度却没有同步提升。他的概括是，开发者在狂欢，用户没收到邀请。[原帖](https://x.com/heydengai/status/2124465666862485742)

**暴论是一亿免费用户，可能还不如一百万付费用户值钱**：他列出豆包月活 4.19 亿、千问 1.58 亿、DeepSeek 1.23 亿，说中国互联网最擅长的免费换规模，正在 AI 行业上演。但微信多一个用户，社交网络就多一分价值；AI 多一个用户，模型未必更聪明，推理账单却是实打实增加。他的判断是，用户规模第一次可能从护城河变成成本中心。[原帖](https://x.com/heydengai/status/2124379599517691935)

看法：代码变更量和发布量对不上，说明现在很多产出还停在「写出来了」，没到「有人用」

## 马天翼 @fkysly

**再强的 AI，也替不掉商业化软件**：原因是人的精力有限。不可能指望一个忙了一整天、一天能赚 1 万甚至 10 万美金的人，晚上再花 1 小时 vibe coding 出一个整理行程的工具，更不可能自己去抠某个软件新版本里滑动手势的适配细节。他的结论是，软件不管怎么变，都需要人来维护，也需要软件公司来维护，不管这家公司是人组成的，还是 AI Native 的。这篇有 47 个赞、18 个收藏。[原帖](https://x.com/fkysly/status/2124390623788900369)

**从 App Store 订 Gemini，价格页面要看对**：新用户如果必须走 App Store（比如美区还有余额），一定要去 Google One App 里看订阅价。Gemini App 里没有三个月优惠，默认 Pro 是 19.9 美元/月；单独下载 Google One App，里面才有和官网一样的 4.99 美元优惠价，优惠三个月。[原帖](https://x.com/fkysly/status/2124467812060352740)

看法：Vibe Coding 能做自己的小工具，但高收入的人更愿意为省下来的那一小时付钱

## 小工具

**Linger**：前 DeepSeek V1 作者张博开源的本地 Personal Agent，可挂本机模型和已有的 Claude Code、Codex、Pi 订阅，早期安装坑还比较多。[GitHub](https://github.com/simplexai-labs/linger) [介绍帖](https://x.com/xiaomovps/status/2124444730746642699)

**Antigravity Flow**：在 Antigravity 里直接操作 Google Flow 做视频，消耗积分前会提示费用。[GitHub](https://github.com/wezzard/antigravity-flow) [介绍帖](https://x.com/Gorden_Sun/status/2124124404208804306)

**Claude Code Code Mode**：终端版 v2.1.323 起，设置 `CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1` 后启动，桌面端和云端会话暂时没有。[文档](https://code.claude.com/docs/en/code-mode)

**pi-H3**：MiniMax H3 的快速推理，Hugging Face Demo 上 15 秒视频大约 1 分钟出片。[模型](https://huggingface.co/Lakonik/pi-H3) [Demo](https://huggingface.co/spaces/Lakonik/pi-H3)

**Sign in with ChatGPT**：开源和本地工具可走现有 ChatGPT 套餐额度调用 Sol，不用另配 API key，目前还是预览。[文档](https://developers.openai.com/siwc/token-sharing-open-source)

**上海飞鸟电台**：Ding 转发了 koji 用 Codex 加树莓派做的 24 小时听鸟鸣、识鸟种项目，用了 BirdNET 和 Google Perch。[介绍帖](https://x.com/Yuancheng/status/2124151562016821438) [站点](https://aihh-bird.kojiyang.me)
