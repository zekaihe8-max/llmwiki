## 数字生命卡兹克 @Khazix0918

**他写了一篇支付宝 SkillPay 上手文，核心判断是好手艺不该只剩免费开源**：常有朋友做了觉得不错的 Skill 来问怎么变现，他不愿说「你为什么不开源」，因为 Skill 的核心就是明文经验，不给人看没人买，给人看了约等于开源，买走也能转发给一百个人。他盘过几家方案，仍觉得支付宝 7 月上线的 SkillPay 是目前最优解，不限制在哪个 Agent 里用，WorkBuddy、豆包工作、Codex、Claude Code 都能调，买之前也可以先试用。[原帖](https://x.com/Khazix0918/status/2126163343023263893) [文章](https://x.com/i/article/2126161832415244288)

**他亲自买了两种卖法，也拿同事的番茄小说拆文 Skill 走了一遍上架**：买断是付一次拿到完整内容，他买过一个「六度人脉连线」，未支付时跟 Agent 说已付款也绕不过去，付完才能看到完整规则，之后本地装好就能换平台接着用。订阅按使用时长收费，到期自动失效、不自动续费，完整 Skill 留在云端沙盒，本地只能看到登录、请求模板和轮询流程，他买的是批改雅思作文，Codex 把题目和作文发到云端，再按返回的批改指引打分。上架要先签 SkillPay 和即刻收两份协议，他说到今年年底平台本身不收服务费，但即刻收抽 1%。买断定价目前是 0.01 到 50 元，订阅可按周、月、季度，上限都是 50 元，付费模式选定后不能改，价格和免费试用可以改，试用最低 5 次。审核通过后会给出收款码和购买指令，更新也不用重新上架，他支付后同事这边进款很快。这篇发出后有 439 个赞、487 个收藏。

看法：Skill 难卖，不是因为没人愿意付钱，而是明文经验一旦被看见就很难再设门槛，云端沙盒至少给了一种不必立刻开源的卖法

**他推荐免费电子学入门站 Electronics 101：现在是 68 节 3D 互动课，支持简体中文，打开浏览器就能学**：开发者是 Dilum Sanjaya，把电路做成能拖动、旋转的 3D 模型，从「电为什么要绕一圈才能流」讲到逻辑门和计数器，不用注册，电脑和手机都能打开。每节都是能动手改的小电路，导线上能看到电流，点高亮元件就能替换。课程分 10 个单元，11 月 5 日上线时是 48 节、13 种语言，第二天补到 20 种语言，11 月 18 日又加了 20 节，补上逻辑门、运算放大器和 555 定时器。Dilum 说，是因为之前的 Arduino 和 ESP32 学习 App 被学校拿去教孩子，才想做一套更基础的。这条有 291 个赞、437 个收藏。[原帖](https://x.com/dotey/status/2126157234144989236) [网站](https://electronics-101-six.vercel.app)

## 小墨同学 @xiaomovps

**他说 Antigravity 不好用，大概率是插件装乱了，筛完只留 5 个不打架的就够**：有人盘了一堆增强插件，功能重叠，全装还容易把自动更新搞坏。他留下的是：agy-fast，把批量搜索、大纲提取、多文件修改和跑测试收成 5 个本地 MCP 工具，项目实测少跑约 34% 轮次、省约 31% 额度；Ponytail，逼着 Agent 复用仓库里已有代码，官方在 Claude Code 里测下来代码量少 53%、Token 省 45%；agy-powertools，给 2.0 桌面端加上下文占用、缓存命中、用量看板、会话分支和中文界面，而且是本地只读挂载，不改安装文件；Paragravity，给多账号做物理隔离窗口，他提醒配置目录里有明文登录凭据，别同步上云盘；antigravity2-cn 是纯汉化包，如果已经装了 powertools 就不必再装，Mac 上打这种底层补丁可能让官方自动更新校验失败。他的日常建议是只留 agy-fast 加 agy-powertools。[原帖](https://x.com/xiaomovps/status/2126149728161370158)

**他解释为什么 Gemini 和 Antigravity 用起来像两家公司的产品：三套班子挂在同一张会员卡上**：Gemini App 归原 Google Labs 的 Josh Woodward 统管，对话、记忆和办公全家桶绑在谷歌云端账号上。Antigravity 则是谷歌在 OpenAI 收购 Windsurf 告吹后，把前 CEO Varun Mohan 和 Kevin Hou 整建制挖进 DeepMind，带着 Cascade 架构独立做出来的，项目知识库和任务清单跟着本地目录走，没接 Gemini 那套云端记忆，甚至为了抢开发者，在谷歌自家地盘里塞进了 Claude。第三拨是收钱的 Google One，AGY 没有独立收费体系，结果变成 One 管扣费、Gemini 管日常权益、AGY 自己写配额校验，这就是有人买了 Pro，在 Gemini 能用 Neon、进 AGY 却卡在初始额度的病根。他觉得这种割裂是为了抢速度故意留下的口子。[原帖](https://x.com/xiaomovps/status/2126131833205325913)

**他不再只丢清单，把 Anthropic 的免费资料排成一篇能跟着练的学习路线**：讨厌对方动不动封号，但承认这些资料讲得最透，5 篇入门文收藏破过一千，很多人还是不知道从哪看起。路线分三层：先学会用，让 Agent 交活时附上证据；再学会搭，分清 MCP 和 Skill，写出第一个自己的 Skill；最后读懂 Harness，对照 Claude Code、Pi 和 DeepSeek Harness，看压缩、断点交接和结果验证怎么落地。主线盯住 Engineering 博客，新手别一上来就啃 Research。文末按小白、写 Skill、折腾 Harness 分了三条路线，资料对照日期是 2026 年 11 月 27 日。[原帖](https://x.com/xiaomovps/status/2126265778148135218) [文章](https://x.com/i/article/2126243062623895552)

**他还顺着官方复盘，写 Anthropic 为什么敢让 AI 把核心 Messages API 从 Python 重写成 Rust**：这套接口 2023 年只是 Python 转发器，两年多请求量大约涨了 1800 倍，今年 3 月只改解析输出那一块，CPU 只省不到 10%，还要来回跨语言边界。5 月团队发现内部合入代码里超过 80% 已是 Claude 写的，才决定整套重写。Claude 大约一周写出初版，700 多个集成测试通过率高达 98%，但对线上真实流量的输入匹配率只有约四分之一，迁移过来的测试里还抓出 100 多处被放水的断言。他们后来让模型只跑一次，把同一份输出同时喂给新旧两套代码，靠字节指纹归类差异，再派子 Agent 去修，并在沙盒外加记忆循环，把打回的教训写进 CLAUDE.md。9 月切流上线后，单请求 CPU 大约砍掉 70%，首字延迟降了约 20%。他的结论是，真正拉开差距的不是模型写代码有多快，而是验证 Harness 严不严，加上人在关键架构上把关。[原帖](https://x.com/xiaomovps/status/2126226771163177456)

看法：插件和资料清单都容易收藏吃灰，小墨这几条比较有用的是「别全装」「别一上来读论文」，以及那句提醒：测试全绿了，不等于它没在放水

## 铁锤人 @lxfater

**他劝黑五开了 Google AI 会员的人，别只拿网页聊天，会员里还藏着显卡算力和云抵扣金**：他说 Pro 和 Ultra 都有，大部分人连入口都没点过。按他的写法，去 Colab 能领计算单元，Pro 每月 200 个，Ultra 直接给 2000 个，可拿来借 A100 跑开源模型；再去谷歌开发者计划或 AI Studio 绑结算账号，Pro 每月送 10 美元云抵扣金，Ultra 按档位送 40 或 100 美元，能付 Gemini 接口费，也能付云主机。他建议把主机网络从默认的高级切成标准，标准网络每月免 200G 出站流量，机器费刚好用抵扣金付掉。云抵扣金要先手动绑定才发，到账后 12 个月内能攒着用；Colab 计算单元自动发，但放满 90 天不用也会过期。[原帖](https://x.com/lxfater/status/2126138948988584375)

**他说 Antigravity 刚给全员重置额度，付费用户却炸锅，开发者后来在 GitHub 揪出两个偷跑额度的 Bug**：有 AI Pro 账号聊了 12 次，就烧掉 45% 周额度。他判断不是全员被砍，论坛里也有人用得很耐用。第一个 Bug 在自定义助手，有人测 1.5.17 版客户端，默认模式扣费正常，切到自定义助手干同样的活，扣费暴涨 4 倍。第二个是后台安检，每改文件或跑命令都会派小模型先审，小模型一撞上限就转给大号模型复审，提交代码时大号模型也会反复重读整段聊天，账全算在套餐里。有用户算了重置后的账，两小时复审 49 次，白吃四分之一额度。再加上独立旧池子被取消，所有模型改从一个总额度扣，用起来就像被砍了一半。这两个 Bug 当时还挂着没修，官方也还没回应。[原帖](https://x.com/lxfater/status/2126145248036356206)

**他反驳「MCP 已经凉了」：大厂后台调用已经很高，新 MCP 也补了四块能力**：他转述 DeepMind 的 Philipp Schmid，Atlassian 的 MCP 每个工作日调用超过 500 万次，其中 44% 来自非研发部门；Linear 和 Notion 大约每周有 240 万条工单和页面是 AI 建的，Notion 的 MCP 流量涨了 60 倍。他说大家骂的是去年的老版本，新 MCP 有代码模式（写脚本连调，只拿结果，登录走个人授权）、Skills 由服务端同步并用时再加载、事件提醒，以及聊天窗直接弹界面。他的分工是：本机跑脚本，命令行加技能包更顺手；要让不懂代码的同事安全用公司软件，就绕不开 MCP。[原帖](https://x.com/lxfater/status/2126137735777800351)

看法：会员里的算力和抵扣金确实该领，但重置额度如果被后台安检再抽走，这种「大善人」宣传只会越描越黑

## meng shao @shao__meng

**他整理了斯坦福 CS329Z 第 12 讲：SWE-bench 共同创建者 John Yang 讲怎么评估 AI 智能体，以及好基准的七项标准**：杨把问题收回到一句很基本的话，前面已经讲了怎么搭智能体、怎么用数据训练，「变好了」到底是相对什么而言。他说基准是比较的公共语言，也容易被过度优化，出现他所说的 benchmaxing：模型在 SWE-bench Verified 上可以很高，你跟它打招呼，它却去查 GitHub issue；也有模型给代码套上大量 try-except，测试能跑过，却不是人们真正想用的。智能体基准要同时写清任务和环境，以及温度、费用上限、用哪套 harness、允许多少次尝试这些评测协议，同一模型换一套脚手架，分数就会变。好基准的七项是：足够难、分得出高下、贴近真实、容易跑、容易验收、结果可解释，而且尽量经得起时间。关于数据污染，他提到私有测试集、请人新写任务、定期纳入截止日期之后的新 issue，这些办法只能推迟污染，不能一劳永逸。[原帖](https://x.com/shao__meng/status/2126252963383627969)

**他还转了 Reddit 上一个 31 年经验开发者看 GTA 6 移植时的震动：有人给 Claude 的提示只是「水还是什么东西坏了」**：高赞评论说，现在关键往往不在一次把提示写得多漂亮，而在口语化地多轮迭代，「还不够好，要比那样更好」这样说就在干活。有人认为，项目太大时先把问题说含糊一点，模型才不会只在「碰撞」这一个点上找原因；也有人坚持还是要更清楚的结构和工单。他这篇把两边的理由都记下了。[原帖](https://x.com/shao__meng/status/2126158574565155132)

看法：基准分数和口语提示看起来是两件事，其实都在问同一个问题：你到底在优化「考得好」，还是在优化「真能把活干完」
