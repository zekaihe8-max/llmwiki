## 数字生命卡兹克 @Khazix0918

**最爱用的 10 句 Agent Prompt**：他翻了最近两个月自己跟 Agent 干活时最常说的话，这条发出来就有 700 多个赞、760 多个收藏。前面几句是从第一性原理找本质原因再修，先把喜好问清楚再出 3 版方案，以及不要默认他提出的问题定义就是对的，先分清症状和原因、手段和目标。后面则要模型推演二阶三阶影响，先假设当前方案是错的再找反例，顺着 Git 历史分辨哪些是有意设计、哪些是过时包袱，还要把反复出现的 Bug 和返工沉淀成规则、自动化或 Skill。[原帖](https://x.com/Khazix0918/status/2122268349707219333)

**这些 AI 手搓的几百 K 的 3D 世界，正在让 HTML 再次伟大**：群里疯传一个 1.4M 的纯 HTML 游戏，画面很吓人，他打开代码发现大约一半是 Three.js，剩下全是代码现场生成的模型、光影和音效，没有一张图、没有一个模型文件。他点明这个文件并不是原创，是把 Anthropic 工程师 Felix Rieseberg 用 Fable 5.2 搓的 demo 汉化后换了个国产 3A 的名字。更小的还有一个 97K 的水世界，连 Three.js 都没有，直接用 WebGPU 渲染。[长文](https://x.com/Khazix0918/status/2122172073170837600)

**怎么自己做一个**：他更推荐老实用 Three.js，别一上来就挑战极限压缩，并给了一段模板，核心是所有模型和贴图都用代码生成、拆成独立组件方便后改。改到审美不够时，让模型每改完一版就截几个固定角度的图，再开一个子 Agent 只看截图、不看代码，以挑剔的美术指导身份列问题，一直改到只剩小问题。模型上他觉得 Fable 5.2 审美仍是断档领先，Gemini 4 Carbon 和 GPT-6 Astra 也能跑，DeepSeek V4.1 Flash 凑合，但改起来更费心。[长文](https://x.com/Khazix0918/status/2122172073170837600)

看法：第 3 条和第 10 条最值钱，先确认问题问对了，再把反复踩的坑写成规则，比再堆一套提示词模板有用

## 宝玉 @dotey

**主会话加 Thread，Token 其实没那么吓人**：主会话不必上最强模型，Sonnet 5.5 这级就够，职责是甄别、路由和调度，像公司前台，不必招专家，只要知道什么任务该找谁。真正干活的 Thread 该用更强的模型，更科学的做法是主会话按任务难度选模型，他自己在 Claude Project 里就是主会话 Sonnet 5.5、子任务 Opus 5.5。[原帖](https://x.com/dotey/status/2122162706606121396)

**两种会话，两套缓存策略**：主会话偶尔才来一条消息，缓存很难用好，过期后不要把全部历史和工具调用再发一遍，只发最新几条，再配合 Session 检索把上下文补齐。Thread 更像传统会话，短时间里对话很密，缓存利用率高，但也可能在缓存过期后又来新消息，他的办法是快过期时先压缩一次上下文，比如缓存一小时就在 50 分钟时动手。[原帖](https://x.com/dotey/status/2122162706606121396)

**四个神经元，怎么学会追光**：他译介 Myriad 系列第二章《Watch a Brain Learn》，作者用四个神经元造了一只小东西，让人亲眼看它学会一件事。没人教，只靠奖励和惩罚，从两千多种接法里找到那不到 2% 的好答案，换一个奖励，它又学会了逃跑、装死和战斗。配套文章在 [aatishb.com](https://aatishb.com/myriad/how-brains-learn/)。[原帖](https://x.com/dotey/status/2122106906814935475)

看法：前台用便宜模型、重活用贵模型，再按会话节奏管理缓存，这套比盲目全开 Opus 实在得多

## meng shao @shao__meng

**No AI Slop 宣言**：AI Engineer Code Summit 2026 的演讲者和参会者参照 2001 年敏捷宣言写了一份新宣言，五组对照是结果重于产量、理解重于速度、自己的思考重于模型的第一稿、更好的工作重于更省事的工作、改进系统重于修补输出。他们对 slop 的定义是：你投入的心思，少于你要求接收者花在理解上的精力。用了 AI 不等于 slop，把模型产出转手发出、却不对质量和读者体验负责，才会变成 slop。宣言站点是 [slopmanifesto.com](https://www.slopmanifesto.com/)，他转述时 Gist 已列出 504 个签名。[原帖](https://x.com/shao__meng/status/2122156731300212773)

**同一模型换评分和配套，排行榜就可能翻面**：他介绍 TensorTonic 的评测长文，核心是评智能体其实评的是模型加工具、提示词和循环，配套变好，分数也会动。CORE-Bench 上同一套 Claude Opus 4.5 起初只有 42%，换到更宽松的运行框架并修正过严评分后到了 95%，其中光换到 Claude Code 就先到约 78%。文中还区分 pass@k 和 pass^k：单次成功率 75%、跑 3 次时，至少成功一次大约 98%，三次全成功只有大约 42%。[原帖](https://x.com/shao__meng/status/2122185171965526089)

**DeepSeek chat-demo 开源三天，Star 已经超 3000**：11 月 13 日开放的参考前端，用静态页面直接接上 App 同款搜索、读链接和语音，没有应用后端，默认模型是 deepseek-flash。他补充了客户端细节：API Key 存在 localStorage，会话在 IndexedDB，历史思考和搜索结果不会回传，成功读过的链接才带 signature，所有生成请求都固定带 safety_check: high。[原帖](https://x.com/shao__meng/status/2122249961077153958)

看法：宣言把责任钉回人身上，评测那篇则提醒看榜先问清楚评的到底是模型还是整套外壳

## Gorden Sun @Gorden_Sun
