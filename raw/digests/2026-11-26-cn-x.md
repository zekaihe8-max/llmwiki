## 数字生命卡兹克 @Khazix0918

**他把斯坦福新书做成 Prompt，先给自己写出一本《个人意义设计手册》**：此前他做过《人生设计课》的 Prompt，前几天又买了同一对作者比尔·博内特和戴夫·伊万斯的新书《人生意义设计课》。书里把生活分成事务世界和心流世界，把意义的最小单位定为「时刻」，不追求一次找到毕生使命。他把这套方法收成多轮对话 Prompt：四个阶段、六到九个问题，大约二三十分钟，最后交付 5000 到 7000 字的手册，过程中禁止一次性抛出所有问题，也不要先替用户总结。他自己先跑了一遍，手册先画出意义地图，再列出可能的思维误区，并提炼出五个罗盘价值观。中间最重要的部分是设计时刻：一个是真的开始做自己的游戏，而且不要考虑能不能写成文章；另一个是找朋友好好去散步；另外还有三个日常小练习，并特意叮嘱不要再做成新的自动化系统。最后留下两个焦点问题：自己能参与创造一个什么样的未来，以及能不能同时成为更有创造力、也更有感受力的人。他的结论是，从小到大最有意义的事一直是创造。这篇发出后有 514 个赞、649 个收藏。[原帖](https://x.com/Khazix0918/status/2125803873575284892) [文章](https://x.com/i/article/2125802173821030400)

看法：这类 Prompt 的价值不在替你给人生下定义，而在逼你把具体时刻讲清楚，再把结论交还给你自己读

## 铁锤人 @lxfater

**Linus 因为一份 4 万多行的 AI 更新发飙了**：挨骂的不是外行，是 ext4 的资深维护者 Ted。他在 Linux 7.4 临近发版前一口气塞进 41,197 行新代码，里面有大批 AI 写的漏洞修复，还有 3 万多行测试。Linus 在邮件里全大写开喷，核心就一句：别再以为你或 AI 修 bug 就不会引入新 bug。他的道理是，这些坑藏了很久没人撞上，说明又偏又冷门，为了修这种问题去动核心代码，新补丁反而更容易埋雷。这次他勉强合了，放话下次再这样直接无视，并要求大改动和测试放到单独分支，等下个版本再合。[原帖](https://x.com/lxfater/status/2125799520080433497)

**Qwen-Audio-3.1 把听写、配音、实时对话三套都补齐了，主攻多语言和中文方言**：听写覆盖 59 种语言加 8 种中文方言，还带润色和多人分角色转写；配音是 65 种语言加 6 种方言，能调语气语速，也能从带杂音的录音里克隆声音；实时对话是 53 种语言加 6 种方言，支持插话打断，还能接知识库。他查了 QwenCloud 官方标价，Flash 版听写输入每百万 token 只要 0.15 美元，配音和实时对话的音文输出都是 1.87 美元。他的判断是，语音 AI 卷完英语之后，接下来拼的是谁更懂张嘴就来的家乡话。[原帖](https://x.com/lxfater/status/2125897108041416782)

**黑苹果这波反而是 AI 给撬开的**：苹果已经砍掉英特尔芯片支持，但非苹果设备上硬装 macOS 反而在爆发。他举的例子包括华硕骁龙本跑通原生 macOS 27，RK3588 开发板硬启 macOS 27.2，Switch 装进 iOS 17，以及开源驱动 NullMoth 让 RTX 50 系显卡跑上图形加速。圈里的做法是用 Ghidra 反编译，再让 Claude Code 和 Codex 通读代码、看报错、一轮轮打补丁。过去顶尖逆向高手才啃得动的活，现在普通极客带着 AI 也能试。原博客在 naut.ca。[原帖](https://x.com/lxfater/status/2125613129832792293) [博客](https://www.naut.ca/blog/2026/11/05/the-hackintosh-reborn-with-ai/)

看法：Linus 这封邮件和方言模型、黑苹果驱动，说的其实是同一件事，AI 让改代码变得很便宜，但改错的代价一点没变

## 小墨同学 @xiaomovps

**Antigravity 的插件市场终于把 MCP 和 Skill 收拢到一起了**：以前配工具要自己找路径改 JSON，还容易跟旧写法冲突。现在一个插件可以把 MCP、Skills、Rules、Hooks 和自定义 Agent 打包，点一下就装齐，桌面端 Marketplace 和命令行 `/plugin`、`agy plugin install` 会自动同步，也能用 `agy plugin import` 导入 Claude Code 和 Gemini CLI 的配置。生态上，谷歌自家补了 Firebase、Chrome DevTools、Docs、Sheets、Drive 和 Gmail，合作市场里还有 GitHub、Cloudflare、Supabase、Figma、Notion、Linear、Context7。底层默认懒加载，Schema 缓存在本地按需读取，新版还支持 MCP Apps，能在侧边栏和对话里渲染交互卡片。需要 API Key 的插件在 CLI 里装完默认禁用，得补完配置才生效；权限保持默认 Ask 即可，别一次装一堆，工具来回调照样烧 5 小时额度。[原帖](https://x.com/xiaomovps/status/2125890873238094143)

**他觉得日常写代码，先装这 5 个 MCP 就够了**：Context7 用来拉带版本号的最新文档；DeepWiki 免费免鉴权，适合快速看懂陌生 GitHub 仓库；GitHub MCP 补远程 PR、Issue 和 Actions 日志；Supabase MCP 看真实库表和线上日志，用的时候记得加 `read_only=true`；做前端再补 Figma MCP。日常只留前三个基本够用。Playwright、Sequential Thinking、Filesystem 他不建议盲装，因为 AGY 桌面端已经自带浏览器，CLI 也接了 Chrome DevTools MCP，思考档位、`/plan` 和本地文件读写都是原生能力。[原帖](https://x.com/xiaomovps/status/2125906913485562294)

**Pi 跟进了 Program Resume Protocol（OSC 7577）**：终端一崩溃或电脑重启，开着的 Agent 会话以前经常没了，套 tmux 遇到系统重启也救不回来。今天早上 Mitchell Hashimoto 推了这个协议，大约一小时后 Armin 就说已经合进 Pi。思路是让最懂如何恢复的程序，主动告诉终端重启后该跑哪条命令把自己拉回来，例如 `pi --session <id>`。正常退出会清掉，意外关闭或重启则保留；每个面板还有随机 Token 做校验，防止从日志或 SSH 被塞恶意命令。协议写明由终端决定要不要恢复，目前还只是合进主线并更新了文档，最新正式版仍是昨天的 1.6.1，还不能更新一下就用上。[原帖](https://x.com/xiaomovps/status/2125869563992797620)

看法：插件市场补上之后，更关键的是别把上下文再装脏，他反复说的还是那句，先留最常用的三个就够

## 蓝哥AI @0xlangeai

**他上手了 DeepSeek Harness 官方桌面端，觉得比 Web 和 CLI 更香**：安装包自带 Node.js 和 Python 环境，含 pandas、python-docx、python-pptx，还有用于文档预览的 LibreOffice，不用自己装 Node 或 pnpm，也不用开终端敲命令。原生窗口加系统托盘，关上主窗口后任务还能在后台跑，定时任务也更稳定。账号可直接用 DeepSeek 登录、消耗账号额度，不必单独申请 API Key；官方桌面端走自定义协议，不暴露本地端口，他觉得安全性比社区套壳版更好。本地文件夹可以直接设为工作区，Word、Excel、PPT 和代码处理更自然，插件管理也做成了图形界面。[原帖](https://x.com/0xlangeai/status/2125571922541113635)

看法：官方如果把运行环境和账号登录都打包进桌面端，Harness 才会从「会用命令行的人的工具」变成更多人愿意每天打开的软件
