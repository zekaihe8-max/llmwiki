## 宝玉 @dotey

**Meta 首席 AI 官发长文，判断已经不卡在够不够聪明**：Alexandr Wang 发表《Superintelligence is Arriving》。宝玉概括他的结论是：AI 现在缺的不是智力，而是各行业的专门知识和实验条件；他同时反对把社会交给 AI，认为整个行业需要换一条路走。这篇有 108 个赞、75 个收藏、56 条讨论。[原帖](https://x.com/dotey/status/2124756676607627434) [Wang 原文](https://x.com/alexandr_wang/status/2124636606959345776)

**Qwen3.5 27B 自己改权重，数学准确率从 57.2% 提到 63.8%**：这是 UIUC、CMU、普林斯顿、斯坦福、耶鲁等校 11 位研究者（Jiajun Fan 等）11 月 18 日发在 arXiv 的论文。平时模型发布后权重就定死了，这次研究者禁掉所有训练工具，只用单块 GPU 跑几小时，让模型写 Python 改自己的权重。它复盘后发现，写完的题 96% 都对，毛病是爱钻牛角尖、话没说完就超限，于是把 48 层里控制「旧信息消退快慢」的参数统一调高 0.5。结果在 490 道没见过的新数学题上，未答完率从 33.6% 降到 26.1%，准确率提升 6.6 个百分点。它甚至修好了被写入随机噪声的受损副本，数学从 0 分回到 33.0%（原版 58.5%），6 项看图测试从 7.3% 恢复到 70.2%。但同系列 2B 动都没动，4B 和 9B 只会乱加噪声，9B 还把自己从 47.5% 改成了 0 分。作者也提醒：8 轮实验每次都是从原版重新开始，还没做到「改完的版本继续改自己」，目前只在 Qwen3.5 家族和数学题上验证过，论文还没经过同行评审。[原帖](https://x.com/dotey/status/2124775538648633370) [论文](https://arxiv.org/abs/2611.21885) [项目页](https://www.jiajunfan.com/projects/self-rewriting/)

**GLM-5.4 上线编程订阅：能看图，周额度比 5.3 多一半**：智谱新模型已向所有 GLM Coding Plan 订阅用户开放，官方说编程能力全面提升，对有每周额度的用户，用量比上一代多 50%。消息来自 Zixuan Li。这篇有 93 个赞、84 条讨论。[原帖](https://x.com/dotey/status/2124726140023537849) [Zixuan Li](https://x.com/ZixuanLi_/status/2124719275864670681)

看法：自己改权重这件事，真正要看的不是 6.6 个百分点，是它还做不到「改完再改」，距离自我进化还差关键一步

## 铁锤人 @lxfater

**GLM-5.4 查漏洞细，但比 Neon 慢约 4 倍**：海外博主 AICodeKing 拿它跑完 6 道复杂编程题，最高档 33.2 分排第 7，前面全是闭源旗舰，国产模型里第一，真实项目里还挖出不少 Claude Fable 5.2 没查出来的漏洞。慢不在单步速度：6 道题它花了 431 分钟，Neon 只要 109 分钟，它平均每步 22.9 秒，比 Neon 的 26.7 秒还快一点，但走了 1128 步，Neon 只走 244 步，光思考就烧掉 104 万 token，单题思考量比 Neon 多 9 到 14 倍。安全小任务上，高档和最高档都想太久撞上 180 秒超时，中低档反倒过了。他的用法是：别拿它当日常写前端的主力，放进多模型评审里专门把关，日常用高档（High），最高档（Max）容易钻牛角尖。目前只先上了智谱 Coding Plan，改模型名 glm-5.4 就能试，公开接口和开源文件还没放。[原帖](https://x.com/lxfater/status/2124805211835236796)

**Pro 用 Neon 为啥有人额度特别不经用**：Perplexity CEO 晒了数据，Neon 上线四天，搜资料每天涨 10.6%，自动干活任务每天涨 15%。论坛有人拿三个 Pro 号反推，网页端每 5 小时大约能撑 5000 万到 1 亿多 token，一周大概 10 到 20 亿，不同号扣分差了 1.7 倍，这不是官方配额。帖主扒完明细，问题出在旧记录能不能复用：网页任务模式里，存下来的内容只留 2 到 5 分钟，中间停超过两分钟再发，旧记录作废，下一轮全部重算，单次消耗会跳涨 3.7 倍以上。他的建议是一口气连着跑，隔太久就新开对话；网页版任务模式也能接 MCP 写代码，但不同系统支持还不统一，也没法手动调思考深度。[原帖](https://x.com/lxfater/status/2124816490138374569)

**中国电信用 8192 张昇腾 910C 训出 Xing4.1-Preview**：这是一个 2850 亿参数的开源模型，技术报告写明用华为 MindSpore 从头训完，支持 100 万 token，专攻写代码和长任务，521G 完整文件按 Apache 2.0 开源。报告的说法是，昇腾 910C 算大块矩阵很猛，但显存搬数据的通道偏窄，所以他们把模型拆成小专家，每次只挑约 170 亿参数来算；长文本沿用 DeepSeek 那类先压缩再挑重点读的办法，读取最高快了 4.68 倍。官方自测对标混元和智谱同档轻量模型，大部分分数还略低一点，跳过显卡沙箱题、只测纯文本这些限制也标在了脚注里。刚开源不到一天，GitHub 仓库还没开，第三方实测还是空白。[原帖](https://x.com/lxfater/status/2124828611811152226) [Hugging Face](https://huggingface.co/XingChen-AGI/Xing4.1-Preview)

**Anthropic 和谷歌、OpenAI 是两派风控**：他写，Claude 更像死板保安，不对劲就弹窗验身份，还盯着聊天记录，动不动封号；谷歌和 OpenAI 更少直接把号干死，圈里体感是异常时悄悄切去弱模型。被封后有人走苹果商店投诉，打了上海 12315 和北京 12345，两天退回了苹果账户余额，但帖里也有人四五天没受理，他自己也说不代表所有人都能退。结论是真要用 Claude，别贪便宜买年付，按月付把损失压小，并多备一个主力模型。[原帖](https://x.com/lxfater/status/2124758635548934291)

看法：GLM-5.4 更适合放在评审席上，Xing4.1 眼下先看的是国产卡能从头训通并开源，分还要等外人测

## 小墨同学 @xiaomovps

**Pi 作者 Mario 点名的 DreamCoder，把多 Agent 工作台做明白了**：这是 Mastering Emacs 作者闭关 15 个月做出来的 AI Coding Harness，跑在浏览器里，不是窄终端，也不是左边列表右边对话框，而是一套会自动分配大小的平铺窗口。每个工作区有实时小地图，哪个窗格在干活会闪，卡在权限审批会提示，跑完变绿。键盘操作用 Alt+x、Alt+m 加 WASD 在窗格间跳。作者介绍缓存命中率能到 99%，能连续跑好几天，也能走 Docker 沙箱，并支持一键导入 Pi、OpenCode 和 Codex 的配置，对 Qwen 3.8 27B、DeepSeek 这类本地模型也友好。作者在评论区说，目前还不支持直连 Claude Code Max 订阅，主要走 API 或本地模型。全平台支持 macOS、Windows、Linux 和 Docker。这篇有 8 个赞、23 个收藏。[原帖](https://x.com/xiaomovps/status/2124804466146984258) [官网](https://www.dreamcoder.ai/) [介绍文](https://www.masteringemacs.org/article/announcing-dreamcoder)

**多 Agent 到底怎么用才对**：他认同 Devin 团队 Cognition 的《Don't Build Multi-Agents》。三个要点是：共享上下文必须共享完整执行轨迹，不能只扔几句拆好的子任务；每个动作都隐含决策，并行时互相看不见，文里用 Flappy Bird 拆成「做背景」和「做小鸟」两个子 Agent，拼起来画风和逻辑全冲突；宁可用单线程把事做完，上下文撑爆了再压缩，也不要硬上多 Agent。连 Claude Code 的子 Agent 用法都很克制，只用来查资料，绝不并行写代码。他自己的做法也是：要么新开一个 Agent 单独处理，要么只用一个 Agent 从 0 到 1 跑完。[原帖](https://x.com/xiaomovps/status/2124820080215441660) [原文](https://cognition.com/blog/dont-build-multi-agents)

**Gemini 和 Antigravity 的额度是分开算的**：很多人买了 Google AI 会员不知道这点。他最近研究 Gemini 时，深度思考和研究多跑几次额度就见底，切到 Antigravity 一看还剩一大截。这篇有 19 个赞、19 个收藏。[原帖](https://x.com/xiaomovps/status/2124716522858012721)

看法：多 Agent 先把信息对齐，再谈并行，DreamCoder 的小地图做的就是让你看见谁在干、谁卡住了

## meng shao @shao__meng

**Anthropic 开了一门 1 小时的评测入门课**：Claude Academy 的「Introduction to evals」面向已经有提示词、却还没有带评分评测的人，4 节正课加 1 次测验，登录免费 Claude 账号可保存进度，测验达到 80% 后领结业徽章。课里用虚构咨询公司 Meridian 串起来：要从每月项目报告里抽出编号、进度和最大风险。门槛按「错一次要付出什么」来定，课里算成 90%。旧提示词上 Haiku 4.5 对了 50 题中的 42 题，只有 84%，失败里有 5 次是报告没有风险却编出了风险；补上何时该返回空值、并要求先引用原句再作答后，Haiku 也到了 100%，仍是最便宜的。官方建议评测集先从 20 到 50 条起步，上线后抽 10 条做拉取请求上的冒烟检查，夜里再抽 1% 到 5% 的真实流量打分。[原帖](https://x.com/shao__meng/status/2124797332051128581) [课程](https://academy.claude.com/courses/introduction-to-evals)

**他同时看到两种年龄标签**：一边是字节跳动大模型专家数据平台 Xpert 专家社区，出现面向 50 岁以上用户的招募，他调侃 35 到 50 岁这 15 年怎么过，并说可以先注册，当闲暇时间的零花钱。另一边他翻出百川智能当年按 80、90、95、00 后分招聘邮箱的做法，说上次见到招聘里明确区分年龄，还是那一次。[Xpert](https://x.com/shao__meng/status/2124763208259109017) [百川招聘邮箱](https://x.com/shao__meng/status/2124750276917854426)

**一种能补出「没拍到的角度」的视角模型**：他写特斯拉 FSD v15 的实时实景视图完全是 AI 合成的，实际摄像头并没有那个角度。AVM 可以做类似的事：给一张照片、几张随手拍或一段普通视频，就能像游戏里一样自由移动镜头，拉远或转弯时会脑补盲区，走开再回来还能对上之前的画面。原理是按时间把画面切成带空间位置标记的 token 再预测。项目页写了目前未开源。[原帖](https://x.com/Gorden_Sun/status/2124803554187874532) [项目页](https://autoregressive-view-model.github.io/main.html)

**他介绍了开源团队 AI 工作区 Trina AX**：一次部署后，可以把 Claude Code 和 Codex 放在统一服务器上，接公司文件、团队技能和业务工具，并带权限控制。新员工不用复制提示词，打开浏览器或客户端就能用团队沉淀下来的知识库和工作流。[原帖](https://x.com/Gorden_Sun/status/2124779272107954639) [GitHub](https://github.com/trina-app/trina-ax)

看法：AVM 想解决的是「镜头不在那儿也能看」，Trina AX 想解决的是「一个人配好，全公司能接着用」

**MemOS 联合英伟达发布 MemT 1.0，冲着长对话的显存瓶颈去**：他写，本地部署里长对话最大的痛点是 KV Cache 越吃越多，几十万 token 下去再好的显卡也容易被撑爆，很难长期挂机当日常助手。官方帖里，MemT-1.0-Pro 是和 NVIDIA 合作的 memory-native 模型，基于 NVIDIA Nemotron 3 Ultra，训练用了 Megatron-Core 和 Megatron Bridge，并和 Flash 版做了对比。这篇有 19 个赞、15 个收藏、16 条讨论。[原帖](https://x.com/servasyy_ai/status/2124821574931136919) [官方帖](https://x.com/MemOS_dev/status/2124623963087126562)
