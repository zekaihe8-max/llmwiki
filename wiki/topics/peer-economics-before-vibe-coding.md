# Vibe Coding 前先算清赚钱同行

*Peer economics before vibe coding*

当写代码与做出「0 付费 0 用户」产品都明显变快时，瓶颈从「能不能做出来」前移到「值不值得做」：动手 Vibe Coding 前，应先扒同赛道真正在赚钱、且流水仍在涨的同行，算清商业模式与获客两笔账，再写第一行代码。耐久主张是**同行经济学前置**，不是某一次产品的流水数字本身。[^0xlangeai-skillry-before-vibe-coding]

When both coding and shipping “0 paid, 0 users” products get markedly faster, the bottleneck moves from “can we build it” to “is it worth building”: before vibe coding, strip-mine peers who are actually making money and still growing in the lane, clear the business-model and acquisition ledgers, then write the first line. The durable claim is **peer economics first**—not any one product’s revenue figure alone.[^0xlangeai-skillry-before-vibe-coding]

## 综合分析 / Synthesis

[蓝哥AI谈 Skillry：Vibe Coding 前先算清赚钱同行](../sources/articles/0xlangeai-skillry-before-vibe-coding.md) 转述 Yihui 以 Skillry 为自证：上线约一月 400+ 活跃付费、近 30 天 $12,037（MRR $3,918）。两笔账的具体切法是：（1）商业模式只抄还在涨的老生意——Skill 导航站不赚钱、一次性买断样板（如 ShipFast）在掉，而 Sleek / TypeUI / Skillry 一类「给 Claude Code / Codex 调的高审美成品模板 + 订阅制」仍进钱，且完整交付物流水可比通用组件高约 3.5 倍；（2）第一批客户先拆同行渠道——如 Sleek 免费绿幕工具吃自然搜索、23 秒实机演示冷启动冲过 10k MRR——并可在 Claude Code / Codex 接 BizPeel MCP 拉同行流水与 SEO/爆帖打法后再动手。[^0xlangeai-skillry-before-vibe-coding] 原帖 <https://x.com/0xlangeai/status/2115266929103700219>。

[0xlangeai on Skillry—peer economics before vibe coding](../sources/articles/0xlangeai-skillry-before-vibe-coding.md) relays Yihui with Skillry as self-evidence: ~one month live, 400+ active paid, $12,037 last 30 days (MRR $3,918). The two-ledger cut is: (1) business model—only copy growing old businesses; Skill directories do not pay, one-time boilerplates (e.g. ShipFast) fall, while Sleek / TypeUI / Skillry-class “high-aesthetic finished templates Claude Code / Codex can call + subscription” still take money, and complete deliverables can out-earn generic components ~3.5×; (2) first customers—tear down peer channels first (e.g. Sleek’s free green-screen SEO tool, 23s demo cold start past 10k MRR), and optionally pull peer revenue plus SEO/viral playbooks via BizPeel MCP in Claude Code / Codex before coding.[^0xlangeai-skillry-before-vibe-coding] Post: <https://x.com/0xlangeai/status/2115266929103700219>.
