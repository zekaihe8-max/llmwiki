# AI 代码与屎山上线双标

*AI code vs messy-code shipping double standard*

对「能不能上线」的信任，常按作者身份分裂：AI 写的代码被默认不放心、怕出问题；人类熬夜脑子不清、复制粘贴拼出的屎山，却仍可被框成体面、安全。质疑的是同一决策上的双标，而不是断言 AI 代码必然更好。[^fkysly-ai-code-messy-double-standard]

Trust about whether code can ship often splits by who wrote it: AI-written code is defaulted as unsafe and problem-prone; human messy piles from late nights and unclear heads, stitched by copy-paste, can still be framed as dignified and safe. The claim targets that double standard on one decision—not that AI code is necessarily better.[^fkysly-ai-code-messy-double-standard]
