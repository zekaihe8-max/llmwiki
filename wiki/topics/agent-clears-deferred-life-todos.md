# Agent 清掉搁置的生活待办

*Agents clear deferred life TODOs*

个人可把信用卡积分兑换一类「早就该做、却一直懒得做」的生活杂务交给能操控已上线手机的 Agent；任务本身可能很小，但长期占着 TODO。主张落在 agent 消化「记下来但懒得做」的摩擦，而不是兑换政策或理财建议。[^turingou-claude-clear-credit-card-points] 适用边界：个案自述与体感，未给出失败率、权限边界或可复用操作手册。

Individuals can hand long-deferred life admin—such as redeeming credit-card points they “should have done ages ago” but kept putting off—to an agent that can drive an online phone; the task may be small yet sit on a TODO for a long time. The claim is that agents digest “noted but too lazy to do” friction, not redemption policy or financial advice.[^turingou-claude-clear-credit-card-points] Scope: one person’s report and feel—no failure rates, permission bounds, or reusable runbook.
