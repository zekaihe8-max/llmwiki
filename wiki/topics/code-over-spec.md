# 代码重于规格

*Code over the spec*

工程注意力应以实际运行的代码为中心，而不是描述它的书面规格。[^mattpocock-code-not-spec]

Engineering attention should center on the code that actually runs, not on the written specification that describes it.[^mattpocock-code-not-spec]
