# Usage limit A/B tests

Providers may run experiments that change how much a subscriber can use: lower monthly value against higher short-window (for example five-hour) caps, applied only to some accounts. Observed drops in limits can reflect that test rather than a universal policy change.[^semianalysis-anthropic-usage-limits-ab]

## Synthesis

[Anthropic usage limits A/B test](../sources/articles/semianalysis-anthropic-usage-limits-ab.md) reports SemiAnalysis detecting an Anthropic experiment that cuts monthly API-value by about 20% and raises five-hour usage limits by about 20% for a subset of accounts, matching user reports of lower limits.[^semianalysis-anthropic-usage-limits-ab] [Dotey on Anthropic usage limits A/B](../sources/articles/dotey-anthropic-usage-limits-ab.md) restates the same A/B framing in Chinese: same plan, different caps; five-hour quota up about 20%, monthly API-value down about 20%; only some accounts.[^dotey-anthropic-usage-limits-ab]
