# 用量上限 A/B 测试

*Usage limit A/B tests*

提供商可能通过实验改变订阅者能用多少：降低月度额度、提高短窗口（例如五小时）上限，且只作用于部分账户。观察到的限额下降可能反映的是该测试，而非普遍政策变更。[^semianalysis-anthropic-usage-limits-ab]

Providers may run experiments that change how much a subscriber can use: lower monthly value against higher short-window (for example five-hour) caps, applied only to some accounts. Observed drops in limits can reflect that test rather than a universal policy change.[^semianalysis-anthropic-usage-limits-ab]
