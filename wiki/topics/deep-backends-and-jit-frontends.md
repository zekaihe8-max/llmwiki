# 深后端与 JIT 前端

*Deep backends and JIT frontends*

随着编程智能体生成更多软件，技术栈两极分化：一侧是耐久的深后端，另一侧是智能体几乎零配置即可部署到线上 URL 的即时前端——包括无需账号。[^rauchg-deep-backends-jit-frontends]

As coding agents generate more software, the stack polarizes: durable deep backends on one side, and just-in-time frontends that agents can deploy to a live URL with almost no setup—including without an account—on the other.[^rauchg-deep-backends-jit-frontends]
