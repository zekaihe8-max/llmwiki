# 网防 Agent Swarm 品类

*Agent swarms for cyber defense*

网络防御可被做成 agent swarm 大品类：智能体审阅代码与基建、穷举风险组合、处理海量数据。安全之所以特别适合 swarm，是因为算力投入与产出价值正相关明显，且人类永远测不完——或至少测不够快——的空白正是智能体可规模化啃下的面。[^levie-agent-swarms-cyber-defense]

Cyber defense can become a major agent-swarm category: agents review code and infra, exhaust risk permutations, and process large volumes of data. Security fits swarms especially well because the compute-to-value link is obvious and the testing surface humans never finish—or never finish fast enough—is exactly what agents can scale into.[^levie-agent-swarms-cyber-defense]
