# Google Cloud 上的 Claude

*Claude on Google Cloud*

Claude Models on Google Cloud 可作为 Anthropic 托管部署提供：完整 Claude Platform 功能集可用，并接到 Google Cloud IAM 凭证、计费与承诺额核销，而不是单独的 Anthropic 账户路径。[^claude-models-google-cloud]

Claude Models on Google Cloud can be offered as an Anthropic-managed deployment: the full Claude Platform feature set is available there, wired to Google Cloud IAM credentials, billing, and commitment retirement rather than a separate Anthropic-only account path.[^claude-models-google-cloud]
