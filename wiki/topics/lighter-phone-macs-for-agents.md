# 手机变轻与 Mac 专供 Agent

*Lighter phones and Macs dedicated to agents*

当 agent 成为日常算力与自动化的主消费者时，个人硬件取舍可跟着变：不必年年换新款手机，而把新买的 Mac 等机器专留给 agent；手机在作者叙事里应「越来越轻」，而不是越堆越重。[^turingou-phone-lighter-macs-for-agents] 适用边界：这是个案购机与体感陈述，不是销量数据或产品规格，也未说明 agent 跑在本机、云电脑还是混合。

When agents become the main consumers of everyday compute and automation, personal hardware choices can follow: skip the yearly phone upgrade and dedicate newly bought Macs (and peers) to agents; in that framing the phone should get “lighter,” not denser.[^turingou-phone-lighter-macs-for-agents] Scope: this is one person’s purchase and feel report—not sales data or product specs—and it does not say whether agents run on-device, on a cloud PC, or in a mix.
