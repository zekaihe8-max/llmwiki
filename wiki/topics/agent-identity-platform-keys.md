# Agent 身份与平台握钥

*Agent identity and platform-held keys*

Agent 的登录与身份层正被跑 Agent 的平台视为控制点：谁运行 Agent 谁就握钥匙，独立身份创业公司因此被安全与云平台成批收购；仍可能独立生长的开口，是嵌进开发者产品的身份能力，而非再做可被平台吞并的横向身份层。[^financeyf5-eight-agent-identity-buys]

Agent login and identity are becoming control points for whoever runs the agent: the runner wants the keys, so security and cloud platforms buy standalone identity startups in batches; room that may still grow independently is identity embedded in developer products, not another horizontal identity layer platforms can absorb.[^financeyf5-eight-agent-identity-buys]
