# Agent 进收件箱

*Agents in the inbox*

邮件客户端可以把 Agent 嵌进收件箱：用户用一两句自然语言交代批量任务（读信、拆附件、汇总导出），不必人手逐封点开。耐久主张是 **Agent 落在邮箱工作面**，数字（封数、秒数、Excel）只是个案证据，不是产品基准。[^0xlangeai-netease-mail-agent] 适用边界：目前证据是短帖转述与招聘收件个案体感，未给失败率、鉴权/隐私边界或跨厂商对比。

Mail clients can embed an agent in the inbox: the user states a batch job in a sentence or two (read mail, open attachments, summarize/export) without opening each message by hand. The durable claim is **the agent lives on the mail surface**; figures (message counts, seconds, Excel) are case evidence, not a product benchmark.[^0xlangeai-netease-mail-agent] Scope: evidence so far is a short-post relay and one recruiting-inbox case feel—no failure rates, auth/privacy bounds, or cross-vendor comparison.
