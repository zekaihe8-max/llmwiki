# 个人 Agent 热潮与 Coding Agent 熟悉度差

*Personal-agent hype vs coding-agent familiarity*

同一轮个人 Agent 热潮，体感可因是否已高频使用前沿 Coding Agent 而分裂：门槛更低、开箱即用时，新人更易被「聪明模型 + 自动化 + 情绪价值」震住；日常已跑 Claude Code / Codex 的人则往往觉得平常。[^dotey-grok-bot-like-crayfish] 与此并行，手机场景下 Claude Code / Codex 虽也支持，但便利性仍不如 Grokbot——尤其不必考虑新开 session——说明热潮之外还有产品侧的移动端体验差。[^dotey-grokbot-mobile-vs-claude-codex]

The same personal-agent craze can split by familiarity with frontier coding agents: when the barrier is lower and setup-free, newcomers are easier to awe with “smart model + automation + emotional payoff”; people already on Claude Code / Codex daily often find it ordinary.[^dotey-grok-bot-like-crayfish] In parallel, Claude Code / Codex do support mobile use, yet still feel less convenient than Grokbot—especially not having to open a new session—so beside the craze there is also a product-side mobile UX gap.[^dotey-grokbot-mobile-vs-claude-codex]
