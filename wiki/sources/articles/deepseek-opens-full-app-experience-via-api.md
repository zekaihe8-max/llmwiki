# DeepSeek 将 App 完整能力开放为 API

*DeepSeek Opens Full App Experience via API*

DeepSeek 官方 X 账号「帖文称」，完整的 DeepSeek App 体验现已通过 DeepSeek API 提供，涵盖搜索、文件、链接、安全和语音等功能；开发者可用少量参数启用内置特性，也可调用 OCR、ASR、TTS 等独立 API，并可使用支持导入 DeepSeek 对话历史的开源前端演示。[^deepseek-api-app-experience]

The DeepSeek official X account stated in a post that the full DeepSeek App experience is now available via the DeepSeek API, covering search, files, links, safety, and voice; developers can enable built-in features with a few parameters or call standalone APIs such as OCR, ASR, and TTS, and use an open-source frontend demo supporting import of DeepSeek conversation history.[^deepseek-api-app-experience]
