# MemOS 与 NVIDIA 发布 554B 参数原生记忆模型 MemT-1.0-Pro

*MemOS and NVIDIA release 554B-parameter memory-native model MemT-1.0-Pro*

「帖文称」MemOS_dev 官方账号于 2026 年 11 月 22 日宣布，与 NVIDIA 开发者合作推出记忆原生模型 MemT-1.0-Pro。模型基于 NVIDIA Nemotron 3 Ultra，使用 NVIDIA Megatron-Core 与 Megatron Bridge 进行分布式训练，拥有 5540 亿参数并具备原生记忆；相较 MemT-1.0-Flash，在 BEAM-1M 提升 4.76 点、在 MemoryAgentBench 提升 6.51 点。帖文还称，该模型可将历史存入原生记忆并在后续交互中使用，而无需将原始历史保留在查询上下文中，旨在推进长时程 AI 智能体的记忆能力。[^e93f297299e17221]

The MemOS_dev official account announced on November 22, 2026 that, in collaboration with NVIDIA developers, it has released the memory-native model MemT-1.0-Pro. Built on NVIDIA Nemotron 3 Ultra and trained using NVIDIA Megatron-Core and Megatron Bridge, the model has 554 billion parameters with native memory. Compared with MemT-1.0-Flash, it improves by +4.76 points on BEAM-1M and +6.51 points on MemoryAgentBench. The post states that the model can store history in native memory for use in later interactions without retaining the original history in the query context, aiming to advance memory for long-horizon AI agents.[^e93f297299e17221]
