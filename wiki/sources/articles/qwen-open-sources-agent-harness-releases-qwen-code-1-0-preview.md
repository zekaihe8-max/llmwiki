# 千问开源 Agent Harness，发布 Qwen Code 1.0 Preview

*Qwen Open-Sources Agent Harness, Releases Qwen Code 1.0 Preview*

「帖文称」阿里千问在发布千问四大模型的同时开源了 Agent Harness，并推出 Qwen Code 1.0 Preview。该项目最初基于 Google Gemini CLI 开发，后逐渐独立维护，整合了 Qoder 与 Qwen Code 的 Agent 能力，围绕任务执行、工具调用和模型交互构建运行框架，并支持 OpenAI、Anthropic、Gemini 等模型协议以及本地模型，覆盖 Windows、macOS、Linux 三端，提供会话恢复与非交互式执行能力。帖文还提到 Qwen Code 目前仍处于 Preview 阶段，作者计划将其与 Pi、DeepSeek Harness 对比。[^qwen-agent-harness-open-source]

The post claims that Alibaba Qwen open-sourced its Agent Harness alongside the Qwen4 models and released Qwen Code 1.0 Preview. Originally based on Google Gemini CLI and later independently maintained, it integrates Qoder and Qwen Code Agent capabilities into a framework for task execution, tool calling, and model interaction. It supports OpenAI, Anthropic, Gemini and other compatible APIs plus local models, runs on Windows, macOS and Linux, and offers session recovery and non-interactive execution. The post notes Qwen Code 1.0 is still in Preview and the author plans to compare it with Pi and DeepSeek Harness.[^qwen-agent-harness-open-source]
