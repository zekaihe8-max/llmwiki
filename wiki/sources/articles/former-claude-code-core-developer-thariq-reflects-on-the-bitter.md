帖文称，前 Claude Code 核心开发者、现独立开发者 Thariq Shihipar 在 AI Engineer Code Summit 2026 做主题演讲「The Sweet Side of the Bitter Lesson」，回顾离开 Anthropic 后一年的反思。他承认曾过度看重 Bash、React 和扩散模型，主张模型能力进入“平滑内部”后，人应通过可读规格和自制脚本语言夺回对软件创作的控制权，推动软件文艺复兴。[^shao-meng-thariq-bitter-lesson-2026]

The post says former Claude Code core developer and now independent developer Thariq Shihipar gave a talk titled "The Sweet Side of the Bitter Lesson" at AI Engineer Code Summit 2026, reflecting on his year after leaving Anthropic. He admits he overvalued Bash, React, and diffusion models, and argues that once model capability enters the "smooth interior," people should reclaim control over software creation through readable specs and custom script languages, driving a software renaissance.[^shao-meng-thariq-bitter-lesson-2026]

- 为自己的 2D 等距格斗游戏，他将代码库拆为无需细读的引擎部分，以及一份人类可读的 spec 文件夹，包含“hero-name”和“bare-number”等规则。[^shao-meng-thariq-bitter-lesson-2026]
