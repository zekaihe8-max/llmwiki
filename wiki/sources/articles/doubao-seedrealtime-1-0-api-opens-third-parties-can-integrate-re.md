# 豆包 SeedRealtime 1.0 API 开放，第三方可接入实时音视频对话能力

*Doubao SeedRealtime 1.0 API Opens, Third Parties Can Integrate Real-Time Audio-Video Conversation Capability*

「帖文称」火山引擎正式开放豆包实时音视频模型 SeedRealtime 1.0 的 API，该模型今年 8 月已在豆包 App 上线，现允许第三方开发者将实时视频通话能力接入自有产品。帖文还称，该模型将摄像头画面、声音和时间顺序放入同一个端到端模型，可边观察、边听、边判断开口时机，以降低传统多模块串联带来的延迟与信息损失。[^doubao-seedrealtime-1-0-api]

The post says Volcano Engine has officially opened the API for Doubao's real-time audio-video model SeedRealtime 1.0, which launched on the Doubao App in August and now allows third-party developers to integrate real-time video call capabilities into their own products. The post also says the model places camera frames, audio, and time sequence into a single end-to-end model, enabling it to observe, listen, and judge when to speak, reducing latency and information loss from traditional cascaded modules.[^doubao-seedrealtime-1-0-api]
