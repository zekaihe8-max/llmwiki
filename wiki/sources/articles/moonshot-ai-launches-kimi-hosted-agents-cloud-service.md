# 月之暗面发布 Kimi Hosted Agents 托管智能体云服务

*Moonshot AI Launches Kimi Hosted Agents Cloud Service*

「帖文称」月之暗面正式发布 Kimi Hosted Agents，把 AI Agent 的整套运行框架做成云端服务，企业无需自行搭建环境、安排工具调用、保存进度或处理断线重试，只需配置任务、接入数据即可将 Agent 放入业务系统持续运行；平台提供 12 套 Agent 模板、140 多项 Skills 和 30 多个插件，并支持接入自有数据库与工具。[^kimi-hosted-agents]

The post says Moonshot AI has officially launched Kimi Hosted Agents, turning the full AI Agent runtime framework into a cloud service. Enterprises no longer need to build their own environments, manage tool calls, save task progress, or handle disconnects and retries; they only need to configure tasks and connect data to run Agents continuously in their business systems. The platform offers 12 Agent templates, over 140 Skills, and over 30 plugins, and supports integration with proprietary databases and tools.[^kimi-hosted-agents]
