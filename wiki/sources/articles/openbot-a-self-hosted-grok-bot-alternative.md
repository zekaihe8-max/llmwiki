# OpenBot：可自建的 Grok Bot 替代方案

*OpenBot: A Self-Hosted Grok Bot Alternative*

帖文称，OpenBot 是 Grok Bot 的较好替代方案：代码公开，支持 Linux、Mac、Windows 及 iOS、Android，不绑定单一模型厂商，可接入 Codex、Claude Code、Grok、Cursor、Hermes 等 Agent，并支持多个 Bot 协作、各自工作空间、任务分配与自动化；还可部署在自有 VPS 或电脑上，数据自行管理，并提供 Grok Bot 角色、Skill、记忆和定时任务的迁移功能。帖文同时指出，Grok Bot 原生 X 连接器暂时无法直接替代，且 OpenBot 默认执行权限较高，需自行做好隔离。[^openbot-grok-bot-alternative]

The post says OpenBot is a good Grok Bot alternative: open-source code, supports Linux, Mac, Windows, iOS and Android, not bound to a single model vendor, and can access Codex, Claude Code, Grok, Cursor, Hermes and other Agents; it supports multiple bots collaborating, each with its own workspace, task assignment and automation; it can also be deployed on one's own VPS or computer, with data self-managed, and provides migration of Grok Bot roles, skills, memory and scheduled tasks. The post also notes that Grok Bot's native X connector cannot yet be directly replaced, and OpenBot's default execution permissions are relatively high, so isolation must be handled by oneself.[^openbot-grok-bot-alternative]
