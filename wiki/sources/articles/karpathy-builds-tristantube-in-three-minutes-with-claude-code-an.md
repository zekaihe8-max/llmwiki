# 卡帕蒂用 Claude Code 三分钟做出 TristanTube，两小时过滤出 HackerTube

*Karpathy Builds TristanTube in Three Minutes with Claude Code and Filters HackerTube in Two Hours*

帖文称，Andrej Karpathy 看到 Tristan 发布的 YouTube 频道推荐后，用 Claude Code 在三分钟内一键做出了 TristanTube，收录约 4.7 万条“超级极客”视频并附带电视模式；随后他花周末用 Claude Opus 5.5 约两小时，把 20 年来约 4300 万条 Hacker News 评论过滤为 6454 个反复被推荐的视频，形成 HackerTube，并称其观看体验明显优于 YouTube 算法推荐。[^7d02c97e1358a6fd]

The post says Andrej Karpathy, after seeing Tristan's YouTube channel recommendations, one-shot TristanTube with Claude Code in three minutes, collecting about 47,000 "super nerdy" videos with a TV mode; he then spent a weekend using Claude Opus 5.5 for about two hours to filter roughly 43 million Hacker News comments over 20 years into 6,454 repeatedly recommended videos, forming HackerTube, which he claims offers a significantly better viewing experience than YouTube recommendations.[^7d02c97e1358a6fd]
