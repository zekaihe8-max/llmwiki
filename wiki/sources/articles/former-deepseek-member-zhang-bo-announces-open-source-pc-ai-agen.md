# 张博公布个人电脑端开源 AI Agent「Linger」

*Former DeepSeek Member Zhang Bo Announces Open-Source PC AI Agent Linger*

帖文称，前 DeepSeek-VL 项目负责人、DeepSeek LLM V1 研发成员张博（Tony Zhang）正式公布创业项目 Linger，一款运行在 Windows、macOS 和 Linux 上的开源 AI Agent，可操作已登录的浏览器和应用，读取邮件、日历及会议记录并整理为长期记忆，还能主动提醒并调用多个 Agent 协作；该项目亦支持本地大模型，依托 PolyStrata 推理引擎，12GB 显存与 64GB 内存即可以每秒 45.5 个 Token 的速度运行 125B 参数模型。[^linger-zhang-bo-announcement]

The post says former DeepSeek-VL project lead and DeepSeek LLM V1 R&D member Zhang Bo (Tony Zhang) has officially announced startup project Linger, an open-source AI Agent running on Windows, macOS, and Linux that can operate logged-in browsers and apps, read emails, calendars, and meeting records, and organize them into long-term memory; it can also proactively remind users and coordinate multiple Agents, and supports local large models via the PolyStrata inference engine, with 12GB VRAM and 64GB RAM sufficient to run a 125B-parameter model at 45.5 tokens per second.[^linger-zhang-bo-announcement]

## 摘要 / Summary

- 张博曾任 DeepSeek-VL 项目负责人，并参与 DeepSeek LLM V1 研发。[^linger-zhang-bo-announcement]
- Zhang Bo formerly led the DeepSeek-VL project and contributed to DeepSeek LLM V1 R&D.[^linger-zhang-bo-announcement]
- Linger 是开源 AI Agent，支持 Windows、macOS 和 Linux，可操作已登录的浏览器和应用。[^linger-zhang-bo-announcement]
- Linger is an open-source AI Agent supporting Windows, macOS, and Linux, capable of operating logged-in browsers and applications.[^linger-zhang-bo-announcement]
- 它能读取邮件、日历及会议记录，整理为长期记忆，并主动提醒重要事项。[^linger-zhang-bo-announcement]
- It can read emails, calendars, and meeting records, organize them into long-term memory, and proactively remind users of important matters.[^linger-zhang-bo-announcement]
- Linger 支持本地大模型，借助 PolyStrata 推理引擎，12GB 显存和 64GB 内存即可以每秒 45.5 个 Token 运行 125B 参数模型。[^linger-zhang-bo-announcement]
- Linger supports local large models; with the PolyStrata inference engine, 12GB VRAM and 64GB RAM can run a 125B-parameter model at 45.5 tokens per second.[^linger-zhang-bo-announcement]
- 该 Agent 可根据用户反馈调整提醒规则，并调用多个 Agent 协同完成任务。[^linger-zhang-bo-announcement]
- The Agent can adjust reminder rules based on user feedback and invoke multiple Agents to collaborate on tasks.[^linger-zhang-bo-announcement]
