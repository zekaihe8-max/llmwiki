# Levie · 工作会往“像写代码”靠

*Levie · Work Becomes Coding-Shaped*

「帖文称」AI 模型在编码、工具与计算机使用等领域将持续进步，能够使用软件或从零生成代码的智能体，其改进速度将快于其他知识工作领域。Box 联合创始人 Aaron Levie 认为，越来越多的工作会变得“像写代码”以适应智能体的强项，而模型只需掌握如何有效使用或生成软件，并结合深度领域专业知识在工作流中做出判断，即可释放几乎所有其他能力。[^levie-work-becomes-coding-shaped]

The post states that AI models will keep improving at coding, tool use, and computer use, so agents that use software or generate code will improve faster than other knowledge work domains. Aaron Levie argues that more work will become coding-shaped to adapt to what agents are good at, and that models mainly need to know how to use or generate software effectively, combined with deep domain expertise to make judgment calls within workflows.[^levie-work-becomes-coding-shaped]
