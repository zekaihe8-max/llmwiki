# Yobiru 主人签名授权

*Yobiru Master Signature Authorization*

帖文称，Yobiru 推出主人签名功能，用于解决不同 agent 之间传递信息时互不认可、需要人类用户到对应线程中转述的问题。用户通过 passkey（Face ID）一次签发授权，agent 可出示签名链接，验证后只执行一次。[^064f3c39b703da03]

The post says Yobiru launched a master-signature feature to solve the problem where agents do not accept messages from other agents and a human must relay instructions. A user can issue authorization once with a passkey (Face ID), and an agent can present a signature link that is verified and executed only once.[^064f3c39b703da03]
