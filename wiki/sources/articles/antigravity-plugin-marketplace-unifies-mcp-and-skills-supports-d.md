# Antigravity 插件市场统一 MCP 与 Skill，支持桌面 CLI 一键安装与同步

*Antigravity Plugin Marketplace Unifies MCP and Skills, Supports Desktop-CLI One-Click Install and Sync*

「帖文称」谷歌 Antigravity 终于把插件市场做明白了，装 MCP 和 Skill 不用再手改配置；新版 Plugin Marketplace 把 MCP、Skills、Rules、Hooks 和自定义 Agent 打包在一起，点一下就全配齐，桌面端 Customizations 里的 Marketplace 一键安装，命令行可用 /plugin 或 agy plugin install，两端自动同步，还能用 agy plugin import 导入 Claude Code 和 Gemini CLI 配置。[^antigravity-plugin-marketplace-mcp-skill]

The post claims Google Antigravity has finally figured out its plugin marketplace, so installing MCP and Skills no longer requires manual config edits; the new Plugin Marketplace bundles MCP, Skills, Rules, Hooks and custom Agents together, one-click installs everything, supports one-click install in the desktop App's Customizations Marketplace, CLI install via /plugin or agy plugin install with automatic sync between both sides, and agy plugin import to import Claude Code and Gemini CLI configurations.[^antigravity-plugin-marketplace-mcp-skill]
