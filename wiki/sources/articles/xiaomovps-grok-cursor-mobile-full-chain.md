# 小墨谈 Grok Bot + Cursor 手机全链路开发

*Xiaomo on Grok Bot + Cursor mobile full-chain development*

[@xiaomovps](https://x.com/xiaomovps)（小墨同学）分享 Grok Bot + Cursor 全链路：出门只带手机也能完成从写代码、测试到 PR 合并和发布；先用同一账号/邮箱关联两服务并分别连接 GitHub，再在 Grok Bot 里下发任务、让 Cursor Cloud 做改码与测试（可经截图、录屏与结果说明检查），最后走 GitHub PR 与 CI/CD，确认后合并，已配自动部署则可直接发布。人主要盯提交任务、检查结果并合并 PR、确认发布到生产；正式上线前仍建议自查代码、测试与权限，尤其涉及数据库与生产环境。[^xiaomovps-grok-cursor-mobile-full-chain] 原帖见 <https://x.com/xiaomovps/status/2114178579345080827>。

[@xiaomovps](https://x.com/xiaomovps) (Xiaomo) shares a Grok Bot + Cursor full chain: phone-only from coding and testing through PR merge and release—link both services with the same account/email and connect each to GitHub, dispatch tasks in Grok Bot for Cursor Cloud to code and test (inspect via screenshots, recordings, and result notes), then GitHub PR plus CI/CD, merge when green, and auto-deploy if configured. The human mainly submits tasks, checks results and merges PRs, and confirms production; before go-live, still self-check code, tests, and permissions, especially for databases and production.[^xiaomovps-grok-cursor-mobile-full-chain] Post: <https://x.com/xiaomovps/status/2114178579345080827>.
