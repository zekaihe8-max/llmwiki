# Harrison Chase 发布 LangSmith 编程 Agent ROI 看板帖文

*Harrison Chase Posts About LangSmith Coding Agent ROI Dashboard*

Harrison Chase（@hwchase17）在 X 上发帖称，LangSmith 不仅用于你构建的代理，也用于你使用的代理；因为人人都在用编程代理，团队为其建立了专用视图。LangChain 同步宣布 LangSmith 新增编程 Agent ROI 看板，可将所有被追踪的编程代理汇总至单一视图，覆盖不同编排工具与模型提供商，并把拉取请求关联到对话线程，以查看合并 PR 的成本以及未促成任何 PR 的支出。[^5d6aa42e4c534140]

Harrison Chase (@hwchase17) posted on X that LangSmith is not just for agents you build but also for agents you use, and that a dedicated view for coding agents has been built because everyone is using them. LangChain announced a new LangSmith dashboard to measure coding agent ROI, pulling every traced coding agent into one view across harnesses and model providers, and linking pull requests to threads so users can see the cost of merged PRs and spend that never led to one.[^5d6aa42e4c534140]
