# Rewind for X：开源插件本地保存 X 首页浏览过的推文

*Rewind for X: Open-source extension locally saves X homepage tweets you've scrolled past*

帖文称，X 首页一刷新，刚看到一半的好帖子就可能不见了；为此作者 yetone 做了小插件 Rewind for X，默默记下首页刷过的每条推文，用户可随时打开侧栏回看、搜索。帖文还强调，数据只存在用户自己电脑上，不上传任何东西，且项目已开源。[^rewind-for-x]

The post says that refreshing the X homepage can make a half-read tweet disappear, so author yetone built a small extension called Rewind for X that silently records every tweet scrolled past on the homepage, allowing users to open a sidebar to review and search. The post also stresses that data exists only on the user's own computer, nothing is uploaded, and the project is open source.[^rewind-for-x]
