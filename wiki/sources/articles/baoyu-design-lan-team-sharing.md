# baoyu-design 局域网团队共享

*baoyu-design LAN team sharing*

「帖文称」宝玉（@dotey）发布推文表示，baoyu-design 已增加局域网内的团队共享功能，用户可生成内部 IP 地址加端口的 URL，让同事或老板在局域网内编辑、评论并实时同步设计稿或幻灯片；所有数据保存在本机，并支持只读、评论、编辑三级权限及随时修改，同时 DeepSeek Harness 插件也同步更新以支持该功能。[^baoyu-design-lan-team-sharing]

The post by 宝玉 (@dotey) says baoyu-design has added LAN team sharing, letting users generate an internal IP plus port URL so colleagues or bosses can edit, comment, and sync designs or slides in real time within the LAN; all data remains local, with read-only, comment, and edit permissions adjustable at any time, and the DeepSeek Harness plugin was updated to support the same feature.[^baoyu-design-lan-team-sharing]
