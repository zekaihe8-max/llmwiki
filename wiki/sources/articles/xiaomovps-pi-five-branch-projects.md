# 小墨谈 Pi 五个分支项目

*Xiaomo on five Pi branch projects*

[@xiaomovps](https://x.com/xiaomovps) 整理学习 Pi 时值得知道的五个分支/周边项目——Oh My Pi（OMP）、senpi、mu、Orbi、Pi Pocket——覆盖功能增强、Agent 工作流重设计、小模型分流决策、GitHub Issue 自动化与移动端远程 Session；并强调这些不全是传统 Fork，有些是基于 Pi 的独立项目，合在一起说明 Pi 核心保持精简而社区能走出完全不同的方向。[^xiaomovps-pi-five-branch-projects] 原文见 <https://x.com/xiaomovps/status/2113912639571255525>。

[@xiaomovps](https://x.com/xiaomovps) lists five branch or adjacent projects worth knowing when learning Pi—Oh My Pi (OMP), senpi, mu, Orbi, and Pi Pocket—spanning feature enrichment, Agent workflow redesign, small-model decision offload, GitHub Issue automation, and mobile remote sessions; and stresses that not all are traditional forks—some are independent projects built on Pi—together showing that Pi keeps a slim core while the community can take fully different directions.[^xiaomovps-pi-five-branch-projects] The post is at <https://x.com/xiaomovps/status/2113912639571255525>.

## 摘要 / Summary

- Oh My Pi（OMP）给 Pi 加上 LSP、Debugger、Subagent、浏览器等能力，面向想要完整 Coding 工作流的用户；仓库见 <https://github.com/can1357/oh-my-pi>。[^xiaomovps-pi-five-branch-projects]
- Oh My Pi (OMP) adds LSP, Debugger, Subagent, browser, and related capabilities for users who want a full coding workflow; repo at <https://github.com/can1357/oh-my-pi>.[^xiaomovps-pi-five-branch-projects]
- senpi 重点改造 System Prompt、权限管理、Context 压缩与并行工具执行，让 Pi 有一套更完整的默认行为；仓库见 <https://github.com/code-yeongyu/senpi>。[^xiaomovps-pi-five-branch-projects]
- senpi reworks the System Prompt, permission management, Context compression, and parallel tool execution so Pi has a fuller default behavior; repo at <https://github.com/code-yeongyu/senpi>.[^xiaomovps-pi-five-branch-projects]
- mu 引入轻量 Judge 模型处理任务分类、上下文保留等决策，减少主模型在简单判断上的消耗；仓库见 <https://github.com/qybaihe/MU>。[^xiaomovps-pi-five-branch-projects]
- mu introduces a lightweight Judge model for decisions such as task classification and context retention, cutting main-model spend on simple judgments; repo at <https://github.com/qybaihe/MU>.[^xiaomovps-pi-five-branch-projects]
- Orbi 让 Pi 自动处理 GitHub Issue：从 Issue 到代码实现、Review、PR，甚至发布流程，适合维护开源项目；仓库见 <https://github.com/orbi-build/orbi>。[^xiaomovps-pi-five-branch-projects]
- Orbi has Pi auto-handle GitHub Issues—from Issue through implementation, Review, PR, and even release flow—suited to maintaining open-source projects; repo at <https://github.com/orbi-build/orbi>.[^xiaomovps-pi-five-branch-projects]
- Pi Pocket 基于 Pi Durable，支持移动端访问、共享 Session 与后台任务恢复，便于出门远程使用 Agent；仓库见 <https://github.com/TannerMidd/pi-pocket>。[^xiaomovps-pi-five-branch-projects]
- Pi Pocket builds on Pi Durable for mobile access, shared Sessions, and background task resume so the Agent can be used remotely while away; repo at <https://github.com/TannerMidd/pi-pocket>.[^xiaomovps-pi-five-branch-projects]
- 作者总结：这些不全是传统意义上的 Fork，有些是基于 Pi 构建的独立项目；Pi 的核心保持精简，社区却能把它玩出完全不同的方向。[^xiaomovps-pi-five-branch-projects]
- The author concludes that these are not all traditional forks—some are independent projects built on Pi—and that Pi’s core stays slim while the community can push it in fully different directions.[^xiaomovps-pi-five-branch-projects]
