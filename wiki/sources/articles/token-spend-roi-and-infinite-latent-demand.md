# 代币支出回报与无限潜在需求

*Token Spend ROI and Infinite Latent Demand*

François Chollet 在 X 上的帖文称，经济中存在基本无限的潜在代币需求，唯一制约是成本；企业愿意花在代币上的金额取决于代币支出的投资回报率，而新模型既提升了现有用例的回报率，也扩大了有效用例范围，因此代币消费可在很长一段时间内几何级增长。[^fchollet-token-roi-demand]

François Chollet's X post argues that latent token demand across the economy is essentially infinite, with cost as the only constraint; willingness to spend on tokens depends on ROI, which new models improve for existing use cases while expanding valid use cases, allowing token consumption to grow geometrically for a long time.[^fchollet-token-roi-demand]
