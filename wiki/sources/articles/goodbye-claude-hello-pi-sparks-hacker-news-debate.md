# 《Goodbye Claude, Hello Pi》在 Hacker News 引发热议

*"Goodbye Claude, Hello Pi" Sparks Hacker News Debate*

帖文称，一位使用 Claude Code 超过一年的开发者决定将主力 Coding Agent 换成 Pi，并在 Hacker News 引发数百条评论讨论。作者认为功能越来越多不代表体验越来越好，Claude Code 截至今年 9 月已发布 244 个版本，其中超 75% 修改过 System Prompt 或工具描述，频繁更新迫使用户反复适应工作流。相比之下，Pi 核心精简，将控制权交还开发者，作者称仅用约 20 分钟通过扩展解决了困扰自己的多会话问题。HN 评论区也有反对意见，有人担忧 Pi 缺少默认安全审批机制，第三方扩展需自行审核，最终又回到 Claude Code。[^goodbye-claude-hello-pi-hn]

The post claims a developer who used Claude Code for over a year decided to switch his primary coding agent to Pi, sparking hundreds of comments on Hacker News. The author argues that more features do not mean better experience; Claude Code had released 244 versions as of September this year, with over 75% modifying the System Prompt or tool descriptions, forcing users to repeatedly adapt their workflows. In contrast, Pi keeps its core minimal and returns control to developers; the author claims he solved his multi-session issue in about 20 minutes via an extension. Hacker News comments also included opposition, with some worrying Pi lacks a default safety approval mechanism and third-party extensions require self-auditing, leading them back to Claude Code.[^goodbye-claude-hello-pi-hn]
