# Genie 4 现已在 Gemini API 上提供

*Genie 4 is now available on the Gemini API*

「帖文称」，Genie 4 现已通过 Gemini API（经交互 API）及 Google AI Studio 面向开发者开放。开发者可从文本提示词、参考图像或两者同时出发，生成连续 720p、24 帧每秒并带原生音频的世界，音频涵盖环境音景、音效与角色对话。借助实时键盘控制与实时文本提示，可在飞行中导航环境并改变天气、光照、物体或事件，Gemini 推理则保持世界状态一致连贯。每份输出均包含不可见的 SynthID 水印。[^genie-4-api]

According to the post, Genie 4 is now available to developers through the Gemini API (via the Interactions API) and Google AI Studio. Developers can start from a text prompt, a reference image, or both to generate continuous 720p worlds at 24fps with synchronized native audio, including ambient soundscapes, sound effects, and character dialogue. Using real-time keyboard controls alongside live text prompts, users can navigate environments and change weather, lighting, objects, or events on the fly, while Gemini reasoning keeps the world state consistent and coherent. Every output includes imperceptible SynthID watermarking.[^genie-4-api]
