# Matt Pocock 提出 Sandcastle v1 软件工厂构想

*Matt Pocock Proposes Sandcastle v1 Software Factory Pitch*

「帖文称」Matt Pocock 正在大力重构 Sandcastle v1，将其定位为运行在用户自有基础设施上的软件工厂，内置六类编排工具（如 Claude Code、Codex），并集成 Daytona、Vercel、E2B 等沙箱供应商；帖文还称，其仓库中的每项技能都将变成可调用的 Agent() 函数，例如 CodeReview()、ImplementSpec()、Retro()、ImproveCodebaseArchitecture()。[^matt-pocock-sandcastle-v1-software-factory]

Matt Pocock outlines a pitch for Sandcastle v1, describing it as a software factory that runs on the user's own infrastructure with opinionated, skills-based defaults. It includes six built-in harnesses such as Claude Code and Codex, integrates with sandbox providers like Daytona, Vercel, and E2B, and turns every skill in his repository into an invocable Agent() function.[^matt-pocock-sandcastle-v1-software-factory]

- Sandcastle v1 旨在帮助用户构建软件工厂。 / Sandcastle v1 aims to help users build a software factory.[^matt-pocock-sandcastle-v1-software-factory]

- 集成 Daytona、Vercel、E2B 等主流沙箱供应商。 / It integrates with top sandbox providers including Daytona, Vercel, and E2B.[^matt-pocock-sandcastle-v1-software-factory]

- 其仓库中每项技能都变成可调用的 Agent() 函数，如 CodeReview()、ImplementSpec()、Retro()、ImproveCodebaseArchitecture()。 / Every skill in his repo becomes an Agent() function, such as CodeReview(), ImplementSpec(), Retro(), and ImproveCodebaseArchitecture().[^matt-pocock-sandcastle-v1-software-factory]
