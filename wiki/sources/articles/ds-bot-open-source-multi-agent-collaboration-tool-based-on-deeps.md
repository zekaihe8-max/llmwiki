# DS Bot：基于 DeepSeek Harness 的开源多智能体协作工具

*DS Bot: Open-source multi-agent collaboration tool based on DeepSeek Harness*

「帖文称」DS Bot 是一款把多个 AI Agent 组织成团队的开源协作工具，基于 DeepSeek Harness，由 Chief 统一协调不同 AI 助手，支持 Bot 群聊、@任务委派、Goal 目标管理、独立记忆和工作目录，并可接入 Claude Code、Codex CLI、Cursor CLI 等本地编程 Agent。与偏向云端 AI 员工服务的 Grok Bot 不同，DS Bot 更侧重本地 Agent 组织与协作，支持 Windows、macOS、Linux 桌面端及 Docker 自托管，采用 Apache 2.0 开源，软件免费，模型费用自理，多 Bot 协作可能增加 Token 消耗。[^ds-bot]

The post describes DS Bot as an open-source collaboration tool that organizes multiple AI Agents into a team based on DeepSeek Harness, with a Chief coordinating assistants, group chat, @task delegation, Goal management, independent memory, and working directories, and integration with local coding Agents such as Claude Code, Codex CLI, and Cursor CLI. Unlike cloud-oriented Grok Bot, it emphasizes local Agent organization, supports Windows/macOS/Linux and Docker self-hosting, is Apache 2.0 licensed with free software but user-borne model costs, and may increase token consumption with multi-Bot collaboration.[^ds-bot]
