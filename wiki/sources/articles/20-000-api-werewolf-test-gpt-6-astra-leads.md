*$20,000 API Werewolf Test: GPT-6 Astra Leads*

帖文称，知名 AI 播客主持人 Dwarkesh Patel 花费约 2 万美元 API 额度，搭建 AI 狼人杀测试，让 11 款模型进行 386 局《血染钟楼》对抗。测试让同一阵营全部由同一模型扮演，随后交换阵营再打；结果显示 GPT-6 Astra 以 1859 Elo 排名第一，在识破骗局和设计骗局两项上均显著高于 Claude Opus 5.5。文中还举例了恶魔牺牲队友洗白、以及 GPT 阵营识破中毒技能失效的两局。[^482861e27c05ba59]

The post says AI podcast host Dwarkesh Patel spent about $20,000 in API credits to run an AI werewolf test, with 11 models playing 386 rounds of Blood on the Clocktower. Each faction was played entirely by the same model, then sides were swapped; results show GPT-6 Astra ranked first at 1859 Elo, significantly ahead of Claude Opus 5.5 in both lie detection and deception design. Two example games are also described.[^482861e27c05ba59]
