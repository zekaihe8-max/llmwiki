# Sand3D：给大模型用的 3D 建模库

*Sand3D: 3D Modeling Library for Large Models*

帖文称，Sand3D 是专为大语言模型打造的 3D 建模 Python 库，基于 Blender 底层构建，能用语义名称定义零件、关节与装配结构，并可直接放入 AI 提示词调用；项目同时开源了超过 10 万个 3D 组件，建好后可一键导出为游戏引擎、机器人仿真和网页端通用的多种标准 3D 格式。[^sand3d-3d-modeling-library-for-llms]

The post says Sand3D is a Python 3D modeling library built for large language models on top of Blender, allowing parts, joints, and assemblies to be defined by semantic names and called directly in AI prompts; it also open-sources over 100,000 3D components and supports one-click export to standard 3D formats for game engines, robotics simulation, and the web.[^sand3d-3d-modeling-library-for-llms]

## 摘要 / Summary

- 基于 Blender 底层，专为大语言模型设计的 Python 3D 建模库。 / Built on Blender, a Python 3D modeling library designed for large language models.[^sand3d-3d-modeling-library-for-llms]
- 支持用语义名称直接定义零件、关节与装配结构，无需手算复杂坐标。 / Supports defining parts, joints, and assemblies by semantic names without manually calculating complex coordinates.[^sand3d-3d-modeling-library-for-llms]
- 可直接放入 AI 提示词中调用，建好后一键导出为游戏引擎、机器人仿真和网页端通用的多种标准 3D 格式。 / Can be called directly in AI prompts and exported with one click to standard 3D formats for game engines, robotics simulation, and the web.[^sand3d-3d-modeling-library-for-llms]
