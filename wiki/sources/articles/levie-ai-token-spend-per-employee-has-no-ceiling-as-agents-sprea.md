# Levie：AI Token 每员工支出无上限，智能体将渗透更多知识工作

*Levie: AI Token Spend per Employee Has No Ceiling as Agents Spread Across Knowledge Work*

这篇来自 Box 联合创始人 Aaron Levie 的 X 帖文称，AI Token 每员工支出仍未见顶，且靠近 AI 前沿的人越发觉得代币使用和采用仍处于早期曲线。帖文提到，编码能力在过去 12 个月里已从基本不可用转为可用，随之而来的计算机使用与工具使用正在让智能体能够介入金融、生命科学、网安等更多知识工作领域；智能体群与后台智能体等新形态将大幅消耗更多 Token，Token 消费基本只会上升。帖文还引用 Kobeissi Letter 的 Ramp 数据称，美国 AI 支出前 1% 企业在 10 月每员工 AI 支出达创纪录的 10,199 美元，自 2026 年 1 月以来已翻三倍；前 10% 企业每员工支出达 801 美元，上升 180%。[^levie-308d88c0]

In this X post, Box co-founder Aaron Levie says AI token spend per employee still has no ceiling, and those closest to AI believe token use and adoption remain early on the curve. He argues coding has only recently become usable, and that computer use and tool use now let agents tackle knowledge work in finance, life sciences, cybersecurity, and beyond. Agent swarms and background agents will consume vastly more tokens, he writes, so token use is only going up. The post also cites Kobeissi Letter/Ramp data showing top-1% U.S. businesses spent a record $10,199 per employee on AI in October, more than tripling since January 2026; top-10% firms spent $801 per employee last month, up 180%.[^levie-308d88c0]
