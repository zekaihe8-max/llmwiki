# Pi Agent、Claude Code 与 DeepSeek Harness：新手 AI 编程工具选型

*Pi Agent, Claude Code, and DeepSeek Harness: A Beginner's AI Coding Tool Selection Guide*

「帖文称」Pi Agent、Claude Code、DeepSeek Harness 三者都能写代码、调用工具，但定位和设计理念不同；新手不必追求功能最多，应根据需求和愿意花的折腾时间选择。帖文建议刚接触 AI 编程的新手优先选择 Claude Code，想研究 Token 成本、上下文和插件的可尝试 Pi，对 Agent 底层架构和运行模式感兴趣的可研究 DeepSeek Harness。[^xiaomovps-agent-selection]

The post states that Pi Agent, Claude Code, and DeepSeek Harness all support coding and tool use but differ in positioning and design philosophy; beginners should not chase the most features and should choose based on needs and tinkering time. It recommends Claude Code for newcomers to AI programming, Pi for those researching token cost, context, and plugins, and DeepSeek Harness for those interested in Agent architecture and runtime modes.[^xiaomovps-agent-selection]

## 摘要 / Summary

- Pi Agent 默认只有 4 个基础工具，架构精简、上下文开销小，适合喜欢折腾、希望自己控制 Agent 每一部分的用户。[^xiaomovps-agent-selection]
- Pi Agent defaults to only four basic tools, has a simple architecture and low context overhead, suiting users who like to tinker and control every part of the Agent.[^xiaomovps-agent-selection]
- Claude Code 定位为 AI 编程助手，内置代码理解、文件修改、Plan Mode、Subagent、权限管理等功能，适合主要想让 AI 帮写代码的普通编程用户。[^xiaomovps-agent-selection]
- Claude Code is positioned as an AI programming assistant with built-in code understanding, file editing, Plan Mode, Subagent, and permission management, suiting ordinary programming users who mainly want AI to write code.[^xiaomovps-agent-selection]
- DeepSeek Harness 采用一切皆插件的模式，提供标准、PTC、极简、创造等模式，适合研究 Agent 架构、插件开发或用 DeepSeek 搭建工作流的用户。[^xiaomovps-agent-selection]
- DeepSeek Harness uses an everything-is-a-plugin model and offers Standard, PTC, Minimal, and Creative modes, suiting users researching Agent architecture, plugin development, or DeepSeek-based workflows.[^xiaomovps-agent-selection]
- 帖文建议新手优先选择 Claude Code 先跑通 AI 辅助开发流程，没必要三个都折腾一遍。[^xiaomovps-agent-selection]
- The post recommends beginners prioritize Claude Code to get the AI-assisted development flow running first, rather than trying all three.[^xiaomovps-agent-selection]
