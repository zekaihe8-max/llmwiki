# AI 恐怖漫剧模型对比：Wan3.0 成主力，SD 系列各有短板

*AI Horror Comic Drama Model Comparison: Wan3.0 Main Force, SD Series Each Has Shortcomings*

「帖文称」作者用同一组素材分别测试了 Wan3.0、SD2.5、SD2.0 和 H3 四款视频模型，最终选用 Wan3.0 作为主力模型、SD2.5 补镜头，并辅以即梦 Seedream 5.0 Flash、GPT Image、LibTV、可灵首尾帧及剪映 UI/对话框，制作出带第一人称走廊和游戏对话框的 AI 恐怖漫剧；帖文强调这只是针对该片的测试感受，而非通用模型排行榜。[^d7ddfde520912f45]

The post says the author tested Wan3.0, SD2.5, SD2.0 and H3 video models with the same materials, finally choosing Wan3.0 as the main model and SD2.5 to supplement shots, supplemented by Seedream 5.0 Flash, GPT Image, LibTV, Kling first/last frames and CapCut UI/dialogue boxes to produce an AI horror comic drama with first-person corridors and game dialogue boxes; the post stresses these are test impressions for this specific film, not a general model ranking.[^d7ddfde520912f45]

## 摘要 / Summary

- 帖文称 Wan3.0 更能保留参考图的 3D 质感，且积分消耗相对较低，因此成为该片主力模型。 / The post says Wan3.0 better retains the 3D texture of reference images and consumes relatively fewer credits, so it became the main model for the film.[^d7ddfde520912f45]
- 帖文称 SD2.5 电影感不错，但偏影视质感，不够像 3A 游戏；SD2.0 不太听提示词且积分消耗偏高。 / The post says SD2.5 has a cinematic feel but leans toward film/TV texture rather than a 3A game look; SD2.0 does not follow prompts well and has high credit consumption.[^d7ddfde520912f45]
- 帖文称 H3 效果尚可，但提示词遵循不够理想，第一人称镜头缺乏游戏代入感。 / The post says H3 is acceptable, but prompt following is not ideal and first-person shots lack game immersion.[^d7ddfde520912f45]
- 除视频模型外，帖文还列出即梦 Seedream 5.0 Flash 定人物、GPT Image 做三视图和场景、LibTV 补场景角度、可灵首尾帧补过渡、剪映叠 UI 和对话框。 / Besides video models, the post also lists Seedream 5.0 Flash for character design, GPT Image for three-views and scenes, LibTV for scene angles, Kling first/last frames for transitions, and CapCut for UI and dialogue boxes.[^d7ddfde520912f45]
- 作者建议先拿几个关键镜头试模型，不要整部开做了才发现风格不对；帖文注明这不是通用排行榜。 / The author suggests testing key shots with models first instead of producing the whole piece before discovering the style is wrong; the post notes this is not a general ranking.[^d7ddfde520912f45]
