# 铁柱AGI谈任意 Agent 可指挥 Grok Bot

*cgnot996 on any agent commanding Grok Bot*

[@cgnot996](https://x.com/cgnot996)（铁柱AGI）称 Grok [@bot](https://x.com/bot) 终于能被别的 Agent 指挥：他在 Codex 里说一句话，就列出账号下的所有 Bot，可与每个 Bot 单独沟通派活并回收结果。帖文列举三条能力方向：(1) 多个 Grok Bot 账号连成网，Bot 跨账号互相派活、队伍可扩；(2) 给 Grok Bot「换大脑」——Claude、GPT 当总指挥，拆需求、派任务、收结果；(3) 任意 Agent 干到一半，都能把上下文交给 Grok Bot 接着做。交付形态是一个 skill + CLI，Codex 与 Claude Code 都能用；答疑群已在内测，是否开源看大家感不感兴趣。帖内另嵌其早前 Grok Bot SDK 与浏览器插件说明（把浏览器所见共享给 Bot），本帖主叙事是外部 Agent 对 Grok Bot 的调度面。[^cgnot996-any-agent-command-grok-bot] 原帖见 <https://x.com/cgnot996/status/2115722202712789476>。

[@cgnot996](https://x.com/cgnot996) (铁柱AGI) says Grok [@bot](https://x.com/bot) can finally be commanded by other agents: in Codex, one prompt lists every bot under his account; he can talk to each bot individually to dispatch work and collect results. The post lists three capability directions: (1) mesh multiple Grok Bot accounts so bots dispatch across accounts and the team scales; (2) “swap the brain” for Grok Bot—Claude or GPT as orchestrator to split requirements, assign tasks, and gather results; (3) any agent mid-task can hand context to Grok Bot to continue. Delivery is one skill plus CLI, usable from Codex and Claude Code; a Q&A group is in private beta, and open source depends on interest. The thread embeds his earlier Grok Bot SDK and browser-extension note (share browser content to the bot); this post’s main claim is the external-agent dispatch surface for Grok Bot.[^cgnot996-any-agent-command-grok-bot] Post: <https://x.com/cgnot996/status/2115722202712789476>.
