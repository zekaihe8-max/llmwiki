# Sperid Labs 开源 Idol：单张图片几秒内生成完整 3D 高斯模型

*Sperid Labs Open-Sources Idol: Generate Complete 3D Gaussian Models from a Single Image in Seconds*

「帖文称」Sperid Labs 开源 Idol，能把任意一张物体照片或渲染图自动抠图并补全未展示的背面，还原成最高百万级细节的 3D 高斯文件；消费级显卡占用 7.2GB 显存即可运行，最快 2 秒左右完成生成，模型已发布于 Hugging Face。[^sperid-labs-idol-open-source]

The post claims that Sperid Labs has open-sourced Idol, which can automatically remove backgrounds and complete unseen backside views from any object photo or render, restoring them into 3D Gaussian files with up to million-level detail; it reportedly runs on consumer GPUs with 7.2GB VRAM and generates in about 2 seconds, with the model released on Hugging Face.[^sperid-labs-idol-open-source]
