# 铁柱：接入 Grok Bot

*Tiezhu: Connecting Grok Bot*

「帖文称」这是「全网首个把 Grok Bot 接入小豆的教程」。用户需在虚拟机安装 GitHub 开源工具，并用已登录 Grok Bot 账号的浏览器打开授权链接；授权完成后，让小豆查询 BOT 列表并向指定 BOT 发消息，收到回复后由小豆转述。发布者称该功能「其实没有什么用」，但证明该路径可行，并欢迎给开源项目点赞。[^tie-zhu-grok-bot-xiaodou]

The post claims this is the first web-wide tutorial for connecting Grok Bot to Xiaodou. Users install a GitHub open-source tool on a VM and complete authorization via a browser logged into the Grok Bot account; after authorization, they ask Xiaodou to query the bot list and message a designated bot, and Xiaodou relays the reply. The author says the feature is not very useful but confirms the path works, and welcomes stars for the open-source project.[^tie-zhu-grok-bot-xiaodou]
