# 阿里 Qwen4 Max 发布：智能指数 43 分，每任务成本约为 Qwen3.8 Max 三分之一

*Alibaba Qwen4 Max Released: Intelligence Index 43, Cost Per Task About One-Third of Qwen3.8 Max*

据 Artificial Analysis 在 X 上的帖文称，阿里巴巴已推出 Qwen4 Max，采用 xhigh 推理努力度，在人工智能分析智能指数上得分 43 分，比 Qwen3.8 Max 高出 9 分，落后 Kimi K3.1 Pro 3 分。帖文还称 Qwen4 Max 每智能指数任务成本为 3.27 美元，约为 Qwen3.8 Max 的三分之一，也低于 Kimi K3.1 Pro 约 11%。[^qwen4-max-alibaba-benchmark]

According to a post by Artificial Analysis on X, Alibaba has launched Qwen4 Max, which scores 43 on the Artificial Analysis Intelligence Index using xhigh reasoning effort—9 points ahead of Qwen3.8 Max and 3 points behind Kimi K3.1 Pro. The post claims Qwen4 Max costs $3.27 per Intelligence Index task, roughly one-third of Qwen3.8 Max and about 11% less than Kimi K3.1 Pro.[^qwen4-max-alibaba-benchmark]

## 摘要 / Summary

- Qwen4 Max 智能指数得分 43 分，领先 Qwen3.8 Max（34 分）9 分，落后 Kimi K3.1 Pro（46 分）3 分。[^qwen4-max-alibaba-benchmark]
- Qwen4 Max scores 43 on the Intelligence Index, 9 points ahead of Qwen3.8 Max (34) and 3 points behind Kimi K3.1 Pro (46).[^qwen4-max-alibaba-benchmark]
- 每智能指数任务成本 3.27 美元，约为 Qwen3.8 Max（10.02 美元）的三分之一，也比 Kimi K3.1 Pro（3.68 美元）低约 11%。[^qwen4-max-alibaba-benchmark]
- Cost per Intelligence Index task is $3.27, about one-third of Qwen3.8 Max ($10.02) and ~11% less than Kimi K3.1 Pro ($3.68).[^qwen4-max-alibaba-benchmark]
- 每任务输出约 105k 个 Token，比 Qwen3.8 Max（约 171k）少用 39%。[^qwen4-max-alibaba-benchmark]
- Uses ~105k output tokens per task, 39% fewer than Qwen3.8 Max (~171k).[^qwen4-max-alibaba-benchmark]
- 上下文窗口 100 万 Token，支持文本与图像输入、文本输出；API 定价为每 100 万 输入/输出 Token 1.50/4.50 美元，缓存命中 0.075 美元。[^qwen4-max-alibaba-benchmark]
- 1M token context window; text and image input with text output; API pricing $1.50/$4.50 per 1M input/output tokens, $0.075 cache hit price.[^qwen4-max-alibaba-benchmark]
- 仅通过阿里通义千问一线 API 提供。[^qwen4-max-alibaba-benchmark]
- Available only on Alibaba Qwen's first-party APIs.[^qwen4-max-alibaba-benchmark]
