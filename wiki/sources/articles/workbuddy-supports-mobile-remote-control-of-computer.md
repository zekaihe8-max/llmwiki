# WorkBuddy 支持手机远程控制电脑

*WorkBuddy Supports Mobile Remote Control of Computer*

「帖文称」WorkBuddy 已升级到最新版本，直接支持手机端远程控制电脑端，测试后基本达到网易 UU 的远程控制效果；用户只需在「设置」→「远程连接」中打开“远程控制插件”开关，并开启“录屏录制与系统录音”及“辅助功能”。[^c270c93274635316]

The post claims WorkBuddy has been upgraded to its latest version and now supports mobile remote control of computers, with testing showing performance basically comparable to NetEase UU; users only need to enable the “Remote Control Plugin” switch under “Settings” → “Remote Connection,” and also enable “Screen Recording and System Audio” and “Accessibility.”[^c270c93274635316]
