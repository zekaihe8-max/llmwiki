# Levie：编程预示知识工作向智能体协作演变

*Levie: Coding Foreshadows Knowledge Work Evolving Toward Agent Collaboration*

「帖文称」编程能让人窥见大量知识工作的未来：工作将从手动进行研究、打字和价值创造，转向协调智能体完成的工作，再进一步演变为向智能体下达目标并让其自行解决更大问题。帖文还指出，智能体将使用计算机、调用现有工具或即时编写代码，使许多非编程任务最终变得“编程相邻”；由于大量工作难以验证，人类将比编程场景更深度地介入环路，但可交给智能体的部分会不断扩大。[^levie-coding-knowledge-work]

The post says coding offers a window into the future of much knowledge work: jobs will shift from manually doing research, typing, and value creation to coordinating agents' work, then to giving agents goals to optimize against so they solve increasingly larger problems. It adds that agents will use computers, leverage existing tools, or write code on the fly, making many non-coding tasks coding-adjacent; because much work remains non-verifiable, humans will stay even more in the loop than in coding, but the handoffable portion will keep growing.[^levie-coding-knowledge-work]
