# DeepSeek Harness 定位 Agent 时代操作系统

*DeepSeek Harness Positioned as Agent Era Operating System*

帖文称，DeepSeek 希望 DeepSeek Harness 可以作为 Agent 时代的操作系统。宝玉提到，许多 DeepSeek Harness 插件作者询问官方会将哪些插件和功能做成内置，若官方会实现某功能，第三方插件是否仍有意义。官方希望以操作系统来类比，如智能手机操作系统会内置一些通用功能，进而定位 DeepSeek Harness。[^deepseek-harness-agent-os]

The post says DeepSeek hopes DeepSeek Harness can serve as the operating system for the Agent era. Bao Yu notes that many DeepSeek Harness plugin authors asked which plugins and features the official team would build in, and whether third-party plugins remain meaningful if the official team implements a feature. The team hopes to use an operating system analogy, such as built-in general functions in smartphone operating systems, to position DeepSeek Harness.[^deepseek-harness-agent-os]
