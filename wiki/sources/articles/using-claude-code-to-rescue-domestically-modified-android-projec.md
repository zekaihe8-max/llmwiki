# 让 Claude Code 把国内改版安卓投影仪救回来

*Using Claude Code to Rescue Domestically Modified Android Projectors*

帖文称，用户去年在国内购买的安卓投影仪预装国内厂商改装的系统，无法安装国外流媒体应用或自有实验性应用；他借助 Claude Code 编写一键开启开发者选项的 APK，并从索尼 Google TV 拷贝日本市场下载的 APK 进行安装，除 Netflix 等需认证的应用外，绝大多数应用均可运行，实现了投影仪的废物利用。[^claude-code-android-projector-rescue]

The post says the user bought Android projectors in China last year running domestically modified systems that could not install foreign streaming apps or his own experimental apps; with Claude Code he wrote a one-tap APK to enable developer options, then copied APKs downloaded from the Japanese market on his Sony Google TV to install them, and except for certified apps like Netflix, almost all worked, giving the projectors new life.[^claude-code-android-projector-rescue]
