# 小墨谈 AI 订阅精简到 $120/月

*Xiaomo on trimming AI subscriptions to $120/month*

[@xiaomovps](https://x.com/xiaomovps)（小墨同学）分享最新 AI 订阅方案：每月约 $120，只保留 Claude Pro（$20/月）与 Grok 最新整合订阅（$100/月）；取消原先单独的 GPT $100/月订阅，并因 Grok 新订阅已含 X Premium+ 权益且可配合 Cursor，不必再为 Premium+ 另付约 $30～40。取消 GPT 后 Computer Use 不如从前灵活，可用 Claude Code 搭配其他工具部分补上；图片与视频生成（主要为 X 封面）多数可由 Grok 覆盖。换来的是 X 数据收集、经 Grok Bot 配 Cursor 的云端编码与 PR 流程，以及出门用手机处理素材、任务与跟进开发；该 $100 套餐周额度基本用不完，最高约到 70%。作者总结：覆盖日常工作流、额度够用、成本可控，比每个平台都开会员更有价值。[^xiaomovps-ai-subs-trim-120] 原帖见 <https://x.com/xiaomovps/status/2114197502153113745>。

[@xiaomovps](https://x.com/xiaomovps) (Xiaomo) shares a trimmed AI stack at about $120/month: Claude Pro ($20/mo) plus Grok’s latest bundled plan ($100/mo); he cancels a separate GPT $100/mo sub, and because the new Grok plan already includes X Premium+ and works with Cursor, he no longer pays an extra ~$30–40 for Premium+. Dropping GPT makes Computer Use less flexible—partly offset with Claude Code plus other tools; image and video (mainly X covers) are mostly covered by Grok. Gains include X data collection, coding via Grok Bot with Cursor to cloud work and PRs, and phone-side media, tasks, and code follow-up; the $100 plan’s weekly quota is rarely exhausted, peaking around 70%. He concludes that covering the daily workflow with enough quota and controllable cost beats owning every platform membership.[^xiaomovps-ai-subs-trim-120] Post: <https://x.com/xiaomovps/status/2114197502153113745>.
