# Untangle 创始人：1 个经理 agent 带 20 个 builder，每 15 分钟巡查，招人只看 45 分钟录屏

*Untangle Founder: 1 Manager Agent Leads 20 Builders, 15-Minute Check-ins, Hiring by 45-Minute Screen Recording*

帖文称，Untangle 创始人兼 CEO Ryan Carson 在 2026 美国 AI Engineer 大会上介绍，其工程团队在云端使用 Devin，由一个从不写代码的「经理 agent」同时调度最多约 20 个 builder agent，人类仅通过语音与经理对话，经理每 15 分钟被自动化强制巡查子会话，审查最多循环 3 次，每个功能上线前创始人亲自查看 agent 录制的演示视频；招聘方面，候选人提交约 45 分钟全屏录屏，由排名 agent 筛选，前五名做 16 小时有偿真实 PR 项目后再电话沟通。[^e59433309b48f106]

The post says Untangle founder and CEO Ryan Carson told the 2026 AI Engineer conference that his engineering team runs on Devin in the cloud, with a manager agent that never writes code dispatching up to about 20 builder agents; humans speak only to the manager by voice, the manager is automatically forced to check sub-sessions every 15 minutes, reviews loop at most three times, and the founder personally watches agent-recorded demo videos before every feature ships; for hiring, candidates submit about 45-minute full-screen recordings, a ranking agent screens them, the top five complete a 16-hour paid real PR project, and only then does a phone call happen.[^e59433309b48f106]

## 摘要 / Summary

- 经理 agent 从不写代码，人类通过语音与其对话，它下面带最多约 20 个 builder agent（实际浮动在 5 到约 25 之间）。[^e59433309b48f106]
- The manager agent never writes code; humans talk to it by voice, and it supervises up to about 20 builder agents (actually floating between 5 and about 25).[^e59433309b48f106]
- 任务来自 Linear 看板，每张票对应一个 PR，经理按依赖关系决定优先级，人只回答经理提出的「1 个问题 + 1 条建议」。[^e59433309b48f106]
- Tasks come from a Linear board; each ticket maps to one PR, the manager sets priority by dependencies, and the human only answers the manager's "1 question + 1 recommendation."[^e59433309b48f106]
- 系统自动每 15 分钟强制经理读所有子会话，审查最多循环约 3 次，三次后未解决的重要 bug 上报经理，必要时再上报创始人。[^e59433309b48f106]
- The system automatically forces the manager to read all child sessions every 15 minutes; reviews loop at most about 3 times, and important bugs unresolved after three rounds are escalated to the manager, then to the founder if needed.[^e59433309b48f106]
- 每个功能上线前，builder 录制功能演示和测试通过视频，创始人必须亲自观看并说「ship it」才能合并。[^e59433309b48f106]
- Before each feature ships, the builder records a demo and test-passing video, and the founder must personally watch it and say "ship it" before merging.[^e59433309b48f106]
- 招聘不做预筛和视频聊天，候选人交约 45 分钟全屏录屏（在已维护应用上做一个功能），由排名 agent 排序，前五名做 16 小时有偿真实 PR 并签 NDA，最后才打电话。[^e59433309b48f106]
- Hiring has no pre-screening or video chats; candidates submit about 45-minute full-screen recordings of building a feature on an app they maintain, a ranking agent sorts them, the top five do a 16-hour paid real PR under NDA, and only then is a phone call made.[^e59433309b48f106]
