# 宝玉：Manus 客户端半透明，技术无护城河，品牌信任才是用户选择关键

*Bao Yu: Manus Client Is Semi-Transparent, Technology Has No Moat, Brand Trust Is Key to User Choice*

「帖文称」Manus 的客户端对于专业人士基本上是半透明的，里面的提示词、skills、harness 的逻辑都可以分析出来；现在有 AI 价值，技术已经没啥护城河了。就算克隆一个 Manus 也没啥意义，多半用户也不会选克隆版。用户选产品的重要因素是对品牌的信任，不知名第三方做的产品用之前就要打问号。跟在别人后面克隆没有前途，永远慢半拍，不能理解产品决策背后的原因，终究走不远。文中另一条回复（DinoDeer）还提到，Manus 允许用户使用自定义 LLM API，客户端用 Electron 封装，破解难度极小，可通过自定义 API 拿到后端逻辑、通过客户端拿到前端逻辑，Manus 肯定懂这一点，代码层面防护基本不 care。[^73e47c35ea17aaab]

The post states that Manus's client is basically semi-transparent for professionals, with prompts, skills, and harness logic analyzable; AI has value but technology has no moat anymore, and cloning Manus is meaningless because most users won't choose a clone. An important factor in users choosing a product is trust in the brand; an unknown third-party product makes users hesitate before using it. Cloning behind others has no future, is always half a step behind, cannot understand the reasons behind product decisions, and will ultimately not go far. Another reply (DinoDeer) also notes that Manus allows custom LLM APIs and its client is Electron-wrapped, making cracking extremely easy; backend logic can be obtained via custom API and frontend logic via the client, and Manus surely knows this, so code-level protection is basically not a concern.[^73e47c35ea17aaab]
