# Chrome 联合 Firefox、Edge 发布 Modern Web Guidance 为 AI Agent 补齐 Web 平台知识

*Chrome Joins Firefox and Edge to Launch Modern Web Guidance for AI Agents*

帖文称，Chrome 联合 Firefox、Edge 等发布了 Modern Web Guidance Skill，可通过 `npx modern-web-guidance@latest install` 安装，旨在为 AI Agent 补齐 Web 平台专业知识，避免生成的内容都是垃圾；ChromiumDev 表示该项目发布 1.0 后 48 小时登顶 GitHub 趋势榜第一，感谢 Firefox、MDN、Edge 及社区贡献者推动 AI 编程 Agent 使用现代、可访问的 Web 技术。[^dingyi-modern-web-guidance]

The post says Chrome, together with Firefox, Edge and others, released the Modern Web Guidance Skill installable via `npx modern-web-guidance@latest install`, intended to equip AI agents with web platform expertise so they stop generating low-quality output; ChromiumDev added that the project hit #1 on GitHub trending 48 hours after launching 1.0, thanking Firefox, MDN, Edge and community contributors for moving AI coding agents toward modern, accessible web practices.[^dingyi-modern-web-guidance]
