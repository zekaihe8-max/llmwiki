# 大规模软件迁移在可验证结果时可行

*Large-scale software migration is viable when results can be verified*

「帖文称」大规模软件迁移现在可行，前提是能够验证结果，这一点对运行关键基础设施的老旧软件系统尤为重要。Amjad Masad 引用 Anthropic 的案例：该公司将 Messages API 从 Python 迁移到 Rust，利用现有服务验证新服务，并由 Claude Agent 团队追踪并修复两个版本之间的差异。[^amasad-large-scale-migration-verification]

The post states that large-scale software migration is now viable provided results can be verified, which is exceptionally important for aging software systems running critical infrastructure. Amjad Masad cites Anthropic's migration of its Messages API from Python to Rust, using the existing service to verify the new one, with teams of Claude agents tracking down and fixing differences between the two versions.[^amasad-large-scale-migration-verification]
