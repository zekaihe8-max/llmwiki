# OpenAI 发布 Images 2.6：支持 SVG 导出与 GIF 动图，出图快一半

*OpenAI Releases Images 2.6 with SVG Export, GIF Support, and 50% Faster Generation*

「帖文称」OpenAI 于 11 月 4 日发布图像模型 Images 2.6，ChatGPT 和 Codex 所有档位用户均可使用，并通过 API 向开发者开放。主要新增功能包括将生成图像导出为 SVG 矢量图、生成 GIF 动图，以及出图速度比上一代快 50%。API 提供侧重速度的 Flare 和侧重画质的 Sunburst 两个版本，定价与上一代 2.5 保持一致。[^openai-images-2-6-svg-gif-faster]

According to the post, OpenAI released image model Images 2.6 on November 4, available to all ChatGPT and Codex tiers and via API for developers. Key new features include exporting generated images as SVG vector graphics, generating GIF animations, and 50% faster image generation than the previous version. The API offers two variants: Flare, optimized for speed, and Sunburst, optimized for image quality, with pricing unchanged from version 2.5.[^openai-images-2-6-svg-gif-faster]

## 摘要 / Summary

- Images 2.6 能将生成图像导出为 SVG 矢量图，适用于网站、App 和印刷品，放大不失真且可在设计软件中单独编辑线条。 / Images 2.6 can export generated images as SVG vector graphics for websites, apps, and print, remaining sharp at any scale and editable line-by-line in design software.[^openai-images-2-6-svg-gif-faster]
- 模型支持生成 GIF 动图，用户可用一句话描述或上传照片、手绘草图制作，并可调整播放速度、逐帧查看和修改。 / The model supports GIF animation generation from text descriptions, photos, or hand-drawn sketches, with adjustable playback speed, frame-by-frame viewing, and editing.[^openai-images-2-6-svg-gif-faster]
- 出图速度比上一版快 50%，改图时能更准确地只修改指定区域。 / Image generation is 50% faster than the previous version, with more accurate targeted edits to specified regions.[^openai-images-2-6-svg-gif-faster]
- API 提供 Flare（侧重速度，低画质下最快约 6 秒出图）和 Sunburst（侧重画质，中高画质下细节更多、编辑后更不易走样）两个版本，定价与 2.5 相同。 / The API provides Flare (speed-focused, as fast as about 6 seconds at low quality) and Sunburst (quality-focused, more detail at medium/high quality and more consistent across edits), priced the same as version 2.5.[^openai-images-2-6-svg-gif-faster]
- OpenAI 表示全球用户每周在 ChatGPT、Codex 和 API 上生成 40 亿张图，平均每天超过 5 亿张；Figma Weave 和 Picsart 等工具已提前接入。 / OpenAI says users generate 4 billion images weekly across ChatGPT, Codex, and API, averaging over 500 million per day; tools including Figma Weave and Picsart have integrated early.[^openai-images-2-6-svg-gif-faster]
