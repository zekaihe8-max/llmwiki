# 郭宇发布 Yobiru Friends：Bot 互聊与对外分享

*Turingou launches Yobiru Friends—bot-to-bot chat and public sharing*

[@turingou](https://x.com/turingou)（郭宇）正式发布 Yobiru 新功能 Yobiru Friends：可让他的 Grok bot 与啵啵的 Grok bot 直接聊天、发送文件、协商日程；也支持把任意 personal agent（如 Grok bot 或 Muse）对外发布或分享给亲朋好友。任何人可用自己的 Grok bot 或其他 personal agent，按 [yobiru.com/zh-cn/install.md](https://yobiru.com/zh-cn/install.md) 官方说明在本机安装并配置 Yobiru、注册 Yobiru Friends，在中心网关取得专有 ID 与网页链接；作者 ID 为 `guoyu`，页面为 [bots.yobiru.com/@guoyu](https://bots.yobiru.com/@guoyu)。关系分单向关注与好友：单向关注时可让 Grok bot 整理未关注人私信、设自动回复、维护粉丝关系并保护隐私；互相关注则自动成好友，私信直接进入对方 Grok bot、无需人工批准。Grok bot Mac 版还可支持 webhook 唤醒任务与对话；也可用 agent 改 Friends 个人主页（头像、社交链接、权限等）。项目与 Yobiru 一样开源，可自建网关并开箱使用双向加密聊天；作者称这是数字孪生领域的实践，并欢迎提交代码。官网 [yobiru.com](https://yobiru.com/)，GitHub [github.com/chekusu/yobiru](https://github.com/chekusu/yobiru)。[^turingou-yobiru-friends] 原帖见 <https://x.com/turingou/status/2114175110416675209>。

[@turingou](https://x.com/turingou) formally launches Yobiru Friends: his Grok bot and 啵啵’s Grok bot can chat directly, send files, and negotiate schedules; any personal agent (e.g. Grok bot or Muse) can be published or shared with friends and family. Anyone can have their Grok bot or other personal agent follow the official steps at [yobiru.com/zh-cn/install.md](https://yobiru.com/zh-cn/install.md) to install and configure Yobiru on that machine and register Yobiru Friends, getting a dedicated ID and page on the central gateway; the author’s ID is `guoyu` at [bots.yobiru.com/@guoyu](https://bots.yobiru.com/@guoyu). Relations split into one-way follow and friends: with one-way follow, a Grok bot can organize DMs from non-followed people, set auto-replies, maintain follower relations, and protect privacy; mutual follow becomes friendship, and DMs go straight into the other party’s Grok bot without human approval. The Grok bot Mac build can also support webhook wake-ups for tasks and conversations; agents can edit the Friends profile (avatar, social links, permissions, and so on). Like Yobiru, the project is open source—you can self-host a gateway and get out-of-the-box bidirectional encrypted chat; the author frames it as a digital-twin practice and welcomes code contributions. Site: [yobiru.com](https://yobiru.com/); GitHub: [github.com/chekusu/yobiru](https://github.com/chekusu/yobiru).[^turingou-yobiru-friends] Post: <https://x.com/turingou/status/2114175110416675209>.
