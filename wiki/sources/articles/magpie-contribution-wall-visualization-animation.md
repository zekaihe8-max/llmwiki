# Magpie 贡献墙可视化动画

*Magpie Contribution Wall Visualization Animation*

帖文称，yetone 给 Magpie 的贡献墙加了一个可视化动画，用来回顾历史、展望未来，原帖还附带一段视频。被引用的另一条帖文称，Magpie 不仅把 GitHub issue 的提出者列为 co-author，用户在 Twitter 或 Discord 里提出的任何 bug 反馈或新功能建议，在实现完毕并发版后都会被作为 co-author，且 Magpie 官网设有贡献墙。[^magpie-contribution-wall-animation]

According to the post, yetone added a visualization animation to Magpie's contribution wall to review the past and look ahead, with a video attached. A quoted post states that Magpie credits not only GitHub issue proposers but any user who reports a bug or suggests a feature on Twitter or Discord as a co-author once it ships, and that Magpie's website hosts a contribution wall.[^magpie-contribution-wall-animation]
