# DeepSeek Harness 能直接操作电脑了

*DeepSeek Harness Can Now Directly Operate Computers*

「帖文称」DeepSeek Harness（DSH）已将 Computer Use 做成实验性插件并随 DSH 一起提供，macOS 用户可在“插件 → 更多 → 实验性插件”中开启，授予系统权限后让 Agent 观察桌面、操作应用程序，不再局限于终端和代码工具；Windows 版本仍在开发中。同期 0.2.2 系列更新还包括 SubAgent 具名与多层级协作、AgentTeam 会话内开启、Git Worktree 代码审查完善、DeepSeek 历史会话导入，以及插件稳定性和 Windows 桌面版更新异常的修复。[^deepseek-harness-computer-use]

The post says DeepSeek Harness (DSH) has made Computer Use an experimental plugin bundled with DSH; macOS users can enable it via Plugins → More → Experimental plugins, and after granting system permissions the Agent can observe the desktop and operate applications instead of being limited to terminals and code tools. The Windows version is still under development. The 0.2.2 series also adds named and multi-level SubAgent collaboration, in-session AgentTeam, improved Git Worktree code review, import of DeepSeek App/web history sessions, and fixes for plugin stability and Windows desktop update exceptions.[^deepseek-harness-computer-use]
