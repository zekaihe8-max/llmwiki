# Flask 作者自查一年 AI Agent 会话：每天 120–190 条 prompt，141 个仓库只维护 10–15 个

*Flask Author Self-Audits One Year of AI Agent Sessions: 120–190 Daily Prompts, 141 Repos but Only 10–15 Maintained*

帖文称，Flask 作者 Armin Ronacher 在 AIE CODE 2026 上自查一年 Pi 编码 agent 会话数据：每天发出 120–190 条 prompt 基本不变，agent 工作时长从数小时增至 11 月初的 43.7 小时，新建 141 个 git 仓库但只持续维护 10–15 个，因此主张先建「软件工坊」而非急于建「软件工厂」。[^armin-ronacher-software-atelier]

The post says Flask author Armin Ronacher self-audited one year of Pi coding agent sessions at AIE CODE 2026: daily prompts stayed at 120–190, agent work time rose to 43.7 hours in early November, he created 141 git repositories but actively maintained only 10–15, so he argues to build a software atelier before a software factory.[^armin-ronacher-software-atelier]

## 摘要 / Summary

- 每天主动推出的 prompt 数在 120–190 条之间来回，一年内基本没涨。[^armin-ronacher-software-atelier]
- Daily prompts sent stayed between 120 and 190, basically unchanged over the year.[^armin-ronacher-software-atelier]
- Agent 替他干活的时间从 3 月的 6 小时涨到 11 月 1–9 日的 43.7 小时，并行 agent 分开计算。[^armin-ronacher-software-atelier]
- Agent work time for him rose from 6 hours in March to 43.7 hours on Nov 1–9, with parallel agents counted separately.[^armin-ronacher-software-atelier]
- 他新建了 141 个 git 仓库，每月投入超过 5 天并会回头维护的项目始终在 10–15 个以内。[^armin-ronacher-software-atelier]
- He created 141 new git repositories, but projects with over 5 days of commits per month and revisited stayed within 10–15.[^armin-ronacher-software-atelier]
- 每百条 prompt 的纠正次数从 GPT-5.3 Codex 的 8.5 降到 Opus 5.5 的 3.9，按 Esc 中断从 13.1 降到 7.2。[^armin-ronacher-software-atelier]
- Corrections per 100 prompts fell from 8.5 on GPT-5.3 Codex to 3.9 on Opus 5.5; Esc interruptions fell from 13.1 to 7.2.[^armin-ronacher-software-atelier]
- 单条 prompt 的 agent 工作 P90 从去年 12 月约 2.4 分钟升至最新模型的 14 分钟以上，工具调用从 19 次升至 44 次。[^armin-ronacher-software-atelier]
- P90 agent work minutes per prompt rose from about 2.4 minutes last December to over 14 minutes on the latest model, with tool calls rising from 19 to 44.[^armin-ronacher-software-atelier]
- 他主张先别急着建「软件工厂」，先把「工坊」建好，目标是做更有野心、质量更高的软件。[^armin-ronacher-software-atelier]
- He argues not to rush into a "software factory" but to first build the "atelier", aiming for more ambitious, higher-quality software.[^armin-ronacher-software-atelier]
