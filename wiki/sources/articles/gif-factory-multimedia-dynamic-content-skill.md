# GIF 工厂：多媒体动态内容制作 Skill

*GIF Factory: Multimedia Dynamic Content Skill*

「帖文称」GIF 工厂是一个可交给 Codex 安装的开源 Skill 仓库，用户提供图片、文字或需求后，即可生成表情包、光栅变画卡、动态海报、动态签名、电影片头、动态绘本或品牌短片等多种 GIF 动态内容。[^gif-factory-skill]

According to the post, GIF Factory is an open-source Skill repository installable via Codex; after users supply images, text, or requirements, it can generate stickers, lenticular cards, dynamic posters, dynamic signatures, cinematic titles, storybooks, and brand films.[^gif-factory-skill]

## 摘要 / Summary

- 仓库提供 GIF 工厂总入口与多个独立 Skill，可制作表情包、光栅变画卡、动态海报、动态签名、电影片头、动态绘本和品牌短片。[^gif-factory-skill]
- The repository provides a GIF Factory main entry and multiple independent Skills for making stickers, lenticular cards, dynamic posters, dynamic signatures, cinematic titles, storybooks, and brand films.[^gif-factory-skill]
- 表情包支持像素、插画、真人、宠物和粘土等风格，可实现点头、摇摆、挥手、行礼等动作。[^gif-factory-skill]
- Stickers support pixel, illustration, photo, pet, and clay styles with actions such as nodding, swaying, waving, and bowing.[^gif-factory-skill]
- 动态签名包含纯文字连笔、意象融字、乐器融字和墨迹聚合四种风格，并支持七种配色与多字体自定义。[^gif-factory-skill]
- Dynamic signatures include four styles—word-only, motif fusion, instrument fusion, and ink assembly—with seven color schemes and multi-font customization.[^gif-factory-skill]
- 电影片头提供 40 种字形风格和五种排版方式，可使用用户提供的场景图、片名和字稿。[^gif-factory-skill]
- Cinematic titles offer 40 character styles and five layout options, accepting user-provided scene images, titles, and manuscripts.[^gif-factory-skill]
- 制作脚本与 Skill 文档采用 MIT 许可，但角色 IP、参考设计语言、第三方字体和配乐按各自许可使用。[^gif-factory-skill]
- Open-source scripts and Skill docs are MIT-licensed, while character IP, reference design language, third-party fonts, and music follow their own licenses.[^gif-factory-skill]
