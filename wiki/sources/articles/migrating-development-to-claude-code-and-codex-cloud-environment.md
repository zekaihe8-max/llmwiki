# 把开发迁到 Claude Code 和 Codex 云环境，个人计算设备沦为终端

*Migrating Development to Claude Code and Codex Cloud Environments, Personal Computing Devices Become Terminals*

帖文称，作者下午集中审查了 Claude Code 和 Codex 自带的云环境，发现这些机器比想象中强大，遂将公司东京开发服务器的一系列工作流平滑迁移到云电脑兼容配置；未来计划把东京服务器仅保留为构建和部署服务器，并将 Mac mini 与 Mac Studio 全部改为 CI 电脑，所有开发工作迁至订阅套餐提供的云电脑。[^turingou-claude-codex-cloud-migration]

The post says the author spent the afternoon reviewing Claude Code and Codex built-in cloud environments, found them more powerful than expected, and smoothly migrated a series of workflows from the company's Tokyo development server to a cloud-computer-compatible configuration; going forward, the Tokyo server will be kept only as a build and deploy server, while all Mac mini and Mac Studio units will be repurposed as CI computers and all development work moved to cloud computers provided by subscription plans.[^turingou-claude-codex-cloud-migration]
