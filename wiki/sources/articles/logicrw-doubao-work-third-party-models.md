# 思维怪怪谈豆包工作向企业开放第三方大模型

*Logicrw on Doubao Work opening third-party models to enterprises*

[@0xLogicrw](https://x.com/0xLogicrw)（思维怪怪）转述：**豆包工作**宣布向企业客户开放第三方大模型服务，首批接入月之暗面 **Kimi K3.1 Pro**、智谱 **GLM-5.3**、**DeepSeek V4.1 Flash** 等模型；企业用户可在豆包工作的对话界面中直接切换模型，不再局限于字节自家的豆包模型。[^logicrw-doubao-work-third-party-models] 原帖 <https://x.com/0xLogicrw/status/2115737151405232503>。

[@0xLogicrw](https://x.com/0xLogicrw) (Logicrw) relays that **Doubao Work** is opening third-party LLM services to enterprise customers, with a first batch including Moonshot **Kimi K3.1 Pro**, Zhipu **GLM-5.3**, **DeepSeek V4.1 Flash**, and other models; enterprise users can switch models directly in Doubao Work’s chat UI instead of being limited to ByteDance’s own Doubao models.[^logicrw-doubao-work-third-party-models] Post: <https://x.com/0xLogicrw/status/2115737151405232503>.

## 摘要 / Summary

- **产品动作**：向**企业客户**开放第三方大模型服务；首批点名 **Kimi K3.1 Pro**、**GLM-5.3**、**DeepSeek V4.1 Flash** 等，在对话 UI **内置模型选择**中切换。[^logicrw-doubao-work-third-party-models]
- **Product move**: third-party LLM services for **enterprise customers**; first batch names **Kimi K3.1 Pro**, **GLM-5.3**, **DeepSeek V4.1 Flash**, and peers, switched via a **built-in model picker** in chat.[^logicrw-doubao-work-third-party-models]
- **与旧能力关系**：豆包工作此前已支持用户**自行接入**第三方模型；本次是把第三方模型**直接放进产品内模型菜单**，降低切换与使用门槛。[^logicrw-doubao-work-third-party-models]
- **Versus prior capability**: Doubao Work already let users **self-connect** third-party models; this change puts third-party models **in the in-product model menu**, lowering switching and usage friction.[^logicrw-doubao-work-third-party-models]
- **战略读法（帖文）**：字节正把豆包工作从「自家模型的应用」推向能承载**多家模型**的企业 **AI 工作入口**。[^logicrw-doubao-work-third-party-models]
- **Strategic read (post)**: ByteDance is reframing Doubao Work from an app for its **own models** toward an enterprise **AI work entry** that can host **multiple vendors**.[^logicrw-doubao-work-third-party-models]
- 抓取正文**未**写企业定价、额度、是否仍默认豆包、第三方接入的合规/数据路由或完整模型清单。[^logicrw-doubao-work-third-party-models]
- The fetched body does **not** state enterprise pricing, quotas, whether Doubao stays default, compliance/data routing for third parties, or a full model list.[^logicrw-doubao-work-third-party-models]
