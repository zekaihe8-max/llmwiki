# 郭宇改用 Drop Line 做语音输入

*Turingou switches to Drop Line for voice input*

[@turingou](https://x.com/turingou)（郭宇）称最近很多语音输入没有用 Typeless，而是换用 Fish Audio 做的小产品 Drop Line：语音识别速度很快、也很准确；唯一缺点是不像 Typeless 能整理得比较像正经文书——因为文书体在 Web Coding 时 Agent 更容易理解，而 Drop Line 识别出来的更像个人口头语言的转述。[^turingou-drop-line-voice-input] 原帖见 <https://x.com/turingou/status/2115389980780708302>。

[@turingou](https://x.com/turingou) says that lately he often skips Typeless for voice input and uses Drop Line, a small Fish Audio product: recognition is really fast and accurate; the only downside is that unlike Typeless it does not polish the text into something more like a proper document—because document-like wording is easier for Agents to understand when Web Coding, while Drop Line’s output is more like a personal oral-language transcript.[^turingou-drop-line-voice-input] Post: <https://x.com/turingou/status/2115389980780708302>.

## 摘要 / Summary

- 产品切换：从 Typeless 换到 Fish Audio 的 Drop Line 做语音输入。[^turingou-drop-line-voice-input]
- Product switch: from Typeless to Fish Audio’s Drop Line for voice input.[^turingou-drop-line-voice-input]
- 优点：识别速度快、准确。[^turingou-drop-line-voice-input]
- Strength: recognition is fast and accurate.[^turingou-drop-line-voice-input]
- 缺点与后果：不如 Typeless 整理成正经文书；文书体更利于 Web Coding 时 Agent 理解，口头转述更难。[^turingou-drop-line-voice-input]
- Downside and effect: does not polish into formal document prose like Typeless; document-like text helps Agents understand during Web Coding, oral transcript less so.[^turingou-drop-line-voice-input]
