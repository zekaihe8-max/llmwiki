# Anthropic 为 Claude Code 加限制：禁复刻现有游戏，仅允原创与借鉴玩法

*Anthropic Adds Restrictions to Claude Code: Bans Game Cloning, Allows Original Games and Gameplay Borrowing*

帖文称 Anthropic 近期在 Claude Code 的 Opus 5.5 版本提示词中加入两句新限制：允许开发原创游戏、借鉴现有玩法，但禁止直接复刻某款具体游戏，即便改名或声称原创也不例外。Anthropic 工程师 Addy Osmani 确认此举旨在防止利用 Claude 侵犯知识产权。独立开发者此前深受 AI 复刻之苦，如 Freya Holmér 的旋转版俄罗斯方块未发布即现大量仿制品，Digital Sun 甚至取消公开试玩。但美国版权法下玩法规则通常不受保护，仅美术、代码等表达受保护，Claude 靠提示词限制难以精准区分合法借鉴与侵权复制。有用户测试发现，相同代码让 Claude「重写」可继续，「复刻」则被拒。[^anthropic-claude-code-game-clone-ban]

Anthropic recently added two sentences to Claude Code Opus 5.5's prompt: original games and genre borrowing are allowed, but direct recreation of specific games is banned—even if renamed or claimed as original. Engineer Addy Osmani confirmed this aims to prevent IP infringement via Claude. Indie developers have long suffered from AI cloning (e.g., Freya Holmér's rotating Tetris cloned pre-launch; Digital Sun canceled a public playtest). However, U.S. copyright law protects expression (art, code) not mechanics, so prompt-based guardrails may not cleanly separate legal borrowing from infringement. Users found "rewrite" passes while "recreate" gets refused.[^anthropic-claude-code-game-clone-ban]
