# 多 Agent 编排写代码多半是浪费 Token

*Multi-Agent Orchestration for Coding Is Mostly Wasted Tokens*

帖文称，大多数项目里用多 Agent 编排写代码，很多时候只是浪费 Token；好的模型根本不需要这种微管理，一口气就能给出满意结果。作者还直言，拆出几个任务、开几个 worktree 看似并行，实际上只是占用电脑空间、浪费 Token，满足的是自己的管理欲望。他表示自己现在只在创建项目时并行，修 bug、加特性都不再并行，但估计大型项目能从中受益。[^multiagent-orchestration-token-waste]

The post claims that in most projects, using multi-agent orchestration to write code often just wastes tokens, since good models need no such micromanagement and produce satisfactory results in one go. The author bluntly adds that splitting out tasks and opening several worktrees only feels parallel while actually taking up computer space and wasting tokens, satisfying one's own desire to manage. He says he now parallelizes only when creating a project, not when fixing bugs or adding features, though large projects probably benefit.[^multiagent-orchestration-token-waste]
