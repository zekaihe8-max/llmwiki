# Aaron Levie 谈网防 Agent Swarm 将成为大品类

*Aaron Levie on agent swarms for cyber defense as a major category*

[@levie](https://x.com/levie) 认为，用于网络防御的 agent swarm 即将成为 AI 最大品类之一：智能体将审阅代码与基建、测试每一种风险组合、处理海量数据；安全特别适合 swarm，因为「投入更多算力就带来更多价值」，且有大量测试人类永远做不完——或至少做不够快——而智能体可以去做。[^levie-agent-swarms-cyber-defense] 原帖见 <https://x.com/levie/status/2113738768645808277>。

[@levie](https://x.com/levie) argues that agent swarms for cyber defense are about to be one of the biggest categories in AI: agents will review code and infra, test every permutation of risk, and process gobs of data; security is one of the best swarm use-cases because more compute in equals more value out, and there is a wide range of testing people never get around to—or at least not quickly enough—that agents can go after.[^levie-agent-swarms-cyber-defense] Post: <https://x.com/levie/status/2113738768645808277>.

- 网防 agent swarm 被框成即将到来的 AI 大品类，工作包括审代码与基建、穷举风险测试与处理大量数据。[^levie-agent-swarms-cyber-defense]
- Agent swarms for cyber defense are framed as an imminent major AI category, covering code/infra review, exhaustive risk testing, and processing large volumes of data.[^levie-agent-swarms-cyber-defense]
