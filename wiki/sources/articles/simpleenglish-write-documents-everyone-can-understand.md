# 把文档写成谁都读得懂的英文

*SimpleEnglish: Write Documents Everyone Can Understand*

「帖文称」SimpleEnglish 是由 AminBlg 开源、MIT 许可、GitHub 获得 4.7K 星的工具，其规则源自航空维修领域使用四十多年的受控语言标准，默认用平实英文重写内容：句子更短、主动语态、简单时态，一个词只表达一个意思，术语第一次出现就解释清楚，适用于说明文档、操作手册、错误提示、发布说明、事故报告及面向非母语读者的技术材料；明确要求严格合规时会切换到完整词表校验。[^simpleenglish]

The post introduces SimpleEnglish, an MIT-licensed open-source tool by AminBlg with 4.7K GitHub stars, whose rules come from a controlled-language standard used in aircraft maintenance for over 40 years. Default mode rewrites content into plain English: shorter sentences, active voice, simple tenses, one meaning per word, and terms explained at first use. It suits documentation, manuals, error messages, release notes, incident reports, and technical materials for non-native readers; strict compliance triggers full word-list validation.[^simpleenglish]
