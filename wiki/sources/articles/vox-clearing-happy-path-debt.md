# Vox · 清理理想路径债

*Vox · Clearing Happy-Path Debt*

「帖文称」Claude Code 与 Codex 容易只在一切顺利时编写代码，忽略加载缓慢、请求失败、列表为空、文本过长或屏幕狭窄等真实场景。Vox 建议查找 App 中的“幸福路径债务”，逐组件修复缺失状态与布局断裂，不改动设计、不破坏现有功能，并按文件总结前后变化。智能体常为演示构建，实际使用远非如此。[^voxyz-happy-path-debt]

The post says Claude Code and Codex tend to write code only when everything goes right, ignoring real scenarios such as slow loading, failures, empty lists, long text, and narrow screens. Vox suggests finding "happy-path debt" in apps, fixing missing states and layout breaks one component at a time without changing the design or breaking anything, and summarizing changes by file. Agents often build for the demo, but real use is different.[^voxyz-happy-path-debt]
