# OpenAI 宣布下一轮内部安全冲刺，提升漏洞赏金并与 Cathedral Systems 合作

*OpenAI Announces Next Security Sprint, Raises Bug Bounties, Partners with Cathedral Systems*

The post says OpenAI is planning its next internal security sprint and partnering with Cathedral Systems, whose researchers will use OpenAI models alongside OpenAI teams to challenge defenses and find and fix weaknesses with AI.
