# Pi 开始自己做手机端了

*Pi starts building its own mobile client*

「帖文称」Pi 官方已撤掉旧版 Pi Mobile APK 构建流程，提交备注直接指向新的 apps/p2；作者 Mario 在访谈中表示自己在手机上高频使用 PIM，下一阶段将是多台机器、多个 Agent 一起协同。文章认为极简 TUI 是 Pi 获得 11 万 Star 的原因，但纯黑框也是增长天花板，官方迟早需要自己立移动端标准，以让非工程师也能在手机和电脑之间无缝切换。[^pi-mobile-official-client]

The post claims Pi has removed the old Pi Mobile APK build process, with commit notes pointing to the new apps/p2 repository; author Mario said in an interview that he frequently uses PIM on mobile, and the next phase will involve multiple machines and multiple Agents collaborating. The article argues that the minimal TUI helped Pi gain 110k stars, but the pure black-box interface is also a growth ceiling, and the official side eventually needs to set a mobile standard so non-engineers can switch seamlessly between phone and computer.[^pi-mobile-official-client]
