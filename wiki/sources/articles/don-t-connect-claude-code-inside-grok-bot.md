# 别在 Grok Bot 里接 Claude Code

*Don't Connect Claude Code Inside Grok Bot*

帖文称，不要在 Grok Bot 里面去接入 Claude Code，因为 Grok bot 的 IP 不稳定，除非自己搞个家宽接在 Grok bot 上面。帖文称，这样做和自己在本地使用没有区别，体验可能还比放在 Grokbot 上面更好；之前能用是因为 Grok bot IP 稳定在美国，现在 IP 会乱飘，所以不建议这么用。[^dont-connect-claude-code-in-grok-bot]

The post warns not to connect Claude Code inside Grok Bot because Grok bot's IP is unstable, unless you set up home broadband to connect to Grok bot yourself. The post claims this is no different from local use and may offer a better experience than on Grokbot; it previously worked because Grok bot's IP was stable in the US, but now the IP "flies around," so it is not recommended.[^dont-connect-claude-code-in-grok-bot]
