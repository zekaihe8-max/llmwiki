# Snug 项目：开源免费的 Mac 远程伴侣，解决手机虚拟屏适配痛点

*Snug Project: Open-source free Mac remote companion solving phone virtual screen adaptation pain points*

「帖文称」铁锤人在 X 上介绍，@zephyrxiang12 在 UU 远程伴侣基础上又做了 Snug 项目，并开源免费。该工具面向在折叠屏手机上远程控制 Mac 的场景，主打三个改进：为手机增加专属竖屏并让 Mac 窗口按手机尺寸铺满、通过类启动器的应用资源库把应用送到虚拟屏、按机型计算比例并内置 800 款机型以避免黑边。[^snug-mac-remote-companion]

The post says @lxfater introduced on X that @zephyrxiang12 built the Snug project on top of UU Remote Companion, open-sourced and free. Targeting remote Mac control from foldable phones, it offers three improvements: a dedicated vertical screen with Mac windows scaled to phone size, a launcher-like app resource library to send apps to the virtual screen, and per-model ratios with 800+ built-in device models to avoid black bars.[^snug-mac-remote-companion]
