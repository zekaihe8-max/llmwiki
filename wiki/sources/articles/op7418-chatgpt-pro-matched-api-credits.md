# 歸藏谈 OpenAI 学 Claude 送会员同额 API

*歸藏 on OpenAI matching Claude with tier-matched API credits*

[@op7418](https://x.com/op7418)（歸藏）在同串引用 [@OpenAIDevs](https://x.com/OpenAIDevs) 英文帖：自当日起，符合条件的 **ChatGPT Pro** 与 **Business** 订阅者可领取最高 **每月 500 美元** API 额度，用于构建应用与 Agent。[^op7418-chatgpt-pro-matched-api-credits] 原帖 <https://x.com/op7418/status/2115646335458349480>。

[@op7418](https://x.com/op7418) (歸藏) quotes [@OpenAIDevs](https://x.com/OpenAIDevs) in the same thread: starting that day, eligible **ChatGPT Pro** and **Business** subscribers can claim up to **$500 per month** in API credits to build apps and agents.[^op7418-chatgpt-pro-matched-api-credits] Post: <https://x.com/op7418/status/2115646335458349480>.

歸藏中文评论称 OpenAI 也学 Claude，开始给**每个档级的会员**送 API 额度，且**与订阅费一样**——例如 **$200 的 Pro 就送 $200 API 额度**。但他发现自己的设置页面**没有领取按钮**，并称评论区有类似问题的人「还不在少数」。他补充领取位置在网页 **ChatGPT 设置 → 账单** 页面。[^op7418-chatgpt-pro-matched-api-credits]

In Chinese, 歸藏 says OpenAI is also following Claude by gifting API credits to **each membership tier**, **matching the subscription fee**—for example **$200 Pro gets $200 in API credits**. But his settings page **has no claim button**, and he says commenters with the same issue are “not a small number.” He adds the claim location is **ChatGPT Settings → Billing** on the web.[^op7418-chatgpt-pro-matched-api-credits]
