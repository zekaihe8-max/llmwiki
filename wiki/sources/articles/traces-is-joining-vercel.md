# Traces 加入 Vercel

*Traces Is Joining Vercel*

「帖文称」Traces 正在加入 Vercel，全团队将继续探索团队如何与智能体协作构建软件；对现有用户而言，首日无任何变化，仍可在 Traces 上分享会话并使用 Traces CLI。[^a53db54b49dc2250]

The post states that Traces is joining Vercel, and the entire team will continue working on how teams build software with agents. For existing users, nothing changes on day one, and they can continue sharing sessions on Traces and using the Traces CLI.[^a53db54b49dc2250]

## 摘要 / Summary

- Traces 于二月启动，最初是一个跨不同智能体分享工作的简单方式。[^a53db54b49dc2250]
- Traces started in February as a simple way to share work across different agents.[^a53db54b49dc2250]
- 过去九个月，Traces 发布了团队版、16 款编程智能体适配器、Git 集成、Handoffs、Traces MCP 和 Surfaces 等功能。[^a53db54b49dc2250]
- In the last nine months, Traces shipped Traces for Teams, adapters for 16 coding agents, Git integrations, Handoffs, Traces MCP, Surfaces, and more.[^a53db54b49dc2250]
- 数千支团队加入 Traces，共享了近 50 万个会话。[^a53db54b49dc2250]
- Thousands of teams have joined Traces and shared nearly 500,000 sessions.[^a53db54b49dc2250]
- 作为过渡的一部分，Traces 已暂停新组织创建，但现有用户仍可发布会话、使用 Traces 并向组织添加用户。[^a53db54b49dc2250]
- As part of the transition, new org creation has been paused, but existing users can continue publishing and using Traces and adding users to their existing orgs.[^a53db54b49dc2250]
- 支持渠道将保持开放，团队承诺审慎处理用户数据。[^a53db54b49dc2250]
- Support channels will remain open, and the team remains committed to handling user data thoughtfully.[^a53db54b49dc2250]
