# 自己下手做一层 Agent 调度

*DIY Agent Scheduling Layer Based on CLIs*

帖文称，@Khazix0918 烦了 Claude、Codex、Antigravity 几家桌面端来回切换，体验二十多个 Agent 调度产品后觉得用户体验太极客、繁琐，界面信息巨大、认知成本过大，遂决定基于各家 CLI 手搓一层 Agent 调度产品。两天内已实现将基于 ACP 协议的 Antigravity 调成类似 Claude、Codex 的流式对话交互感，并可统一管理 skill 与规则文档，称做到自己喜欢和满意的那一天会开源。[^self-built-agent-scheduling-layer]

The post says @Khazix0918, tired of switching among Claude, Codex, and Antigravity desktop clients and dissatisfied with over twenty Agent scheduling products for being too geeky and cognitively heavy, decided to build a DIY Agent scheduling layer on top of various CLIs. Within two days, they made ACP-protocol Antigravity stream like Claude/Codex during tasks and unified skill and rule document management, with plans to open-source once satisfied.[^self-built-agent-scheduling-layer]
