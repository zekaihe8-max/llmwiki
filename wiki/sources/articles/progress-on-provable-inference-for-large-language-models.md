# 大语言模型可证明推理的进展

*Progress on provable inference for large language models*

「帖文称」Anthropic 的 Frontier Red Team 发布 FlashProve，这是一个用于大语言模型可证明推理的开源原型系统，通过 zkSNARK 让模型提供商承诺特定模型并证明每条响应由该模型生成，同时不泄露模型权重。[^43862ef771dfba65]

Anthropic's Frontier Red Team releases FlashProve, an open-source prototype for provable inference of large language models, using zkSNARKs to let providers commit to a model and prove each response came from it without revealing model weights.[^43862ef771dfba65]

## 摘要 / Summary

- 「帖文称」FlashProve 在单块 H100 GPU 上为 400B 参数混合专家模型（Llama 4 Maverick，4 位量化）生成证明的速度约为每秒 110 个 token，每 1024 个 token 请求的证明大小约为 19 MB。 / The post states that FlashProve generates proofs at around 110 tokens/second on a single H100 GPU for a 400B-parameter mixture-of-experts model (Llama 4 Maverick, 4-bit quantized), with a proof size of ~19 MB per 1,024-token request.[^43862ef771dfba65]
- 生成证明的 GPU 时间约为使用 vLLM 运行同长度模型本身的 70 到 95 倍。 / Proof generation takes about 70-95x the GPU time of running the model itself on vLLM for prompts of the same length.[^43862ef771dfba65]
- 系统基于 zkSNARK，承诺模型权重并生成推理证明；证明隐藏权重，但不以隐藏模型架构为目标。 / The system uses zkSNARKs to commit to model weights and produce inference proofs; the proofs hide the weights but do not aim to hide the model architecture.[^43862ef771dfba65]
- 发布物包括技术报告、协议规范、可执行代码（Prover、C++ 快速验证器和 Lean 可证明正确验证器）以及 Lean 形式化证明和交互式可视化器。 / Artifacts include a technical report, protocol specification, executable code (prover, C++ fast verifier, and Lean provably correct verifier), Lean formal proofs, and an interactive visualizer.[^43862ef771dfba65]
- 代码、Lean 证明和文档采用 Apache 2.0 许可证发布，旨在加速可证明推理的发展并展示零知识简洁论证对推理验证的实用性。 / Code, Lean proofs, and documentation are released under Apache 2.0, with the aim of accelerating provable inference development and demonstrating that zkSNARKs are practical for model inference verification.[^43862ef771dfba65]
