# baoyu-design 上 Motion：多人协作与可编辑动画

*baoyu-design Adds Motion with Multiplayer Collaboration and Editable Animation*

「帖文称」baoyu-design 新增了 Motion 功能，在 Claude Motion 基础上完善了多人协作和编辑器功能，用户无需等待整个视频渲染完成即可看到渲染过程，文字可随时编辑，并支持 Design System 与风格样式；该功能可运行在任意 Agent，包括 DeepSeek Harness 插件，但效果仍需配合擅长 Motion 的模型（如 Opus 5.5）与特定提示词或 skill。[^baoyu-design-motion]

The post says baoyu-design has added a Motion feature atop Claude Motion, improving multiplayer collaboration and the editor so users can see the rendering process from the start without waiting for full video rendering; text is editable anytime and supports Design System and style styles. It can run on any Agent, including the DeepSeek Harness plugin, but quality still depends on models skilled at Motion (e.g., Opus 5.5) and specific prompts or skills.[^baoyu-design-motion]
