# DeepSeek 联网工具重新免费

*DeepSeek Web Search Tools Free Again*

「帖文称」DeepSeek 调整 API 计费规则，11 月 1 日才开始收费的联网工具仅过约 17 天即重新免费；从 11 月 18 日起，模型自主调用的网页搜索、图片搜索和网页抓取不再按次收费，只收模型 Token 费用，覆盖 DeepSeek 自带联网工具、Claude Code 接入 DeepSeek 的网页搜索及 DeepSeek Harness 默认服务端搜索，但开发者直接调用独立 Search 和 Fetch API 仍需付费，每 1000 次成功请求 5 元。[^84a050d3938b8c0c]

The post says DeepSeek adjusted API pricing, making its web tools free again after charging for only about 17 days since Nov 1; from Nov 18, model-invoked web search, image search, and page scraping are no longer charged per call and only model token fees apply, covering DeepSeek's built-in web tools, Claude Code's web search via DeepSeek, and DeepSeek Harness default server-side search, while direct calls to standalone Search and Fetch APIs remain paid at 5 yuan per 1,000 successful requests.[^84a050d3938b8c0c]
