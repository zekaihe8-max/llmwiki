# 匿名模型 HungerG 前端对答案实测

*Anonymous Model HungerG Frontend Answer-Checking Test*

「帖文称」博主 huangserva 在 Qoder 与 OpenCode Go 上免费试用匿名模型 HungerG，将其与 Opus 5.5、GPT-6.2 Sol 分别跑同一份提示词的直流电机、唱片页、云上城堡三个前端任务，并称 HungerG 半小时交卷、无需“继续”，但微观细节不如 Opus、构图光影不如 Sol，模型到底属于哪家尚未确认。[^5911b583fecae6f0]

The post claims blogger huangserva tried anonymous model HungerG for free on Qoder and OpenCode Go, running it against Opus 5.5 and GPT-6.2 Sol on the same prompts for three frontend tasks—disassemblable DC motor, openable record page, and cloud castle—and says HungerG finished all three in half an hour without “continue,” but lacks Opus’s microscopic detail and Sol’s clean composition and lighting; the model’s provider remains unknown.[^5911b583fecae6f0]
