# 停车场应用 parkuma 一天做完，复用 harness 中台与 wanman 能力

*Parking app parkuma built in one day by reusing harness middle platform and wanman capabilities*

「帖文称」开发者郭宇表示，停车场应用 parkuma 仅用一天即完成开发，原因是此前已花大量时间构建 harness 中台，沙盒、云浏览器等细节也在 wanman 项目中处理过；另一条关联帖文则称，SandBank Agent 中台就绪后，该停车应用仅花 15 分钟制作，可解决日本投币停车场费用计算问题，并与多种个人助理联动。[^parkuma-one-day-harness-reuse]

The post claims developer Guoyu built the parking app parkuma in one day by reusing an existing Agent harness middle platform and prior wanman project capabilities such as sandbox and cloud browser; a related post says the SandBank Agent middle platform enabled a 15-minute build to help calculate Japanese coin parking fees and link with personal assistants.[^parkuma-one-day-harness-reuse]
