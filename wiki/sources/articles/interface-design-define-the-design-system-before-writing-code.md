# 先定设计系统再写代码的界面设计

*Interface Design: Define the Design System Before Writing Code*

「帖文称」先定配色、排版与间距，再写组件代码，做出有质感的界面；像建筑师先画图纸，把配色、字体、间距、圆角和层次关系组织成一套完整设计系统，再落到具体组件与页面，避开通用 AI 风格，让仪表盘、后台面板和网页应用有自己的辨识度。[^a4974c71127f9e4a]

The post argues that interface quality is decided before coding: define colors, typography, spacing, corner radius, and hierarchy as a design system first, then apply it to components and pages, avoiding generic AI looks and giving dashboards, admin panels, and web apps their own identity.[^a4974c71127f9e4a]
