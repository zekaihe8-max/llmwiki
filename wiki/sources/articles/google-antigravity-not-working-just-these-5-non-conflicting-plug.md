# 谷歌 Antigravity 不好用？只需这 5 个不打架的插件

*Google Antigravity Not Working? Just These 5 Non-Conflicting Plugins*

「帖文称」谷歌 Antigravity（AGY）不好用大概率是插件装乱了，筛掉功能重叠的扩展后只需保留 5 个不打架的插件，包括 agy-fast、Ponytail、agy-powertools、Paragravity 和 antigravity2-cn；日常写代码只需 agy-fast 加 agy-powertools 组合即可，且提醒 Mac 上打底层包补丁会触发重签名导致官方自动更新失效。[^antigravity-five-plugins]

The post claims that Google Antigravity (AGY) performs poorly likely because too many conflicting plugins are installed; after removing overlapping extensions, only five non-conflicting plugins are needed—agy-fast, Ponytail, agy-powertools, Paragravity, and antigravity2-cn—and daily coding requires only agy-fast plus agy-powertools. It also warns that patching on Mac triggers local re-signing, breaking official auto-updates.[^antigravity-five-plugins]

- agy-fast 把批量搜索、大纲提取、多文件修改和跑测试合并为 5 个本地 MCP 工具，项目实测少跑约 34% 轮次、省下约 31% 计费额度。[^antigravity-five-plugins]
- agy-fast merges batch search, outline extraction, multi-file edits, and test runs into five local MCP tools; project testing shows about 34% fewer rounds and roughly 31% less billed quota.[^antigravity-five-plugins]
- Ponytail 在 Claude Code 测试中使代码量减少 53%、Token 省 45%，目前 AGY CLI 能跑完整命令，桌面端当规则集挂载。[^antigravity-five-plugins]
- Ponytail reduced code volume by 53% and saved 45% tokens in Claude Code testing; it runs full commands in AGY CLI and mounts as a rule set on desktop.[^antigravity-five-plugins]
- agy-powertools 为 2.0 桌面端提供上下文占用、缓存命中率、吐字速度及 5 小时和每周限额看板，并包含会话分支、原位改消息重发与简体中文界面。[^antigravity-five-plugins]
- agy-powertools adds context usage, cache hit rate, token speed, and 5-hour/weekly quota dashboards to the 2.0 desktop client, plus session branching, inline edit resend, and Simplified Chinese UI.[^antigravity-five-plugins]
- Paragravity 利用官方原生数据目录沙箱让多个谷歌 Pro 账号独立窗口并排运行，但配置目录存有明文登录凭据，不应同步上云盘。[^antigravity-five-plugins]
