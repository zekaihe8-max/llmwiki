# Grok Bot 可继承其他 AI 记忆

*Grok Bot Can Inherit Memory from Other AI*

「帖文称」Grok Bot 终于可以继承其他 AI 的记忆，用户可在设置中找到导入入口，将此前在 Hermes Agent、OpenClaw 等个人 Agent 中积累的个人信息、偏好和工作习惯，经由 ChatGPT 或 Claude 整理后以文本形式导入 Grok Bot 主 Bot，无需重新聊天数百轮即可完成迁移，但并非直接同步数据库或聊天记录，导入前建议检查过期与敏感信息。[^grok-bot-memory-import]

The post claims Grok Bot can now inherit memory from other AI agents; users can access the import entry in Settings, have ChatGPT or Claude organize previously accumulated personal information, preferences, and work habits from Hermes Agent, OpenClaw, or similar personal agents, then import the text into Grok Bot's main bot via Add to Memory, avoiding hundreds of rounds of retraining, though it does not directly sync databases or chat history and users should review content for outdated or sensitive data before importing.[^grok-bot-memory-import]

## 摘要 / Summary

- 导入路径：电脑端 Settings → General → Import → Start Import；手机端 Settings → Import Memory，部分账号仍在逐步开放。[^grok-bot-memory-import]

- 操作流程：复制 Grok Bot 提供的提示词，交给 ChatGPT、Claude 等 AI 整理个人信息、长期偏好和工作习惯，再把整理好的内容复制回 Grok Bot 并点击 Add to Memory。[^grok-bot-memory-import]
- Workflow: copy the prompt provided by Grok Bot, give it to ChatGPT, Claude, or similar AI to organize personal information, long-term preferences, and work habits, then copy the organized content back to Grok Bot and click Add to Memory.[^grok-bot-memory-import]
- 适用对象：之前使用 Hermes Agent、OpenClaw 或其他开源 Personal Agent 的用户尤为适用，可基于已有记忆文件整理内容。[^grok-bot-memory-import]

- 导入方式：不是直接同步其他 Agent 的数据库和聊天记录，而是通过整理后的文本导入记忆，建议先检查内容，避免带入过期信息和敏感数据。[^grok-bot-memory-import]
