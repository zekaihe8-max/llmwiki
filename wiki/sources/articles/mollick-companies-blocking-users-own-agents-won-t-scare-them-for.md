# Mollick · 公司挡用户自己的 agent，吓不了太久

*Mollick · Companies blocking users' own agents won't scare them for long*

Ethan Mollick 在帖文称，公司若以安全为由阻止客户使用自己的 AI Agent 管理账户或电脑，只会让大量用户沮丧，而“吓唬”策略难以长期奏效。该帖引用 Mark Gurman 的报道：苹果正在开发自有计算机使用 Agent，并在 macOS 27.3 中将启用 ChatGPT 第三方计算机使用支持的步骤从四步增加至十四步；苹果引用安全理由，部分用户则将其视为反竞争行为。[^emollick-computer-use-agent-curb]

Ethan Mollick says in the post that companies frustrating customers by blocking their own AI agents from managing accounts or computers will find that scaring users works only for so long. Citing Mark Gurman, the post notes Apple is developing its own computer-use agent and, in macOS 27.3, raised the steps to enable ChatGPT’s third-party computer-use support from four to fourteen; Apple cites security, while some users see anti-competitiveness.[^emollick-computer-use-agent-curb]
