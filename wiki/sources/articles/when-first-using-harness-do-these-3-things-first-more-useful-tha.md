# 刚用 Harness，先做好这 3 件事，比装一堆插件更有用

*When First Using Harness, Do These 3 Things First—More Useful Than Installing a Bunch of Plugins*

「帖文称」刚开始使用 AI Harness 时，建议先做好三件事：配置 AGENTS.md（Claude Code 为 CLAUDE.md）项目规则、根据需求按需配置常用 Skills、以及养成先规划、再执行、最后验证的习惯，强调 AI 效果取决于给定资料的整理质量。[^xiaomovps-harness-first-three-things]

The post says that when first using an AI Harness, one should first configure project rules (AGENTS.md, or CLAUDE.md for Claude Code), set up commonly used Skills on demand, and build the habit of planning before executing and verifying afterward, stressing that AI results depend on how well the provided materials are organized.[^xiaomovps-harness-first-three-things]

## 摘要 / Summary

- 帖文推荐先配置 AGENTS.md 项目规则，记录项目结构、技术栈、开发规范等，Claude Code 主要使用 CLAUDE.md，不同 Harness 配置文件可能不同。[^xiaomovps-harness-first-three-things]
- The post recommends configuring AGENTS.md project rules first to record project structure, tech stack, and development norms; Claude Code mainly uses CLAUDE.md, and config file names may differ across Harnesses.[^xiaomovps-harness-first-three-things]
- 不建议新手一开始就安装一大堆 Skills，可先从浏览器操作、代码审查、文档处理等常用功能开始，后续按需扩展。[^xiaomovps-harness-first-three-things]
- The post advises against installing too many Skills at once for beginners; start with common functions such as browser operations, code review, and document processing, then expand as needed.[^xiaomovps-harness-first-three-things]
- 遇到复杂任务应先让 AI 分析需求、制定计划，再按步骤执行，最后让其运行测试并检查任务是否真正完成。[^xiaomovps-harness-first-three-things]
- For complex tasks, the post suggests letting AI analyze requirements and make a plan first, then execute step by step, and finally run tests and verify whether the task is truly complete.[^xiaomovps-harness-first-three-things]
- 帖文提到 AI 的能力取决于给定的资料，针对资料能反馈出多少内容取决于花了多少时间整理。[^xiaomovps-harness-first-three-things]
- The post states that AI capability depends on the materials provided, and how much it can feedback depends on how much time is spent organizing those materials.[^xiaomovps-harness-first-three-things]
- 帖文引用了 OpenAI 官方 AGENTS.md 配置指南、Agent Skills 官方入门文档和 Anthropic Claude Code 最佳实践作为推荐阅读。[^xiaomovps-harness-first-three-things]
