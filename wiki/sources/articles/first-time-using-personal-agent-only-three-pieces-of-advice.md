# 第一次用 Personal Agent，只给三个忠告

*First Time Using Personal Agent: Only Three Pieces of Advice*

「帖文称」小墨同学在 X 上发文总结，新手小白第一次接触 Personal Agent 时不应盲目安装大量 Skill、MCP 或插件，而应先学会使用其自带的浏览器操作、文件整理、搜索资料等基础功能；其次应把工作习惯、常用软件和常处理的事情告诉 Agent，并建立个人知识库，因为数据是 AI 工具的基础；最后应从每天检查邮件、整理日历、监控项目等简单自动化任务入手，让 Agent 定时检查并出现问题时通知用户。帖文强调，Personal Agent 本质只是 Agent 的另一种形式，只有能提升效率或解决现实问题才是其根本作用。[^personal-agent-first-time-three-advice]

The post says that Xiao Mo Xuesheng summarized on X that beginners first contacting Personal Agent should not blindly install many Skills, MCPs, or plugins, but should first learn to use built-in basic functions such as browser operation, file organization, and information search; second, they should tell the Agent their work habits, frequently used software, and common tasks, and build a personal knowledge base because data is the foundation of AI tools; finally, they should start with simple automation tasks such as daily email checking, calendar organization, and project monitoring, letting the Agent check on a schedule and notify when problems arise. The post emphasizes that Personal Agent is essentially just another form of Agent, and its fundamental role is to improve efficiency or solve real-world problems.[^personal-agent-first-time-three-advice]

- 第一个忠告：不要急着安装各种 Skill 和 MCP，建议先简单使用和学习，或根据官方教程实操，了解基本运行原理和使用方法。[^personal-agent-first-time-three-advice]
- First advice: Do not rush to install various Skills and MCPs; it is recommended to simply use and learn first, or practice according to official tutorials, to understand the basic operating principles and usage methods.[^personal-agent-first-time-three-advice]
- 第二个忠告：让 Agent 慢慢熟悉你，告诉它工作习惯、使用的软件和经常需要处理的事情，并建立自己的知识库，因为数据才是最重要的。[^personal-agent-first-time-three-advice]
- Second advice: Let the Agent slowly get to know you; tell it your work habits, software used, and frequently handled matters, and build your own knowledge base, because data is the most important.[^personal-agent-first-time-three-advice]
- 第三个忠告：先从简单的自动化任务开始，例如每天检查邮件、整理日历或监控项目，先让它定时检查，有问题再通知你。[^personal-agent-first-time-three-advice]
