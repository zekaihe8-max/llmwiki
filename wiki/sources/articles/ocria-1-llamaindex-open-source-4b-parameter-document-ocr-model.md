# OCRia-1：LlamaIndex 开源 4B 参数文档 OCR 模型

*OCRia-1: LlamaIndex Open-Source 4B-Parameter Document OCR Model*

帖文称，LlamaIndex 开源了 OCRia-1，一个 4B 参数的 OCR 模型，能把复杂文档还原为 Markdown，可本地部署，但不能任意商用。该模型支持单页文档图像，并可处理带合并单元格的复杂表格、需从坐标提取数据的图表、手写公式，以及删除线、下划线、复选框等特殊格式。模型权重在 Hugging Face 上发布。[^f35ca468372f7264]

The post says LlamaIndex has open-sourced OCRia-1, a 4B-parameter OCR model that restores complex documents to Markdown, supports local deployment but not arbitrary commercial use. It handles single-page document images, complex tables with merged cells, charts requiring coordinate-based data extraction, handwritten formulas, and special formats such as strikethrough, underlines, and checkboxes. Model weights are released on Hugging Face.[^f35ca468372f7264]
