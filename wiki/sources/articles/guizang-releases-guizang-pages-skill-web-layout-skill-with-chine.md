# 歸藏发布 guizang-pages-skill 网页排版 Skill，内置中文排版优化与 PDF 导出

*Guizang releases guizang-pages-skill web layout Skill with Chinese typography optimization and PDF export*

「帖文称」歸藏（guizang.ai）在 X 上发布内置于插件的网页排版 Skill guizang-pages-skill，可把图文、视频排成非常精美的网页，所有字体、字号、间距和细节都是为了阅读而设计，并专门针对中文排版做了很多优化；右下角可以自定义样式，也做了移动端优化，同时还可以导出 PDF，适合将自己写的内容和 AI 的内容分享给朋友们。同条推文还提到，已把几个设计 Skill 合并为 DSH 插件 dsh-guizang-design，共用一套设计系统和 Design Token，并加了几个有用的功能。[^guizang-pages-skill]

The post says Guizang (guizang.ai) released the guizang-pages-skill web layout Skill built into its plugin, arranging text, images, and video into beautiful web pages with fonts, sizes, spacing, and details designed for reading and heavily optimized for Chinese typography; styles are customizable in the bottom right, mobile optimization is included, and PDF export is supported for sharing personal and AI content with friends. The same post also says several design Skills have been merged into the DSH plugin dsh-guizang-design, sharing one design system and Design Tokens with added useful functions.[^guizang-pages-skill]
