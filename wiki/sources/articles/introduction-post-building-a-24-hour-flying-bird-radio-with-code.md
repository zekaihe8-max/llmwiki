# 介绍帖：用 Codex 与树莓派搭建 24 小时飞鸟电台

*Introduction post: Building a 24-hour Flying Bird Radio with Codex and Raspberry Pi*

帖文称，用户 Yuancheng 使用 Codex 配合树莓派，在上海建立了一座名为「飞鸟电台」的24小时自动听鸟鸣、识鸟种服务，并提供网址 aihh-bird.kojiyang.me 供鸟友访问；文中还感谢 BirdNET、Google Perch、BirdNET-Go 及 Cornell Birds 的 Birdsong 前端等开源社区资源。[^yuancheng-bird-radio-codex-raspberry-pi]
