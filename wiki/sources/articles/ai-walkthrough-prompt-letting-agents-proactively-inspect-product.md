# AI 走查提示词：让 Agent 主动审视产品页面与交互

*AI Walkthrough Prompt: Letting Agents Proactively Inspect Product Pages and Interactions*

向阳乔木在 X 上发帖称，他为开发中的工具编写了一条 AI 走查提示词，模拟大厂产品、设计走查验收环节。该提示词要求 AI 集产品经理、UX 研究员与顶级 UI 设计师于一身，主动走查每个页面与交互细节，自行决定顺序与优先级，并从信息架构、用户流程、操作效率、反馈机制、视觉层级、组件一致性六个维度审视；发现问题后立即判断严重程度，高优先级交由子 Agent 修复，其余整理成可执行方案，以真实用户认知负担与情绪体验为最终标准，目标是达到行业顶级而非“能用就行”。帖文还提到 AI 会挨个功能截图，查看并优化 onboarding 与功能操作 UX 等细节。[^2ab9cd82d7910ff1]

Xiangyang Qiaomu posted on X that he wrote an AI walkthrough prompt for a tool under development, simulating the product and design walkthrough acceptance process at major tech companies. The prompt asks the AI to act as a product manager, UX researcher, and top UI designer combined, proactively inspecting every page and interaction detail, deciding order and priority on its own, and reviewing across six dimensions: information architecture, user flow, operational efficiency, feedback mechanism, visual hierarchy, and component consistency. Upon finding issues, it judges severity immediately, hands high-priority items to a sub-agent for repair, and organizes the rest into executable plans, using real-user cognitive load and emotional experience as the ultimate standard, aiming for industry-top quality rather than merely "usable." The post also says the AI will screenshot each function one by one to inspect and optimize details such as onboarding and functional operation UX.[^2ab9cd82d7910ff1]
