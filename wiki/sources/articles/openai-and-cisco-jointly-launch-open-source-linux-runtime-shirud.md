# OpenAI 与 Cisco 联合推出开源 Linux 运行时 Shirudo，让 AI 智能体在不停机的情况下为系统编写 eBPF 防护

*OpenAI and Cisco jointly launch open-source Linux runtime Shirudo, letting AI agents write eBPF defenses for systems without downtime*

「帖文称」OpenAI 与 Cisco 共同推出名为 Shirudo 的开源 Linux 运行时，允许 AI 智能体编写动态 eBPF 控制来防御系统漏洞，在不停机的情况下为防御者争取测试和部署补丁的时间；该项目被描述为自防御基础设施的第一步，旨在让防御者与 AI 智能体协作，发现受影响系统、测试并共享防护层，并在不干扰工作负载的前提下部署。[^openai-shirudo-linux-runtime]

The post says OpenAI and Cisco have jointly launched Shirudo, an open-source Linux runtime that lets AI agents write dynamic eBPF controls to shield systems from exploits, giving defenders time to test and roll out patches without downtime; it is described as a first step toward self-defending infrastructure, with the goal of enabling defenders to work with AI agents to find affected systems, test and share shields, and deploy them without disrupting workloads.[^openai-shirudo-linux-runtime]
