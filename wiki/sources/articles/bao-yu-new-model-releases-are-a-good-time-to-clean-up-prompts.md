# 宝玉：新模型发布是清理提示词的好时机

*Bao Yu: New model releases are a good time to clean up prompts*

帖文称，每次新模型发布都是清理精简提示词的好机会，前提是后续一直使用新模型。宝玉引用 Alex Albert 的做法：在所有项目上运行同一条简单提示词，让模型阅读整个项目，找出损坏、不一致、低效或不再需要的东西，确定的部分直接修复，其余列出供审查，并高度推荐尝试。[^dotey-new-model-prompt-cleanup]

The post says every new model release is a good opportunity to clean up and simplify prompts, provided you keep using the new model. Bao Yu quotes Alex Albert's practice of running the same simple prompt across all projects: read the entire project, find broken, inconsistent, inefficient, or unneeded items, fix what you're sure about, and list the rest for review, highly recommending it.[^dotey-new-model-prompt-cleanup]
