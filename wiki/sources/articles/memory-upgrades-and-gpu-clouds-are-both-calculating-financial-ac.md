# 内存升级和 GPU 云都在算金融账

*Memory upgrades and GPU clouds are both calculating financial accounts*

帖文称，GPU 云厂商的商业模式带有浓厚的金融工程色彩：借钱购买显卡，以长期合同抵押，并为签约长期合同向客户提供折扣；银行收取利息，客户获得折扣，而云厂商则锁定长期合同，作者讽刺称这像是一份“长期劳动合同”。[^gpu-cloud-financial-engineering]

The post claims that GPU cloud providers' business model has a strong financial engineering flavor: borrowing money to buy GPUs, mortgaging long-term contracts, and discounting for customers to sign long-term agreements; banks receive interest, customers receive discounts, and cloud providers lock in long-term contracts, which the author jokingly calls a “long-term labor contract.”[^gpu-cloud-financial-engineering]
