# 剪映官方插件接入豆包工作，全自动剪辑时代到来

*Jianying Official Plugin Integrates Doubao Work, Fully Automatic Editing Era Arrives*

「帖文称」剪映官方插件已接入豆包工作，全自动剪辑时代已经到来。作者@cgnot996提到，此前开源项目「无头剪映」曾遭遇 DMCA，他便预料字节会有动作。随着多模态理解、工具调用和长任务执行能力提升，筛选素材、切片、添加字幕、调整时间轴等繁琐操作可逐步交给 Agent，人只需要把控创意和最终效果。他还认为这不只限于剪映，传统软件都值得用 Agent 的方式重新做一遍，未来软件厂商争夺的可能不再只是用户入口，还有 Agent 的调用入口。[^x-cgnot996-jianying-doubao-auto-editing]

The post claims Jianying's official plugin has integrated Doubao Work, marking the arrival of the fully automatic editing era. Author @cgnot996 notes that the open-source “Headless Jianying” project previously faced DMCA, leading him to expect action from ByteDance. As multimodal understanding, tool calling, and long-task execution improve, tedious operations such as material selection, cutting, subtitles, and timeline adjustment can gradually be handed to Agents, with humans only overseeing creativity and final results. He also believes this is not limited to Jianying: traditional software is worth rebuilding with Agents, and future software vendors may compete not only on user entry points but also on Agent access points.[^x-cgnot996-jianying-doubao-auto-editing]
