# 微软开源 Aion 1.0 Instruct（2.3B 端侧模型）

*Microsoft Open-Sources Aion 1.0 Instruct (2.3B On-Device Model)*

「帖文称」微软开源了 Aion 1.0 Instruct，模型仅 2.3B，支持 32K 上下文，可在本地直接处理多页文档分析、长邮件梳理、文本总结与问答；后续优化版本计划于 2027 年 1 月底集成进 Windows 操作系统，专为端侧设备设计。模型已在 Hugging Face 发布。[^microsoft-aion-1-0-instruct-2-3b]

The post claims Microsoft has open-sourced Aion 1.0 Instruct, a 2.3B model with 32K context that can locally handle multi-page document analysis, long-email triage, text summarization and Q&A; optimized versions are planned for integration into Windows at the end of January 2027 for on-device devices. The model is available on Hugging Face.[^microsoft-aion-1-0-instruct-2-3b]
