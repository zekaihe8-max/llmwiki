# Grok Bot 浏览器插件通过 Chrome 应用商店审核

*Grok Bot browser extension passes Chrome Web Store review*

帖文称，铁柱AGI（@cgnot996）开发的可将网页内容直接发送给指定 Grok Bot 的浏览器插件已通过 Chrome 插件市场审核。作者称已实现网页截图、元素选择、整页打包，以及 X 帖子、小红书笔记、抖音内容和公众号文章的采集；计划支持抖音、小红书博主主页批量采集并发给 Bot。插件下载地址放在评论区。[^grok-bot-chrome-extension-approved]

The post says that Tiezhu AGI (@cgnot996) developed a browser extension that can send webpage content directly to a specified Grok Bot, and it has passed the Chrome Web Store review. The author claims implemented features include webpage screenshots, element selection, full-page packaging, and collection of X posts, Xiaohongshu notes, Douyin content, and Official Account articles; batch collection of Douyin and Xiaohongshu blogger homepages is planned. The download link is in the comments.[^grok-bot-chrome-extension-approved]
