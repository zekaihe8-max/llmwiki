# Logan：Gemini API 推出文件分片控制，支持按需读取 PDF、Office 与多媒体

*Logan: Gemini API ships file slicing controls for on-demand PDF, Office, and media access*

「帖文称」Google DeepMind 的 Logan Kilpatrick 在 X 上宣布，Gemini API 今日发布文件分片控制，开发者可直接传入 PDF、Office 文档（文档、演示文稿、电子表格）、音频和视频，并仅请求需要的页面、电子表格单元格、媒体片段或图层；相关博文为 Introducing file slicing controls in the Gemini API。[^logan-gemini-api-file-slicing]

According to the post, Google DeepMind's Logan Kilpatrick announced on X that the Gemini API is shipping file slicing controls today, letting developers pass PDFs, Office files (docs, slides, spreadsheets), audio, and video directly to the API and request only the pages, spreadsheet cells, media segments, and layers they need; the related blog post is Introducing file slicing controls in the Gemini API from blog.google.[^logan-gemini-api-file-slicing]
