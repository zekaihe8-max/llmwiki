# 同题权重编程

*Weight-Space Programming*

「帖文称」MIT CSAIL 团队使用 GPT-6 Astra 直接编辑了千问 Qwen 0.8B 的模型权重，仅改动约 0.016% 的参数，就将数学能力提升约 6 倍、指令跟随能力提升约 3 倍，且未进行重新训练、后训练或强化学习。该方法被称为“权重空间编程”，可直接修改参数以释放模型已有能力、移植控制策略或重新组织计算，暗示小模型未来可能大幅提升，而大模型因参数量庞大可能更难操作。[^x-op7418-weight-space-programming]

The post claims an MIT CSAIL team used GPT-6 Astra to directly edit Qwen 0.8B model weights, changing only about 0.016% of parameters to raise math ability about 6x and instruction following about 3x, without retraining, post-training, or reinforcement learning. Dubbed “Weight-Space Programming,” the approach suggests parameters can be edited directly to unlock existing capabilities, transplant control strategies, or reorganize computation, with small models seen as more feasible than large ones.[^x-op7418-weight-space-programming]
