# Matt · 主仓库

*Matt · Home Repo*

Matt Pocock 在帖文中称，他通过一个“主仓库”（Home Repo）来跨多个代码仓协作 Agent：将所有技能、导航文件与 Wiki 放在单一仓库，在 AGENTS.md 中写入指向其他仓库的克隆路径，从而在一个位置运行 Agent 并对多个仓库做统一变更。[^fbb619ae7defd3d5]

Matt Pocock says in the post that he uses a single “home repo” to work with agents across multiple repositories: all skills, steering files, and wiki live in one place, and AGENTS.md contains clone pointers to other repos, letting him run agents from one spot and make sweeping changes across repos.[^fbb619ae7defd3d5]
