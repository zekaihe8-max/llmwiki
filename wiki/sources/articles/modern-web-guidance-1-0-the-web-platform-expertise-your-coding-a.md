# Modern Web Guidance 1.0 稳定发布：为编程智能体注入 Web 平台专业知识

*Modern Web Guidance 1.0: The web platform expertise your coding agent is missing*

Chrome 博客帖文称，Modern Web Guidance 1.0 已达稳定版，为编程智能体提供经过专家审核的 Web 开发最佳实践、浏览器兼容性数据与现代化工作流，Firefox 与 Edge 亦加入该跨浏览器项目。[^modern-web-guidance-v1]

The Chrome blog post announces that Modern Web Guidance 1.0 is stable, providing coding agents with expert-vetted web development best practices, browser compatibility data, and a modernization workflow, with Firefox and Edge joining the cross-browser effort.[^modern-web-guidance-v1]

- Modern Web Guidance 1.0 稳定发布，包含新的代码库现代化工作流与数百个经过专家审核的 AI 知识缺口指南。[^modern-web-guidance-v1]
- Modern Web Guidance 1.0 is stably released, including a new codebase modernization workflow and hundreds of expert-vetted guides targeting AI knowledge gaps.[^modern-web-guidance-v1]
