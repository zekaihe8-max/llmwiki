# 传送门实验

*Portal Experiment*

帖文称，Ethan Mollick 指示 Fable 5.2 构建一个无需人工干预、通过传送门连接的无尽 3D 世界旅程；据帖文称，该实验生成了 25,000 个智能体和 450 个受书籍、艺术与地点启发的世界，全部以代码形式呈现，并附带可玩网页与 GitHub 代码库。[^emollick-portals-experiment]

The post says Ethan Mollick instructed Fable 5.2 to build an endless, hands-off journey through 3D worlds linked by portals; according to the post, the experiment generated 25,000 agents and 450 worlds inspired by books, art, and places, all in code, with a playable web page and GitHub repository provided.[^emollick-portals-experiment]
