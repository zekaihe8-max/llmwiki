# ChatGPT Wallet 面向 Pro 用户推出，Agent 可代为安全购买

*ChatGPT Wallet Rolls Out to Pro Users, Letting Agents Make Secure Purchases*

帖文称，OpenAI 联合创始人 Greg Brockman 转发 ChatGPT 官方消息，ChatGPT Wallet 从当天起开始向 dots 中的 Pro 订阅者推出。该功能允许 Agent 在用户批准下安全代为完成购买，且不获取用户实际卡片信息，每笔交易均需通过安全检查。合作方包括 American Express、Mastercard 和 Visa。[^chatgpt-wallet-secure-purchases]

The post says OpenAI co-founder Greg Brockman boosted the official ChatGPT announcement that ChatGPT Wallet is rolling out starting today to Pro subscribers among dots. The feature lets agents securely complete purchases on users' behalf with approval, without accessing actual card details, and every purchase requires a security check. Partners include American Express, Mastercard, and Visa.[^chatgpt-wallet-secure-purchases]
