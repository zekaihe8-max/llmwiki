# 少说废话省 Token：DeepSeek Harness 优化 Agent 流程

*Cut the Chatter to Save Tokens: DeepSeek Harness Optimizes Agent Workflow*

「帖文称」让 AI Agent 少说废话是最大的性能优化：写完代码后询问是否编译、编译成功后询问是否测试、测试通过后询问下一步。引用清华与微软的研究，称优化这套流程可使 DeepSeek Harness 节省近 88% 的 Token，同时成功率提升；文中比喻 Agent 有“职场病”，干活五分钟、开会两小时。[^deepseek-harness-agent-token-saving]

The post claims that the biggest AI Agent performance optimization is to make it talk less: ask whether to compile after writing code, whether to test after successful compilation, and what to do next after tests pass. Citing research from Tsinghua University and Microsoft, it says optimizing this flow can save DeepSeek Harness nearly 88% of tokens while improving success rate; it likens Agents to having an “office worker’s disease”—five minutes of work, two hours of meetings.[^deepseek-harness-agent-token-saving]
