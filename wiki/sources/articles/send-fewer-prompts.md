# 少发提示

*Send Fewer Prompts*

「帖文称」Kent C. Dodds 建议，每次启动 Agent 会话或向现有会话发送提示词时，都应自问：如何才能不亲自发送这条提示词，却仍能获得相同的预期结果？他认为，这就是构建软件工厂（以及其后形态）的方法。[^b5c769f02e38f99a]

Kent C. Dodds suggests that whenever you spin up an agent session or prompt an existing one, you should ask how to achieve the same desired outcome without sending the prompt yourself. He calls this the path to building a software factory—and whatever comes after.[^b5c769f02e38f99a]
