# Rewind for X 推文回看

*Rewind for X — Tweet Rewatch*

「Rewind for X 推文回看」是一款非 X 官方的 Chrome 扩展，会默默记下用户在 X 首页看到的每条推文，包括作者、正文、图片、引用推文、转帖人和链接，并将数据仅保存在本机，最多保留 3000 条。[^rewind-for-x]

"Rewind for X — Tweet Rewatch" is an unofficial Chrome extension that silently records every tweet seen on the X homepage, including author, text, images, quoted tweets, reposters, and links, storing data locally only and keeping up to 3,000 items.[^rewind-for-x]

## 摘要 / Summary

- 推文在屏幕上露出一半以上就算“看过”，记下作者、正文、图片、引用推文、转帖人和链接。 / A tweet counts as “seen” once more than half is visible; the extension records author, text, images, quoted tweets, reposters, and link.[^rewind-for-x]
- 只记录首页时间线（推荐 / 关注），不记录广告、推文详情页或个人主页。 / Only the homepage timeline (For You / Following) is recorded; ads, tweet detail pages, and profiles are excluded.[^rewind-for-x]
- 点右下角按钮或工具栏图标、Alt+Shift+R 打开抽屉，最新的在最上面，按浏览时段分组，可搜索；点推文在新标签页打开。 / Open the drawer via the bottom-right button, toolbar icon, or Alt+Shift+R; newest items appear first, grouped by browsing session, with search; clicking a tweet opens it in a new tab.[^rewind-for-x]
- 数据只存在本机 chrome.storage.local，最多保留 3000 条，可一键清空。 / Data is stored only locally via chrome.storage.local, up to 3,000 items, with one-click clear.[^rewind-for-x]
