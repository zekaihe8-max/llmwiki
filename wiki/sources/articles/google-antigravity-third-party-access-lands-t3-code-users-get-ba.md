# Google Antigravity 第三方接入落地，T3 Code 用户获封号豁免

*Google Antigravity third-party access lands, T3 Code users get ban exemption*

「帖文称」Google Antigravity 第三方接入已落地：10 月官方论坛确认允许接入，11 月 Google 工程师亲自将 T3 Code 加入客户端白名单，并公开保证通过 T3 Code 使用 Antigravity 订阅不会因此封号；目前主要开放 Gemini，Claude 额度仍有限制。[^antigravity-t3-code-google-access]
