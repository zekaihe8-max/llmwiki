# Matt Pocock 为非开发者推出首个 Agent Skill /vector

*Matt Pocock launches first Agent Skill /vector for non-developers*

帖文称，Matt Pocock 为非开发者做了第一个 Skill /vector，通过 VECTOR 六问（Verification、Existing process、Context、Trust、Order、Remember）把已有工作流映射成可验证、会记忆的流程地图，并计划发布配套框架和文档供公司组织 VECTOR 讨论。[^shao-meng-vector-skill]

The post says Matt Pocock created the first Skill /vector for non-developers, using the VECTOR six questions—Verification, Existing process, Context, Trust, Order, Remember—to map existing workflows into verifiable, memorable process maps, and plans to release frameworks and docs for companies to run VECTOR discussions.[^shao-meng-vector-skill]

## 摘要 / Summary

- 帖文称 /vector 是 Matt Pocock 面向非开发者的第一个 Skill，用于指导如何把任务委托给 AI。[^shao-meng-vector-skill]
- /vector is Matt Pocock's first Skill for non-developers, guiding how to delegate tasks to AI.[^shao-meng-vector-skill]
- 该帖介绍称 VECTOR 包含六个问题：Verification、Existing process、Context、Trust、Order、Remember。[^shao-meng-vector-skill]
- VECTOR includes six questions: Verification, Existing process, Context, Trust, Order, Remember.[^shao-meng-vector-skill]
- 用户应先拿一条自己已在做、至少耗时 20 分钟的流程（如每天清理收件箱）按顺序回答六问。[^shao-meng-vector-skill]
- Users should start with a workflow they already do taking at least 20 minutes (e.g., daily inbox cleanup) and answer the six questions in order.[^shao-meng-vector-skill]
- 走完六问后得到工作流地图：做完是什么样子、怎么检查、每一步用什么、Agent 被允许做什么、人与 Agent 如何交接、两次运行之间记住什么。[^shao-meng-vector-skill]
- After completing the six questions, users get a workflow map: what done looks like, how to verify, what each step uses, what the Agent is allowed to do, human-Agent handoff, and what to remember between runs.[^shao-meng-vector-skill]
- 他计划放出配套框架和文档，方便公司自己组织 VECTOR 讨论；公开的四条讨论材料是找出 AI 能帮忙的工作流、给 Agent 配上下文、重新安排流程顺序、找出靠记忆随时间变好的办法。[^shao-meng-vector-skill]
- He plans to release frameworks and docs for companies to run VECTOR discussions; the four public discussion points are finding AI-helpful workflows, equipping Agents with context, reordering workflows, and finding memory-based improvement methods.[^shao-meng-vector-skill]
