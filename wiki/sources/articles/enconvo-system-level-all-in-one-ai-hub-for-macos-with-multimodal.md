# EnConvo：macOS 系统级全能 AI 中枢，接管多模态能力与应用侧边栏

*EnConvo: System-Level All-in-One AI Hub for macOS with Multimodal Capabilities and App Sidebars*

帖文称 EnConvo 是近期推出的 macOS AI 助手，功能极其全面，基本接管了整个系统。核心优势在于：一是可为 AI 配置完整的外接多模态能力（生图、生视频、ASR、TTS、OCR），支持本地模型运行；二是深度融合进任意应用，提供侧边栏伴随式协助、全局快捷键唤起、划词工具栏、语音输入等，免去复制粘贴。还能接入已订阅的 GPT、Claude 等模型，免费可用、付费按量用 Opus。功能清单覆盖 Codex 编程、多媒体工作台、飞书会议、豆包输入法、Ollama 本地模型、UU 远程、桌面宠物、实时语音对话、视频下载、知识库等。[^gorden-sun-enconvo-system-ai-hub]

The post calls EnConvo a newly released macOS AI assistant with exceptionally comprehensive features that essentially take over the entire system. Core strengths: (1) configurable full external multimodal capabilities (image/video generation, ASR, TTS, OCR) with local model support; (2) deep integration into any app via sidebars, global hotkeys, text-selection toolbars, voice input, eliminating copy-paste. It also connects to subscribed models like GPT and Claude — free to use, pay-as-you-go for Opus. Feature list covers Codex coding, multimedia workbench, Feishu meetings, Doubao input method, Ollama local models, UU remote, desktop pet, real-time voice chat, video downloading, knowledge base.[^gorden-sun-enconvo-system-ai-hub]
