# 小墨 · Antigravity 也能把 agent 放到云端

*Xiaomo · Antigravity Can Also Put Agents in the Cloud*

「帖文称」Google Antigravity（AGY）已支持 Remote Agents 功能，用户可将 Coding Agent 放到 Google 云端运行，无需长期开启本地电脑，即可将修 Bug、升级依赖、运行测试等耗时任务交给云端 Agent；使用步骤为打开 antigravity.google.com、创建 Remote Project 并连接 GitHub 仓库、分配任务并在网页或手机查看进度，目前面向 Google AI Pro 和 Ultra 用户逐步开放。帖文还提到，Google AI Ultra 用户可在 AGY 中使用 Claude Opus 5.5，并通过 Pi 插件与 ACP 协议接入 Antigravity 模型。[^xiaomovps-antigravity-remote-agent]

The post claims Google Antigravity (AGY) now supports Remote Agents, letting users run Coding Agents on Google Cloud without keeping local computers on, and delegate time-consuming tasks such as bug fixes, dependency upgrades, and test execution to cloud agents. Steps include opening antigravity.google.com, creating a Remote Project connected to a GitHub repo, assigning tasks, and checking progress on web or mobile; the feature is gradually rolling out to Google AI Pro and Ultra users. The post also notes that Google AI Ultra users can use Claude Opus 5.5 in AGY, and a Pi plugin can connect Antigravity models via Google's ACP protocol.[^xiaomovps-antigravity-remote-agent]
