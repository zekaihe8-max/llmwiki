# Mihail Eric on Boris Cherny at Stanford

[@mihail_eric](https://x.com/mihail_eric) reports that Boris Cherny (creator of Claude Code) returned to his Stanford course The Modern Software Developer and, when asked how many Claude agents he was running, answered "a few thousand."[^mihail-eric-bcherny-stanford] The post is at <https://x.com/mihail_eric/status/2113277483701395508>.

## Summary

- Automate your bottleneck: Claude has written 100% of his team's code since November and output is up about 10x per engineer; after people stopped reading carefully and started skimming, they automated code review, with approvals next.[^mihail-eric-bcherny-stanford]
- Build for the model six months out: early Claude Code revenue was flat until Opus 4, then growth became astronomic; the method is to read agent transcripts, find where the model fails, and treat that as where the next release will improve.[^mihail-eric-bcherny-stanford]
- Small teams go faster: for months Claude Code was basically just him; with AI, one or two people can outship a team a hundred times their size.[^mihail-eric-bcherny-stanford]
- Think in loops: Boris writes loops that run for days or weeks and spawn many agents, and expects typing code by hand to head where punch cards went.[^mihail-eric-bcherny-stanford]
- Domain-specific builders are the future: when code is cheap, knowing the problem deeply is the only alpha—he expects the best accounting software of 2027 to be built by an accountant.[^mihail-eric-bcherny-stanford]
