# 混元 Hy4 正式发布：首次支持视觉与 Computer Use，权重计划开源

*Tencent Hunyuan Hy4 Officially Released: First Supports Vision and Computer Use, Weights Planned for Open Release*

帖文称，腾讯混元正式发布 Hy4 大模型，总参数约 770B、MoE 架构、上下文 1M token，首次加入视觉识别和 Computer Use 电脑操作能力，主打金融、办公、前端游戏和科研四大场景。帖文还称模型权重「计划开源」，目前主要通过 API 和腾讯产品可用，团队坦诚与顶尖闭源模型仍有明显差距。[^tencent-hunyuan-hy4-released]

The post says Tencent Hunyuan officially released the Hy4 large model, with about 770B total parameters, MoE architecture, and 1M token context, adding visual recognition and Computer Use computer operation capabilities for the first time, targeting finance, office, frontend gaming and research scenarios. The post also says model weights are planned to be open sourced, currently mainly available via API and Tencent products, and the team candidly admits a significant gap remains with top closed-source models.[^tencent-hunyuan-hy4-released]

## 摘要 / Summary

- Hy4 总参数约 770B，采用 MoE 架构，上下文窗口为 1M token。 / Hy4 has about 770B total parameters, uses MoE architecture, and has a 1M token context window.[^tencent-hunyuan-hy4-released]
- 首次支持视觉和 Computer Use，可操作命令行和图形界面，并专门针对 Blender、CAD 等专业软件及跨应用长周期任务训练。 / First supports vision and Computer Use, can operate command line and graphical interfaces, and is specially trained for Blender, CAD and other professional software as well as cross-application long-horizon tasks.[^tencent-hunyuan-hy4-released]
- 权重「计划开源」，并会配套系统卡；目前正式版权重尚未公开，主要通过 TokenHub、OpenRouter、WorkBuddy/CodeBuddy、元宝、企业微信「大元」、ima 等入口使用。 / Weights are planned to be open sourced and will come with a system card; the official release weights are not yet public, mainly accessible via TokenHub, OpenRouter, WorkBuddy/CodeBuddy, Yuanbao, WeCom "Da Yuan", ima and other entry points.[^tencent-hunyuan-hy4-released]
- 定价与预览版一致：输入每百万 token 6 元，输出 18 元，缓存命中 0.3 元；腾讯云 TokenHub 优惠至 2026-12-31 打五折。 / Pricing is consistent with the preview: input 6 yuan per million tokens, output 18 yuan, cache hit 0.3 yuan; Tencent Cloud TokenHub discount until 2026-12-31 at 50% off.[^tencent-hunyuan-hy4-released]
- 在金融任务评测中，Hy4 得分 3.04，高于 DeepSeek-V4.1-Flash-1017 的 2.97 和 Kimi K3.1 Pro / GLM-5.3 的 2.68。 / In financial task evaluation, Hy4 scored 3.04, higher than DeepSeek-V4.1-Flash-1017's 2.97 and Kimi K3.1 Pro / GLM-5.3's 2.68.[^tencent-hunyuan-hy4-released]
- 团队坦诚和顶尖闭源模型仍有明显差距，尤其在前沿数学、超长开发任务、模型迭代和视觉问答方面。 / The team candidly admits a significant gap remains with top closed-source models, especially in frontier mathematics, ultra-long development tasks, model iteration, and visual question answering.[^tencent-hunyuan-hy4-released]
