# 谷歌 Gemini 推出 Tasks 个人 Agent 功能

*Google Gemini Launches Tasks Personal Agent Feature*

「帖文称」Google 其实也有自己的 Personal Agent，名为 Tasks in Gemini。作者实际体验后表示，该功能可让 Gemini 打开网站、在自有云电脑上进行浏览器操作，还能整理邮件、操作 Google Drive、管理日历并执行定时任务。交互体验有点像 Muse，Google 意图将 Personal Agent 与普通 AI 聊天平台合并在一起，区别于 Codex 的分环境设计。需注意只在 Task 模式下才具备完整云电脑任务执行能力，默认 Chat 模式不具备；执行任务会消耗套餐额度，部分地区免费用户也可体验，但不同套餐的任务额度和自动化功能有所区别。[^xiaomovps-gemini-tasks-personal-agent]

The post claims Google also has its own Personal Agent, called Tasks in Gemini. After hands-on testing, the author says it lets Gemini open websites and perform browser operations on its own cloud computer, as well as organize emails, operate Google Drive, manage calendars, and execute scheduled tasks. The interaction feels somewhat like Muse, and Google appears to want to merge the Personal Agent with the regular AI chat platform rather than separating environments like Codex. Note that full cloud-computer task execution is only available in Task mode, not the default Chat mode; task execution consumes subscription quota, and some free users in certain regions can try it, though quotas and automation features vary by plan.[^xiaomovps-gemini-tasks-personal-agent]
