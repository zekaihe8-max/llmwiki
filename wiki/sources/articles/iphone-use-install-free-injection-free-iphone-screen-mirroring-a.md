# iPhone-use：免安装、零注入的 iPhone 屏幕投射与蓝牙输入操控

*iPhone-use: Install-free, injection-free iPhone screen mirroring and Bluetooth input control*

帖文称，开发者 YueChen 开源的 iPhone-use 项目通过 Mac 的 USB 口直接拉取手机屏幕画面，用蓝牙模拟外接鼠标和键盘，并用本地 OCR 替代云端模型进行识别定位。手机侧零 App、零测试证书、零注入，在银行、微信等注重风控的应用眼里，它只是一台连了蓝牙键盘和触控板的普通 iPhone。帖文还称这应该是目前最好用的 iPhone Use 项目。[^iphone-use-local-ocr-bluetooth-control]

The post says that iPhone-use, open-sourced by developer YueChen, pulls the phone screen directly through the Mac's USB port, simulates an external mouse and keyboard via Bluetooth, and uses local OCR instead of cloud models for recognition and positioning. The phone side has zero apps, zero test certificates, and zero injection; to risk-sensitive apps such as banks and WeChat, it is merely an ordinary iPhone connected to a Bluetooth keyboard and trackpad. The post claims it should be the currently best iPhone Use project.[^iphone-use-local-ocr-bluetooth-control]
