# 他发现 Gemini 自带一台 2 核 8G 的 Linux 云电脑

*He Found Gemini Comes with a 2-Core 8GB Linux Cloud Computer*

帖文称，Google Gemini 现在自带一台 Linux 云电脑，不用购买 VPS，可直接让 AI 运行代码、安装软件和处理文件。开启方法是在 gemini.google.com 左下角设置进入 Task settings，开启 Network access for remote computer，再切换到 Task 模式执行命令。帖文给出的配置为 2 核 Intel Xeon、8GB 内存、20GB 硬盘、Debian 12，并预装 Python、Node.js、FFmpeg 等工具；该环境是临时的，不能长期挂机，但跑脚本和处理文件够用。[^9c465398958cd4cc]

The post says Google Gemini now includes a Linux cloud computer, so users do not need to buy a VPS and can let AI run code, install software, and process files. To enable it, open gemini.google.com, enter Task settings from the lower-left settings, turn on Network access for remote computer, and switch to Task mode to execute commands. The post lists the configuration as 2 Intel Xeon cores, 8GB RAM, 20GB disk, Debian 12, and preinstalled tools such as Python, Node.js, and FFmpeg; the environment is temporary and not for long-running sessions, but it is enough for scripts and file processing.[^9c465398958cd4cc]
