# Magpie 贡献墙：反馈者被列作 co-author

*Magpie's Contribution Wall: Feedbackers Credited as Co-authors*

帖文称，Magpie 的做法不止于把 GitHub issue 的提出者列为对应 change 的 co-author；用户在 Twitter 或 Discord 提出的 bug 反馈或新功能建议，在实现完毕并发版后也会被作为 co-author。帖文还提到 Magpie 官网设有贡献墙。[^magpie-contribution-wall-coauthor]

The post says Magpie goes beyond listing GitHub issue proposers as co-authors of the corresponding change: bug reports or feature suggestions from Twitter or Discord are also credited as co-authors after implementation and release. It also mentions a contribution wall on Magpie's official website.[^magpie-contribution-wall-coauthor]
