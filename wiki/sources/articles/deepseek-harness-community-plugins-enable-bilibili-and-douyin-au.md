# DeepSeek Harness 社区插件实现 B 站与抖音自动化

*DeepSeek Harness Community Plugins Enable Bilibili and Douyin Automation*

「帖文称」DeepSeek Harness 已经能通过社区插件自动刷 B 站、玩抖音，甚至主动发私信；文中介绍了 dsh-bili-scroll、Aurabot 和 dsh-douyin-tools 三个项目，并提醒使用第三方 API 时应登录小号，不要开自动模式污染他人评论区。[^deepseek-harness-bilibili-douyin-automation]

The post claims DeepSeek Harness can now automatically browse Bilibili and Douyin and send direct messages via community plugins, introducing dsh-bili-scroll, Aurabot, and dsh-douyin-tools, while advising users to log in with secondary accounts and avoid automated modes that pollute others' comment sections.[^deepseek-harness-bilibili-douyin-automation]

## 摘要 / Summary

- dsh-bili-scroll 有 1200 多个 Star，可自动刷 B 站、读取字幕、生成每日报告，并通过私信推荐视频或 @ 用户，支持双向私信和回复评论。 / dsh-bili-scroll has over 1,200 stars, automatically browses Bilibili, reads subtitles, generates daily reports, and recommends videos via DM or @ mentions, supporting two-way DMs and comment replies.[^deepseek-harness-bilibili-douyin-automation]
- Aurabot 为 DSH 创建了带人格和记忆的 QQ 机器人，支持聊天、表情包、语音，并可在 B 站刷视频、发表评论，集成抖音互动能力。 / Aurabot creates a QQ bot with personality and memory for DSH, supporting chat, emojis, voice, Bilibili browsing and commenting, plus Douyin interaction.[^deepseek-harness-bilibili-douyin-automation]
- dsh-douyin-tools 支持自动浏览推荐视频、读取评论、点赞、发私信和回复评论，还可做视频转发、表情包互动和本地成片投稿。 / dsh-douyin-tools supports auto-browsing recommended videos, reading comments, liking, sending DMs and replying to comments, as well as video forwarding, emoji interaction, and local video submission.[^deepseek-harness-bilibili-douyin-automation]
- 作者说明 dsh-douyin-tools 部分发送和投稿流程未经过真实账号完整验证，适合用测试账号折腾。 / The author notes some sending and submission flows in dsh-douyin-tools have not been fully verified with real accounts, making it suitable for testing accounts.[^deepseek-harness-bilibili-douyin-automation]
- 帖文建议使用第三方 API 时登录小号，不要开自动模式污染他人评论区。 / The post recommends using secondary accounts for third-party APIs and avoiding auto mode to prevent polluting others' comment sections.[^deepseek-harness-bilibili-douyin-automation]
- 另有一个 dsh-im 插件支持微信、飞书、钉钉等 12 种聊天渠道，可在插件市场搜索安装。 / A separate dsh-im plugin supports 12 chat channels including WeChat, Feishu, and DingTalk, installable via the plugin market.[^deepseek-harness-bilibili-douyin-automation]
