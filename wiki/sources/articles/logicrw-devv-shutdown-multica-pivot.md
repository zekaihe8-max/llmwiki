# 思维怪怪谈 Devv 停运转 Multica

*Logicrw on Devv shutdown and Multica pivot*

[@0xLogicrw](https://x.com/0xLogicrw)（思维怪怪）转述：开发者 AI 搜索引擎 **Devv** 宣布停运；创始人 **张佳圆**（Jiayuan Zhang）称团队将把全部精力转向 AI Agent 协作平台 **Multica**。过去三年 Devv 累计服务全球上百万开发者。[^logicrw-devv-shutdown-multica-pivot] 原帖 <https://x.com/0xLogicrw/status/2115744209856799087>。

[@0xLogicrw](https://x.com/0xLogicrw) (Logicrw) relays that developer AI search **Devv** is shutting down; founder **Jiayuan Zhang** says the team will put all effort into multi-agent collaboration platform **Multica**. Over three years Devv served more than a million developers worldwide.[^logicrw-devv-shutdown-multica-pivot] Post: <https://x.com/0xLogicrw/status/2115744209856799087>.

## 摘要 / Summary

- **Devv 背景**：2023 年 10 月上线，为程序员建搜索索引、整合技术文档与 GitHub 代码并由 AI 直接给答案；上线四周周活约 **2.5 万**，后推付费订阅，首月收入超 **2.8 万美元**。[^logicrw-devv-shutdown-multica-pivot]
- **Devv background**: launched October 2023 with a programmer-focused search index blending docs and GitHub code into AI answers; about **25k** weekly active users in four weeks, then paid subscription with first-month revenue over **$28k**.[^logicrw-devv-shutdown-multica-pivot]
- **差异化被通用工具吸收**：ChatGPT、Claude 可联网查资料，Claude Code、Codex 等编程 Agent 能自行查资料、写代码、跑测试并完成任务；Devv 曾引以为傲的搜索优势逐渐成为通用 AI 的基础能力。[^logicrw-devv-shutdown-multica-pivot]
- **Edge absorbed by general tools**: ChatGPT and Claude can search the web; coding agents such as Claude Code and Codex can fetch, write code, run tests, and finish tasks—Devv’s former search edge became baseline capability in general AI tools.[^logicrw-devv-shutdown-multica-pivot]
- **更早信号与中间尝试**：张佳圆 **2026 年 5 月** 已透露 Devv 将下线；团队曾尝试 AI 编程产品 **DevCode** 后放弃。[^logicrw-devv-shutdown-multica-pivot]
- **Earlier signals and pivots**: Zhang signaled Devv would go offline in **May 2026**; the team also tried AI coding product **DevCode** and dropped it.[^logicrw-devv-shutdown-multica-pivot]
- **Multica 方向**：不再做搜索、也不自研编程 Agent；多个 Agent 像团队成员协作——用户安排任务，Agent 执行、汇报进度、遇问题主动反馈，完成后交用户审核。[^logicrw-devv-shutdown-multica-pivot]
- **Multica direction**: no new search product and no in-house coding agent; multiple agents collaborate like teammates—the user assigns work, agents execute, report progress, proactively flag issues, then hand results back for human review.[^logicrw-devv-shutdown-multica-pivot]
