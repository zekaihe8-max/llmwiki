# 法律当巨型 Git

*Law as a Giant Git*

「帖文称」全球法律正在被程序员变成一个巨型 Git 仓库，每次法律生效相当于一次 Commit，每个字的修改都能追溯到具体法律；AI Agent 可像读代码一样读法律，使用 git log 查历史、git diff 看变化、git blame 追溯修改来源，使法律成为可追踪、可验证、可供 AI 调用的版本化知识库。帖文还提及 GitHub 项目 github.com/lexifina/global-law，并设想 AI 可能用 Git 找法律漏洞，出现“法律版 Claude Code”。[^216912e1032f7b03]
