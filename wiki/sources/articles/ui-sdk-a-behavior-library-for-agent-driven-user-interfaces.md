# UI SDK：面向智能体的 UI 行为库

*UI SDK: A Behavior Library for Agent-Driven User Interfaces*

「UI SDK」帖文称其是一套供智能体构建和驱动下一代用户界面的行为库，把弹窗、选择、输入等复杂交互拆分为可复用行为，并教会智能体自行选用和组装，无需人工编写组件。[^ui-sdk-dev-a4fba8aa9fc51fa8]

The "UI SDK" post describes it as a behavior library for agents to build and drive the next generation of user interfaces, splitting complex interactions such as popups, selection, and typing into reusable behaviors that agents select and assemble without manual component authoring.[^ui-sdk-dev-a4fba8aa9fc51fa8]
