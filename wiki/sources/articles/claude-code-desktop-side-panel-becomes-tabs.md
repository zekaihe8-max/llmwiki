# Claude Code 桌面端侧栏改为标签页

*Claude Code Desktop Side Panel Becomes Tabs*

帖文称，Claude Code 桌面端已重新设计侧栏：文件、变更、终端及其他工具现在在会话旁以标签页打开，用户仍可移动标签并排查看，或将其弹出为独立窗口；该更新正在 Mac 上推送，Windows 与 Linux 即将到来。[^claude-code-side-panel-tabs]

The post says Claude Code has redesigned its desktop side panel so Files, Changes, Terminal and other tools open as tabs next to the session; tabs can be moved to view several at once or popped out into their own windows, with the rollout starting on Mac and Windows/Linux coming soon.[^claude-code-side-panel-tabs]
