# Claude 企业插件自动连接

*Claude Auto-connects Enterprise Plugins via MCP Trusted Issuer*

「帖文称」Claude 现支持团队与企业管理员统一设置公司插件，队友首次使用时自动连接，无需逐一登录授权；构建 Claude 插件的开发者可添加接受 Claude 作为可信颁发者的 MCP 服务器支持，帮助用户更快上手并保持连接。[^9f76cd6a90934cd7]

The post says Claude now lets Team and Enterprise admins set up company plugins so teammates connect automatically on first use, avoiding repeated logins; developers building Claude plugins can add MCP server support that accepts Claude as a trusted issuer to help users get started faster and stay connected.[^9f76cd6a90934cd7]

- Boris Cherny 发帖称，逐个登录公司插件很麻烦，因此 Claude 现在支持自动连接插件。 / Boris Cherny said logging into company plugins one by one is annoying, so Claude now supports auto-connecting plugins.[^9f76cd6a90934cd7]
- 团队与企业管理员可以设置插件，队友首次使用插件时会自动连接。 / Team and Enterprise admins can set up plugins, and teammates are connected automatically the first time they use the plugins.[^9f76cd6a90934cd7]
