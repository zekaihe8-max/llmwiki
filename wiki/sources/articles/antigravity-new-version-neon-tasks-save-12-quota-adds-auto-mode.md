# Antigravity 新版本：Neon 任务省额度 12%，新增 Auto 模式

*Antigravity New Version: Neon Tasks Save 12% Quota, Adds Auto Mode*

「帖文称」谷歌 Antigravity 负责人 Varun Mohan 宣布新版本进一步优化 Agent Harness：使用 Gemini 4 Neon 运行任务时，每项任务消耗额度减少 12%，完成速度提升 17%；新增 Auto 模式减少 50% 不必要权限确认，位于默认模式与完全放开权限的 Turbo 模式之间，可自动放行安全操作，高风险操作仍需用户确认。[^d00b8177aac1a58a]

The post says Google Antigravity head Varun Mohan announced the new version further optimizes Agent Harness: running tasks with Gemini 4 Neon consumes 12% less quota per task and finishes 17% faster; the new Auto mode cuts 50% of unnecessary permission confirmations, sitting between default mode and fully permissive Turbo mode, automatically allowing safe operations while still requiring user confirmation for high-risk operations.[^d00b8177aac1a58a]
