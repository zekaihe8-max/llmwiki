# 豆仓 BeanPod 开源：原生 macOS 录音转写与知识库工具

*BeanPod Open-Sourced: Native macOS Audio Transcription & Knowledge Base Tool*

帖文称 Berryxia 耗时开发的豆仓 BeanPod 正式开源（MIT 协议）。这是一款原生 macOS 应用，最初为 Anker 录音豆 D3200 编写：录音连 Mac 后自动下载、本机转写、生成纪要与待办，全程数据不出电脑。无硬件也可用作免费录音与学习工具，支持 Mac 录音、导入音频、解析小宇宙/Apple 播客/喜马拉雅链接；转写支持逐句跳转、单句循环、跟读高亮；英语学习模式可自动抽取分级词汇、短语、难句结构并回链原音；内置知识库问答，通过 MCP 一键接入 Claude/Codex 调用录音内容；还能配合 Claude + Renoise 生成数字人视频。新增得到录音卡支持（未真机测试），中英双语界面。作者强调录音与转写最好留在本地，构建个人知识库；也坦承仅在固件 04.92 测试，得到录音卡支持未上真机。[^beanpod-open-source-macos-audio]

The post announces that Berryxia's BeanPod is now open-source (MIT). Originally built for the Anker D3200 recorder, this native macOS app auto-downloads recordings, transcribes locally, and generates summaries and to-dos—all on-device. It also works without the hardware as a free recorder/learning tool: record/import audio, parse links from Xiaoyuzhou, Apple Podcasts, Himalaya; clickable transcripts with sentence looping and karaoke highlight; English-learning mode extracts graded vocab, phrases, and difficult sentences with audio back-links; knowledge-base Q&A via MCP to Claude/Codex; digital-human video export via Claude + Renoise. New support for Dedao recording cards (untested on real hardware), bilingual UI. Author stresses local-first philosophy for recordings and transcription; caveats include testing only on firmware 04.92 and no real-device test for Dedao support.[^beanpod-open-source-macos-audio]
