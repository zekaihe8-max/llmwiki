# Pi 官方维护者提草稿 PR 接入 Google AI 会员

*Pi Maintainer Files Draft PR to Add Google AI Membership*

帖文称，Pi 官方维护者提交了一份草稿 PR，准备让 Pi 接入 Google AI 会员：用户无需额外购买 API，登录谷歌账号即可使用会员额度。该方案据称走谷歌单独批准的 OAuth 客户端与个人配额通道，不允许分支或套壳项目共用，并首发内置四个模型，目前文档只写了 Ultra。[^0e43c4a0bcebaef2]

According to the post, a Pi maintainer has opened a draft PR to integrate Google AI membership, allowing users to use membership quotas in Pi after signing in with a Google account instead of buying API access separately. The post says the integration uses an officially approved OAuth client and personal quota channel, prohibits forks or wrapper projects from sharing it, and initially includes four models, with only Ultra mentioned in the docs.[^0e43c4a0bcebaef2]

## 摘要 / Summary

- 帖文称该草稿 PR 旨在让 Pi 用户登录谷歌账号后直接使用 Google AI 会员额度，而不是额外购买 API。[^0e43c4a0bcebaef2]
- The post says the draft PR aims to let Pi users use Google AI membership quotas by signing in with a Google account rather than purchasing API access separately.[^0e43c4a0bcebaef2]
- 帖文称该接入走谷歌单独批给 Pi 的 OAuth 客户端和个人配额通道，不允许分支或套壳项目共用。[^0e43c4a0bcebaef2]
- The post says the integration uses an OAuth client and personal quota channel approved specifically for Pi, and forks or wrapper projects are not allowed to share it.[^0e43c4a0bcebaef2]
- 帖文称首发内置四个模型：Gemini 4 Neon、Hydrogen、Carbon 和 3.5 Flash-Lite，其中前两个最高可开到 xhigh 思考档。[^0e43c4a0bcebaef2]
- The post says the initial lineup includes four models—Gemini 4 Neon, Hydrogen, Carbon, and 3.5 Flash-Lite—with the first two able to reach the xhigh thinking tier.[^0e43c4a0bcebaef2]
- 帖文称文档目前只写了 Ultra，没有提到 20 美元的 Pro，草稿状态可能是在等待正式官宣。[^0e43c4a0bcebaef2]
- The post says the documentation currently mentions only Ultra and not the $20 Pro tier, suggesting the draft may be waiting for an official announcement.[^0e43c4a0bcebaef2]
- 帖文认为，如果正式上线并带上 Pro 会员，第三方 Agent 接入谷歌订阅会更实用，而 Pi 的省 Token 特性会增强吸引力。[^0e43c4a0bcebaef2]
