# 蓝哥AI谈 Skillry：Vibe Coding 前先算清赚钱同行

*0xlangeai on Skillry—peer economics before vibe coding*

[@0xlangeai](https://x.com/0xlangeai)（蓝哥AI）转述 [@yihui_indie](https://x.com/yihui_indie)（Yihui）拆解：新产品 Skillry 上线 1 个月拿到 400+ 活跃付费订阅，近 30 天收入 $12,037（MRR $3,918）；写代码快了约 10 倍，做出「0 付费 0 用户」产品的速度也快了约 10 倍——因此写第一行代码前，更要先把同赛道真正在赚钱的同行扒一遍，算清两笔账再动手 Vibe Coding。[^0xlangeai-skillry-before-vibe-coding] 原帖 <https://x.com/0xlangeai/status/2115266929103700219>；所转 Yihui 帖 <https://x.com/yihui_indie/status/2115251581998563837>。

[@0xlangeai](https://x.com/0xlangeai) (蓝哥AI) relays [@yihui_indie](https://x.com/yihui_indie) (Yihui): new product Skillry hit 400+ active paid subscriptions in one month and $12,037 last 30 days (MRR $3,918); coding ~10× faster also makes shipping “0 paid, 0 users” products ~10× faster—so before the first line, strip-mine peers who are actually making money in the lane, clear two ledgers, then vibe-code.[^0xlangeai-skillry-before-vibe-coding] Post: <https://x.com/0xlangeai/status/2115266929103700219>; relayed Yihui post: <https://x.com/yihui_indie/status/2115251581998563837>.

## 摘要 / Summary

- 商业模式：只抄还在涨的老生意。纯搬运的 Skill 导航站不赚钱；一次性买断样板（如 ShipFast 近 30 天只剩 $1,694）在掉。Sleek（近 30 天 $16,684）、TypeUI 与 Skillry 走的是「给 Claude Code / Codex 直接调的高审美成品模板 + 订阅制」；越聚焦完整网页、演示文稿、动效等直接交付物，流水可比通用组件高出约 3.5 倍。[^0xlangeai-skillry-before-vibe-coding]
- Business model: only copy growing old businesses. Pure Skill-directory clone sites do not make money; one-time buyout boilerplates (e.g. ShipFast at only $1,694 last 30 days) are falling. Sleek ($16,684 last 30 days), TypeUI, and Skillry sell high-aesthetic finished templates Claude Code / Codex can call directly, on subscription; focusing on complete deliverables—full pages, decks, motion—can pull about 3.5× the revenue of generic components.[^0xlangeai-skillry-before-vibe-coding]
- 第一批客户：先拆同行渠道再抄作业。例：Sleek 靠「免费绿幕去除」小工具页吃下美区约 55.5% 自然搜索流量；冷启动用一条 23 秒实机演示视频加评论领内测，打出约 89 万浏览，零广告费冲过 10k MRR。[^0xlangeai-skillry-before-vibe-coding]
- First customers: tear down peer channels before copying the homework. Example: Sleek’s free green-screen-removal tool page took about 55.5% of US organic search traffic; cold start used a 23-second real-product demo plus comment-for-beta, ~890k views, and crossed 10k MRR with zero ad spend.[^0xlangeai-skillry-before-vibe-coding]
- 工具侧：可在 Claude Code 或 Codex 里接 BizPeel MCP，一句话拉同赛道近 30 天真实流水、SEO 截流词与爆帖打法再对比，算得过账才写代码。[^0xlangeai-skillry-before-vibe-coding]
- Tooling: plug BizPeel MCP into Claude Code or Codex to pull peers’ last-30-day real revenue, SEO intercept keywords, and viral-post playbooks in one prompt—compare, then code only if the ledger clears.[^0xlangeai-skillry-before-vibe-coding]
