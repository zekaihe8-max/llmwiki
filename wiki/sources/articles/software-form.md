# 软件形态

*Software Form*

「帖文称」软件开发的瓶颈早已不再是如何构建专业软件，而是如何让 Agent 更好地使用软件、如何让人类更好地预览和微调，以及如何满足个性化需求。宝玉认为复杂 GUI 对 Agent 价值低，CLI、MCP 和代码更友好；人类只需检查结果并标记、评论、微调，视频编辑器无需复杂时间轴；Agent 让软件制作成本降低，未来软件能力将原子化为 CLI 命令和 MCP 调用，由脚本按需组合，但当人人都能做软件时如何售卖仍是未解之题。[^software-form]

The post argues that software development's bottleneck is no longer building professional software, but enabling Agents to use software, letting humans preview and fine-tune results, and meeting personalized needs. Complex GUIs are of low value to Agents; CLI, MCP, and code are more friendly. Humans only need to check output and mark, comment, and fine-tune, so a video editor needs only a player plus annotation tools. Agents lower production costs, atomizing software capabilities into CLI commands and MCP calls composed by scripts, but how to sell software when everyone can build it remains unanswered.[^software-form]
