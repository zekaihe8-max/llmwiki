# 向阳乔木谈用 DSH 插件复刻 Landing Page

*vista8 on cloning Landing Pages with a DSH plugin*

[@vista8](https://x.com/vista8)（向阳乔木）称蝗虫群有人问有没有做 Landing Page 的 Skill；昨天推荐的前端 Skill 可以，但更简单可靠的方法是选一个网站复刻。他推荐安装 DSH 插件轻松复刻优质网站 Landing Page，仓库见 <https://github.com/joeseesun/qiaomu-ui-learn-dsh>，复制提示词给 Agent 开发即可。[^vista8-dsh-landing-page-clone] 原帖见 <https://x.com/vista8/status/2115293920955605424>。

[@vista8](https://x.com/vista8) (向阳乔木) says someone in 蝗虫群 asked whether there is a Skill for Landing Pages; yesterday’s recommended frontend Skill can work, but a simpler and more reliable method is to pick a website and clone it. He recommends installing a DSH plugin to easily clone quality-site Landing Pages—repo <https://github.com/joeseesun/qiaomu-ui-learn-dsh>—and copying the prompt to an Agent for development.[^vista8-dsh-landing-page-clone] Post: <https://x.com/vista8/status/2115293920955605424>.
