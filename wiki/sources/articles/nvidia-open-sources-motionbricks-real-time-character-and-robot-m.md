# NVIDIA 开源 MotionBricks：实时生成角色与机器人动作

*NVIDIA Open-Sources MotionBricks: Real-Time Character and Robot Motion Generation*

「帖文称」NVIDIA 开源 MotionBricks，一个实时动作生成模型，只需给出前后几个关键动作，即可自动补全中间连贯的运动过渡；其模块化设计将翻越、入座等复杂交互拆解为可自由拼接的动作积木，无需重新训练即可让角色在场景中灵活运动，同时支持数字人和具身人形机器人，代码托管于 GitHub NVlabs 仓库。[^nvidia-motionbricks-real-time-motion]
