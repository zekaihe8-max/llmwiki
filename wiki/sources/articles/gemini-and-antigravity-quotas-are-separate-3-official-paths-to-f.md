# Gemini 与 Antigravity 额度分开算，3 种官方路径充分利用 Google AI 会员额度

*Gemini and Antigravity quotas are separate: 3 official paths to fully use Google AI membership quota*

「帖文称」许多购买 Google AI 会员的用户并不知道 Gemini 和 Antigravity 的额度是分开计算的，两边不互通，容易出现一边额度耗尽、另一边闲置浪费的情况。作者小墨同学在研究 Gemini 时发现深度思考和研究会快速消耗额度，而切到 Antigravity 后额度仍剩较多，因此整理了三种官方原生解决方案：按任务轻重拆开使用、在电脑开启 Remote Control 并以手机浏览器当 Antigravity App、以及使用云端 Remote Agents 让关机后手机仍能派活；作者目前更偏向前两种方案的组合。[^xiaomovps-gemini-antigravity-quota-separation]

The post claims many Google AI members do not realize Gemini and Antigravity quotas are calculated separately and are not interoperable, often leaving one side exhausted while the other remains unused. Author xiaomovps found deep thinking and research drain Gemini quickly while Antigravity still has plenty, and outlines three official native solutions: splitting tasks by weight, using Remote Control on a computer with a mobile browser as the Antigravity app, and running cloud Remote Agents so a phone can dispatch tasks even when the computer is off; the author currently prefers combining the first two.[^xiaomovps-gemini-antigravity-quota-separation]

## 摘要 / Summary

- Gemini 与 Antigravity 额度不互通，一边用完另一边可能仍有大量剩余，容易造成浪费。[^xiaomovps-gemini-antigravity-quota-separation]
- Gemini and Antigravity quotas are not interoperable; one side can run out while the other still has plenty, leading to waste.[^xiaomovps-gemini-antigravity-quota-separation]
- 轻活（随手搜索、语音聊想法、日常问答）建议留在 Gemini，重活（写长文、整理资料、读本地知识库）挪到 Antigravity，并可开启 Orchestrator 模式。[^xiaomovps-gemini-antigravity-quota-separation]
- Light tasks such as quick search, voice chat, and daily Q&A are suggested for Gemini, while heavy tasks like long-form writing, knowledge organization, and local knowledge base reading should move to Antigravity, which supports Orchestrator mode.[^xiaomovps-gemini-antigravity-quota-separation]
- 电脑开启 Antigravity Remote Control，手机浏览器登录 antigravity.google 并添加到主屏幕，可像普通 App 一样使用，走 Antigravity 额度并读写本地文件，前提是电脑开机并联网。[^xiaomovps-gemini-antigravity-quota-separation]
- Turn on Antigravity Remote Control on a computer, log in to antigravity.google via mobile browser and add to home screen to use it like an app, consuming Antigravity quota and reading/writing local files, provided the computer stays on and online.[^xiaomovps-gemini-antigravity-quota-separation]
- Pro 和 Ultra 个人账号可在 Antigravity 建 Remote Project、接 GitHub 仓库，通过 antigravity.google/remote 在手机发任务、看进度，电脑关机也不受影响。[^xiaomovps-gemini-antigravity-quota-separation]
- Pro and Ultra personal accounts can create Remote Projects in Antigravity, connect GitHub repositories, and dispatch tasks or check progress via antigravity.google/remote on a phone even when the computer is off.[^xiaomovps-gemini-antigravity-quota-separation]
- 接私有知识库前应检查仓库里是否留有明文密钥和 token。[^xiaomovps-gemini-antigravity-quota-separation]
- Before connecting private knowledge bases, check that repositories do not contain plaintext keys or tokens.[^xiaomovps-gemini-antigravity-quota-separation]
- 作者目前更偏向方案 1 加方案 2 的组合，手机查资料用 Gemini App，动笔和折腾文件切去 Remote Control。[^xiaomovps-gemini-antigravity-quota-separation]
- The author currently prefers combining options 1 and 2, using Gemini App on mobile for lookups and switching to Remote Control for writing and file work.[^xiaomovps-gemini-antigravity-quota-separation]
