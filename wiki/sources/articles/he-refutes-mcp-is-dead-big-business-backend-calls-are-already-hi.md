# 他反驳「MCP 已经凉了」：大厂后台调用已经很高，新 MCP 也补了四块能力

*He refutes "MCP is dead": big-business backend calls are already high, new MCP adds four capabilities*

帖文称，MCP 压根没凉，大厂后台早就跑冒烟了；Atlassian 的 MCP 每个工作日调用超 500 万次，其中 44% 来自非研发部门，Linear 和 Notion 约一半工单和页面也是 AI 建的，Notion 的 MCP 流量直接涨了 60 倍。新 MCP 补齐了代码模式、Skills 收编、事件提醒和聊天窗直接弹界面四块能力。[^f2751b3f00c1faf2]

The post claims MCP is far from dead and big-business backends are already running hot; Atlassian's MCP sees over 5 million calls per workday, 44% from non-engineering departments, about half of Linear tickets and Notion pages are AI-built, and Notion's MCP traffic surged 60x. The new MCP adds four capabilities: Code Mode, Skills integration, event alerts, and MCP Apps in chat windows.[^f2751b3f00c1faf2]

## 摘要 / Summary

- Atlassian 的 MCP 每个工作日调用超 500 万次，其中 44% 来自非研发部门。[^f2751b3f00c1faf2]
- Atlassian's MCP exceeds 5 million calls per workday, with 44% from non-engineering departments.[^f2751b3f00c1faf2]
- Linear 和 Notion 约一半工单和页面是 AI 建的，Notion 的 MCP 流量涨了 60 倍。[^f2751b3f00c1faf2]
- About half of Linear tickets and Notion pages are AI-built; Notion's MCP traffic rose 60x.[^f2751b3f00c1faf2]
- 新 MCP 补齐代码模式：AI 写脚本连调只拿结果，登录走个人账号授权，不用把密钥交给 AI。[^f2751b3f00c1faf2]
- New MCP adds Code Mode: AI writes and runs scripts, returns only results; login uses personal account authorization, no keys handed to AI.[^f2751b3f00c1faf2]
- Skills 收编进 MCP，由服务端自动同步，用时再加载，Claude 已经公测。[^f2751b3f00c1faf2]
- Skills are folded into MCP, auto-synced server-side and loaded on demand; Claude is in public beta.[^f2751b3f00c1faf2]
- 新增事件提醒和 MCP Apps：半夜报警或急件可叫醒 AI 查日志写摘要；看监控、筛数据可直接在聊天框操作，Slack 和 Claude 已支持。[^f2751b3f00c1faf2]
- New event alerts and MCP Apps: midnight alarms or urgent items can wake AI to check logs and write summaries; monitoring and data filtering can be done directly in chat, supported by Slack and Claude.[^f2751b3f00c1faf2]
