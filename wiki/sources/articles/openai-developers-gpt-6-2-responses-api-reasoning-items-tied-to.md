# OpenAI 开发者：GPT-6.2 在 Responses API 中的推理项绑定对话历史

*OpenAI Developers: GPT-6.2 Responses API reasoning items tied to conversation history*

「帖文称」OpenAI 开发者账号 @OpenAIDevs 发布消息，使用 GPT-6.2 的智能体在 Responses API 中可基于更早的推理构建，从而以更少 Token 和更多缓存命中交付更好结果；自最新前沿模型起，每条推理项均绑定其之前的对话历史，编辑更早消息会导致 API 丢弃其后的推理。[^openai-devs-gpt-6-2-responses-api-reasoning]

The @OpenAIDevs post states that agents using GPT-6.2 in the Responses API can build on earlier reasoning to deliver better results with fewer tokens and more cache hits; starting with the newest frontier models, each reasoning item is tied to the conversation history before it, so editing earlier messages causes the API to drop reasoning that follows the change.[^openai-devs-gpt-6-2-responses-api-reasoning]
