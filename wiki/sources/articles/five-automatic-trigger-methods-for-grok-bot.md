# Grok Bot 五类自动触发方式

*Five Automatic Trigger Methods for Grok Bot*

「帖文称」玩 Grok Bot 必须知道五种自动触发方式，分别是邮件、GitHub 代码事件、Slack 消息、Linear/Sentry 任务与故障监控，以及 Webhook 外部系统触发，适用于个人办公、团队协作和项目运维等场景。[^0d433dceb5501040]

The post says there are five automatic trigger methods for Grok Bot: email, GitHub code events, Slack messages, Linear/Sentry tasks and fault monitoring, and Webhook external system triggers, suitable for personal office work, team collaboration, and project operations.[^0d433dceb5501040]

## 摘要 / Summary

- 邮件触发可让 Grok Bot 自动整理收到的合作邮件、重要通知或账单，并生成回复草稿。 / Email trigger lets Grok Bot automatically organize incoming partnership emails, important notifications, or bills, and generate reply drafts.[^0d433dceb5501040]
- GitHub 触发适合写代码的朋友，新 Issue 或 PR 出现时可自动让 Grok Bot 分析问题，甚至交给 Cursor Cloud 处理。 / GitHub trigger suits coders; new Issues or PRs can automatically prompt Grok Bot to analyze problems, or hand tasks to Cursor Cloud.[^0d433dceb5501040]
- Slack 触发可根据频道消息或指定关键词启动任务，例如有人反馈 Bug 时自动整理问题，适合团队协作。 / Slack trigger starts tasks based on channel messages or specified keywords, such as automatically organizing issues when someone reports a Bug, suitable for team collaboration.[^0d433dceb5501040]
- Linear / Sentry 触发用于项目新增任务或系统异常，自动收集日志、分析原因并生成处理建议。 / Linear / Sentry trigger is used for new project tasks or system anomalies, automatically collecting logs, analyzing causes, and generating handling suggestions.[^0d433dceb5501040]
- Webhook 触发扩展性最大，任何能发送 HTTP 请求的服务（如 VPS、监控脚本）都可接入 Grok Bot 执行任务。 / Webhook trigger has the greatest extensibility; any service capable of sending HTTP requests, such as a VPS or monitoring script, can connect to Grok Bot to execute tasks.[^0d433dceb5501040]
