# Codex 加 Tripo 画布，做了个办公室小游戏《谁要上这个破班》

*Codex + Tripo Canvas Office Mini-Game "Who Wants to Work This Overtime Shift"*

「帖文称」作者 huangserva（@servasyy_ai）跑通了 Codex 搭配 Tripo Agentic Canvas 的 3D 游戏开发管线，制作了办公室小游戏《谁要上这个破班》，并在 X 上发布演示。[^servasyy-tripo-codex-office-minigame]

The post claims that user huangserva (@servasyy_ai) built an office mini-game called "Who Wants to Work This Overtime Shift" using a Codex + Tripo Agentic Canvas 3D game development pipeline, and shared a demo on X.[^servasyy-tripo-codex-office-minigame]

## 摘要 / Summary

- 作者为老板、卷王、摸鱼大师、甩锅侠、实习生和自己六个角色准备了正面、侧面、背面三张概念图，并通过 Tripo 画布生成 3D 模型。[^servasyy-tripo-codex-office-minigame]
- The author prepared front, side, and back concept art for six characters—boss, overachiever, slacker, blame-shifter, intern, and self—and generated 3D models via Tripo Canvas.[^servasyy-tripo-codex-office-minigame]
- Tripo 画布支持复用整条资产生成流程，上传不同概念图即可批量跑出角色、工位、电梯、白板、大饼、黑锅和保温杯等资产。[^servasyy-tripo-codex-office-minigame]
- Tripo Canvas supports reusing the full asset-generation pipeline; uploading different concept art batch-produces characters, desks, elevators, whiteboards, pancakes, black pots, and thermoses.[^servasyy-tripo-codex-office-minigame]
- 模型完成后，作者在 Tripo 内自动绑骨并套用现成动作，缺少“老板画饼”等特殊动作时可通过文字生成新动作。[^servasyy-tripo-codex-office-minigame]
- After modeling, the author auto-rigged models in Tripo and applied existing motions; missing actions such as "boss drawing pancakes" can be generated via text.[^servasyy-tripo-codex-office-minigame]
- Codex 负责审查资产、编写代码并把模型接入游戏，最终交付完整的网页游戏工程。[^servasyy-tripo-codex-office-minigame]
- Codex reviews assets, writes code, and integrates models into the game, ultimately delivering a complete web game project.[^servasyy-tripo-codex-office-minigame]
- 游戏中玩家可把大饼砸回老板脸上、把黑锅扣回甩锅侠头上，并带同事乘坐最后一班电梯下班。[^servasyy-tripo-codex-office-minigame]
- In the game, players can throw pancakes back at the boss, put black pots back on the blame-shifter's head, and take colleagues on the last elevator home.[^servasyy-tripo-codex-office-minigame]
