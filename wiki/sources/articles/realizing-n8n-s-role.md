# 想通了 n8n 的位置

*Realizing n8n's Position*

帖文称，发布者原先设想用 Agent 调用 n8n API 自动搭建工作流会很火爆，但仔细一想 n8n 到头来只是一个包含触发器的脚本运行器，而 Agent 搓脚本加执行日志更快且运行时更省资源，因此很多场景不再需要 n8n，并非说它完全没用。[^cgnot996-n8n-position]

The post says the author originally imagined Agents calling n8n's API to auto-build workflows would be very popular, but on reflection n8n is essentially a script runner with triggers, while Agents can write scripts plus execution logs faster and with lower runtime resource usage, so many scenarios no longer need n8n—though not that it is completely useless.[^cgnot996-n8n-position]
