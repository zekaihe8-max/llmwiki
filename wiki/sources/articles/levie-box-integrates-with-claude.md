# Levie · Box 进 Claude

*Levie · Box Integrates with Claude*

帖文称，Box 创始人 Aaron Levie 宣布 Box 与 Anthropic 合作，通过 Claude 为 Box 内容带来完整读写互操作性：代理不仅能拉取内容用于工作流，还能通过 MCP 将文件更新写回 Box，并在 Claude 中直接查看，用于合同、演示文稿、策略文档等内容。[^levie-box-claude]

The post says Box founder Aaron Levie announced a partnership with Anthropic to bring full read/write interoperability to Box content via Claude: agents can pull content for workflows and write file updates back to Box via MCP, viewable directly inside Claude for contracts, presentations, strategy docs, and more.[^levie-box-claude]

## 摘要 / Summary

- Aaron Levie 宣布 Box 与 Anthropic 合作，通过 Claude 为 Box 内容提供完整读写互操作性。[^levie-box-claude]
- Aaron Levie announced Box is partnering with Anthropic to bring full read/write interoperability to Box content via Claude.[^levie-box-claude]
- 代理可通过 MCP 从 Box 拉取内容、写回文件更新，并在 Claude 中直接查看。[^levie-box-claude]
- Agents can pull content from Box, write back file updates via MCP, and view them directly inside Claude.[^levie-box-claude]
- 用户可在 Claude 中创建、编辑和更新合同、演示文稿、策略文档等内容。[^levie-box-claude]
- Users can create, edit, and update contracts, presentations, strategy docs, and other content in Claude.[^levie-box-claude]
- 帖文称，未来智能体处理企业文件的频率将比人类高出 100 倍。[^levie-box-claude]
- The post claims agents will work with enterprise files 100X more than people do today.[^levie-box-claude]
- Anthropic 还推出交互式连接器，可在 Claude 内打开 Adobe、Atlassian 和 Box 的完整工具版本，已在网页和桌面端推出。[^levie-box-claude]
- Anthropic also launched interactive connectors to open full versions of Adobe, Atlassian, and Box tools inside Claude, rolling out on web and desktop.[^levie-box-claude]
