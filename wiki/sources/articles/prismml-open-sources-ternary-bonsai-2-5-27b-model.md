# PrismML 开源 Ternary Bonsai 2.5 27B 模型

*PrismML Open-Sources Ternary Bonsai 2.5 27B Model*

帖文称 PrismML 开源了 Ternary Bonsai 2.5 27B 模型，基于 Qwen3.8 27B 训练，通过三值量化技术将模型体积压缩至全精度版本的九分之一，仅需 5.9GB 显存即可在消费级 GPU 上运行。该模型重点强化了 AI 的自主编程、多轮工具调用与长周期任务执行能力，模型权重已发布在 Hugging Face。[^prismml-ternary-bonsai-25-27b]

The post announces PrismML open-sourcing Ternary Bonsai 2.5 27B, built on Qwen3.8 27B. Ternary quantization compresses the model to 1/9 of full precision, requiring only 5.9GB VRAM to run on consumer GPUs. The model focuses on enhancing autonomous programming, multi-turn tool calling, and long-horizon task execution. Weights are available on Hugging Face.[^prismml-ternary-bonsai-25-27b]
