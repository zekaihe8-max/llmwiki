# 日常写代码，先装这 5 个 MCP 就够了

*Five MCP Servers Are Enough for Daily Coding*

「帖文称」Antigravity（AGY）已自带插件市场与 MCP 支持并默认懒加载，小墨同学从官方市场和社区整理出 5 个最实用的 MCP：Context7 用于查带版本号的最新文档、DeepWiki MCP 用于快速看懂陌生开源项目、GitHub MCP 用于远程 PR 与 Issue 协作、Supabase MCP 用于连真实数据库和线上日志、Figma MCP 用于前端还原设计稿。日常写代码只留前 3 个基本就够了；Playwright、Sequential Thinking、Filesystem 等无需盲装，因为 AGY 桌面端自带浏览器、CLI 底层接了 Chrome DevTools MCP，思考档位、/plan 和本地文件读写均为原生功能。[^antigravity-five-mcp-daily-coding]

The post says Antigravity (AGY) now ships a built-in plugin marketplace with MCP support and lazy loading by default. The author recommends five MCP servers from the official market and community: Context7 for versioned latest docs, DeepWiki MCP for understanding unfamiliar open-source projects, GitHub MCP for remote PR/Issue collaboration, Supabase MCP for real databases and online logs, and Figma MCP for design-file restoration. Only the first three are needed for daily coding; Playwright, Sequential Thinking, and Filesystem should not be installed blindly because AGY desktop includes a browser, CLI connects to Chrome DevTools MCP, and thinking modes, /plan, and local file read/write are native.[^antigravity-five-mcp-daily-coding]
