# 出门用手机口喷，就能指挥家里的多支 AI 团队

*Use mobile voice commands on the go to command multiple AI teams at home*

帖文称，出门只需用手机上的 UU 远程连接家中常年开机的 Mac，对主控口喷几句，就能指挥研发、视频、媒体等多支 AI 团队写代码、跑测试、做分镜、剪片、写稿配图；作者还称 UU 远程可替代 Tailscale、Claude 远程、Codex 远程和 frp 等旧方案。[^servasyy-ai-uu-remote-mobile-ai-teams]

The post claims that while away, a user only needs UU Remote on a phone to connect to always-on home Macs and issue voice commands to a main controller, directing R&D, video, and media AI teams to write code, run tests, storyboard, edit, write articles, and create illustrations; the author also claims UU Remote can replace legacy solutions such as Tailscale, Claude Remote, Codex Remote, and frp.[^servasyy-ai-uu-remote-mobile-ai-teams]
