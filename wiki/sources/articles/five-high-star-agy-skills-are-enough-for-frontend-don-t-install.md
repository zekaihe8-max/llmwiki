# 用 AGY 写前端，5 个高星 Skill 就够了，别装上千个合集

*Five High-Star AGY Skills Are Enough for Frontend, Don't Install Thousands*

「帖文称」小墨同学在 X 上发文，推荐用 Antigravity（AGY）写前端时只需安装 5 个高星 Skill：ui-ux-pro-max-skill、impeccable、vercel-labs/agent-browser、vercel-labs/agent-skills 和 google-labs-code/stitch-skills，分别覆盖 UI/UX 定调、AI 廉价感清理、浏览器验收、代码规范与性能、以及设计转代码；文中还提醒，Antigravity 的规则、Skill 元数据和 MCP 描述共享 2 万 Token 预算，千万不要安装几百上千个 Skill 合集，否则上下文变脏会导致模型跑偏。[^agy-frontend-five-skills]

The post says Xiaomovps recommends installing only five high-star Skills when writing frontend with Antigravity (AGY): ui-ux-pro-max-skill, impeccable, vercel-labs/agent-browser, vercel-labs/agent-skills, and google-labs-code/stitch-skills, covering UI/UX tone-setting, AI slop removal, browser acceptance, code standards and performance, and design-to-code conversion; it also warns that Antigravity rules, Skill metadata, and MCP descriptions share a 20k token budget, and installing hundreds or thousands of skills will dirty the context and cause the model to drift.[^agy-frontend-five-skills]

## 摘要 / Summary

- ui-ux-pro-max-skill 拥有 153.8k Star，内置 80 种 UI 风格、194 套配色、74 组字体和 141 条 UX 准则，覆盖 React、Next、Vue、Tailwind。[^agy-frontend-five-skills]
- ui-ux-pro-max-skill has 153.8k stars, with 80 UI styles, 194 color schemes, 74 font sets, and 141 UX criteria, covering React, Next, Vue, and Tailwind.[^agy-frontend-five-skills]
- impeccable 拥有 116.5k Star，自带 24 个设计指令和 Rust 编写的 62 项 AI-slop 检测器，用于治理 AI 廉价感和后期精修。[^agy-frontend-five-skills]
- impeccable has 116.5k stars, with 24 design commands and a Rust-based 62-item AI-slop detector for fixing AI cheapness and post-production refinement.[^agy-frontend-five-skills]
- vercel-labs/agent-browser 拥有 53.8k Star，是 Rust 浏览器自动化 CLI，支持无障碍树、视觉 diff、Core Web Vitals 和截图。[^agy-frontend-five-skills]
- vercel-labs/agent-browser has 53.8k stars, a Rust browser automation CLI supporting accessibility tree, visual diff, Core Web Vitals, and screenshots.[^agy-frontend-five-skills]
- vercel-labs/agent-skills 拥有 34.9k Star，包含 40 多条 React 性能规则和 100 多条 Web 设计与无障碍准则。[^agy-frontend-five-skills]
- vercel-labs/agent-skills has 34.9k stars, including 40+ React performance rules and 100+ web design and accessibility criteria.[^agy-frontend-five-skills]
- Antigravity 的规则、Skill 元数据和 MCP 描述共享 2 万 Token 预算，建议先装 ui-ux-pro-max-skill 和 impeccable，React 项目再补 vercel-labs/agent-skills。[^agy-frontend-five-skills]
- Antigravity rules, Skill metadata, and MCP descriptions share a 20k token budget; it is recommended to install ui-ux-pro-max-skill and impeccable first, then add vercel-labs/agent-skills for React projects.[^agy-frontend-five-skills]
