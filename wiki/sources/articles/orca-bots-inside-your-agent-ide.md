# Orca：Agent IDE 中的机器人

*Orca: Bots inside your agent IDE*

「帖文称」Orca 是一个开源 Agent IDE，把机器人带入你的 Agent IDE，支持在 Slack、Linear 或 GitHub 中向机器人提交修复错误的请求，并在 Orca 中审查或介入其生成的经过测试的拉取请求，运行在你自己的 Claude Code 或 Codex 上。[^0a8884baa5f55aa6]

The post describes Orca as an open-source agent IDE that brings bots into your agent IDE, letting you ask bots in Slack, Linear, or GitHub to fix bugs and return tested pull requests, running on your own Claude Code or Codex.[^0a8884baa5f55aa6]

## 摘要 / Summary

- Orca 支持任何在终端中运行的 CLI 智能体，包括 Claude Code、Codex、Cursor、GitHub Copilot 等。[^0a8884baa5f55aa6]
- Orca works with any CLI agent that runs in a terminal, including Claude Code, Codex, Cursor, and GitHub Copilot.[^0a8884baa5f55aa6]
- 用户可在 Slack、Linear 或 GitHub 中向 Orca 机器人提交修复错误的请求，并在 Orca 中审查或介入其生成的经过测试的拉取请求。[^0a8884baa5f55aa6]
- Users can ask Orca bots in Slack, Linear, or GitHub to fix bugs and review or step into the tested pull requests they produce.[^0a8884baa5f55aa6]
- Orca 允许在聊天界面与原生 CLI 之间无缝切换而不丢失上下文，并支持远程服务器、SSH 主机和云虚拟机等多种运行方式。[^0a8884baa5f55aa6]
- Orca allows moving conversations between Chat UI and raw CLI without losing context, and supports running on remote Orca servers, SSH hosts, or cloud VMs.[^0a8884baa5f55aa6]
- 桌面端提供 macOS、Windows、Linux 构建，移动端提供 iOS 和 Android 应用，用于在外出时监控和回复智能体。[^0a8884baa5f55aa6]
- Desktop builds are available for macOS, Windows, and Linux, with iOS and Android mobile apps to monitor and steer agents away from the desk.[^0a8884baa5f55aa6]
- Orca 采用 MIT 许可证开源，并包含 Git 工作区、设计模式、插件和分割窗格等功能。[^0a8884baa5f55aa6]
