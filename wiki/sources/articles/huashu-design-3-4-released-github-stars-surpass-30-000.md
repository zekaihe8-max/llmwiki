# huashu-design 3.4 发布，GitHub 星标过 3 万

*huashu-design 3.4 Released, GitHub Stars Surpass 30,000*

「帖文称」花叔（@AlchainHust）在 X 上发布 huashu-design 3.4，并称该项目 GitHub 星标已突破 3 万，是其继女娲.skill 之后的第二个 3 万星标开源项目；新版本通过拆解 2025 和 2026 两届 App Store Awards 入围 App，提炼出八条 Agent 做 App 设计范式，并新增小红书头图、DeepSeek Harness 及 App Store 宣传图生成能力，MIT 开源、商用免费。[^huashu-design-3-4-release]

The post claims that 花叔 (@AlchainHust) released huashu-design 3.4 on X, saying its GitHub stars have surpassed 30,000, making it his second 30k-star open-source project after 女娲.skill; the new version analyzes 90 apps from the 2025 and 2026 App Store Awards finalists to distill eight Agent app design paradigms, and adds Xiaohongshu cover images, DeepSeek Harness support, and App Store promotional image generation, MIT licensed and free for commercial use.[^huashu-design-3-4-release]

## 摘要 / Summary

- huashu-design 3.4 已发布，GitHub 星标超过 3 万，采用 MIT 协议，商用免费。[^huashu-design-3-4-release]
- huashu-design 3.4 has been released, with GitHub stars exceeding 30,000, under the MIT license and free for commercial use.[^huashu-design-3-4-release]
- 作者拆解了 2025 和 2026 两届 App Store Awards 入围名单中的 90 个作品，取得 89 个的 1572 张商店截图，提炼出八条设计口诀。[^huashu-design-3-4-release]
- The author analyzed 90 works from the 2025 and 2026 App Store Awards finalist lists, obtained 1,572 store screenshots from 89 of them, and distilled eight design maxims.[^huashu-design-3-4-release]
- 3.4 新增小红书头图设计、DeepSeek Harness 支持，以及按 1320×2868 输出的 App Store 宣传图生成功能。[^huashu-design-3-4-release]
- 3.4 adds Xiaohongshu cover design, DeepSeek Harness support, and App Store promotional image generation at 1320×2868.[^huashu-design-3-4-release]
- Agent 可通过 Codex、豆包、WorkBuddy 等自带生图能力生成界面图，或调用 GPT-Image 2.6、Seedream 5.5 等外部生图 API，避免使用表情符号或灰色占位符。[^huashu-design-3-4-release]
- Agents can generate UI images using built-in image generation from Codex, Doubao, WorkBuddy, etc., or call external image APIs such as GPT-Image 2.6 and Seedream 5.5, avoiding emojis or gray placeholders.[^huashu-design-3-4-release]
- 安装方式为复制 GitHub 链接 https://github.com/alchaincyf/huashu-design 给 Agent，或执行 npx skills add alchaincyf/huashu-design。[^huashu-design-3-4-release]
- Installation is done by copying the GitHub link https://github.com/alchaincyf/huashu-design to the Agent, or running npx skills add alchaincyf/huashu-design.[^huashu-design-3-4-release]
