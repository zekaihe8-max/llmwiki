# Claude auto mode by default

[@claudeai](https://x.com/claudeai) announces that starting the following week, sessions across Claude web, desktop, and mobile apps will run in auto mode by default on Pro, Max, and Team plans.[^claude-auto-mode-default] The post is at <https://x.com/claudeai/status/2113360845409583307>.

## Summary

Rather than asking the user to approve each step, an automated check blocks risky actions. Users can switch back to manual mode at any time.[^claude-auto-mode-default]

The fetched post also surfaces a related [@ClaudeDevs](https://x.com/ClaudeDevs) note that auto mode became the default permission mode in Claude Code for Pro, Max, and Team users starting 14 August, with a separate classifier reviewing shell commands and actions. In testing that classifier caught 89% of dangerous commands, versus 14% for manual approval.[^claude-auto-mode-default]
