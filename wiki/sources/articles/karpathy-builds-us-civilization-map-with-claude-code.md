# 卡帕蒂用 Claude Code 做美国《文明》地图

*Karpathy Builds US Civilization Map with Claude Code*

「帖文称」安德烈·卡帕蒂要求 Claude 用美国真实公开数据填充一张《文明》风格地图；Opus 5.5 下载并解析大量数据，耗时 7 小时、输出 4.5 万行代码后实现了该项目。地图基于 25 公里六边形网格，整合了普查局、BEA、BLS、EIA、NOAA、USGS、国防部、NPS、FAA、FEMA、CDC 等 31 个数据源，并把经济、就业、电厂、港口、机场、公园、大学等信息转化为《文明》术语，例如 GDP 对应金币产量。项目还提供 19 个透镜、524 个都会区城市视图、九位顾问，以及可对 3100 多个县任意列生成表格和散点图的探索者。卡帕蒂表示系统是在 Claude Code 桌面应用中用 Opus 5.5 构建，克劳德跳过了个别州和领地。[^karpathy-us-civ-claude-code]

The post says Andrej Karpathy asked Claude to populate a Civilization-style game map with real US public data; Opus 5.5 downloaded and parsed a large amount of data, and after 7 hours and 45K lines of code it works. The map is built on a 25 km hex grid and integrates 31 data sources including Census, BEA, BLS, EIA, NOAA, USGS, DoD, NPS, FAA, FEMA, and CDC, translating economic, employment, power plant, port, airport, park, and university information into Civilization terms—for example, GDP as Gold yield. It offers 19 lenses, City View for 524 metros, nine advisors, and an Explorer that turns any column for 3,100+ counties into tables and scatter plots. Karpathy says it was built with the Claude Code desktop app using Opus 5.5, and Claude skipped a few states and territories.[^karpathy-us-civ-claude-code]
