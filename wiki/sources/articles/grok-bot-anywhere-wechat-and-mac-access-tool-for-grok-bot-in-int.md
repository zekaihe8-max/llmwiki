# Grok Bot Anywhere：微信与 Mac 接入 Grok Bot 的内测工具

*Grok Bot Anywhere: WeChat and Mac Access Tool for Grok Bot in Internal Testing*

「帖文称」铁柱AGI 发布名为 Grok Bot Anywhere 的工具，宣称已打通微信与 Grok Bot，Mac 版已完成签名公证并开放内测，Windows 版仍在申请证书；功能包括快捷键打开悬浮输入框、Tab 切换 Bot 对话、微信聊天记录转发给指定 Bot、Finder/资源管理器文件分享、其他 Agent 调用 Bot，以及每个 Bot 配置两个快捷键，其中微信 ClawBot 接入尚未实现。[^grok-bot-anywhere-wechat-mac]

The post says Tiezhu AGI released a tool called Grok Bot Anywhere, claiming to connect WeChat with Grok Bot; the Mac version is signed, notarized, and in internal testing while the Windows version awaits certificate approval. Features include hotkey-activated floating input, Tab switching between Bot chats, forwarding WeChat chat history to a designated Bot, sharing files from Finder or Windows Explorer, letting other Agents invoke the Bot, and configuring two shortcuts per Bot, while WeChat ClawBot integration remains unfulfilled.[^grok-bot-anywhere-wechat-mac]
