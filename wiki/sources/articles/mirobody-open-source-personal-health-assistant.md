# Mirobody：开源个人健康助理

*Mirobody: Open-Source Personal Health Assistant*

「帖文称」Theta Health 团队开源了 Mirobody，一款面向普通人的开源个人健康助理，内置超 6 万种医学指标的离线词库，可将多语言、多单位的检查项目统一归类；支持网页版体验或通过 Docker 在本地部署，配合 llama.cpp 运行模型，病历数据无需传至外部服务器。[^c293d1021ac2fd2e]

The post says Theta Health has open-sourced Mirobody, an open-source personal health assistant for ordinary people, with an offline dictionary of more than 60,000 medical indicators that unifies multi-language, multi-unit test items; it offers a web version or local Docker deployment with llama.cpp, so medical records do not need to be sent to external servers.[^c293d1021ac2fd2e]

## 摘要 / Summary

- 内置 6 万多种医学指标的离线词库，统一多语言、多单位的检查项目。[^c293d1021ac2fd2e]
- Built-in offline dictionary of over 60,000 medical indicators, unifying multi-language and multi-unit test items.[^c293d1021ac2fd2e]
- 支持导入 Apple Health 导出包、23andMe 等基因文件，并可连接 Garmin、Oura。[^c293d1021ac2fd2e]
- Supports importing Apple Health export packages and 23andMe genetic files, and can connect to Garmin and Oura.[^c293d1021ac2fd2e]
- 可通过 Docker 在自家电脑部署，配合 llama.cpp 运行本地模型，病历全程不用传到外部服务器。[^c293d1021ac2fd2e]
- Can be deployed via Docker on personal computers and run local models with llama.cpp, with medical records never sent to external servers.[^c293d1021ac2fd2e]
- AI 回答指标变化时，每个数字带下划线，点击可打开原始化验单核对。[^c293d1021ac2fd2e]
- When AI answers about indicator changes, each number has an underline that opens the original lab report for verification.[^c293d1021ac2fd2e]
- 整套本地版可在 16G 内存的普通电脑上运行。[^c293d1021ac2fd2e]
- The full local version can run on an ordinary computer with 16 GB RAM.[^c293d1021ac2fd2e]
