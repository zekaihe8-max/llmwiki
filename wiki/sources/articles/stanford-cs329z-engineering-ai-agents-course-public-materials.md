# 斯坦福 CS329Z 工程化 AI 智能体课程公开资料

*Stanford CS329Z Engineering AI Agents Course Public Materials*

「帖文称」斯坦福 CS329Z: Engineering AI Agents 公开课程资料已发布，讲座录像陆续上传至 Stanford Online YouTube 频道，HW1 与 HW2 两份作业仓库亦已开放并采用 MIT 许可。[^b98cbcb0b32424c1]

The post says Stanford CS329Z: Engineering AI Agents course materials are now public, with lecture videos rolling out on Stanford Online's YouTube channel and both HW1 and HW2 assignment repositories released under MIT license.[^b98cbcb0b32424c1]

## 摘要 / Summary

- 课程重点从单一大模型转向复合系统，涵盖检索器、工具、优化器等部件组合。[^b98cbcb0b32424c1]
- The course shifts focus from single LLMs to compound systems, combining retrievers, tools, optimizers, and other components.[^b98cbcb0b32424c1]
- 课表包括 Agent 结构、RAG、工具、记忆、多智能体、优化、数据、评测、安全、编程 Agent 和主动式 Agent。[^b98cbcb0b32424c1]
- The syllabus covers agent structure, RAG, tools, memory, multi-agent, optimization, data, evaluation, safety, programming agents, and proactive agents.[^b98cbcb0b32424c1]
- HW1 要求不使用现成 Agent 框架，仅用对话补全接口和自写代码搭建 Agent Harness，成本低于 5 美元 API 额度。[^b98cbcb0b32424c1]
- HW1 requires building an Agent Harness using only chat completion APIs and custom code without existing agent frameworks, costing under $5 in API credits.[^b98cbcb0b32424c1]
- HW2 使用 Harbor 框架制作接近 Terminal-Bench 风格的真实 Agent 评测任务，自拟任务占满分 100 分中的 70 分。[^b98cbcb0b32424c1]
- HW2 uses the Harbor framework to create Terminal-Bench-style real agent evaluation tasks, with self-authored tasks worth 70 out of 100 points.[^b98cbcb0b32424c1]
- 两份作业均采用 MIT 许可，HW1 由 Michael Ryan 设计，HW2 由 John Yang 设计。[^b98cbcb0b32424c1]
- Both assignments are MIT licensed; HW1 was designed by Michael Ryan and HW2 by John Yang.[^b98cbcb0b32424c1]
