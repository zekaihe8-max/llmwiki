# 宝玉谈搭 Agent 不值钱

*Dotey on building agents not being valuable*

[@dotey](https://x.com/dotey) 回应「Agent+」讨论：同意搭 Agent 不值钱，给 Agent 做工具、用 Agent 重构工作流更值钱；并类比软件开发里搭系统、装软件、写代码本身一直没那么值钱，用代码解决业务问题才值钱。[^dotey-building-agents-not-valuable] 帖文见 <https://x.com/dotey/status/2113637983333093855>。

[@dotey](https://x.com/dotey) replies in an Agent+ thread: assembling Agents is low-value; building tools for Agents and using Agents to restructure workflows matter more—just as assembling systems, installing software, and writing code have long been less valuable than solving business problems with code.[^dotey-building-agents-not-valuable] The post is at <https://x.com/dotey/status/2113637983333093855>.

- 搭 Agent 不值钱；给 Agent 做工具、用 Agent 重构工作流更值钱。[^dotey-building-agents-not-valuable]
- Assembling Agents is not valuable; building tools for Agents and using Agents to restructure workflows are more valuable.[^dotey-building-agents-not-valuable]
- 类比：搭系统、装软件、写代码本身一直没那么值钱；用代码解决业务问题才值钱。[^dotey-building-agents-not-valuable]
