# Matt Pocock 谈下一代「给 Agent 的语言」

*Matt Pocock on the next language for agents*

[@mattpocockuk](https://x.com/mattpocockuk) 主张：下一代伟大的「给 agent 的语言」应快如 Rust、设计空间少如 Go，并拥有有史以来最严的类型/验证系统；他认为 Bend 是有意思的初步尝试。[^mattpocock-language-for-agents] 原文见 <https://x.com/mattpocockuk/status/2114407583167705279>。

[@mattpocockuk](https://x.com/mattpocockuk) argues that the next great “language for agents” should be as fast as Rust, as little design space as Go, and have the strictest type/verification system ever written; he calls Bend an interesting first effort.[^mattpocock-language-for-agents] The post is at <https://x.com/mattpocockuk/status/2114407583167705279>.

## 摘要 / Summary

- 目标语言应同时满足：速度对标 Rust、设计空间对标 Go、类型与验证系统尽可能严格。[^mattpocock-language-for-agents]
- The target language should combine Rust-level speed, Go-level small design space, and the strictest type/verification system possible.[^mattpocock-language-for-agents]
- Bend 被点名为朝这一方向的有意思的初步尝试，而非终局声明。[^mattpocock-language-for-agents]
- Bend is named as an interesting first effort toward that direction, not a final verdict.[^mattpocock-language-for-agents]
