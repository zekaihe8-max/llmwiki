# OpenAI 与 AMD 合作，AI 模型助力 GPU IP 与定制推理芯片设计

*OpenAI Partners with AMD; AI Models Aid GPU IP and Custom Inference Chip Design*

「帖文称」OpenAI 与 AMD 合作，其模型在不到五个月内识别出旗舰 GPU IP 最高可达 14% 的 PPA 改进，此前 AMD 工程师已在相关设计上投入多年优化；同一方法也用于改进 OpenAI 首款定制推理芯片 Jalapeño，相关收益已在真实硅片上验证。该帖文还称，新评估显示模型在特定芯片设计任务上表现更好，OpenAI 正与 Synopsys 合作，将模型能力与 EDA 设计和验证工具推广给更多芯片设计师。[^openai-amd-chip-design-14ppa]

The post says OpenAI worked with AMD, and its models identified up to 14% PPA improvement on flagship GPU IP in less than five months, building on designs AMD engineers had already optimized for years. The same approach helped improve Jalapeño, OpenAI's first custom inference chip, with gains verified on real silicon. New evaluations show models getting better at certain chip design tasks, and OpenAI is sharing results while working with Synopsys to bring model capabilities and trusted EDA design and validation tools to more chip designers.[^openai-amd-chip-design-14ppa]
