*Meta Releases Muse Ember, a Small and Efficient Agent Model*

帖文称，Meta 今日推出 Muse Ember，称其为“最小且最高效”的模型，专为复杂推理执行和日常 Agent 工作构建。帖文还称，Muse Ember 可跨应用承载工作流、按顺序调用工具、运行测试并进行有针对性的代码修复；拥有 100 万 Token 上下文窗口，并原生理解文本、图像、音频与视频，能够处理大量文档集和多种输入。[^meta-muse-ember-release]

The post says Meta today introduced Muse Ember, calling it the "smallest and most efficient" model built for complex reasoning execution and everyday agent work.
