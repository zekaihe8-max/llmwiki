# Antigravity 交互补丁：让模型边干边说

*Antigravity interaction patch: make the model narrate while working*

帖文称，Antigravity 的默认交互方式可能让模型长时间闷头工作、很少输出信息，直到最后才给出结论。作者分享了一个小技巧：在 GEMINI.md 中加入一句话，要求模型动手前先说明要做什么，之后在有发现、换方向、卡住或连续干了四五步时再汇报，从而获得类似 Claude 或 Codex 的实时进度感。[^antigravity-gemini-md-progress]

The post says Antigravity's default interaction can make the model work silently for a long time before finally giving a conclusion. The author shares a small tip: add one sentence to GEMINI.md asking the model to state what it will do before starting, then report again when it finds something, changes direction, gets stuck, or after four or five steps, creating a real-time progress feel similar to Claude or Codex.[^antigravity-gemini-md-progress]
