# OpenAI Decisions API generally available

[@OpenAIDevs](https://x.com/OpenAIDevs) announces that the Decisions API is generally available for adding near real-time decisions to a workflow.[^openai-decisions-api-ga] The post is at <https://x.com/OpenAIDevs/status/2113346642787086538>.

## Summary

Developers can build faster, more cost-efficient apps and agents that classify text and images, evaluate inputs, and determine what happens next without generating a full model response.[^openai-decisions-api-ga]

The fetched post also surfaces an earlier [@OpenAIDevs](https://x.com/OpenAIDevs) note that Decisions API had entered public beta for all developers, letting an app choose the right model, tool, or action in near real-time, and that it made decisions up to 10x faster than GPT-6 Luna through the Responses API.[^openai-decisions-api-ga]
