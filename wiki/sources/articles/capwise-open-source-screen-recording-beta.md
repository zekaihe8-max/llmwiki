# Capwise 开源录屏内测版

*Capwise Open Source Screen Recording Beta*

帖文称，Capwise 开源录屏软件内测版已发布，录好视频后可自动生成双语字幕，支持鼠标点击自动缩放与快捷键展示，并提供摄像头美颜和录屏背景美化；此外，该工具支持 CLI，允许第三方 Agent 调用自动录屏，发帖人称示例视频由 Capwise 自身录制，实现“自闭环”，开源地址和官网见评论区。[^capwise-open-source-screen-recording-beta]
