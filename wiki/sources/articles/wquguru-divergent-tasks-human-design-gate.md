# WquGuru 谈发散任务先人类把关设计

*WquGuru on human design gates for divergent tasks*

[@wquguru](https://x.com/wquguru)（WquGuru）把与 Agent 协作分成两块：发散性强的任务（例如界面设计）最好先由人类把关设计稿再实现；发散性弱、或已有标准化 Agent Skill 的任务，单个提示词往往就能做得比较好，人类负责结果审核即可。他还补一点：模型越弱越需要事前把关，这也是他推荐「无脑选强模型」的原因——能省心很多。[^wquguru-divergent-tasks-human-design-gate] 原帖见 <https://x.com/wquguru/status/2114162927926383065>。

[@wquguru](https://x.com/wquguru) (WquGuru) splits agent collaboration into two blocks: for highly divergent tasks (e.g. UI design), humans should preferably gate the design draft before implementation; for weakly divergent tasks or ones that already have a standardized Agent Skill, a single prompt can often do well, and humans only need to review the result. He adds that weaker models need more pre-gating—that is why he recommends defaulting to strong models, which really saves hassle.[^wquguru-divergent-tasks-human-design-gate] Post: <https://x.com/wquguru/status/2114162927926383065>.

## 摘要 / Summary

- 强发散（如界面设计）：人先审设计稿，再让 Agent 实现。[^wquguru-divergent-tasks-human-design-gate]
- High divergence (e.g. UI design): humans gate the design draft first, then have the agent implement.[^wquguru-divergent-tasks-human-design-gate]
- 弱发散或已有标准化 Agent Skill：单提示词即可，人做结果审核。[^wquguru-divergent-tasks-human-design-gate]
- Low divergence or standardized Agent Skill: a single prompt can suffice; humans review results.[^wquguru-divergent-tasks-human-design-gate]
- 模型能力：越弱越需事前把关；推荐无脑选强模型以省心。[^wquguru-divergent-tasks-human-design-gate]
- Model strength: weaker models need more pre-gates; default to strong models to reduce hassle.[^wquguru-divergent-tasks-human-design-gate]
