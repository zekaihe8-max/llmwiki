# AI 时代的代码行数？工程师 Token 消费衡量什么的个案研究

*The AI Era's Lines of Code? A Case Study on What an Engineer's Token Spend Measures*

这篇 arXiv 论文通过将 JetBrains 404 名工程师五周的代理 Token 使用与提交记录关联，并调查 412 名员工，探讨 Token 消费是否能衡量工程产出。研究发现，Token 消费主要在工程师之间存在差异，且高消费者在五周内基本保持不变；在提交量相近的周内，第 90 百分位消费是第 10 百分位的 39 到 240 倍。受访者在近九成的代理评估中将代理用于编码以外的分析、研究与规划任务。作者建议，Token 消费最多只应用于资源核算，评估代理辅助工作应依据任务与结果证据。[^ai-era-lines-of-code-token-spend]

This arXiv paper links five weeks of coding-agent token usage to commits from 404 JetBrains engineers and surveys 412 employees to examine whether token spend measures engineering output. It finds that spend varies mostly between engineers, with high spenders remaining stable over five weeks; among weeks with similar commit counts, the 90th percentile of spend was 39 to 240 times the 10th. Respondents reported using agents for tasks beyond coding—such as analysis, research, and planning—in nearly nine of ten agent evaluations. The authors recommend using token spend at most for resource accounting and evaluating agent-assisted work with evidence about tasks and outcomes.[^ai-era-lines-of-code-token-spend]
