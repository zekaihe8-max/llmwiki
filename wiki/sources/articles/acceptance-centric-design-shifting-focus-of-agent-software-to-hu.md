# 验收为中心：Agent 软件设计的重心转移

*Acceptance-Centric Design: Shifting Focus of Agent Software to Human Verification*

「帖文称」即使是让 Agent 操作软件，人仍需查看结果，因此软件设计重心正转向如何让人更好地验收；文中以 Claude Artifacts、Claude Motion、Claude Design/Slides 为例，说明人机协作、标记评论以及 Agent 采访后实施等设计方向。[^2e0d656504a2cfbe]

The post argues that even when Agents operate software, humans must still review outcomes, so design focus shifts to better human acceptance; it cites Claude Artifacts, Claude Motion, and Claude Design/Slides as examples of human-agent collaboration, commenting, and Agent-led interviewing before implementation.[^2e0d656504a2cfbe]

## 摘要 / Summary

- 多人协作模式演变为人与 Agent 协作，用户可在设计稿中查看 Agent 操作历史并添加评论，Agent 回复评论后供用户再次查看。[^2e0d656504a2cfbe]
- Multi-person collaboration evolves into human-Agent collaboration; users can view Agent operation history in design drafts, add comments, and review again after Agent replies.[^2e0d656504a2cfbe]
- 传统视频剪辑需人工放大时间线波形并手动标记静音片段，Claude Motion 则允许用户框选时间段并通过评论指示 Agent 自动删除静音部分。[^2e0d656504a2cfbe]
- Traditional video editing requires manually zooming waveform timelines and marking silent segments, while Claude Motion lets users select a time range and instruct Agent via comment to automatically remove silence.[^2e0d656504a2cfbe]
- 传统软件要求用户先想清楚再实施，Claude Design 或 Claude Slides 可基于模糊想法向用户提问，用户选择后生成多个版本供挑选。[^2e0d656504a2cfbe]
- Traditional software requires users to fully formulate ideas before execution, while Claude Design or Claude Slides can ask questions based on vague ideas, generate multiple versions after user choices for selection.[^2e0d656504a2cfbe]
- 核心观点是 Agent 操作软件时，人仍然要看结果，验收成为软件设计的新重心。[^2e0d656504a2cfbe]
- The core point is that when Agents operate software, humans still need to see results, making acceptance the new focus of software design.[^2e0d656504a2cfbe]
