# Amjad 发布 Replit Agent 群体扩展定律研究

*Amjad Shares Replit Agent Swarm Scaling Laws Research*

帖文称，Replit 新研究探讨 Agent 群体的扩展定律：在固定两小时窗口内，Opus 5.5 在 NumPy 任务上从单 Agent 的 3.7x 加速提升至 32 Agent 的 18.9x；GPT-6.2 Astra 虽是最强单 Agent，但超过 8 个 Agent 后出现负扩展。研究还发现，模型会自发形成不同组织结构，去中心化群体优于依赖集中协调的群体，任务可并行性是群体表现的强预测因子，而单模型智能是集体智能的差预测因子。Replit 同时开源 Optimization-Bench。[^replit-agent-swarm-scaling-laws]

The post says Replit's new research explores scaling laws for agent swarms: within a fixed two-hour window, Opus 5.5 improved from 3.7x speedup on NumPy with one agent to 18.9x with 32 agents; GPT-6.2 Astra was the strongest solo agent but showed negative scaling beyond 8 agents. Models spontaneously developed different organizational structures, decentralized swarms scaled better than centralized coordination, problem parallelizability strongly predicted swarm performance, and individual model intelligence was a poor predictor of collective intelligence. Replit also open-sourced Optimization-Bench.[^replit-agent-swarm-scaling-laws]
