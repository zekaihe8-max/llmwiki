# PiClaw：基于 Pi Agent 的可插件个人 AI 助手工作台

*PiClaw: Plugin-based Personal AI Assistant Workbench Built on Pi Agent*

「帖文称」PiClaw 是一个开源项目，作者未重新开发 Agent 内核，而是基于 Pi Agent 搭建了完整的 Web 工作台，支持网页聊天、文件管理、代码编辑和终端操作，并可通过插件接入 SSH、Proxmox 等工具管理服务器；项目还支持定时任务、长期记忆、Dream 自动整理对话与笔记，以及 Docker 自托管和模型自由切换，旨在把 Coding Agent 变成可长期使用的 Personal Agent。[^bf62e44dfd3f2adb]

The post says PiClaw is an open-source project that, rather than redeveloping an agent kernel, builds a complete web workbench on Pi Agent. It supports web chat, file management, code editing, and terminal operations, and can connect to tools such as SSH and Proxmox via plugins. The project also supports scheduled tasks, long-term memory, Dream-based automatic organization of conversations and notes, Docker self-hosting, and free model switching, aiming to turn a coding agent into a personal agent for long-term use.[^bf62e44dfd3f2adb]
