# Cursor 推出 Live Apps，云端 Agent 可直接构建并发布可运行网页应用

*Cursor Launches Live Apps, Letting Cloud Agents Build and Publish Runnable Web Apps*

「帖文称」Cursor 推出 Live Apps，用户只需描述需求，云端 Agent 即可直接搭建可运行的网页应用，并按需创建 Postgres 数据库、配置基于 Cursor SSO 的身份验证并准备托管环境。应用完成后可预览、选域名、通过安全检查并确认发布，最终获得可分享的在线链接。官方列出的场景包括活动报名、工位安排、销售数据看板、新员工培训和工程服务门户；团队可分享给指定成员或整个组织，访问者通过 Cursor 账号登录。发布前系统会检查代码中的 API 密钥和暴露凭证，团队管理员可查看所有应用、设置安全规则并随时撤下应用。目前仅支持 Cloud Agents，本地 Agent 暂不支持。[^cursor-live-apps]

The post says Cursor has launched Live Apps, where users only need to describe requirements and a cloud agent directly builds a runnable web app, creating a Postgres database as needed, configuring Cursor SSO-based authentication, and preparing the hosting environment. After completion, users can preview, choose a domain, pass security checks, and confirm publishing to get a shareable online link. Official scenarios include event registration, desk arrangement, sales dashboards, new employee training, and engineering service portals; teams can share apps with specific members or the whole organization, with visitors logging in via Cursor accounts. Before publishing, the system checks code for API keys and exposed credentials, and team administrators can view all apps, set security rules, and take down published apps at any time. Currently only Cloud Agents are supported; local agents are not yet supported.[^cursor-live-apps]
