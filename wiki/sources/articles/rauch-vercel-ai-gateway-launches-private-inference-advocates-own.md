# Rauch：Vercel AI Gateway 上线私有推理，主张自主智能路线图

*Rauch: Vercel AI Gateway launches Private Inference, advocates owning the intelligence roadmap*

帖文称，Guillermo Rauch 发布“拥有你的智能路线图”四条原则：使用开源 SDK 与编排工具、通过网关掌握模型选择、拥有痕迹与数据并强制零数据留存，以及通过私有推理拥有模型。随后宣布 Vercel AI Gateway 现已上线私有推理（`private/<slug>`），用户可将自有微调、自托管或预发布模型与目录模型并用，使用相同 API、鉴权与日志。[^rauchg-vercel-ai-gateway-private-inference]

The post says Guillermo Rauch shared a four-point “own your intelligence roadmap” framework: use open SDKs and harnesses, own model choice via Gateways, own traces and data while enforcing ZDR, and own models with private inference. It then announces that Private Inference is now on Vercel AI Gateway, letting users bring their own fine-tuned, self-hosted, or prerelease models alongside catalog models with the same APIs, auth, and logs.[^rauchg-vercel-ai-gateway-private-inference]
