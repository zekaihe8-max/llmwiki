# Ripple-65B Preview：开源65B稠密模型

*Ripple-65B Preview: Open-Source 65B Dense Model*

帖文称，Ripple-65B Preview 是一款开源 65B 稠密模型，基于 AI2 的 Olmo 3 和 StepFun 的技术方案从头训练，训练成本 3200 万美元，支持 100 万上下文，且评分超过美国其他开源模型；发帖人还称 Qwen 系列长期未推出 70B 模型，该模型可作为平替。模型托管于 Hugging Face（ricursiveAI）。[^ripple-65b-preview]

The post presents Ripple-65B Preview as an open-source 65B dense model trained from scratch using AI2's Olmo 3 and StepFun's technical approach, at a cost of $32 million, with a 1-million-token context window and claimed scores above other U.S. open-source models; it is positioned as a substitute for Qwen's absent 70B-class models and is hosted on Hugging Face under ricursiveAI.[^ripple-65b-preview]
