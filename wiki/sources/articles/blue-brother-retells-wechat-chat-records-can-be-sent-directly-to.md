# 蓝哥转述：微信聊天记录可直发 Grok Bot，开源工具 Grok Bot Anywhere 发布

*Blue Brother Retells: WeChat Chat Records Can Be Sent Directly to Grok Bot, Open-Source Tool Grok Bot Anywhere Released*

帖文称，蓝哥AI转发了铁柱AGI开源的“Grok Bot Anywhere”工具，声称用户可通过微信官方「合并转发 → 其他应用」路径，将聊天记录以压缩包形式直接发给 Grok Bot，并在弹出悬浮框中补一句指令后发出；工具不破解微信、也不读取本地数据库。原帖表示该工具已经历多个版本迭代，现免费开源，旨在结束手动复制粘贴，帮助用户沉淀知识库、挖掘商机和提炼要点。[^wechat-grok-bot-anywhere-open-source]

The post says Blue Brother AI reposted the open-source "Grok Bot Anywhere" tool by Tiezhu AGI, claiming users can send WeChat chat records directly to Grok Bot as a compressed package via the official "merged forward → other applications" path, then add an instruction in a pop-up floating box and send; the tool allegedly neither cracks WeChat nor reads local databases. The original post states the tool has undergone multiple version iterations and is now free and open source, aiming to end manual copy-pasting and help users sink knowledge bases, mine business opportunities, and extract key points.[^wechat-grok-bot-anywhere-open-source]
