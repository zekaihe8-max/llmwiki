# Boris Cherny on Agent Skills to AAIF

[@bcherny](https://x.com/bcherny) writes that Agent Skills started as an experiment in Claude Code, and that after industry adoption Anthropic is donating it to the Agentic AI Foundation ([@AgenticAIFdn](https://x.com/AgenticAIFdn)), next to MCP.[^bcherny-agent-skills-aaif] The post is at <https://x.com/bcherny/status/2113333859907747871>.

## Summary

- Agent Skills began as a Claude Code experiment; broad adoption across the industry made donating the standard to AAIF a better fit than keeping it as a vendor-only surface.[^bcherny-agent-skills-aaif]
- The post amplifies the [@ClaudeDevs](https://x.com/ClaudeDevs) announcement that Anthropic is donating Agent Skills to AAIF (the same foundation that received MCP) and that, since December 2025, more than seventy agent platforms have integrated the standard, including ChatGPT, Cursor, GitHub Copilot, and VS Code.[^bcherny-agent-skills-aaif]
