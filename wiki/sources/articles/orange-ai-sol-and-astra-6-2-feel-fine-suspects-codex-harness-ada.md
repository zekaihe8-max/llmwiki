# Orange AI：Sol 与 Astra 6.2 体感尚可，怀疑 Codex Harness 适配导致调用变慢

*Orange AI: Sol and Astra 6.2 feel fine, suspects Codex harness adaptation causes slow calls*

「帖文称」Orange AI 使用 Sol 和 Astra 6.2 的体感还行；Tibo 指出三四天前的 KOL 测试版本存在严重问题，当前版本已好转。但多方反馈在 Codex 中调用较慢，而 Pi 及其产品 Cola 调用 API 很快，怀疑是 Codex 的 harness 适配存在问题。[^oran-ge-sol-astra-6-2-codex-harness]

The post says Orange AI finds Sol and Astra 6.2 feel fine; Tibo noted the KOL test version from three or four days ago had serious issues, but the current version has improved. However, multiple reports say calls in Codex are slow, while Pi and their product Cola call the API quickly, suspecting a Codex harness adaptation problem.[^oran-ge-sol-astra-6-2-codex-harness]
