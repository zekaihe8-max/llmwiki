# 给孩子 Vibe Coding App

*Vibe Coding Apps for Kids*

「帖文称」他儿子学习和平时玩的游戏 App，现在基本都是他 Vibe Coding 的了：看到哪个 App 要收费，就直接手搓一个，最多半小时就能用，再通过 Claude Code / Codex 边用边提要求、多轮改进。帖文还称，给孩子做的 App 并非复杂大型企业项目，Claude Opus 5.5 这类重型武器一般用不上，Flash 类模型最为合适，因为速度快、能更快看到效果并更快迭代；多模态也很实用，可用于收费 App 截图的 1:1 复刻。他还分享了一个 GitHub 上的孩子打字游戏，包含不同字母进阶和句子大写、空格等关卡；另一条关联帖文则提到把手机“小蜜蜂学习看板”改成网页版，方便大人孩子一起查看今日任务与周进度。[^give-kid-vibe-coding-app]

The post says his son's learning and gaming apps have basically been replaced by ones he vibe-coded himself: when he sees an app that charges money, he hand-codes a substitute usable within half an hour, then iterates with Claude Code or Codex. It also claims that apps made for kids are not complex enterprise projects, so heavy models like Claude Opus 5.5 are generally unnecessary; Flash-class models are most suitable because they are fast and allow quicker results and iteration, while multimodality is useful for 1:1 recreation of paid-app screenshots. He shared a GitHub typing game for kids with letter progression and levels such as sentence capitalization and spaces; a related post mentions turning the mobile "Little Bee Learning Board" into a web version so adults and children can view today's tasks and weekly progress together.[^give-kid-vibe-coding-app]
