# Ding 谈 Ideogram Vector 与工具自建模型

*Ding on Ideogram Vector and tools shipping their own models*

[@dingyi](https://x.com/dingyi)（Ding）称才看到 Ideogram Vector 1.0 模型上线：可用文字生成可编辑的 SVG，也能把任意图片转成可缩放的矢量图。[^dingyi-ideogram-vector] 他接着评论：今年下半年各家工具产品都在做自己的模型了——没有模型没有话语权，没有模型资本没有故事可讲。[^dingyi-ideogram-vector] 帖文引用 [@ideogram_ai](https://x.com/ideogram_ai) 宣布 Ideogram 首个矢量模型：从文本提示生成干净可编辑、带平滑渐变与清晰字体的 SVG，或把任意图片转为可缩放矢量；产品与 API 已上线，见 [ideogram.ai/models/vector](https://ideogram.ai/models/vector)。[^dingyi-ideogram-vector] 原帖见 <https://x.com/dingyi/status/2114009771443667379>。

[@dingyi](https://x.com/dingyi) (Ding) says he just saw Ideogram Vector 1.0 go live: text can generate editable SVGs, and any image can become a scalable vector.[^dingyi-ideogram-vector] He then comments that in the second half of this year, tool products are each building their own models—without a model there is no discourse power, and without a model capital has no story to tell.[^dingyi-ideogram-vector] The post quotes [@ideogram_ai](https://x.com/ideogram_ai) introducing Ideogram’s first vector model: generate clean, editable SVGs with smooth gradients and sharp typography from a text prompt, or turn any image into a detailed, scalable vector; live in Ideogram and the API at [ideogram.ai/models/vector](https://ideogram.ai/models/vector).[^dingyi-ideogram-vector] Post: <https://x.com/dingyi/status/2114009771443667379>.
