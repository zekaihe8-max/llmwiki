# Google AI Studio 发布 Gemini Decisions API

*Google AI Studio Launches Gemini Decisions API*

帖文称，Google AI Studio 介绍了 Gemini Decisions API，该接口由新的多模态决策模型 Gemini Decision 1 驱动，可在 AI Studio 和 Gemini API 中快速对多达 1000 个跨文本、图像、音频、视频和 PDF 的问题进行校准决策。[^google-ai-studio-gemini-decisions-api]

The post says Google AI Studio introduced the Gemini Decisions API, powered by the new multimodal decision model Gemini Decision 1, enabling fast, calibrated decisions on up to 1000 questions at once across text, images, audio, video, and PDFs via AI Studio and the Gemini API.[^google-ai-studio-gemini-decisions-api]
