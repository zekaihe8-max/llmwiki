# 小墨整理五个 Grok Bot 开源替代项目

*Xiaomo on five open-source alternatives to Grok Bot*

## 摘要 / Summary

小墨同学整理 Munder Difflin、OpenMausBot、Open Duet、Rakazo 与 OpenBot，认为多 Agent、云电脑与长期记忆的产品组合正被更多社区项目复刻；作者较推荐先看 OpenMausBot 和 Rakazo。以下均为原帖的项目介绍与判断，并非本 wiki 的实测或独立核验。[^xiaomovps-five-grok-bot-alternatives]

Xiaomo surveys Munder Difflin, OpenMausBot, Open Duet, Rakazo, and OpenBot, arguing that more community projects are recreating the combination of multiple agents, cloud computers, and long-term memory; he favors looking at OpenMausBot and Rakazo first. The following are the post’s descriptions and judgments, rather than tests or independent verification by this wiki.[^xiaomovps-five-grok-bot-alternatives]

- Munder Difflin 被描述为虚拟办公室：支持 Claude Code、Codex、Pi、OpenCode、Cursor 等十多个 Coding Agent，各有记忆、邮箱和位置，可互派任务，并复用现有 CLI 与订阅。[^xiaomovps-five-grok-bot-alternatives]
- Munder Difflin is described as a virtual office supporting over ten coding agents, including Claude Code, Codex, Pi, OpenCode, and Cursor, with individual memories, inboxes, and seats, mutual task assignment, and reuse of existing CLIs and subscriptions.[^xiaomovps-five-grok-bot-alternatives]

- OpenMausBot 使用聊天界面，各 Bot 有身份、模型和工作环境，可调用 Claude Code、Codex 等 CLI 并连接独立虚拟电脑；原帖称有 Mac、Windows、Linux 桌面客户端。[^xiaomovps-five-grok-bot-alternatives]
- OpenMausBot uses a chat interface with a separate identity, model, and work environment for each bot, can invoke CLIs such as Claude Code and Codex, and can connect to independent virtual computers; the post reports desktop clients for Mac, Windows, and Linux.[^xiaomovps-five-grok-bot-alternatives]

- Open Duet 偏 AI 员工管理，包含派活、长期记忆、定时任务、多 Agent 协作、任务看板与操作审批，可用 Claude Code 或 Codex 执行，并部署在自有服务器。[^xiaomovps-five-grok-bot-alternatives]
- Open Duet focuses on AI employee management, including task assignment, long-term memory, scheduled tasks, multi-agent collaboration, task boards, and action approval; it can use Claude Code or Codex for execution and run on a self-managed server.[^xiaomovps-five-grok-bot-alternatives]

- Rakazo 基于 Pi Agent，提供长期记忆、定时任务、多 Bot 协作及浏览器、终端和独立电脑；原帖称有 Web、桌面、iPhone 和 Android 客户端，支持 Docker 与 VPS 常驻部署。[^xiaomovps-five-grok-bot-alternatives]
- Rakazo builds on Pi Agent and offers long-term memory, scheduled tasks, multiple cooperating bots, browsers, terminals, and independent computers; the post reports web, desktop, iPhone, and Android clients plus Docker and persistent VPS deployment.[^xiaomovps-five-grok-bot-alternatives]

- OpenBot 被描述为本地优先的多 Agent 工作台，支持 Claude Code、Codex、Grok、OpenCode、Gemini，各 Agent 有独立目录和会话，可传消息、文件及控制浏览器；原帖称支持桌面和服务器部署，但仍是开发预览、默认执行权限较高，采用非商业许可证。[^xiaomovps-five-grok-bot-alternatives]
- OpenBot is described as a local-first multi-agent workbench supporting Claude Code, Codex, Grok, OpenCode, and Gemini, with individual work directories and sessions, messaging, file transfer, and browser control; the post reports desktop and server deployment, but calls it a development preview with broad default execution permissions and a noncommercial license.[^xiaomovps-five-grok-bot-alternatives]
