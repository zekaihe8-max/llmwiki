*Can Qwen4-Max Preview Get Things Done After 229 Unattended Rounds?*

This post says Hua Shu built a benchmark suite for Qwen4-Max Preview and tested it across coding, frontend, 3D and Blender modeling via Qianwen APP, Token Plan and Claude Code, including unattended long-horizon agent tasks, with head-to-head comparisons against Opus 5.5.[^82d4d15a9be0bd11]

- Qwen4-Max 预览版在鲁布·戈德堡机械连锁机关题上无人值守连续运行 229 轮，超过一个半小时，直至测试额度被跑光。[^82d4d15a9be0bd11]
