# Hermes Mobile Beta 公测，个人 Agent 进军手机端

*Hermes Mobile Beta Launches, Personal Agents Move to Mobile*

「帖文称」Nous Research 近期开放了 Hermes Mobile Beta，iOS 与 Android 均可申请测试；发布者表示，此前主要通过 Telegram 或远程连接使用 Hermes，现终于有官方手机客户端，可远程接管部署在 VPS 上的 Hermes Gateway、在手机直接审批工具调用，并管理服务器上长期运行的 Routines 自动化任务。官网为 hermes-agent.nousresearch.com/mobile。[^cd302a925373b515]

The post says Nous Research has opened Hermes Mobile Beta for iOS and Android; the author previously used Hermes via Telegram or remote connection and now welcomes the official mobile client, which can remotely take over a Hermes Gateway hosted on a VPS, approve tool calls directly on the phone, and manage Routines automation tasks running on the server. Official site: hermes-agent.nousresearch.com/mobile.[^cd302a925373b515]
