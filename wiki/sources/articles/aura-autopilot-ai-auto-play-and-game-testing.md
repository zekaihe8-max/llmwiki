# Aura Autopilot：AI 自动玩游戏与测试游戏

*Aura Autopilot: AI Auto-Play and Game Testing*

「帖文称」Aura 开源了 Autopilot，以插件形式集成到虚幻引擎 5、Unity 6 或 Godot 4，开发者可配合 Claude Code 或 Codex 下达指令，让 AI 像真人玩家一样自动跑图、探索、攻击和决策，并在测试后生成排查报告，指出穿模或卡顿；帖文还声称其比 Claude Code 更准确、更快，并能“打通智能体循环”。[^aura-autopilot]

The post says Aura has open-sourced Autopilot, a plugin for Unreal Engine 5, Unity 6, and Godot 4 that lets developers use Claude Code or Codex to direct an AI agent to play games like a human—running, exploring, attacking, and making decisions—then automatically close the window and emit a report flagging clipping or stalls. It also claims 43% higher accuracy, nearly 2x speed, and better playtesting than Claude Code.[^aura-autopilot]
