# Shopify 移动应用攻击面地图与 Agent 安全审查

*Shopify Mobile App Attack Surface Map and Agent Security Review*

帖文称，Shopify 移动应用代码吞吐已达去年同期的 11 倍，12 周重写期间平均每周改动约 43.4 万行；团队为每个应用按深链、WebView、本地存储、权限、依赖绘制攻击面地图，由专属 Skill 生成并每日对照变更审查，每次只审一项，结论仅限五种，并与 Agent 漏洞扫描器 Dispatch 互补。[^shopify-agentic-attack-surface-map]

The post claims Shopify's mobile app code throughput is 11x the same period last year, with ~434,000 lines changed weekly during a 12-week rewrite; the team draws attack surface maps for each app by deep links, WebViews, local storage, permissions, and dependencies, generated by dedicated Skills and reviewed daily against changes, one item at a time, with conclusions limited to five types, complementing the Agent vulnerability scanner Dispatch.[^shopify-agentic-attack-surface-map]

## 摘要 / Summary

- 代码吞吐提升：Shopify 移动应用代码吞吐是去年同期的 11 倍，12 周重写期间平均每周改动约 43.4 万行，去年同期约 3.9 万行。[^shopify-agentic-attack-surface-map]
- Code throughput: Shopify mobile app code throughput is 11x the same period last year; during the 12-week rewrite, average weekly changes were ~434,000 lines versus ~39,000 lines last year.[^shopify-agentic-attack-surface-map]
- 攻击面地图分类：每个应用维护安全敏感清单，按深链、WebView、本地存储、权限、依赖分类，每条附结论和代码链接，结论仅允许修复、权衡、安全、已修复、仅调试五种。[^shopify-agentic-attack-surface-map]
- Attack surface map categories: each app maintains a security-sensitive list categorized by deep links, WebViews, local storage, permissions, and dependencies; each item includes a conclusion and code link, with conclusions limited to fix, tradeoff, safe, fixed, and debug only.[^shopify-agentic-attack-surface-map]
- Skill 生成与复用：地图由按类别划分的 Skill 生成，起点是 OWASP MASVS/MASTG 并叠加历史漏洞，同一 Skill 供定时审查、一次性评审和代码中 Agent 使用。[^shopify-agentic-attack-surface-map]
- Skill generation and reuse: maps are generated by category-specific Skills starting from OWASP MASVS/MASTG plus historical vulnerabilities; the same Skills serve scheduled reviews, one-time assessments, and Agents working in code.[^shopify-agentic-attack-surface-map]
- 单项逐日审查：模型每个工作日对比最新提交与已接受地图，仅在引用代码行或盘点结果变化时判定为变更，并只审查相关代码，每条回答检查格式、行号范围、措辞并确认不含密钥。[^shopify-agentic-attack-surface-map]
- Single-item daily review: the model compares the latest commit with the accepted map each workday, flags changes only when referenced code lines or inventory results changed, reviews only relevant code, and checks every answer for format, line ranges, wording, and absence of secrets.[^shopify-agentic-attack-surface-map]
- Dispatch 互补与闭环：攻击面地图是 Agent 漏洞扫描器 Dispatch 的补充，每发现并修复一个漏洞，下一次检查会更严；Agent 还会阅读安全新闻并仅在相关时提醒团队。[^shopify-agentic-attack-surface-map]
- Dispatch complement and closed loop: attack surface maps supplement the Agent vulnerability scanner Dispatch; every found and fixed vulnerability makes the next check stricter, and Agents read security news to alert the team only when relevant.[^shopify-agentic-attack-surface-map]
