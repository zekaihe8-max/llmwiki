# 斯坦福 CS329Z AI Agent 工程课程资料全面公开

*Stanford CS329Z AI Agent Engineering course materials fully released*

「帖文称」斯坦福新课 CS329Z“AI Agent 工程”已开始对外公开全部课程资料，讲座视频每日在 Stanford Online YouTube 频道发布，两份作业代码仓库托管于 GitHub 并采用 MIT 协议，校外自学者可注明出处后使用。[^stanford-cs329z-ai-agent-engineering-course-publ]

The post says Stanford's new course CS329Z "Engineering AI Agents" has begun releasing all course materials publicly, with lecture videos posted daily on the Stanford Online YouTube channel and two assignment code repositories hosted on GitHub under the MIT license for external self-learners to use with attribution.[^stanford-cs329z-ai-agent-engineering-course-publ]

## 摘要 / Summary

- 讲座视频每日上 YouTube，已上第 1 讲《什么是 agent 系统》和第 2 讲《写给 agent 开发者的大模型知识》，第 1 讲播放量过 9 万。[^stanford-cs329z-ai-agent-engineering-course-publ]
- Lecture videos are released daily on YouTube; Lecture 1 "What is an Agent System" and Lecture 2 "LLM Knowledge for Agent Developers" are already up, with Lecture 1 exceeding 90,000 views.[^stanford-cs329z-ai-agent-engineering-course-publ]
- 第一份作业禁止使用任何 Agent 框架，只提供最原始接口，要求从零实现 Agent Harness，包括邮件优先级判断、BM25 检索、多跳问答及虚构能源公司内部助理等功能。[^stanford-cs329z-ai-agent-engineering-course-publ]
- Assignment 1 prohibits any Agent frameworks and provides only the most basic interface, requiring students to build an Agent Harness from scratch, including email priority classification, BM25 retrieval, multi-hop QA, and an internal assistant for a fictional energy company.[^stanford-cs329z-ai-agent-engineering-course-publ]
- 作业一自动评分 88 分中有 48 分来自不调用模型的测试，参考答案跑完全部线上测试花费约 0.05 美元，模拟用户评测再花 0.18 美元。[^stanford-cs329z-ai-agent-engineering-course-publ]
- Of the 88 auto-graded points in Assignment 1, 48 come from tests that do not call models; running the full online tests with the reference solution costs about $0.05, plus $0.18 for simulated-user evaluation.[^stanford-cs329z-ai-agent-engineering-course-publ]
- 第二份作业由 SWE-bench 共同作者 John Yang 设计，教用 Harbor 制作 Terminal-Bench 风格题目，占 70% 分数的是自出一道题并用 mini-SWE-agent 配 Gemini 3.8 Flash 跑五次分析。[^stanford-cs329z-ai-agent-engineering-course-publ]
- Assignment 2, designed by SWE-bench co-author John Yang, teaches creating Terminal-Bench-style questions using Harbor; 70% of the score comes from authoring a new question and analyzing it with mini-SWE-agent and Gemini 3.8 Flash over five runs.[^stanford-cs329z-ai-agent-engineering-course-publ]
- 课程由 Diyi Yang 与博士生 Michael Ryan、John Yang 讲授，后续还会有 Andrew Ng 炉边对谈及 SWE-bench 两位作者的客座讲座，主要资助方包括 Laude Institute、Thinking Machines、Google Cloud、AWS 和 Harbor。[^stanford-cs329z-ai-agent-engineering-course-publ]
- The course is taught by Diyi Yang and PhD students Michael Ryan and John Yang, with future fireside chats by Andrew Ng and guest lectures by two SWE-bench authors; major sponsors include Laude Institute, Thinking Machines, Google Cloud, AWS, and Harbor.[^stanford-cs329z-ai-agent-engineering-course-publ]
