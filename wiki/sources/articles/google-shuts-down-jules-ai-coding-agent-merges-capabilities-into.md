# Jules 并入 Antigravity，Google 停止 AI 编程 Agent Jules

*Google Shuts Down Jules AI Coding Agent, Merges Capabilities Into Antigravity*

「帖文称」Google 正在逐步关停 AI 编程 Agent Jules，并将其异步远程执行能力整合进 Antigravity。Jules 的核心价值在于用户可下达任务后合上电脑，让其自行继续工作；目前关键问题是 Antigravity 是否能完整继承这项能力。帖文还讽刺称，Jules 可能是 Google 产品坟场中第一个能自己写讣告的产品。[^jules-antigravity-google-agent]

The post says Google is gradually shutting down the AI coding agent Jules and integrating its asynchronous remote execution capabilities into Antigravity. Jules's core value was letting users assign a task and close their computer while it kept working independently; the key question is whether Antigravity can fully inherit that capability. The post also jokes that Jules may be the first product in Google's graveyard able to write its own obituary.[^jules-antigravity-google-agent]
