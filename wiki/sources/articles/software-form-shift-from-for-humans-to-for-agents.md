# 软件形态变化：从“给人用”到“给 Agent 用”

*Software Form Shift: From "For Humans" to "For Agents"*

「帖文称」当年 Google Docs 通过从“单机”到“云端”的转变颠覆本地 Office；如今 Claude Artifacts 代表软件正从“给人用”变成“给 Agent 用，人审查微调”，使用软件的主体变了，软件形态也就彻底变了。文中还提到 Claude 新增白板和表格（测试版，付费套餐可用），仪表盘改名 Claude Data 正式上线。[^software-form-shift-to-agent-use]

The post claims that just as Google Docs disrupted local Office by shifting from "desktop" to "cloud," Claude Artifacts represents software shifting from "for humans" to "for Agents, with humans reviewing and tweaking." Since the subject using software has changed, the form of software has changed fundamentally. It also notes Claude added whiteboards and sheets (beta, available to paid plans), and dashboards were renamed Claude Data and officially launched.[^software-form-shift-to-agent-use]
