# 让 HungerG 按玻璃按钮风格做组件，仅用两轮

*HungerG creates glass-button component set in just two rounds*

帖文称，用户丁丁（@dingyi）此前分享的 theca.media 中的玻璃质感按钮让他印象深刻，于是让神秘模型 HungerG 按照该风格制作一套组件，底层基于 Vercel 的 ui-sdk.dev。实际运行仅用了两轮，速度很快，体感接近 DeepSeek V4.1 Flash；复刻效果整体尚可，玻璃质感基本呈现，但细节仍需手动调整才能完全一致。他表示，过去设计师维护一套设计系统需花费大量时间，如今只需一句话即可。此外，他推荐关注 Vercel 的 UI SDK，称其并非普通组件库，而是面向 AI Agent 的「交互行为积木 + 无样式组件 + Agent 操作接口」，现有组件库可基于它重构。HungerG 在 OpenCode 和 Qoder 免费至 30 号，Qoder 可能排队，可用 OpenCode Go 套餐。Demo 源码已放在 GitHub。[^dingyi-status-2125514605573378096]

The post says user Ding (@dingyi) was impressed by the glassmorphism buttons in theca.media he previously shared, so he asked the mysterious model HungerG to create a set of components in that style, based on Vercel's ui-sdk.dev. It took only two rounds in practice, very fast, subjectively comparable to DeepSeek V4.1 Flash; the replication is generally acceptable with the glass texture basically achieved, though details still need manual tweaking to be identical. He noted that maintaining a design system used to take designers a lot of time, but now it takes just one sentence. He also recommends Vercel's UI SDK, describing it not as an ordinary component library but as "interaction behavior building blocks + unstyled components + Agent operation interfaces" for AI Agents, with existing component libraries refactorable on top of it. HungerG is free on OpenCode and Qoder until the 30th; Qoder may have queues, while OpenCode Go is available without waiting. Demo source code is on GitHub.[^dingyi-status-2125514605573378096]
