# Antigravity 体验三件套：Superpowers、Context7 与 UI UX Pro Max

*Antigravity Experience Trio: Superpowers, Context7, and UI UX Pro Max*

「帖文称」谷歌 Antigravity（AGY）体验不尽如人意，可通过安装开源插件或 Skill 进行优化。小墨同学挑选了三款热门开源项目：拥有 32.2 万 Star 的 Superpowers 用于 AI 编程前的规划与执行、拥有 6.5 万 Star 的 Context7 用于获取较新开发文档和 API 用法、以及拥有 15.2 万 Star 的 UI UX Pro Max 用于提升前端设计能力。作者个人更推荐先尝试 Superpowers 和 Context7，UI UX Pro Max 仅在有前端开发需求时安装。[^antigravity-experience-three-piece-suite]

The post claims Google Antigravity (AGY) is not very usable and can be improved with open-source plugins or Skills. Xiaomou Tongxue selected three popular open-source projects: Superpowers with 322k stars for AI coding planning and execution, Context7 with 65k stars for up-to-date developer docs and API usage, and UI UX Pro Max with 152k stars for frontend design. The author personally recommends trying Superpowers and Context7 first, and installing UI UX Pro Max only if frontend development is needed.[^antigravity-experience-three-piece-suite]

## 摘要 / Summary

- Superpowers 拥有 32.2 万 Star，主要提升 AI 编程工作流，让 Agent 在写代码前先做规划，再按步骤执行、测试和 Debug。[^antigravity-experience-three-piece-suite]
- Superpowers has 322k stars and mainly improves AI coding workflow, making the Agent plan before writing code, then execute, test, and debug step by step.[^antigravity-experience-three-piece-suite]
- Context7 拥有 6.5 万 Star，解决 AI 使用过时文档问题，可获取较新开发文档和 API 用法，减少版本不匹配和 API 调用错误。[^antigravity-experience-three-piece-suite]
- Context7 has 65k stars and solves the problem of AI using outdated documentation, providing newer developer docs and API usage to reduce version mismatches and API call errors.[^antigravity-experience-three-piece-suite]
- UI UX Pro Max 拥有 15.2 万 Star，提升 AI 前端设计能力，提供大量设计风格、配色方案、字体和布局规范。[^antigravity-experience-three-piece-suite]
- UI UX Pro Max has 152k stars and improves AI frontend design capabilities, offering many design styles, color schemes, fonts, and layout standards.[^antigravity-experience-three-piece-suite]
- 作者说明三者并非必须安装，Antigravity 本身也有对应能力；个人推荐先尝试 Superpowers 和 Context7，无前端需求可不装 UI UX Pro Max。[^antigravity-experience-three-piece-suite]
- The author notes none of the three are mandatory since Antigravity has corresponding capabilities; personally recommends Superpowers and Context7 first, and skipping UI UX Pro Max without frontend needs.[^antigravity-experience-three-piece-suite]
