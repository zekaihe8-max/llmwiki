# 宝玉谈 ChatGPT Pro/Business 每月送 API 额度

*Dotey on ChatGPT Pro/Business monthly API credits*

[@dotey](https://x.com/dotey)（宝玉）整理 OpenAI 2026 年 10 月 28 日宣布的政策：付费 **ChatGPT Pro** 与 **Business** 订阅用户可在订阅内每月领取一笔 API 额度，最高 **500 美元**，不另收费；以前 ChatGPT 订阅与 API 按量是两本账，现在额度算在订阅里。[^dotey-chatgpt-pro-business-api-credits] 原帖 <https://x.com/dotey/status/2115591064073413118>。

[@dotey](https://x.com/dotey) summarizes OpenAI’s October 28, 2026 announcement: paid **ChatGPT Pro** and **Business** subscribers can claim monthly **API credits** inside the subscription, up to **$500**, at no extra charge; ChatGPT membership and pay-as-you-go API used to be separate bills, and the allowance now sits in the subscription.[^dotey-chatgpt-pro-business-api-credits] Post: <https://x.com/dotey/status/2115591064073413118>.

## 摘要 / Summary

- **谁能领**：Pro 与 Business；**Plus、Go、免费版、Enterprise 没有**。[^dotey-chatgpt-pro-business-api-credits]
- **Who can claim**: Pro and Business; **Plus, Go, free, and Enterprise are excluded**.[^dotey-chatgpt-pro-business-api-credits]
- **Pro 额度**：按档位每月 **100、200 或 500 美元**；据 CellCog 转述，额度与各档月费相等，相当于订阅费原样变成 API 额度。[^dotey-chatgpt-pro-business-api-credits]
- **Pro allowance**: **$100, $200, or $500** per month by tier; per CellCog’s relay, the credit matches each tier’s monthly fee—subscription fee effectively becomes API credit.[^dotey-chatgpt-pro-business-api-credits]
- **Business 额度**：标准席位每席 **20 美元**、高级席位每席 **100 美元**，工作区合并使用，**上限 500 美元**（约 25 个标准或 5 个高级席位封顶，再加人不涨）。[^dotey-chatgpt-pro-business-api-credits]
- **Business allowance**: **$20** per standard seat and **$100** per advanced seat, pooled for the workspace, **capped at $500** (about 25 standard or 5 advanced seats max; more seats do not raise the cap).[^dotey-chatgpt-pro-business-api-credits]
- **资格细节**（据 CellCog 转述帮助页）：订阅须满 **7 天**；免费试用与赠送订阅不算；官方推文与两家媒体未写地区限制。[^dotey-chatgpt-pro-business-api-credits]
- **Eligibility detail** (CellCog relay of the help page): subscription must be **7+ days** old; free trials and gifted subs do not qualify; the official tweet and both media pieces do not mention regional limits.[^dotey-chatgpt-pro-business-api-credits]
- **怎么领**：ChatGPT **设置 → 账单** 领取，绑定同一邮箱名下的 API 组织；Business 由工作区管理员在账单或管理后台领取。领完后可在 ChatGPT 或 Codex 里用 **OpenAI Developers** 插件生成 API key、建项目，**不必先绑信用卡**。[^dotey-chatgpt-pro-business-api-credits]
- **How to claim**: **Settings → Billing** in ChatGPT, link an API organization under the same email; Business admins claim in billing or admin console. After claiming, use the **OpenAI Developers** plugin in ChatGPT or Codex to create API keys and projects **without binding a credit card first**.[^dotey-chatgpt-pro-business-api-credits]
- **能花在哪**：OpenAI 开发者平台大部分服务——对话与智能体、实时语音、图片，以及联网搜索、代码解释器等内置工具。[^dotey-chatgpt-pro-business-api-credits]
- **Where it spends**: most OpenAI developer-platform services—chat and agents, realtime voice, images, and built-in tools such as web search and code interpreter.[^dotey-chatgpt-pro-business-api-credits]
- **限制**（据 CellCog 转述帮助页）：当月有效、周期结束清零不结转，首月按剩余天数折算；**用 API key 跑 Codex 不能花这笔额度**；**也不提高 ChatGPT/Codex 应用内使用上限**（两边各算各的）；先用赠送额度再用自充，两笔都花完则请求报错，除非开自动充值。[^dotey-chatgpt-pro-business-api-credits]
- **Limits** (CellCog relay of help page): valid for the billing month only, no rollover, first month prorated; **Codex via API key cannot spend these credits**; **does not raise in-app ChatGPT/Codex usage caps** (separate pools); gifted credits spend first, then paid balance—both empty yields errors unless auto-recharge is on.[^dotey-chatgpt-pro-business-api-credits]
- **出处说明**：OpenAI 帮助中心原文这次未能直接打开；推文外细则来自 AlphaSignal 与 CellCog 对帮助页的转述，两家一致的部分包括 Plus/Enterprise 不能领、额度不累积、Codex 不能用；满 7 天与同一邮箱等细节仅 CellCog 写了。[^dotey-chatgpt-pro-business-api-credits]
- **Provenance note**: the OpenAI Help Center article could not be opened directly this time; details beyond the tweet come from AlphaSignal and CellCog relays of the help page—both agree on Plus/Enterprise exclusion, no rollover, and Codex exclusion; 7-day age and same-email rules appear only in CellCog.[^dotey-chatgpt-pro-business-api-credits]
