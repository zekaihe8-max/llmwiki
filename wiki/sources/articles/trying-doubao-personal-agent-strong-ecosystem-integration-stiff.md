# 试了豆包个人 Agent：生态整合亮眼，连接器引导生硬

*Trying Doubao Personal Agent: Strong Ecosystem Integration, Stiff Connector Onboarding*

「帖文称」豆包 personal agent 终于开始内测，作者试用后认为与飞书、抖音、汽水音乐等字节系产品整合较好，内置购票、苹果健康等连接器，并提供 2 核 4G、10G 硬盘、Ubuntu 的云端电脑；主动性方面，它在查天津火车票时顺带推荐了杭盖乐队演出。不足之处在于上来就引导添加抖音、健康、日历等连接器，不如 Muse 和 Grok Bot 的渐进式触发，且百度云盘等个别连接器配置不便或不稳定。作者仍看好字节 PA 产品迭代与未来前景。[^doubao-personal-agent-internal-test]

The post says Doubao's personal agent has entered internal testing; the author finds good integration with ByteDance products such as Feishu, Douyin, and Soda Music, built-in connectors for tickets and Apple Health, and a cloud computer with 2 vCPUs, 4 GB RAM, 10 GB disk running Ubuntu. It showed proactivity by recommending a Hangai Entertainment concert while checking Tianjin train tickets. Downsides include upfront onboarding to add Douyin, Health, and Calendar connectors—felt stiffer than Muse and Grok Bot's progressive triggering—and inconvenient or unstable configuration for some connectors such as Baidu Cloud Drive. The author remains optimistic about ByteDance's personal agent products.[^doubao-personal-agent-internal-test]
