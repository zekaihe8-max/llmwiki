# UI SDK：智能体构建 UI 的 x86 指令集

*UI SDK: The x86 Instruction Set for Agent-Built UI*

帖文称，在智能体时代，框架与组件库需要更深入钻研，通过删除冗余、优化、加速和自动化来适应新形态。格雷莫·劳奇（Guillermo Rauch）将 UI SDK 比作智能体自发构建新 UI 组件的 x86 指令集，并称智能体是新的设计工程师，能够根据用例构建任何 UI。高级、僵化的单一框架抽象被描述为这种无限创造机器的氪石。UI SDK 被宣传为提供可访问性、性能和凝聚力的打包行为，同时节省 Token、减少错误和精力，且对可生成的 UI 没有限制和权衡。[^rauchg-ui-sdk-agents-era]

The post argues that in the agent era, frameworks and component libraries must go deeper—deleting, optimizing, accelerating, and automating. Guillermo Rauch likens UI SDK to the x86 instruction set that lets agents spontaneously build new UI components, calling agents the new design engineers capable of building anything tailored to a use case. High-level, rigid, single-framework abstractions are described as kryptonite to this infinite creation machine. UI SDK is presented as packaged behaviors delivering accessibility, performance, and cohesion while saving tokens, errors, and effort, with zero limitations or tradeoffs for generated UIs.[^rauchg-ui-sdk-agents-era]
