## 小墨同学 @xiaomovps

**把 Grok Bot 从 100 刀降到 30 刀**：不是额度不够，是整体不好用了。他最烦模型不能自己选、路由越来越偏向自家 Grok，任务结果不稳定；额度消耗还不透明，有些活没干好还得拿 Claude 或 GPT 擦屁股，总订阅费反而更高。他已经在看 OpenBot 和 OpenMausBot，两者都支持自选模型和运行环境，并提供从 Grok Bot 迁数据的路子，核心判断是 Personal Agent 不能绑死一家，知识和记忆最好留在自己手里。[原帖](https://x.com/xiaomovps/status/2119664340278378659)

**好 Personal Agent 的三个条件**：基座模型要稳，随机路由会让同任务时灵时不灵；UI 和任务反馈要够，Muse 会阶段性汇报或给任务卡片，Grok Bot 有时后台干活完全没提示；应用生态要通，连不上别的服务就还是信息孤岛。他自己总结成四个字：低打扰、高智能，理想状态是它自主干活，做完简单汇报，只在需要你介入时才喊人。[原帖](https://x.com/xiaomovps/status/2119637854888378691)

**DSH 3.5 万插件后开始担心稳定性**：官方数据是 154 万日活、约 3.5 万第三方插件、六成活跃用户装过或做过插件。有人从 0.2.1-rc.5 升到 0.2.2-rc.1，34 个插件 Bundle 只剩 2 个，花了约 5 小时才恢复。他提了三件事：插件 API 要有兼容期、市场要标兼容版本和维护状态、升级前要能备份和一键回滚；社区里还有人做了 dsh-plugin-health 做兼容检查。[原帖](https://x.com/xiaomovps/status/2119694729927671820)

**学习 Pi 必读的 5 篇文章**：从 Getting Started、半年实战体会，到中文扩展开发手册、SDK 才是重点的发票系统案例，再到把长期记忆、异步 Subagent、Discord 遥控和 MCP 网关拼成个人栈。官方还点名了 4 个社区插件：自媒体工作台、歸藏设计、上下文可视化、论文阅读器。[Pi 书单](https://x.com/xiaomovps/status/2119717470730940740) · [官方推荐插件](https://x.com/xiaomovps/status/2119733737126563952)

看法：降级和三条件其实是一件事，大家开始拿「能不能换、数据能不能带走」来衡量私人 Agent。

## 思维怪怪 @0xLogicrw

**Pinky：RSSHub 作者 DIYgod 开源的真机控制**：Codex、Claude Code 等经 MCP 就能看屏、开 App、点滑和打字，电脑端覆盖 Mac、Windows、Linux。安卓走 ADB + scrcpy，Android 13 以上还能开隐藏虚拟屏让 AI 在后台操作；iOS 27 及以上用 CoreDevice，更早版本仍靠 WDA。敏感操作写在控制程序里：付款转账前暂停等人批，60 秒未确认就拒绝，银行钱包密码管理器默认对 Agent 隐藏，每步有录屏留在本机。[原帖](https://x.com/0xLogicrw/status/2119638011763941577) · [GitHub](https://github.com/DIYgod/pinky)

**Swipt：自动化跑在 iPhone 本机**：多数 iPhone Use 要电脑常驻，Swipt 装好后不必 Mac 挂着，靠 CoreDevice、设备配对和环回 VPN 读无障碍控件树。内置 JS 运行时，Agent 可经 MCP 一次提交多步脚本；还能装 Swiplet 插件，官方做了类似「李跳跳」的开屏广告跳过。目前优先 iOS 27，免费账号签名大约每 7 天续一次。[原帖](https://x.com/0xLogicrw/status/2119750796476829832) · [官网](https://swipt.io/)

**GitHub Rubicon：为 Agent 并行改仓**：内部测试里 5000 个 Agent 同仓工作，每秒约 7200 次推送。关键是把「存代码」和「更新分支」拆开，用 Ref-CAS 管分支指针，不同分支可同时更新，全仓只维护一个统一版本号方便读取。仍在有限私测，计划 2027 年初扩大上线。[原帖](https://x.com/0xLogicrw/status/2119744561660764353)

**阿里云 Token Plan 个人版加量约 74% 到 78%，价格不变**：Lite 39 元从 1.15 万增到 2 万 Credits，Essential 和 Standard 同步加量；Pro 从 499 元降到 312 元并加到 20 万。按 Credit 单价算，四档成本大约都降四成多，存量用户会补当前周期额度。[原帖](https://x.com/0xLogicrw/status/2119674363490476145)

看法：Phone Use 从「电脑遥控手机」走到「手机自己跑脚本」，Git 基础设施也在按 Agent 并发重写。

## meng shao @shao__meng

**Garry Tan 开源 g-harness-evals**：同一模型只换 harness（系统提示、工具、记忆），比谁更准、谁更省。任务是虚构公司 Pemberline 的模拟 Slack，agent 当团队机器人处理权限、审批和后续纠正，主榜 20 道公开开发集。准确率大约都在 71% 到 79%，区分不开；真正拉开的是成本和速度，Opus 上 OpenClaw 解一题约 0.44 美元、中位约 99 秒，其余约 0.19 到 0.24 美元、Claude Code 和 QM 大约 40 秒。[原帖](https://x.com/shao__meng/status/2119715268393836956) · [GitHub](https://github.com/garrytan/g-harness-evals)

**给孩子 Vibe Coding App**：看到要收费就手搓一个，半小时内能用，边用边让 Claude Code / Codex 改几轮。这种小场景一般用不上 Opus 5.5，Flash 就够。[原帖](https://x.com/shao__meng/status/2119678626442662111)

**PMs are back**：转述 Lenny 播客对谈 Gemini 产品负责人 Tulsee Doshi。AI 降低了实现成本，却没降低选错方向的代价；当「能不能做出来」不再最难，做什么、什么算好、押注什么就更值钱。[原帖](https://x.com/shao__meng/status/2119632702014132569)

看法：harness 评测把「外围设计」从玄学变成可比成本的数字，给孩子做 App 则提醒很多场景根本不需要最贵模型。

## Gorden Sun @Gorden_Sun

**确认：Grok Bot 免费重置了，而且不是假重置**：原重置时间不变，和那种清完立刻再扣的玩法不一样，和铁柱的观察对得上。[原帖](https://x.com/Gorden_Sun/status/2119684410715054217)

**billion-context：省上下文的 Agent 插件**：在客户端和模型之间做智能中继，把早先历史折叠压缩，需要时再还原，宣称可把消耗压到约五分之一，并维持较高前缀缓存命中。向上下文注入 compress、decompress、search_context、acp_status 四个工具，由模型自己判断何时打包旧对话。[原帖](https://x.com/Gorden_Sun/status/2119742606460813495) · [GitHub](https://github.com/ranxianglei/billion-context)

看法：重置是短期情绪，上下文中继这种东西才决定长会话能不能便宜地跑下去。

## WquGuru @wquguru

**在 Cicada 里跑隐式状态机提示词**：`find all of the implicit state machines in my app`，实测找出 18 个，其中 5 个值得优化，用来提升健壮性。和今天前沿简报里 Vox 聊状态机是同一条线，这边是落地到自己产品上的结果。[原帖](https://x.com/wquguru/status/2119630602366488732)

**插件被官方内置怎么办**：Tianyi 用手机 OS 作答：出厂自带闹钟计算器，但系统方更希望有人做出更好的，甚至做出发明者没想过的 App。DSH 想做 Agent 时代操作系统，官方功能也是插件，可被第三方替换；他复述了 154 万日活、约 92 万亿日 Token、3.5 万插件，以及官方点名的几个社区作品。[原帖](https://x.com/wquguru/status/2119463877583028631)

看法：状态机提示词适合定期扫自己的产品，OS 叙事则把「被官方吃掉」从恐惧改写成可替换的契约。
