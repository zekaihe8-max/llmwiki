## 歸藏 @op7418

**一下午做出 3D 动作游戏「雾锁山门」**：Fable 5.2 只用一下午、45 亿 token，就把模型、场景、动作和优化全做完，全部融合进一个 30 兆的 HTML 文件。他自己也觉得这制作能力太恐怖了，并放出了网页试玩。[原帖](https://x.com/op7418/status/2120694045299327187) · [试玩](https://op7418.github.io/guizang-game-skill/)

**他认为网页游戏要回到日常生活里**：这类 3D 游戏都能压进一个 HTML，手机和电脑打开就能玩，发布方式最方便、适配的平台也最多。他甚至说「4399 即将迎来复兴」，并提到前阵子已有人把《GTA5》移植成网页。[网页游戏](https://x.com/op7418/status/2120700493634867417) · [4399](https://x.com/op7418/status/2120541276970094774)

**想用 skill 加 DeepSeek Harness 复刻 Fable**：玩过「雾锁山门」之后，他公开问朋友，能不能用自己的 skill 和 DeepSeek Harness 做出同样的效果。[原帖](https://x.com/op7418/status/2120724676024717467)

**豆包工作终于接上了三方模型**：新用户登录电脑版还能领 30 天会员，他觉得有了三方模型，这 30 天就很值，并说刚上的套餐看起来挺划算。[原帖](https://x.com/op7418/status/2120829705431744707)

看法：一个下午加一个 HTML，就把「会不会做游戏」变成「打不打得开这个链接」，分发的门槛比模型本身降得还快。

## 郭宇 @turingou

**AI 对普通人最大的优势不是更快**：不是把产品做得多快，而是让普通人或小团队，也能像字节那样用数据和方法论做出增长飞轮，并用来管理自己的产品和商业逻辑。这条很快到了 300 多个喜欢、100 多个收藏。[原帖](https://x.com/turingou/status/2120752921814151425)

**因为 AI 写代码太快、CI 太慢，他做了急速构建**：自己做了 macOS 和 iOS 的急速构建服务，支持 agent 操作、模拟器截图录视频，以及 TestFlight 和应用市场发布。原先在 Mac Studio 上要跑五分钟的 Tuwa App 构建，被他压到 25 到 30 秒。换成这套之后，超大型项目也能在一分钟内完成构建，三十多个项目的 PR 一起涌进来，跑 CI 最多等五六分钟。[发布预告](https://x.com/turingou/status/2120716134832079053) · [速度](https://x.com/turingou/status/2120719407802679353)

**垂直个人助理和即将上线的 wanman**：他最近做了十几二十个垂直化个人助理，其中一个放在山月夜，做全日本温泉旅行地图和旅馆相关的卖店。他很早想做这件事，但当地人很难理解 SaaS，平时只用电话和邮件联系。有人问怎么下载使用，他说等公开测试了再发链接。晚上他又预告，精心打造的 wanman 1.0 即将在手机上见面。[温泉助理](https://x.com/turingou/status/2120810034909397311) · [wanman](https://x.com/turingou/status/2120838149052207503)

看法：他把瓶颈从「模型会不会写」挪到了「构建和发布跟不跟得上」，这才是写代码被加速之后，最先露出的那截短板。

## 蓝哥AI @0xlangeai

**写了 DeepSeek Harness 保姆级教程**：他说现在这套太火了，教程之外还做了一个案例：用 Grok Bot 筛评论，再交给 DeepSeek Harness 插件分析读者疑问，最后生成选题卡。想上手、又想从评论区找创作素材的，可以按他的步骤做一遍。[教程](https://x.com/0xlangeai/status/2120769549679386878)

**试用了宝玉推荐的 baoyu-design**：昨天宝玉在他的 DeepSeek Harness 帖子评论区推荐了这个项目，他试用后觉得很惊艳，其中 dsh-claude-design 已经有 Claude Design 的效果。他后来还拆了几个子项目，比如 claude-slides 可以把笔记和需求交给 Agent，生成能改字、能拖元素、能导出 PDF、HTML 或 PowerPoint 的幻灯片，网页设计和数据看板也能做。[推荐](https://x.com/0xlangeai/status/2120492559344791853) · [拆解](https://x.com/0xlangeai/status/2120516830607606197)

**dsh-market 下载量最高的插件到了 310 万**：他按下载量看完热门插件后的判断是，大家最想补的不是聊天花样，而是三件事：管住上下文、让 AI 操作电脑、看清钱花在哪。[原帖](https://x.com/0xlangeai/status/2120540111150739694)

**用 Muse 做免费工作台，也用 Grok Bot 加 ChatCut 剪视频**：他转了锦鲤的方法，觉得 Muse 免费、很适合搭监控台这类工作台。剪视频时最省事的是把要求说清楚，不用自己拖时间轴，4 段录屏上传后直接交代怎么切。[Muse](https://x.com/0xlangeai/status/2120750249568588285) · [ChatCut](https://x.com/0xlangeai/status/2120745792164286962)

看法：Harness 热起来之后，真正被反复问的已经不是「它是什么」，而是怎么把它接进选题、设计和剪辑这些每天都要干的活。

## 小墨同学 @xiaomovps

**用 Pi 做内核的个人助手 PiClaw**：最近大家都在看 Grok Bot 这类 Personal Agent，也有人用插件把 Pi Agent 做成自己的助手。开源项目叫 PiClaw，作者没有重写一套内核，而是基于 Pi，搭了一套完整的 Web 工作台。[原帖](https://x.com/xiaomovps/status/2120541856857817154)

**千问开源了 Qwen Code 1.0 Preview**：这不是全新项目，最早基于 Google Gemini CLI，现在把 Qoder 的 Harness 能力整合了进去。他拿它和 Pi、DeepSeek 做了对比：Pi 主打极简核心加 Extensions，只保留少量核心工具，其他能力按需扩展，轻量、灵活。[开源](https://x.com/xiaomovps/status/2120488740779180303) · [对比](https://x.com/xiaomovps/status/2120524176650043410)

**DeepSeek Harness 插件的两个老问题，官方开始动手**：一个是稳定性，更新之后插件经常不能用，现在官方已经直接下场修；另一个是安全性，相关讨论也在往 GitHub 上走。[原帖](https://x.com/xiaomovps/status/2120807310876422308)

**AI Coding 套餐已经卷到 39 元**：他整理了一圈国内外套餐，觉得没必要一上来就买几百块的订阅，并挑了 6 款自己觉得性价比高的，第一条是阿里百炼 Lite，39 元一个月，支持 Qwen、DeepSeek 等模型。[原帖](https://x.com/xiaomovps/status/2120838013366517974)

看法：开源 Harness 越来越多，差别已经不在「有没有壳」，而在插件会不会坏、安不安全、以及能不能用很便宜的套餐先把日常活跑起来。

## 向阳乔木 @vista8

## Orange AI @oran_ge

**Gemini 4 Carbon 用着比预期友好**：他觉得明显比 DeepSeek Flash 强，写作更自然丝滑。价格上他以为会跟 Opus 一样贵，实际只有 Sonnet 的价。[原帖](https://x.com/oran_ge/status/2120834850597011530)

**年末大厂重组，他看成提效之后没有增量**：AI 能让工作大幅提效，但如果只是提效、没有新的增量经济，结局就只能是重组。[原帖](https://x.com/oran_ge/status/2120674417122656493)

**A 社路演提到已经在用 AMD 的 GPU**：Mythos 用了三天，就写出了在 AMD 上跑 Claude 的内核，以前这需要数十名工程师花费数月。[原帖](https://x.com/oran_ge/status/2120669369013555248)

**从美国就业看职业变化**：他说软件行业基本已经停滞，AI 数据中心相关的实体岗位大幅增加，并引用一组数字：科技公司空缺职位超过 281,000 个，比一年前增长 17%，产品经理、工程和设计职位仅增长 2%。[原帖](https://x.com/oran_ge/status/2120662791829008806)

看法：Carbon 的手感可以当天就下判断，但他对就业和重组的判断更冷，提效如果换不来新需求，最后被优化的就是人。
