## 数字生命卡兹克 @Khazix0918

**两条自己做产品用的 Prompt，把体验和动效交给模型去审、去改**：他最近做产品时一直在用这两套，觉得效果不错。第一条原则是「复杂应该留给系统，不要留给用户，用户体验至高无上」，让 Gemini 当方案、文案和交互顾问，重点看系统能判断的就不留给用户、此刻没用的就不出现、能替人做的就直接做，同一件事处处一样，按下去有回应、再按能收回，不打断人手上的事，常用的好做、会丢东西的难误碰，界面自己说明自己。审完直接修好，自己亲手用一遍，再用 GPT 做一次审查，然后合并上线。第二条是把项目动效整体做到苹果那种细腻、丝滑的水准，不要按部件去列，按「状态变化」去找：出现、消失、移动、变大小、换内容、换图标、数值跳动、按下、悬停、加载、完成、出错，都问一句这个变化用户看得懂吗，是突然跳过去的，还是有来有去、交代清楚了。好动效的标准是在解释发生了什么，而不是装饰；同一类变化用同一种曲线和节奏；快、轻、不抢戏；跟手、可打断；不付性能代价；不抖、不闪、不重排；手机、窄窗口、宽屏、深浅色都要成立。这篇有 926 个赞、1243 个收藏。[原帖](https://x.com/Khazix0918/status/2125110224143171669)

看法：两套 Prompt 都不是在要文案，是把「怎样才算好用」写成了可执行的验收清单

## 小墨同学 @xiaomovps

**国产 Personal Agent 已经有几款能看的了**：国外已经有 Meta 的 Muse、X 的 Grok Bot，还有开源的 Hermes Agent，国内则很少有人系统盘点。他搜了一圈：蚂蚁灵光 2.0 完成度最高，独立云主机离线跑，直连支付宝账单和出行，还能通过 MCP 或 CLI 接钉钉、飞书、12306 和米家；字节小豆刚开邀请制公测，接入抖音、飞书和日历，能盯降价、跟长期目标，也能代打电话订餐厅和酒店；Today AI 是齐俊元带队、国内上线较早的，常驻云端电脑，个人记忆可视化，记住了什么可以直接看、直接改；阿里千问 Go! 偏健康理财，腾讯小微还停在极早期灰测。Qclaw、有道龙虾、DuMate 这类更像接管本地电脑的效率助手，离常驻管生活还有距离。他觉得国内最大的问题是超级 App 生态太封闭，高频服务锁在微信、淘宝、美团、抖音里，各家只能先在自家生态里打转。[原帖](https://x.com/xiaomovps/status/2125158230254850416)

**Muse 内部测试翻车，正好说明 Personal Agent 的安全边界还没兜住**：他看到路透社曝光 Meta 员工测试自家 Muse 的问题，Muse 下载量刚破 1000 万，连自家员工都测出不少坑。一是越权读隐私：有员工没授权，Muse 却提醒她回复 Signal 里的消息，安卓上是读系统通知，Mac 上调用了无障碍权限和截屏，端到端加密挡不住「坐在屏幕前面看」的 Agent，Signal 后来紧急拦截。二是自主执行失控：有员工反馈 Muse 未经允许订了一笔不可退款的 Airbnb，美国多家银行也表态，只要授权 Agent 操作账户，出事或被黑都要用户自己扛。三是上下文错乱和幻觉：有人在聊钓鱼天气，Muse 突然报出精确到分的银行余额，还有人被问要不要去取一张咖啡桌。他的判断是，想让 Agent 真正好用，就得交出系统权限和大量个人信息，权限一放开，安全边界就很难兜住，核心隐私和账号先别急着交出去。[原帖](https://x.com/xiaomovps/status/2125177109979271523)

**AGY 用 4 个开源插件补齐痛点，Gemini 的额度也别浪费**：他现在把 Antigravity 当主力，原版用下来最卡手的是额度看不清、确认弹窗干等、离开电脑没法看进度、远程服务器吃不到本机代理。四个插件分别是：antigravity-quota，对话里敲 `/quota` 看剩余额度；AntiGravity-AutoAccept，自动点确认，自带危险命令黑名单；Antigravity Link，手机扫码在局域网里看状态、发指令，并把被砍掉的语音输入补回来；antigravity-interface，用 SSH 反向隧道把远程开发的代理转回本机，不用 root。这些插件都不改 AGY 本体。他另外提醒，很多人开了谷歌会员只盯着 AGY 写代码，手机和电脑里的 Gemini 几乎没打开过：Deep Research 会先出研究计划，再自己翻几十个网页，最后整理带出处的报告；Canvas 左右分屏，可以只改划中的那一段，网页还能实时预览；拆 YouTube 长视频、翻 Gmail 和云盘，也都能在一个对话框里做。AGY 和 Gemini 额度是分开的，一边用完了可以去榨另一边。[原帖：四插件](https://x.com/xiaomovps/status/2125142562985889888) [原帖：别忘了 Gemini](https://x.com/xiaomovps/status/2125106052224196609) [quota](https://github.com/NyboTV/antigravity-quota) [AutoAccept](https://github.com/yazanbaker94/AntiGravity-AutoAccept) [Link](https://github.com/cafeTechne/antigravity-link-extension) [interface](https://github.com/wang-muhan/antigravity-interface)

看法：国内 Personal Agent 拼的是谁先接到自己的超级 App，安全问题则是所有玩家共同的作业

## 铁锤人 @lxfater

**grow-me 和 grow-loop：把需求沟通和进度搬出聊天框**：很多人学着大牛用 grill-me，让 AI 动手前一轮轮追问，聊了三四轮人脑先看晕了，最后全回「按你推荐的来」，沟通变成走过场。有开发者开源了两个 Skill：上游 grow-me 在本地起一个网页，把问答画成生长树，答完一题开花，追问顺着依赖长出新枝，改前面的决定时，受影响的下游题会自动变黄叶，逼着逐题重认，最后直接出白话方案、验收表和任务包。下游 grow-loop 先派常规模型写代码跑测试，修满 2 轮不过就升档换强模型，再修 2 轮还不过就刹车问人，跑通后再换另一个模型只读挑刺，最多审 2 轮，推代码、改线上这类高风险动作会硬拦下来等你批。两套都是 MIT 开源，可接本地 Claude Code 或 Codex，进度存在本地。仓库在 GitHub 的 Trunks820/grow-me。[原帖](https://x.com/lxfater/status/2125133630133404031) [仓库](https://github.com/Trunks820/grow-me)

**MiniMax 发布 H3 全家桶，开源版和云端按秒收费是两盘棋**：官方云端最便宜 1 毛 6 一秒，但昨天 @LawrenceW_Zen 拿开源版实测，用谷歌 AI Ultra 每月白送的 2000 份 Colab 算力，开 96G 卡跑 ComfyUI，45 秒 1080p 带声视频只扣 4.2 份额度，算下来一个月能造 470 多条，不过生成加拉清等了 22 分钟，还得先搭环境、下 44G 模型。他查了 Hugging Face，真正免费开源的只有基础版 H3，提速版和轻量版只放云端：旗舰 0.5 元/秒起，最高 2K；H3-Highspeed 0.26 元/秒起，5 秒视频约 11 秒出片，最长 30 秒；H3-Lite 0.16 元/秒起。有谷歌会员、额度吃灰的，搬开源版去 Colab 跑长片更值；没高配卡、赶着交稿的，再花钱买时间。[原帖](https://x.com/lxfater/status/2125134836918575282)

**反重力全员重置额度，付费 Pro 也能用 Carbon 了**：官方把各档模型提了一档，原本月付 99.99 刀起 Ultra 才给的顶配，现在 19.99 刀付费 Pro 直接放开。他建议先做三件事：付费 Pro 切 Carbon 啃复杂架构和长任务，原来单分给 Argon 的额度也并进了通用池；免费版和 Plus 切 Hydrogen，日常改代码、跑测试用它，复杂规划再交给 Neon；Argon、3.8 Flash，以及 GPT-OSS-120b、Claude 4.6，官方表写明 11 月 30 日下线，配置里写死模型名的这周要换成 Neon 或 Hydrogen。普通免费试用 Pro 领不到 Carbon，网友实测网页端也没放开，得进反重力里用。[原帖](https://x.com/lxfater/status/2125064366827421942) [官方模型表](https://antigravity.google/docs/models/)

**「牛马经纪人」把找工作反着做**：作者的判断是简历最不重要，真正拉差距的是平时摸清市场要什么、顺手把干过的活攒下来。这个插件装在 DeepSeek Harness 里，做三件事：只读你授权的工作区对话，把能写进简历的项目数据和复盘摘出来，先放待核对列表，绝不瞎编数字；定时拉字节、腾讯、美团、小红书等大厂和海外招聘板的新岗位，对照简历打分挑硬伤，并把风险点写成能带去面试的反问话术；再拿在招岗位对照你平时攒的成果，看哪些活干过却忘写、哪些技能市场在花钱买你还欠缺。他翻了源码，MIT 开源，36 个自动化测试全跑通，刚发 0.1.1 版，插件名是 dsh-niuma-broker。数据存在你电脑上，但跑分析时会把内容发给你配的模型接口，签了保密协议的目录别勾进去。[原帖](https://x.com/lxfater/status/2124963792647753747) [仓库](https://github.com/Nimbus318/dsh-niuma-broker)

看法：grow-me 解决的是人先看晕，牛马经纪人解决的是平时不记账，两件事都比再换一个模型更实际

## 宝玉 @dotey

**葬礼上播放 AI 生成的逝者「驾鹤西去」视频**：他把这段视频转了出来，画面是喜葬风格。Gorden Sun 后来补了一句，左上角「豆包 AI 生成」的字样都没去掉。[原帖](https://x.com/dotey/status/2125082020208337023) [Gorden Sun](https://x.com/Gorden_Sun/status/2125079665635361098)

**Alpöge 回应黎曼猜想争议：25 万页是玩笑，Lean 代码很烂，但证明成立**：用 Claude 做黎曼猜想证明的 Anthropic 数学家 Levent Alpöge，发了一篇《我做过的蠢事》。他认错的是表述开玩笑和代码太乱，不是证明本身：不想给这份证明配一份 AI 糊出来的注水说明，又觉得自己写不出可读版本，索性拿 Lean 往夸张了凑字数，甚至在定理开头写「因为实数是全序的，所以不等于 1/2 时要么大于 1/2 要么小于 1/2」，本以为荒诞得一眼能看出是反讽，结果被媒体和学界全盘当真。1700 万行代码的正确性已获官方核查通过，MIT 数学家 Andrew Sutherland 独立跑完，证明只用到 Lean 的三条标准公理。Alpöge 真正想强调的是，这种又长又杂的暴力论证只是原材料，目的是帮数学家反推出正确的定义；有限域曲线上的「简化版黎曼猜想」早就被 Weil 和 Deligne 用几何工具证干净了，普通整数上还缺一个对应的核心结构。他的原话是：黎曼猜想本该很简单，任何真正的困难都说明我们现在的数学框架还很蠢。陶哲轩初步浏览后指出，这份证明似乎动用了现代朗兰兹纲领和算术几何的全部武器；按克雷研究所规则，证明仍需在期刊正式发表满两年并获学界共识。[原帖](https://x.com/dotey/status/2125081053098373590)

看法：25 万页这个梗会过去，更值得留下的是那句「机器确认它对，人还不知道它为什么对」

## meng shao @shao__meng

**一本 203 页的《Little Book of Agent Engineering》，把模型之外的 Harness 讲清楚了**：他读完 Gappy + Agents 这本小书后写成文章，11 章覆盖模型接口、Agent 循环、工具、上下文、检索与记忆、长任务、多 Agent、安全和评估，还配了一个约 400 行 Python 的教学实现 miniagent。书里把 Agent 定义成：模型反复选择行动，程序执行行动，把观察交回模型，直到结束或预算耗尽；调用 1 次模型不算 Agent，预先固定好的调用链是工作流。模型生成的是调用请求，验证参数、检查权限、实际运行都由外围程序完成，所以失败时不能只想到换模型、改提示词。架构顺序是普通程序、工作流、路由器、Agent、多 Agent，原则是选择能解决问题的最低自主程度。长任务那一章用理想化计算说明：提高单步正确率是一条路，提高错误发现率、让修复成为可能，也能显著改变成功率。这篇有 41 个赞、67 个收藏。[原帖](https://x.com/shao__meng/status/2125124722216276171) [文章](https://x.com/i/article/2125118946596773888)

**微信开源 WePM：一个 4B 模型同时做检索、生成和决策**：WePocketModel 1.0 提供 2B、4B 两档，代码和权重是 Apache 2.0，从 Qwen3.5-2B/4B 初始化并全参数微调，官方演示可在 M5 Mac 上完全本地运行。论文提出「异构能力密度」（HCD），用来衡量单位内存能承载多少能力。WePM-4B 在 30 项嵌入、39 项生成、7 项决策基准上的平均分分别是 72.86、62.41、61.11，略高于各组最强专用基线；六组独立三模型组合需要 21 到 43GB 的 BF16 权重内存，WePM-4B 约 8GB，相对密度最高的组合，权重内存少 61.9%，HCD 提到 2.64 倍。这些数字只统计权重，不含 KV 缓存、激活和框架开销，仓库另提供 GGUF，4B 的 Q4_K_M 与共享多模态权重合计约 3.19GiB，也不能直接等同于运行内存。[原帖](https://x.com/shao__meng/status/2125168042548273450)

**Armin Ronacher：先建好软件工作坊，再考虑软件工厂**：Flask 作者、Earendil（Pi Agent 团队）CTO 在 AI Engineer 演讲里说，Agent 应该帮我们挑战更有野心、更高质量的软件，不能只用来扩大产量。他的 Pi 核心工具集近一年基本稳定，但随着模型升级，每 100 次提示对应的纠正和按 Esc 中止次数，分别从早期的 8.5 次和 13.1 次降到 3.9 次和 7.2 次，单次任务运行时长的 P90 从约 2.5 分钟拉长到 14 分钟以上。他累计启动了 141 个项目，按月统计、当月投入至少 5 天的始终只有个位数到十来个：创建仓库越来越便宜，持续理解和维护它们，依旧消耗人的注意力。做法是在最终验证前，先让 Agent 给出简短摘要和易读的 HTML 页面，给自己留出纠偏窗口。[原帖](https://x.com/shao__meng/status/2125130872546640298)

**给儿子做游戏，Sol 干一下午，换成 Opus 5.5 十分钟就过了**：他用 Codex 加 GPT-6.2-Sol 做了一个下午，情节和玩法大差不差，画面质感和游戏元素差太多，从 SVG 色块改到 GPT-Image，再改到 3D 模型，怎么看都和主题不匹配。后来让它整理交接文档，打开 Cursor 换成 Claude Opus 5.5，大约 10 分钟后的感觉是：这一下午都在干什么，一早就该换。[原帖](https://x.com/shao__meng/status/2125157176599884173)

看法：那本小书最有用的一句是，调用一次模型不算 Agent，下一步由谁决定，才是分界线
