## 今日主线
- Fable 5.2 落地第一天，中文圈把实测刷成了作品展：墨水流体、音乐不再「嘟嘟嘟」、复刻官方片、用代码一笔笔画出照片，同时也有人抱怨先想 3 到 5 分钟才吐字，十个重活能吃掉约四分之一 Ultra

## 小墨同学 @xiaomovps

**Pi 1.5.1 更像一次日常打磨**：没有大功能，但默认行为变了。终端可直接 `pi auth login`，服务器还能加 `--no-browser`；缓存保温默认从 streaming 改成 idle，空闲时最多保温 30 分钟，并会先判断刷新是否划算，一直开着却不说话也可能产生费用，可用 `/session` 查看，也可在设置里改回 streaming 或关掉。Anthropic 官方 API 默认启用 Message Threads，连续对话只发新增消息，网关若不支持要在配置里关闭；默认模型也切到了 Opus 5.5、GPT-6.1 Sol、Gemini 4 Argon 等新档。[更新要点](https://x.com/xiaomovps/status/2119946221087539663) · [四条使用差异](https://x.com/xiaomovps/status/2120051114200711252)

**《Goodbye Claude, Hello Pi》在 HN 吵起来了**：作者用了 Claude Code 一年多，统计到今年 9 月已发布 244 个版本，超过 75% 改过 System Prompt 或工具描述，多会话还不能稳定接收编辑器选中文本。换成 Pi 大约 20 分钟就用 Extension 修好了。小墨的判断是：Claude Code 想把一套完整 Agent 交给你，Pi 更希望你自己决定 Agent 该长成什么样，自由度高也意味着配置和安全审批要自己扛。[原帖](https://x.com/xiaomovps/status/2120087420582646246) · [原文](https://caleb.software/posts/claude-to-pi.html)

**国内 Coding 套餐卷到 40 元左右**：火山方舟 Agent Plan Small 40 元，一个套餐能切豆包、DeepSeek V4、GLM-5.3、MiniMax M3、Kimi K2.8 Preview，每月 2 万 AFP、每 5 小时还有窗口；小米 MiMo Token Plan Lite 39 元，41 亿 Credits 共享，没有单独的 5 小时限制，凌晨还有 0.8 倍消耗优惠；MiniMax M Plan Plus 49 元，官方按 M3 估算约 6 亿以上 Token，支持 3 到 4 个 Agent 并发。他的用法是：爱切模型选火山，想连续跑、怕 5 小时窗口选小米。[原帖](https://x.com/xiaomovps/status/2119772167231693052)

**降到 30 刀之后额度基本够用**：大活发给 Pi、Codex 或 CLI，Grok Bot 只做下发和验收；日常多是扫邮箱、私信和评论区的定时任务，消耗有限。替代方案他点名 OpenBot、OpenManus 和 Hermes，前两者可能遇到网络问题，Hermes 需要自己准备服务器。[原帖](https://x.com/xiaomovps/status/2120028818442444841)

看法：Pi 的卖点已经不只是便宜，而是「更新不会把你的工作流整盘打乱」，30 刀够用则建立在把重活分流出去的前提上。

## 宝玉 @dotey

**彭博社的 AI Coding 面试并不比 LeetCode 更友好**：他转了 Reddit 上伦敦或法兰克福的二面经历，题是庞大的 Django 代码库，面试者对框架并不熟。前 30 分钟是行为面，留给写代码的只剩 30 分钟，AI 能用到什么程度又说不清。当事人用了 planning 和 ask mode，过了几个测试仍被拒，还提醒别指望一句提示词一次性做完。宝玉的评语是：现在虽然不考 LeetCode 了，但要考 AI Coding，不见得更容易，还更玄学。[原帖](https://x.com/dotey/status/2120064894376558646) · [Reddit](https://www.reddit.com/r/leetcode/comments/1xrrdps/to_anyone_who_thinks_ai_interview_is_good_well/)

**「苦涩的教训」常被读成「堆算力就够了」**：他引用 Sutton 本人的帖子，以及 Prashant Rai 的回复，指出这篇文章反对的是把人类巧思写死进系统，不是反对算法创新。评论区也有人提醒：很多人其实只看过标题，原文本来就在讲要找能随算力扩展的通用方法。[原帖](https://x.com/dotey/status/2120039846118821976)

看法：面试规则一变，考生的准备从刷题变成了同时读懂生代码、跟面试官说话、还要审查 AI 输出，难度转移了，并没有消失。

## 铁柱AGI @cgnot996

**一份 11 页报告把 Grok Bot 变难用拆开了**：从额度缩水、模型疑似降智到虚拟机频繁休眠，他觉得根子比「再重置一次」更严重。马斯克承认运行成本相对收入难持续。报告把额度耗在定时任务空转、长对话反复读上下文、多 Bot 互聊上，也把变慢归到对话历史越背越重。官方已建议降低定时任务频率、改用事件触发；报告还模拟了把同类任务的额度消耗从 100% 降到 20%，但这不是官方实测。完整 PDF 放在评论区。[原帖](https://x.com/cgnot996/status/2120022724471111953) · [PDF](https://drive.google.com/file/d/1SsM7mBM4gVfQPXDFx6rx9IRdikjtZHQc/view)

**新订阅的重置比老用户晚了大约半天**：昨天先给老套餐重置，新订阅用户后来才陆续到账，答疑群里有人一度担心自己不在范围内。官方随后说已给所有 Grok Bot 用户重置了每周额度。他测下来速度明显快了，但额度消耗还是偏快，重置也不刷新周期。[时间差](https://x.com/cgnot996/status/2119949288646300075) · [新订阅也重置](https://x.com/cgnot996/status/2119841246072218015)

看法：重置能止血，11 页报告指出的是另一件事，计费不透明和空转，不改结构的话下次还得再按一次按钮。

## 蓝哥AI @0xlangeai

**DSH 工作台被他称为「真香」**：点名 dsh-media-desk 和 dsh-guizang-design，都是一键安装。他的搭配是 Grok Bot 做信息采集，DeepSeek Harness 做内容工作台。小墨同一天把 media-desk 拆成了灵感、内容、排期、复盘、风格五块，并给出了仓库地址。[工作台](https://x.com/0xlangeai/status/2120023646974640332) · [五模块拆解](https://x.com/xiaomovps/status/2119986770855297348) · [GitHub](https://github.com/woniuniuniu/dsh-media-desk)

**一个月上千个 PR，靠的不是多开 Agent**：他拆了 Grok Bot 工程师 Lauren（@poteto）的 38 分钟分享。关键是先把验收做成 Agent 能跑、能读结果的验证技能，再维护功能地图，把重复错误变成结构、lint 和 CI，而不是继续补提示词，最后才用事件自动复现 bug 并开 PR。她还观察到，临时代码和注释会被 Agent 当成新范例继续绕路。[原帖](https://x.com/0xlangeai/status/2120049568331280486)

看法：插件工作台降低的是上手成本，poteto 那套方法降低的是返工成本，后者更接近把项目改造成「Agent 不容易反复犯同样的错」。

## meng shao @shao__meng

**Meta 的 JiTTests：不靠更快审代码，而是生成会失败的测试**：针对尚未合入的改动，自动写出在新版本失败、在父版本通过的测试，把行为差异摊开。误报用规则工具和模型评判团过滤，工程师只确认变化是否符合预期。博客的生产口径是 589 名工程师参与过，自报真阳性约 60%，2026 年上半年在合入前帮着捕获 74 起严重隐私事故，同期这类事故发生率约降 20%。这些数字来自公司自己的反馈和对比，文中没有可独立核对的对照实验。[原帖](https://x.com/shao__meng/status/2119978619196084717) · [博客](https://engineering.fb.com/2026/10/29/security/catching-bugs-before-they-land-jittestings-human-on-the-loop-approach-at-full-scale/)

**Airbnb 微调小分类器，高流量下成本约 1%**：用内部框架 GLOWC 把开源小模型微调成分类器，再和开源基座、前沿 API 比质量、时延和费用，延迟可做到 100 毫秒以内。[原帖](https://x.com/shao__meng/status/2119973180945387755)

**第二场面试更像付费咨询**：三位面试官没等他自我介绍就开始问，场景非常具体，比如私有化部署 MiniMax H3 的成本、生成效率、要不要专职运维、100 以上用户并发的最低 GPU，以及基于 H3 做特定场景 RL 需要多少数据、周期和备选方案，还问 1 个月内上线、算上他一共 2 个人够不够。他的感觉是：这不像面试，像在跟甲方做前期沟通。[原帖](https://x.com/shao__meng/status/2119762091796283468)

看法：评测和面试都在往「先定义什么算成功」靠，只展示能把功能做出来，已经不够用了。

## 小工具

- [IconMCP](https://iconmcp.com/)：Ding 推荐的免费图标库，已有 6248 个原创线框和实心图标，网页可复制 SVG、下载 PNG，也能让 Agent 直接找图标，官方说由 AI agent 全天候补充，目标是 10 万个，也包括动画图标。[原帖](https://x.com/dingyi/status/2120079767814996447)
- [Mirage](https://huggingface.co/Cactus-Compute/mirage)：约 22MB 的端侧视觉模型，三星 S26 NPU 上约 74 毫秒跑完一轮，适合做本地看图和结构化输出。[原帖](https://x.com/Gorden_Sun/status/2119810857920307387)
- [xnews](https://github.com/joeseesun/xnews)：vista8 开源的 Grok Bot 流水线，把海外长文抓来写成中文网站，体验站在 [xnews.qiaomu.ai](https://xnews.qiaomu.ai/)。[原帖](https://x.com/vista8/status/2120099636149153857)
- [dsh-media-desk](https://github.com/woniuniuniu/dsh-media-desk)：DeepSeek Harness 上的自媒体工作台，覆盖灵感、内容、排期、复盘和风格。[原帖](https://x.com/xiaomovps/status/2119986770855297348)
- [huashu-selfie-sticker](https://github.com/alchaincyf/huashu-selfie-sticker)：花叔开源的 Seedream 5.5 GIF 表情包 skill。[原帖](https://x.com/AlchainHust/status/2119948102698475938)
- [Simular Box](https://box.simular.ai/)：蓝哥说可以让 Muse 或 Grok Bot 去申请一台免费的 2 核 4G 云服务器，需邮箱登录，支持 Google 邮箱。[原帖](https://x.com/0xlangeai/status/2119781222582993224)
- WquGuru 展示了 SAM3D Body、MiniMax H3 和 BFS Character Swap 的组合，可做角色置换，帖子收藏过百。[原帖](https://x.com/wquguru/status/2120023424663974193)
