## 宝玉 @dotey

**Lauren Tan 的演讲《All Code Is Slop (Except Mine)》要点**：她在 SpaceXAI 负责 Grok Bot 桌面版，核心做法是每纠正 AI 一次，就写成 lint 这类自动检查，少往 agents.md 里加话，因为违规代码直接提交不上去，文档里的话 AI 不一定照做。代码库是 AI 最主要的学习材料，坏写法会被下一个 AI 当惯例照抄，所以她们禁掉了 99% 的注释，React 里人都常用错的功能也直接禁用。[原帖](https://x.com/dotey/status/2121835140850602200)

**让 AI 自己验收，结果看得见**：AI 把程序像用户一样跑一遍，交录屏和截图，人审代码变成看这些材料，她大部分 token 都花在这一步。团队上个月合并 1.1 万个 PR，被撤回的约 0.5%，应用比刚发布时还快，她的结论是先打好地基再谈全自动，不然只会更快地产出烂代码。[原帖](https://x.com/dotey/status/2121835140850602200)

**转译：面试聊得挺好为什么还是没 Offer**：面试官视角的几个原因，比如加分项答得漂亮但核心硬技能答得薄，或者评审团里早有内部候选人和熟人。他建议面试一开始就直接问清楚岗位里哪几项优先级最高，再把重点放在那里。[原帖](https://x.com/dotey/status/2121837146357006829)

看法：把纠错写进 lint 而不是写进提示词，这条比任何 agents.md 模板都值钱

## meng shao @shao__meng

**Claude Code 实验功能 Code Mode**：打开后 Claude 不再一次调一个工具，而是先写一段 JS 在里面批量调 rg、改文件、跑测试，只把需要的结果放回上下文，原本四五轮的操作一步做完。开启要设 CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1，写在项目设置里不生效，只支持终端交互会话和 Opus 5.5、Sonnet 5.5、Haiku 5.5、Fable 5.2，auto 模式下分类器改成审整段代码，必须管住的调用要靠规则或 hook 兜底。[原帖](https://x.com/shao__meng/status/2121899873083764877)

**读 Claude「Building always-on agents」的五个要点**：始终在线是体验不是一直开机，agent 大部分时间休眠，有事件或到点才醒。所有事件先进一个持久化收件箱再由 worker 领取，计时器到期也只是往收件箱投事件，记忆只存下次查不到的东西，审批时就挂起这次调用、结束运行，等用户回复作为事件回来再继续。[原帖](https://x.com/shao__meng/status/2121852475053359340)

**Grok Bot 做客 YC Lightcone 的一小时访谈**：Lauren Tan 和 Roman Ugarte 讲了从第一行代码到上线只用七周，三条原则是以 Bot 为工作单位、Bot 用和人一样的工具、Bot 一直在线并主动找人。他也指出「独立身份」目前是分层实现，同账户的多个 Bot 共用一台云电脑和登录状态，Bot 有自己的电话和信用卡还是 2027 年的期望。[原帖](https://x.com/shao__meng/status/2121791852559188373)

**Semgrep CEO 在斯坦福 CS146S 讲 agent 时代的安全**：47 页讲义的核心是漏洞修不完，就让利用漏洞变得更贵，已公开 CVE 里被实际利用的只有约 2%。他不认同「雇一批 agent 把漏洞全找出来」，主张建一座安全工厂，把业务风险变成能降风险的安全能力，并把 agent 的风险拆成行为失控靠沙箱、写出的代码靠供应链和扫描。[长文](https://x.com/shao__meng/status/2121629344758169995) · [讲座](https://x.com/shao__meng/status/2121771537871344048)

看法：Code Mode 加 always-on 这两篇放一起看，agent 的竞争点已经从模型挪到外围架构和权限设计上了

## Gorden Sun @Gorden_Sun

**Meta 和纽约大学的视觉模型设计研究**：视觉编码器不用提前单独训练，跟主模型一起从零训，看图问答准确率不输，还省算力。但必须保留图像专用参数，删掉要多花 3 倍算力才能追平，专用参数放进语言模型前八层最有效，1.7B 模型在 H200 上首字延迟从 64 毫秒降到 37 毫秒。[原帖](https://x.com/Gorden_Sun/status/2121806966062485776)
