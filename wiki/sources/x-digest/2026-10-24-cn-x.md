## 宝玉 @dotey

**Kimi K3.1 Pro 长文拆解**：月之暗面 10 月 23 日发 K3.1 Pro，网页 / App / Work / Code / API 当天可用，称最强开放权重，完整权重计划 11 月 4 日前放出。MoE 约 2.8T 总参、每次约 1040 亿激活，100 万上下文，写代码接近 Opus 5.5，金融 OfficeQA 自称第一，幻觉内部压测从 23% 错降到约 8%。API 输入 $2 / 输出 $10 每百万 token，约为 Opus 一半价。[原帖](https://x.com/dotey/status/2113689823311524225)

**Computer Use 原理科普**：模型只负责看和想，真正点鼠标的是另一段程序循环「看、想、做、查」。讲清楚截图 / 辅助功能 / 软件接口怎么定位按钮，以及 Mac 能后台、Windows 常占桌面的差异，并提到 GPT-6 Astra 变快与安全边界。[原帖](https://x.com/dotey/status/2113694852281938162)

**搭 Agent 不值钱**：呼应「Agent+ 场景里会搭 Agent 最不重要」的讨论，强调给 Agent 做工具、用 Agent 重构工作流更值钱，就像写代码本身不如用代码解决业务问题。[原帖](https://x.com/dotey/status/2113637983333093855)

看法：K3.1 Pro 的长文把官方分数和价格摊开，比口号有用；Computer Use 这期适合给非工程朋友看。

## meng shao @shao__meng

**Agentic SDLC ≠ 软件工厂**：转述 Qodo 创始人观点，各阶段有 Agent 还不等于工厂；目标是有边界的 L4：授权生命周期能自主走完、产出可检验证据、失败能安全兜底。优先级口号是 System > Agents > LLMs，工程团队要自建并拥有边界、证据、权限和反馈。[原帖](https://x.com/shao__meng/status/2113923043936612792)

**Netflix 可观测性本体**：排障慢常不是缺日志指标，是「应用 / 服务 / 集群」说法不一致、关系只在人脑子里。Netflix 用 Observability Ontology + RDF 图谱（QuipuDB）把非确定性匹配收成可 SPARQL 的事实，再喂 AutoRCA，把四小时里「拼关系」吃掉。[原帖](https://x.com/shao__meng/status/2113925598443675835)

**Pro 模型集体拉胯？**：吐槽 DeepSeek V4 Pro、Kimi K3.1 Pro 等「Pro」后缀近期不如预期，并问做 Flash 是否才是多数团队正路。[原帖](https://x.com/shao__meng/status/2113891829586579946)

看法：L4 工厂这篇比堆 Agent 口号实在；Pro 吐槽和社区实测潮是同一件事的两面。

## 小墨同学 @xiaomovps

**Pi 五个分支项目**：整理 Oh My Pi（LSP/Debugger/Subagent）、senpi（系统提示与权限）、mu（小模型帮大模型决策）、Orbi（Issue→PR）、Pi Pocket（移动端远程 Session），强调 Pi 核心保持精简、社区玩出不同方向。[原帖](https://x.com/xiaomovps/status/2113912639571255525)

**DSH 用 AGENTS.md / CLAUDE.md 省 token**：同目录两文件内容不同会同时加载，建议以 AGENTS.md 为主、CLAUDE.md 复用同一份；规则写「直接执行、少扫仓库、控制改动范围、验证通过就停、报错先分析」，复杂流程拆 Skills 按需加载。[原帖](https://x.com/xiaomovps/status/2113950309278167104)

**DSH 标准模式偏啰嗦**：同一 DeepSeek 在 Pi 上两三轮结束，换 DSH 标准模式常跑十几二十轮，效果只多几分但时间和 token 不值，怀疑系统提示词过重。[原帖](https://x.com/xiaomovps/status/2113852900673998855)

看法：harness 比底座更能决定「感觉笨不笨」，这组对比很适合自己复测。
