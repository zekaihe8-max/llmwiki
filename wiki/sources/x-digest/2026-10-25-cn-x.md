**订阅精简到 $120/月**：只留 Claude Pro $20 + Grok 整合 $100（含 X Premium+、可配 Cursor），取消 GPT $100；换来 X 数据收集与手机端，额度周消耗最高约 70%。[原帖](https://x.com/xiaomovps/status/2114197502153113745)

**Claude Code 省 Token 五项目**：context-mode / RTK / claude-mem / Serena / caveman，建议先试前三个，别一次全装。[原帖](https://x.com/xiaomovps/status/2114285431324057857)

**DSH 渠道比价 + WorkBuddy 同题实测**：官方 / OpenCode Go / OpenRouter / Command Code GOAT；$80 是模型限额非官方余额。同「鹈鹕骑车」提示词两边都约百万 token、缓存约 99%，他更认 DSH 成品质感。[原帖](https://x.com/xiaomovps/status/2114263858869318047) · [实测](https://x.com/xiaomovps/status/2114312906703847698)

看法：手机全链路和三个坑是今天最可抄作业的 Grok Bot 实操；省 token 清单适合进小工具栏。
