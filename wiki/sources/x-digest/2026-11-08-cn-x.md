## 宝玉 @dotey

**Anthropic 分析约 20.7 万次科研会话**：样本是 2026 年 8 月 2 日到 9 月 30 日的个人订阅用户，聊天和 Cowork 约 12.9 万次，Claude Code 约 7.8 万次。分析数据占 Claude 科研会话的 33.7%、Claude Code 的 48.1%，写作里单项最多的是起草论文；科学家自评最重要的提想法和收集数据，用得反而最少，提想法在 Claude 上只占 4.2%，Claude Code 上只有 2.1%。现有能力如果普及，产出大约能到 1.35 到 2 倍；若 AI 包揽全部不用动手的步骤，统计和计算机能到约 15 到 16 倍，生物和化学只有 3 到 4 倍，因为约 40% 时间还得人在实验室干活。面向科研的 Claude Science 上，提想法占到 8%，约七成会话由 AI 高度自主完成。[原帖](https://x.com/dotey/status/2119283516143776186) · [报告](https://www.anthropic.com/research/how-researchers-use-claude)

**姚顺雨谈用户黏性**：清华讲席教授张亚勤问 DeepSeek、腾讯、Anthropic、OpenAI 的护城河在哪。姚顺雨说更多在产品层，不在模型层：别人没有的私有数据和上下文，加上你是否信任 AI 拿着这些数据去行动。他举例微信里的 AI 不必最聪明，但知道你的日程、朋友和活动，就很难被更聪明却不了解你的模型取代。张亚勤随后开玩笑说，那 Anthropic 总有一天会变成同质化商品。[原帖](https://x.com/dotey/status/2119264167483850884)

**纽约时报给 Dario Amodei 写上市前人物稿**：11 月 5 日刊出，采访二十多位同学、朋友、老师和同事，还看到早年邮件和 OpenAI 内部消息，本人通过发言人拒绝受访。稿子的主线是：他年轻时泡在理性主义和有效利他主义圈子里，认定 AI 危险到只有想法相近的人才值得托付去造。文中写到他在 OpenAI 立场变硬、兄妹影响力引发争议，以及 2020 年 12 月离职四周后创办 Anthropic；他也一直在和这两个圈子划清界限。[原帖](https://x.com/dotey/status/2119191652770226525) · [纽约时报](https://www.nytimes.com/2026/11/05/technology/dario-amodei-anthropic-ai.html)

看法：科研报告把「AI 擅长什么，人就拿它干什么」写得很清楚，姚顺雨和人物稿则提醒，黏性和掌控权都不在榜单分数上。

## 小墨同学 @xiaomovps

**DeepSeek 也有消费级显卡能跑的小模型**：他整理了 6 款 4-bit 量化参考，从 R1-Distill-Qwen-1.5B（约 1.1GB，GTX 1650 / RTX 3050 可试）到 32B（约 20GB，需要 3090 / 4090 这类 24GB 卡）。他特别点名基于 Qwen3-8B 再蒸馏的 R1-0528-Qwen3-8B，以及每次只激活约 2.4B 的 DeepSeek-Coder-V2-Lite-16B。这些 R1 小模型很多是从 Qwen 底座蒸馏来的，显存占用还会随上下文变长，不能简单拿去和新一代千问正面对比。[原帖](https://x.com/xiaomovps/status/2119390726933107116)

**DSH 公开 7 套插件开发 Prompt**：官方把演示视频里的中英文提示词整理出来，走 Creator Mode 就能让 DeepSeek Harness 试做插件。他重点看了 Transformer 3D 可视化、自然语言剪辑的视频工作台，以及能高亮、做笔记并在会话里提问的论文阅读器，另外还有 3D 地标、像素风界面、海报设计和 Token 统计。他也提醒，官方演示往往经过多轮调整，复制一次不一定能完全复现。[原帖](https://x.com/xiaomovps/status/2119340144822214767) · [Prompt 合集](https://cdn.deepseek.com/harness/dsh-creator-mode-prompt-collection-zh.html)

**6 家开发者福利，外加 DSH 插件激励**：DeepSeek Harness 已开放插件开发者意向登记，承诺 Token、技术交流和作品推荐，具体额度还没公布；另外还列了 Cline 的 1000 到 1 万美元 Credits、Codex 的 6 个月 ChatGPT Pro、Claude Ultra 半年、Kilo Code 企业权益，以及 Dify 模板入选送一个月 Professional。他同时提醒，审核看项目影响力，福利账号一样可能因违规被封。[原帖](https://x.com/xiaomovps/status/2119296103292301532) · [DSH 激励](https://x.com/xiaomovps/status/2119241686845211081)

**Grok Bot 3D Campus 开源**：社区把多个 Bot 做成一座 3D 虚拟办公园区，能看各团队任务、额度、定时任务和异常，也能集中处理审批并派新活。作者连 Skill 和部署教程都准备好了，可以把 GitHub 地址发给 Grok Bot，让它在 Vercel 上搭私有管理界面；公开演示是模拟数据，刷新状态会读 Bot 信息、消耗额度，不必刷得太勤。[原帖](https://x.com/xiaomovps/status/2119261159681560750) · [GitHub](https://github.com/sarbarshem/grok-bot-3d-campus)

看法：本地小模型、官方 Prompt 和可视化管理，都在降低「自己动手做一个 Agent 工作台」的门槛。

## 思维怪怪 @0xLogicrw

**Cua Driver Bench：后台干活别抢键鼠**：Cua 联合 Scale AI 做电脑操作评测，要求 Agent 在用户持续打字时完成后台任务，不能抢鼠标键盘，也不能弹窗打断。macOS 上完整通过率是 Cua Driver 58%，Codex Computer Use 33%，Vercel agent-desktop 20%，browser-use 只有 3%。browser-use 40 次里做成了 32 次，但 31 次打扰了用户；Cua 做成 25 次，其中 23 次没打扰，一次也没抢走键盘焦点。所有工具都用 Claude Sonnet 5.5，比的是操作层，Cua 靠的是 macOS 辅助功能接口直接点后台窗口，不必把目标切到前台。[原帖](https://x.com/0xLogicrw/status/2119077068923429005)

**OpenCode Browse 接管你正在用的浏览器**：通过 MCP 和浏览器扩展连接 Codex、Claude Code、OpenCode，复用现有标签页、登录态和扩展，不必再给 AI 单独开一个浏览器。Agent 可在后台用 Playwright 点击、填表、截图、录屏和记网络请求，登录、双重验证或付款会交还给人；远程服务器上的 Agent 也能控你本机已登录的 Chrome，跨设备通常要再加 Tailscale。项目用 Patchright 并默认模拟人类鼠标和打字节奏，试图降低被识别成机器人的概率，但不能保证绕过验证码，已按 MIT 开源。[原帖](https://x.com/0xLogicrw/status/2119069106968441222)

看法：电脑操作评测终于把「别打扰人」算进通过条件，浏览器方案则开始抢用户自己的登录态，而不是再造一个干净环境。

## meng shao @shao__meng

**Addy Osmani：管 Agent 不该让你更忙**：一旦你开始挑任务、交代背景、委派和验收，你已经在管理 Agents。关键不是多开几个会话，而是让 Agent 先跑测试、构建、类型检查，界面改动还可以用截图，失败先自己改，再带着证据交付；必要时换一个没参与原对话的 Agent 独立审查。任务说明最该补仓库里看不到的东西：为什么做、业务约束、不要做什么、怎样算成功。并行的上限往往是人的注意力，成效应看交付周期、返工和回退，而不是写了多少代码。[原帖](https://x.com/shao__meng/status/2119356506932125856)

**rea-video：让 Agent 逆向拆视频**：作者 @yao_june12106 开源，可拆实拍、口播、AI 视频、3D 和混剪。流程分三步：先用本地规则逐帧看切镜、运动、噪声、文字和音频，不耗大模型 token；再让多模态模型按镜头解释，并给出复刻提示词；最后由 Claude 或 Codex 对照镜头拼图复核，结论来自「本地测量 + 模型分析 + Agent 复核」，并不会还原原始工程。[原帖](https://x.com/shao__meng/status/2119311344260583683) · [GitHub](https://github.com/JuneYaooo/rea-video)

**千问办公绑双 11 卖 1 分钱月会员**：阿里副总裁、千问办公 CEO 去直播卖 token，天猫旗舰店用 1 分钱拉新。他怀疑活动结束后续费和自然扩散都会很难，更多是传播薅羊毛，并问这么快从核心办公用户沉到很泛的人群，到底好不好。[原帖](https://x.com/shao__meng/status/2119272398587617634)

**Agent 说「完成了」，过程里可能藏着坑**：转述 Warp 的 Ben Holmes 在 AI Engineer 的演讲：过时的端口说明会让 Agent 反复试错，最后仍能交差，团队只觉得「慢了一点」。他主张用评分标准让评审 Agent 查记录，再由另一个 Agent 找反复出现的共因，把修复变成可审查的技能或配置 PR，而不是每次都靠临场变聪明。[原帖](https://x.com/shao__meng/status/2119256650649587747)

看法：管理 Agent 的重点从「再开一个窗口」变成了自验证、补上下文和复盘没被汇报的弯路。

**东京有人用 200 米光纤绕圈跑神经网络**：部分实验里计算成本和参数最多减少 90%，他调侃这是算力竞赛里不按套路出牌的选手。[原帖](https://x.com/heydengai/status/2119383931774521522)

## Gorden Sun @Gorden_Sun

**Grok Bot「基本废了」**：他说现在基本不会路由到 Opus 5.5，额度至少砍了 50% 到 60%。这条下面很快引出 Ding 关于大厂补贴的讨论，是今天中文圈里声量最大的产品情绪之一。[原帖](https://x.com/Gorden_Sun/status/2119281653839519924)

**METR 评估 Anthropic 的研发加速**：第三方机构进到 Anthropic 内部看 AI 把自身研发加快了多少。2026 年 10 月，Anthropic 在定义明确的任务上提升模型能力的速度，大约是 2024 年 3 月到 2025 年 10 月期间的 2 倍，其中超过一半来自 AI 辅助人类研究员，而不是 AI 完全自主做研发；报告认为未来 12 个月还没看到算法、训练算力、实验算力或数据上的明显瓶颈。Gorden 还从报告里推论，Anthropic 内部至少还有 Model 3 和 Model 4 两款领先于 Opus 5.5 的模型。[原帖](https://x.com/Gorden_Sun/status/2119278879907189214) · [报告](https://metr.org/blog/2026-11-05-anthropic-ai-rd-acceleration-assessment/)

**Sand3D：给大模型用的 3D 建模库**：基于 Blender，能用语义名称定义零件、关节和装配，不必手算坐标，建好后可导出到游戏引擎、机器人仿真和网页。项目同时开源了超过 10 万个 3D 组件。[原帖](https://x.com/Gorden_Sun/status/2119251746207977952) · [GitHub](https://github.com/Sandflow-ai/sand3d)

**MatAnyone-E 做超高清视频抠像**：先低分辨率扫一遍，只在发丝边缘等复杂区域做高精度计算，4K 速度提到原先的约 7.4 倍，显存降到约十三分之一，单卡原生 4K 能到每秒 28 帧以上，1080p 约每秒 73 帧，RTX 3090 也能流畅跑，项目主页写了后续会开源。[原帖](https://x.com/Gorden_Sun/status/2119390142960193998) · [项目页](https://shuyun-wang.github.io/projects/MatAnyone-E/)

看法：产品体验帖最能带动情绪，METR 和两个开源项目则把今天的信息密度拉了回去。

## yetone @yetone

**Alma 的 UI 层已用 MyGo 重构成原生**：他专门感谢 @localhost_4173 的 MyGo，这条很快拿到近 300 个赞。评论区有人嫌安装包还是两三百 MB，他解释只是 UI 层换了，server 层仍是 JavaScript；后来又按反馈把 dmg 改成 Alma 旁边带 Applications 快捷方式的干净布局，0.4.505 正在构建。[原帖](https://x.com/yetone/status/2119334800066826625)

**magpie 公网访问和额度不够用**：有人觉得 HTTP 公网访问像裸奔，他给出做法：`magpie serve` 或 `magpie daemon install` 加上 `--tls-cert` 和 `--tls-key`，证书续期后自动生效；也可以在前面用 Tailscale Serve、Caddy 或 nginx 做 HTTPS。另有人想在 5 小时额度到达某个百分比时自动压缩，他说压缩本身要把整段上下文再发一遍，往往省不下额度，magpie 的做法是把多个账号放进一个路由组，一个用完自动换下一个。[原帖](https://x.com/yetone/status/2119376688857715100) · [原帖](https://x.com/yetone/status/2119353062951428178)
