## 今日主线

### 宝玉 @dotey

**Dario 回应安全路线质疑**：Encode 的 Nathan Calvin 发长文，质问 Anthropic 是安全组织还是竞赛选手，导火索是一份法案草案，政府要叫停模型得先证明可能造成 50 人以上伤亡或 10 亿美元损失。Dario 认了三处沟通失误，分别是一封国会信、那句「没法在第二名的位置上做安全」和这份草案，但「向上竞争」的路线不改

**How Codex Happened**：宝玉整理了 Every 长文里 Codex Desktop 那段，Tibo 和 Andrew Ambrosino 没走 fork VS Code 的路，做成聊天软件式的原生应用，还故意不放代码编辑器。一开始内部没人主力用，直到 GPT-5.2-Codex 出来才翻盘 https://x.com/dotey/status/2111487902869832182

**先上设计系统，别让 AI 只会 shadcn**：前沿模型默认就是那一套，做出来千篇一律。Claude Design 的思路是先导入或做一套 Design System，PPT、网页、视频都用它，宝玉自己直接用 Adobe 的设计系统 https://x.com/dotey/status/2112598829870575718

**GPUI 换回 Electron 的坑**：baocut 上一版用 GPUI，Rust 编译吃满资源，没有热更新，改一点 UI 要等几分钟，agent 验证还得靠 computer use。换回 Electron 后，复杂渲染编成 wasm，转录和 TTS 留成 Rust worker 进程 https://x.com/dotey/status/2112552063640997984

看法：GPUI 那条最实用，选技术栈时「agent 能不能快速看到结果」已经是硬指标



### WquGuru @wquguru

**REA 逆向 Claude Code 风控**：用 REA 分析了 Mac CLI、Mac App 和安卓端。安卓端检测最强，靠 Sift 查 SIM 卡国家，硬件 ID 重装也不变，Mac 端靠 Sentry 和 Datadog 采遥测，设备 ID 是随机的 https://x.com/wquguru/status/2113181135522214168

**八大天坑**：国区 SIM 卡、清数据换号、CLI 多账号共用 ~/.claude.json、只给主域名配住宅 IP 而遥测走机场、被限后换 IP 反复请求、一个住宅 IP 挂多号，这些都是明显信号

**OpenAI 硬件站 32 个项目**：基本是 Codex 做的，至少 14 个用 ESP32，8 个用树莓派。挑了 7 个开源的，有 Kindle 用量屏、ChatGPT Dot 状态屏、理光 GR 热靴遥控、六色墨水屏相框等 https://x.com/wquguru/status/2110607087697088822

看法：风控那两条信息密度很高，不用手机端加走朋友方案是目前最稳的



### 郭宇 @turingou

**Pi 加 DeepSeek 做垂直代理**：郭宇说 Pi 配 DeepSeek 基本能做任何垂直个人代理，剩下的是找价值。很大一部分价值在人的刚需，而且是大模型会拒答的那块，无审查的 DeepSeek 有优势

**Personal agent 的长期信任**：Grok Bot 帮他找的美容诊所和理发店都很好。他觉得下一代用户会更依赖 bot 给的信息，长期信任会形成正反馈 https://x.com/turingou/status/2110212078674042925

**Codex 自动按相关性建项目**：不用先选文件夹。他现在更想在 Dots 或 Grok Bot 这种主线程里让 agent 操作电脑整理文件、项目和会话 https://x.com/turingou/status/2110212078674042925

**私人药物实验室**：AI 研发药物越来越快，他猜以后会有针对个人的药物实验室，甚至药物的 DNA 锁

看法：「主线程管一切」和不再手动建文件夹，是很典型的 AI 原生工作习惯



### 张立行 @bylixing

**中小团队 Agent 落地框架**：在传统跨境电商团队推 Agent 的一手复盘，开头一句「个体提效 10 倍容易，组织提效 20% 困难」，难点是权限、基建和分工。AI Native 组织要满足三点：信息对 Agent 可读、Agent 参与决策、链路闭环可验证 https://x.com/bylixing/status/2110752982103175238

**协作是次优解**：最高效的是完整业务上下文在一个人脑子里，由他带着 Agent 干，每多加一个人都该想想能不能用 Agent 替代。落地方式是人员三层架构，不追 token 用量只求单点替换，一台服务器加开源工具撑起全队基建

看法：这篇是今天最值得完整读的长文，很少有人写旧组织怎么落地
