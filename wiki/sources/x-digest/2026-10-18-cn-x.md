### 思维怪怪 @0xLogicrw

**Claude Code 九成代码由 Claude 写**：转 Anthropic 披露，Claude Code 约 90% 代码已由 Claude 编写；6 到 9 月合并 PR 翻倍有余，需要撤销的比例反而降超 40%。为跟上 AI 写码速度，他们重构审查：提交前 Claude 先跑测试，再让独立子 Agent 参与。背景是「AI 写、人审」从口号变成工程流程。https://x.com/0xLogicrw/status/2111776928147681356

**Reason Network 让跨机 Agent 直接聊**：YC 孵化的 Reason Machines 开源 Reason Network，不同电脑上的 Claude Code、Codex、Cursor、OpenCode 可互发消息。每个会话有地址，能看到开发者、仓库、分支和当前任务，比如前端 Codex 问后端 Claude 接口有没有改。默认直接投递，也可改成 hold 先审再放行。https://x.com/0xLogicrw/status/2111692290565771474

**Perplexity REA 逆向复刻**：Perplexity 把开源逆向工具 REA 接进 Computer，没有源码也能分析软件行为再写出近似版，并展示了 5 款可在线玩的复刻。10 月底前相关任务有免费额度。逆向门槛被压到「跟 AI 说一句想复刻什么」。https://x.com/0xLogicrw/status/2111647451384037421

**OpenCode 安全事件**：OpenCode 披露 Distillation 相关入侵，波及 1.4% Console 用户，受影响者曾在云端关联第三方模型；旧系统被未授权访问，工作区里的 OpenAI、Anthropic 等 key 可能泄露。官方按邮箱通知，没收到信基本没事。https://x.com/0xLogicrw/status/2111655129526960493

看法：今晚信息密度最高的一节，安全和多 Agent 协作两条线都值得跟进。
